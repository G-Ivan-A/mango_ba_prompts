# Журнал RUN-0082

## Цель

Принять решение BL-156б по замеру, устойчивому к разбросу: опубликовать
ли тип гейта в `prompts/` (A) и черновик Ш-В «по тесту» (D, П-Ш-В).
Владелец разрешил бюджет (issue #446, пункт 2: «разрешаю бюджет»).
Правило решения записано до запуска:
[`preregistration.md`](../../../../experiments/issue_446/run0082/preregistration.md),
коммит `24e97e83`.

## Процедура

1. **Подготовка** — `python3 experiments/issue_446/run0082/run.py prepare /tmp/run82`.
   Для каждого повтора r1…r3 вызывается `prepare.py` RUN-0081: кейсы и
   карта T-NN сверяются с RUN-0079. Промпты заменяются измеренными версиями
   RUN-0081 (сверка SHA-256).
2. **Исполнение** — 12 изолированных подагентов `claude-opus-5-5`: в каждом
   повторе A×2 пакета и D×2 пакета. Инструкция — та же, что в RUN-0081
   ([`executor-instruction.md`](executor-instruction.md)).
3. **Слепая подготовка судьи** — `run.py judge`: `judge_prepare.py`
   RUN-0081 с seed 8082, 8083, 8084. Остатков маскировки — 0 во всех трёх
   повторах.
4. **Оценка** — 6 изолированных подагентов-судей `claude-opus-5-5`, по два
   пакета на повтор ([`judge-instruction.md`](judge-instruction.md)).
   Каждый судья видел только рубрику, правила реестра и свой пакет.
5. **Пересчёт** — `run.py score` (вывод —
   `experiments/issue_446/run0082/score.log`): метрики каждого повтора,
   медианы, проверки DEC-427-11, частота провалов.
6. **Фиксация** — `run.py fixate`.
