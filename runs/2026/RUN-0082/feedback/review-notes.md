снял человеческий гейт на текущую итерацию (issue #446, пункт 3: «нет в
текущей итерации на человеческий гейт, ревью»). Итог прогона — оценка
модели, а не приёмка.

провала по трём повторам (пред-регистрация, п. 6) и чтение автором всех

| Кейс | Провалов A / D | Вывод автора |

1. **Р-03.** Принять схему «одновременный контроль, N = 3, медиана, не хуже
   контроля» вместо сравнения с историческим RUN-0079 (отчёт, раздел
   «Рекомендации», п. 1).

   - BL-156в «правка без добавлений» плюс тип гейта (BL-156б) в одном
     замере, плечи A0 / A1 / A2, N = 3 — около 1 млн токенов;
   - только BL-156в (A0 / A2) — около 0,7 млн.

- входы синтетические;
- нет одновременного контроля A0;
- N = 3, доверительные интервалы не оценивались;
- человек оценки не подтверждал.
