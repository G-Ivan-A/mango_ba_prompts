## Решаемая проблема

В RUN-0094 v1.0 строка исходника = строка отчёта. Строка исходника часто содержит
комплексное требование (вводная фраза и перечень из 2–12 пунктов, несколько предложений с
самостоятельными требованиями, несколько строк Таблицы 1 SLA), поэтому одна оценка
(в основном `Частично`) скрывает, какие именно атомарные требования исполнимы, и не даёт БА
комментировать их по отдельности. В отчёте нет собственной нумерации строк, на которую можно
ссылаться.

## Story

**Как есть:** БА получает 43 строки, 17 из них `Частично` с перечнем «подтверждено / не
подтверждено» внутри обоснования; для ответа Заказчику по конкретному пункту перечня БА
вручную разбирает обоснование.

**Как должно быть:** БА получает отчёт, где каждая атомарная часть требования — отдельная
строка со сквозным «№ пп», исходным «№» и собственной оценкой, обоснованием и цитатами;
заголовки и обобщающие фразы видны отдельными строками. Пользователь принимает результат
мержем PR или возвращает комментарием в PR.

## Правила разбиения (решения Исполнителя)

- Единица разбиения — пункт перечня с маркером `-`; предложение или абзац сплошного текста с
  самостоятельным требованием; строка ячейки Таблицы 1 листа SLA. Определения и пояснения
  (формула расчёта, состав отчёта, скобочное «подтверждается …») остаются в строке
  требования, к которому относятся, если сами не являются требованием.
- Числовой порог внутри пункта перечня не выделяется в отдельную строку: это атомарная часть
  оценки по правилу issue #484 (`Частично`, если порог не подтверждён).
- Вводная фраза, требующая функцию или продукт («Система должна предоставить функционал …:»),
  оценивается как требование верхнего уровня по собственной формулировке. Вводная фраза,
  которая задаёт только условие показа, этап работ или перечень («Система обладает
  функционалом, который на 100% подтверждается на презентации:», «На этапе внедрения …»,
  «Реализация функционала админ. панели:», подписи приоритетов Таблицы 1), — заголовок
  комплексного требования: пустая оценка, ссылка на диапазон «№ пп» своих строк.
- Строка исходника, у которой заполнена только колонка сроков (продолжение объединённой
  ячейки «Тип Заявки» Таблицы 1), разбивается так же; её строки входят в диапазон заголовка
  из строки выше.
