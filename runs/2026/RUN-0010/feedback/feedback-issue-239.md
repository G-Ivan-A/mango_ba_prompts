# Feedback RUN-0010 (issue #239)

> Источник: issue [#239](https://github.com/G-Ivan-A/mango_ba_prompts/issues/239).
> Задача: создать актуальную версию ФТ BCREQ-1025 (email-маршрутизация по «Точке
> входа») по условиям изменений и правилам, процесс —
> [`governance/bcreq-fr-generation-contract.md`](../../../../governance/bcreq-fr-generation-contract.md).

## Условия изменений в ФТ

1. Добавить в соответствующий пункт раздела 4 явное указание текущего поведения
   (As-Is): при открытии E-mail-редактора в интерфейсе «КЦ → Мои обращения»
   Пользователь видит e-mail, который будет использован в качестве «Ящика
   отправителя». Адрес определяется настройками «КЦ → Все настройки → Исходящие
   обращения» и ЛК. Пользователь может нажать на шестерёнку справа от e-mail и
   перейти к выбору другого e-mail.
2. Явно указать в ФТ, что после доработки переключатель режима авто подстановки
   влияет на: подстановку e-mail «Точки входа» в окно редактора и далее
   использование этого адреса как «Ящика отправителя» при условии, что
   Пользователь его не изменил. Триггер — открытие редактора; действие —
   автоподстановка «Ящика отправителя» в соответствии с настройками. Пользователь
   в любом случае может изменить этот e-mail в соответствии с текущей
   функциональностью. Переключатель **не** выполняет принудительную неизменяемую
   подстановку «Ящика отправителя».

## Правила доработки

- Корректировать только требования, связанные с условиями изменения ФТ.
- Другие разделы или текст, не связанные с условиями изменений, не затрагивать.
- Изменения, внесённые в рамках условий изменения, размечать `[]`.
- Если выявлена необходимость дополнительной переработки ФТ по контракту,
  рекомендации (включая предложения по результирующим формулировкам) вывести
  после основного тела документа.
