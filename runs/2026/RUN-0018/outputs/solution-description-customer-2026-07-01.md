## 1. Какую задачу решаем

- Клиенты звонят на номера ВАТС трёх продуктовых направлений (мини-брус, ПРЕКАТ,
  ПРЕФАБ). Звонок переадресуется на телефон партнёра, партнёр ведёт разговор.
- «Речевая аналитика» уже оценивает эти разговоры по чек-листам (скриптам
  продаж). Но вы не можете посмотреть оценку **отдельно по каждому направлению**.
- Фильтр по сотрудникам не помогает: сотрудники партнёров в ВАТС не заведены.
  Единственный признак направления — это **номер ВАТС**, на который пришёл
  звонок.

Итог: нужен способ быстро отобрать в отчёте «Анализ по чек-листам» только те
разговоры, которые пришли на номера нужного направления.

## 2. Что мы предлагаем

Мы предлагаем **не создавать отдельные группы номеров**. Вместо этого мы
добавляем в отчёт «Анализ по чек-листам» новый фильтр — **по номерам ВАТС с
поиском по комментарию**.

Идея простая: направление номера вы уже можете записать **в комментарий к
номеру** в личном кабинете ВАТС (там это поле уже есть, и по нему уже работает
поиск). Фильтр же умеет искать не только по цифрам номера, но и по этому
комментарию — и выбрать сразу все найденные номера одной кнопкой.

### 2.1. Как вы настраиваете (один раз, в ЛК ВАТС)

- В личном кабинете ВАТС вы вписываете в комментарий к номеру наименование
  направления — например, «мини-брус». При необходимости — рядом с другими
  пометками, которые уже там есть.
- Всё. Отдельные наборы номеров создавать и поддерживать не нужно.

### 2.2. Как вы фильтруете (в отчёте «Анализ по чек-листам»)

1. Открываете чек-лист и в блоке фильтров выбираете новый фильтр — по номерам
   ВАТС.
2. В поле поиска вводите наименование направления, например «мини-брус».
3. Система ищет сразу по двум полям — по номеру телефона **и** по комментарию — и
   показывает все номера, где встретилось это слово.
4. Нажимаете мастер-выбор («выбрать все найденные») — отмечаются все номера из
   результата поиска.
5. Нажимаете «Выбрать» — фильтр запоминает выбор и применяется к отчёту.
6. Отчёт по чек-листу показывает оценку только по разговорам выбранных номеров —
   то есть по нужному направлению.

## 3. Сильные стороны этого решения

1. **Вы уже используете комментарии в ВАТС.** Не нужно отдельно создавать наборы
   номеров по направлениям и следить за их изменениями. Если добавился или ушёл
   партнёр — вы, как и сейчас, один раз правите комментарий к номеру, и это сразу
   применяется в фильтре. Не нужно помнить, что помимо комментария надо ещё
   поправить какую-то группу.

2. **Нечего рассинхронизировать.** В первом варианте «набор номеров» и
   «комментарий к номеру» — это два разных места, которые легко разъезжаются. Тут
   источник один — комментарий, поэтому данные всегда согласованы по определению.

3. **Гибкость поиска.** Поиск идёт по вхождению сразу по номеру и по комментарию.
   Можно искать не только по направлению, но и по любой пометке, которую вы
   ведёте в комментарии (город, партнёр, любой ваш тег). Один номер может
   попадать под разные поисковые запросы — его не нужно «жёстко» приписывать к
   одной группе.

4. **Меньше нового в продукте — быстрее и надёжнее.** Мы не вводим новую сущность
   «группа номеров» со своим созданием, изменением, удалением и правилами
   целостности (номер только в одной группе, что делать при удалении группы и
   т. п.). Поле «комментарий» и поиск по нему уже существуют — мы переиспользуем
   готовое. Меньше новых экранов и правил — меньше поводов для ошибок.

5. **Ничего не нужно чистить при изменениях.** Убрали партнёра — просто убрали
   пометку из комментария. Не остаётся «пустых» или устаревших групп, которые
   надо отдельно поддерживать.

6. **Знакомый механизм.** Поиск по комментарию к номеру в ЛК ВАТС вам уже
   знаком — мы приносим ту же логику прямо в фильтр отчёта.

## 4. Что честно хуже, чем в первом варианте

Мы понимаем, что за простоту настройки платим удобством самой фильтрации:

- **Путь фильтрации на один шаг длиннее.** В первом варианте (готовые
  группы-направления) вы бы каждый раз просто выбирали одно из трёх готовых
  направлений одним кликом. Здесь каждый раз нужно **ввести слово направления →
  нажать мастер-выбор → нажать «Выбрать»**, то есть по чек-листу на один клик
  (и один ввод) больше, и так при каждом построении отчёта.
- **Нет заранее заданного «имени направления».** Направление существует не как
  отдельный объект с названием, а как результат поиска по комментарию. Поэтому
  корректность зависит от того, что во всех нужных номерах в комментарии
  действительно есть одинаковое слово направления.

Это осознанный компромисс: **простота и отсутствие поддержки на настройке** в
обмен на **один дополнительный клик при каждой фильтрации**. По нашему мнению, для
вашего сценария это выгодный размен, потому что настройку вы ведёте постоянно (при
каждом изменении по партнёрам), а фильтрацию делаете реже.
