```text
**Версия документа: v1.3 (Финальная)**

**1. Термины и определения**
Система - совокупность интегрированных продуктов Mango Office.
КЦ - Контакт-центр Mango Office. 
МД - Манго Диалоги Mango Office. Продукт Mango Office для организации многоканальной коммуникации с клиентами через мессенджеры, SMS, email и другие каналы связи.
АК - Адресная книга, справочник контактов в Системе Mango Office.
Контакт - физическое лицо, с которым сотрудник Заказчика осуществляет коммуникацию через каналы коммуникации (телефон, SMS, email и др.) с использованием КЦ или других сервисов Mango Office. Контакт может быть как зарегистрированным в Адресной книге КЦ, так и не сохраненным в ней.
Карточка контакта - интерфейсный элемент (окно) в КЦ, содержащий всю информацию о Контакте (физическом или юридическом лице): ФИО, организация, способы связи (телефоны, email, аккаунты мессенджеров и соцсетей) и другие данные, а также связанные с ним данные: история обращений, задачи, сделки и документы. 
Пользователь - сотрудник Заказчика, наделенный определенной бизнес-ролью, который имеет (или имел, либо потенциально получит) доступ к Системе для выполнения операций в соответствии с правами, назначенными через Личный кабинет Mango Office.
Идентификатор мессенджера - уникальный текстовый или цифровой идентификатор аккаунта клиента в мессенджере (**Max**, Telegram) в Системе.
Канал коммуникации - канал, предварительно настроенный в модуле "Текстовые коммуникации → Каналы". 

**2. Проблема, цель, задачи**
2.1. Проблема
В разделе "КЦ → Клиенты → Контакты" механизм глобального поиска не индексирует идентификаторы мессенджеров (Max, Telegram). Пользователи не могут оперативно находить Контакты по известному идентификатору мессенджера.

2.2. Цель
Обеспечить возможность поиска Контактов в Адресной книге КЦ по идентификаторам мессенджеров (Max, Telegram) через механизм глобального поиска с сохранением текущей логики отображения данных в общем списке.

2.3. Задачи
2.3.1. Расширение области индексации глобального поиска в разделе "КЦ → Клиенты → Контакты".
2.3.2. Обеспечение поиска по вхождению в значения идентификаторов мессенджеров (Max, Telegram) при вводе символов в поле глобального поиска.
2.3.3. Унификация логики поиска с учётом ролевых ограничений доступа к персональным Контактам.
2.3.4. Обеспечение корректной работы поиска по идентификаторам мессенджеров при включенной услуге «Скрытие номера клиента».

**3. Описание разрабатываемого решения**
3.1. - 3.4. #в работе, будет зафиксировано в процессе оценки 
3.5. Обновление разделов документации.
3.6. **Стабилизация**, тестирование и отладка.
3.7. **Доставка** на продуктивную среду.

**4. Функциональные требования и сценарии использования**
4.1. Система должна предоставлять Пользователю возможность применения глобального поиска Контактов в разделе "КЦ → Клиенты → Контакты" по Идентификаторам мессенджеров.

4.1.1. Поиск должен осуществляться по значениям полей, настроенных в МД Каналов коммуникации.
4.1.2. Поиск должен поддерживаться для Каналов коммуникации: **Max**, Telegram.
4.1.3. Если у Контакта указано несколько Идентификаторов мессенджера одного Канала коммуникации, поиск считается успешным при совпадении запроса с любым из них (выводится строка с успешным вхождением).
4.1.4. Поиск должен выполняться по частичному вхождению цепочки символов строки запроса в значение Идентификатора мессенджера без учёта регистра символов (регистронезависимо). 
4.1.5. Специальные символы (если они присутствуют в идентификаторе) должны учитываться как часть строки при поиске.
4.1.6. Система должна запускать поиск при вводе не менее одного символа в поле глобального поиска.
4.1.7. При очистке поля глобального поиска (ввод 0 символов) Система сбрасывает примененные фильтры и отображает полный список Контактов.

4.2. Система должна обеспечивать отображение результатов поиска в табличных данных в разделе "КЦ → Клиенты → Контакты" в соответствии с текущей функциональностью Системы.

4.2.1. Отображение данных реализуется построчно с учетом сохраненных Пользовательских настроек отображения колонок и сортировки данных по колонкам. 

4.3. Система должна учитывать права доступа Пользователя к Адресной книге при формировании результатов глобального поиска по Идентификаторам мессенджеров.

4.3.1. Если доступ к Контакту ограничен ролевой моделью Пользователя, такой Контакт не включается в результаты поиска.
4.3.2. Идентификатор мессенджера недоступного Контакта не отображается ни в списке, ни во всплывающих подсказках (см. п. 4.4).

4.4. Система должна обеспечивать визуальную идентификацию Канала коммуникации, указанного в Карточке контакта, в общем списке раздела "КЦ → Клиенты → Контакты" без открытия Карточки контакта.

4.4.1. При наведении курсора мыши на пиктограмму Канала коммуникации в строке Контакта Система должна отображать всплывающую подсказку.
4.4.2. Всплывающая подсказка должна содержать текстовое значение Идентификатора мессенджера (например: **Max**, Telegram), сохраненного в Карточке контакта.
4.4.3. Если у Контакта сохранено несколько Идентификаторов мессенджера одного Канала коммуникации, во всплывающей подсказке отображаются все сохраненные идентификаторы данного Канала.

**5. Нефункциональные требования**
-

**6. Особенности реализации**
6.1. Ограничения
6.1.1. Функциональные возможности разрабатываемого решения ограничены функциональными возможностями продуктов Mango Office.
6.1.2. Разработка не предполагает процессы, связанные с иными настройками работы Продуктов Mango Office.
6.1.3. Дизайн экранных форм может быть доработан по усмотрению Исполнителя.
6.1.4. Система не проверяет корректность введённых в Адресную книгу Идентификаторов мессенджеров (в том числе наличие пробелов, специальных символов и регистра). Ответственность за достоверность и формат данных, внесённых в Карточку Контакта, лежит на Пользователе, вводящем эти данные.
**6.1.5. При включенной услуге «Скрытие номера клиента» обработка и отображение Идентификаторов мессенджеров осуществляются в соответствии с текущей функциональностью Системы. [Сформировано по черновику — требует уточнения автора]**

6.2. Используемые технологии
6.2.1. Используются языки программирования, библиотеки, фреймворки и базы данных на усмотрение разработчиков Mango Office.

***```
