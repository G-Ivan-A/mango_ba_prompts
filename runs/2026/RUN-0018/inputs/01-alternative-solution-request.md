## Сценарий настройки

Пользователь в ЛК ВАТС добавляет в комментарий к номеру наименование направления
(можно дополнительно к другим наименованиям). Всё просто — отдельные наборы
номеров не заводятся.

## Сценарий фильтрации в РА «Анализ по чек-листам»

1. Пользователь выбирает новый фильтр в блоке фильтров — по номерам ВАТС.
2. Пользователь в поле поиска вводит наименование направления.
3. Система осуществляет гибридный поиск по полям «номер телефона» и «комментарий»
   (логика ИЛИ).
4. Система по вхождению формирует список номеров, соответствующих вхождению.
5. Пользователь применяет мастер-выбор.
6. Система фиксирует выбор группы номеров, соответствующих результирующему списку
   (по вхождению).
7. Пользователь инициирует «Выбрать», фильтр запоминает состояние.
8. Система применяет фильтр при инициации пользователем «Выбрать» (сверить с
   руководством Речевой аналитики —
   `kb/mango-product-docs/processed/speech-analytics/rukovodstvo-polzovatelya-rechevaya-analitika`).

`.../100-nomera-podklyuchennye-k-ats.md` (PDF §4.4.1).
