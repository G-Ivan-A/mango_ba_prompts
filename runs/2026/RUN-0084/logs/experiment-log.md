# Журнал RUN-0084

## Цель

Принять решение BL-156б (тип гейта) и BL-156в («правка без добавлений»)
по замеру с одновременным контролем (Р-03). Владелец принял Р-03 и бюджет
варианта 1 (issue #448, ответы 3 и 4). Правило решения записано до
запуска:
[`preregistration.md`](../../../../experiments/issue_448/run0084/preregistration.md),
коммит `6f82731e`.

## Процедура

1. **Тексты** — `python3 experiments/issue_448/run0084/run.py texts /tmp/run84`:
   A0 из `git show 4a4df7bc:…`, A1 — `apply_typing()`, A2 — `apply_rule()`.
   SHA-256 сверены с пред-регистрацией.
2. **Подготовка** — `run.py prepare /tmp/run84`: для каждого повтора r1…r3
   кейсы и карта T-NN сверяются с RUN-0079 (62 кейса, seed 79).
3. **Исполнение** — 18 изолированных подагентов `claude-opus-5-5`: в каждом
   повторе 3 плеча × 2 пакета, параллельно. Инструкция — та же, что в
   RUN-0082 ([`executor-instruction.md`](executor-instruction.md)).
4. **Слепая подготовка судьи** — `run.py judge`: три выхода на кейс под
   метками X/Y/Z, порядок по seed 8484, 8485, 8486. Остатков маскировки —
   0 во всех трёх повторах, 62 кейса на плечо (вывод —
   [`judge-prepare.log`](../../../../experiments/issue_448/run0084/judge-prepare.log)).
5. **Оценка** — 6 изолированных подагентов-судей, по два пакета на повтор
   ([`judge-instruction.md`](judge-instruction.md)). Судьи повтора стартовали
   только после записи всех шести выходов исполнителей повтора. Каждый
   судья видел только рубрику, правила реестра и свой пакет.
6. **Пересчёт** — `run.py score` (вывод —
   [`score.log`](../../../../experiments/issue_448/run0084/score.log)):
   метрики повторов, медианы, проверки Р-03, парные разности, частота
   провалов. Различия по кейсам с примечаниями судей —
   [`diff_cases.py`](../../../../experiments/issue_448/run0084/diff_cases.py),
   вывод — [`diff-cases.log`](../../../../experiments/issue_448/run0084/diff-cases.log).
7. **Фиксация** — `run.py fixate`.
