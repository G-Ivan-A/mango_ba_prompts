## Что такое уровень L4

L4 наследует структуру L2 ([RUN-0058](../../RUN-0058/outputs/L2-gap-matrix.md))
и расширяет каждый раздел ФТ-хх до трёх обязательных подразделов:

1. **БА** — вывод бизнес-анализа с дословной цитатой каждого подпункта §4.х.х,
   отдельным вердиктом на уровне подпункта и вердиктом на уровне ФТ; каждый
   параметр или группа параметров помечены сноской.
2. **СА** — модель системного анализа: JSON запроса/ответа к API hh.ru и
   диаграмма деятельности (**не** диаграмма последовательности), назначение
   которой — подтвердить или опровергнуть вывод «БА».
3. **Источники** — таблица сносок с прямыми ссылками на конкретные операции
   в документации hh.ru, чтобы рецензент открывал метод сразу, без поиска.

## Главный вывод

Из десяти ФТ полностью закрываются четыре, шесть — частично. Относительно L2
изменился один вердикт: **ФТ-05 понижен с «Да» до «Частично»** — обнаружен
новый разрыв GAP-R11 (`filter_has_text_message` фильтрует «чаты с активными
переписками», а не «чаты с текстовым сообщением», а тип `SIMPLE` покрывает и
сообщения без текста). Остальные выводы L2 подтверждены; исправлено шесть
неточностей в ссылках на схемы и обоснованиях — раздел 15 отчёта.
