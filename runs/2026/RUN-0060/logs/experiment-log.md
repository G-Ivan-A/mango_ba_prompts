## Решения по формату (формат L4 определялся на лету)

| Решение | Почему так |
| --- | --- |
| Диаграмма деятельности с дорожками вместо диаграммы последовательности | Прямое требование постановки: нужна модель взаимодействия систем и акторов **без детализации обмена**. Дорожки дают зоны ответственности, ветвления — условия, которые проверяет «БА» |
| Оценка **каждого** подпункта §4.х.х отдельной строкой таблицы | DoD требует оценки «и на уровне ФТ-хх, и на уровне детализации». Табличная форма делает расхождение вердиктов подпункта и ФТ видимым |
| Сноски нумеруются **внутри раздела** ФТ, а не сквозно | Раздел читается автономно: рецензент видит `^3` и находит его в таблице источников того же раздела, не листая документ |
| Ссылки — прямые якоря на операцию, а не на страницу раздела | Требование постановки: «перейдя по ссылке… быстро найти метод». Якорь открывает метод сразу |
| Индекс источников — отдельный артефакт, генерируемый скриптом | Ссылок больше пятидесяти; ручное составление не воспроизводимо и не проверяемо |
| Каждый подраздел «СА» заканчивается явным «Вывод СА» | Назначение модели по постановке — подтвердить или опровергнуть «БА»; вывод должен быть написан, а не подразумеваться |

## Наблюдения по ходу анализа

1. **Спецификация меняется между прогонами.** Между RUN-0058 и RUN-0060
   контрольная сумма изменилась. Для gap-анализа, выводы которого живут
   месяцами, фиксация версии источника обязательна — иначе отчёт нечем
   проверить.
2. **Самая опасная ошибка L2 — не отсутствующий факт, а правдоподобная
   формулировка.** `filter_has_text_message` был описан «по имени параметра»,
   и описание выглядело убедительно, пока не сверено с текстом документации
   (GAP-R11). Отсюда практическое правило: параметр, чьё имя кажется
   самоочевидным, требует цитаты не меньше остальных.
3. **Сноски меняют характер отчёта.** Требование поставить ссылку на каждый
   параметр заставило перечитать схемы, а не полагаться на конспект
   предыдущего прогона; пять из шести исправлений найдены именно при
   расстановке сносок.
4. **Диаграмма деятельности ловит то, что не ловит таблица.** Модель раздела
   12.4 сделала явным узел «ошибок нет, но потока нет» — GAP-R1 не
   обнаруживается тестом «сообщение дошло». Из этого выведено требование
   к контролю, которого нет ни в ФТ, ни в L2.
