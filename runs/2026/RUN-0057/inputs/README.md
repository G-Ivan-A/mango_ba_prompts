Во всех четырёх приложениях третья колонка содержит **ответы участника закупки** (`Да`, `Нет`, `На уточнении`, `Да, но необходимо дообучение`, `Да, частично`, `Да, через фоновые события` и т. д.). Это не пустая форма для заполнения, а уже поданный ответ.

Постановка [#319](https://github.com/G-Ivan-A/mango_ba_prompts/issues/319) прямо запрещает менять формулировки требований Заказчика и структуру таблицы, поэтому:

- колонки `№`, `Требование`, `Комментарий участника` перенесены в [`../outputs/L2-feasibility-matrix.md`](../outputs/L2-feasibility-matrix.md) **дословно**, включая опечатки и форматирование исходника;
- оценка исполнимости добавлена **новыми колонками справа**, существующие не редактируются;
- расхождения между «Комментарием участника» и тем, что подтверждается документацией, вынесены отдельно и помечены маркером недостатка данных, а не исправлением ответа участника.
