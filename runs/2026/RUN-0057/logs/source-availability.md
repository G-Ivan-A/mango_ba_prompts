### Уточнение от 2026-08-26 (issue #325)

Вывод «техническая документация не найдена» **опровергнут**: у платформы есть открытая база знаний
на Wiki.js — <https://wiki.twin24.ai/ru/home>, 452 страницы (перечень зафиксирован в
`experiments/issue_325/twin-wiki-pages.tsv`, выгрузка — `experiments/issue_325/fetch_wiki.py`).
Почему источник не был найден при RUN-0057: домен `docs.twin24.ai` отдаёт несовпадение имени в
сертификате TLS, а GraphQL-метод `pages.single` закрыт (`PageViewForbidden 6013`) — читаемым остаётся
только отрендеренный HTML страниц, поэтому обычный поиск по документации результата не дал.

| Проверка | Результат (2026-08-26) |
|---|---|
| Техническая документация платформы | **Найдена.** Описаны блоки сценария, перебивания (стоп-слова), гибридный синтез, NLU-агенты и сущности, функции языка BPL, отчёты, ограничения исходящих вызовов по ФЗ-230 |
| Интеграция с Mango Office | **Косвенно подтверждена.** В перечне страниц присутствует `integration/mango-ats-integration` — «Создание сотрудника для подключения с регистрацией АТС от Манго»; сама страница отдаёт 403, поэтому как доказательство по существу не использовалась |
| Заявление о точности ~95 % | Без изменений: в публичной вики метрика отсутствует, заявление на маркетинговом сайте методики не приводит |

Этот источник использован как SSOT колонки «Оценка по публичной док. TWIN» в
`outputs/L0-customer-form-with-assessment.md`. Ранее выставленные в `L2-feasibility-matrix.md`
уровни покрытия и метрика `coverage_l2_twin: 0` **намеренно не пересматриваются**: задача #325
ограничена файлом L0, а пересмотр каскада уровней затронул бы вердикты в остальных артефактах.
Пересчёт уровня 2 по матрице — отдельная задача.
