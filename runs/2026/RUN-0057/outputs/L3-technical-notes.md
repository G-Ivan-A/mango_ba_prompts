## 3. Проектные ограничения, влияющие на архитектуру решения

| № | Ограничение | Источник | Следствие для проектирования |
|---|---|---|---|
| P1 | Не более 100 блоков на скрипт | [ROBOTFIL, §5, с.46-49] | Дробление на связанные скрипты, отдельная схема передачи контекста |
| P2 | Настройки голоса и распознавания — на уровне скрипта | [ROBOTFIL, §3.5, с.28-32] | Этапы с особыми таймингами (сбор номера, паспортных данных) выносятся в отдельные скрипты |
| P3 | Текст одной реплики синтеза — до 500 символов | [ROBOTFIL, §5.1, с.49-59] | Длинные реплики разбиваются на цепочку блоков |
| P4 | Фоновые события: только «По ключевым словам» и «По завершению звонка», срабатывают один раз, не более 10 связок | [ROBOTFIL, §5.17, с.122-125] | Нельзя строить на них постоянно активную обработку возражений |
| P5 | Не более 40 категорий в Справочнике NLU | [ROBOTFIL, §11.1, с.178-180] | Иерархия справочников по этапам диалога вместо единого плоского классификатора |
| P6 | Блок «Перезвонить абоненту» доступен только для типа «Исходящий обзвон» | [ROBOTFIL, §5.11, с.86-88] | Персонифицированный перезвон недоступен во входящих сценариях |
| P7 | Речевая аналитика работает постфактум и требует включённой Записи разговоров; одноканальные записи не расшифровываются | [SA, §1, с.4-7] | Уровень 3 не может закрывать требования реального времени |
| P8 | Заявки на улучшение качества распознавания доступны только для технологии 3iTech | [SA, §6.6, с.54-57] | Выбор технологии распознавания влияет на возможность дообучения словаря |
| P9 | ИИ-функции лимитированы по частоте (подбор синонимов — 8 запросов в час, YandexGPT — 30 запросов в час) | [SA, §6.2.1, с.44-46]; [ROBOTFIL, §10.1, с.175-176] | Непригодны для онлайн-обработки потока звонков |

## 4. Что делать с расхождениями по ответам участника

Строки, где оценка строже ответа участника (перечень в конце `L2-feasibility-matrix.md`), до отправки заказчику должны быть либо подтверждены письменно вендором (вопросы Q6, Q8, Q9, Q12, Q13, Q14), либо переформулированы в ответе. Публикация ответа «Да» на требование, противоречащее документированному лимиту (например, п. 14.1 против лимита в 40 категорий), создаёт риск невыполнимого обязательства в договоре.
