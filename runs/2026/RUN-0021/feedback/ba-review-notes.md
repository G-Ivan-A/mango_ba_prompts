# Обратная связь БА по прогону 59295

## Оценка человека внутри сессии

**Явной обратной связи в диалоге нет.** Это главное отличие прогона от
[`RUN-0020`](../../RUN-0020/feedback/ba-review-notes.md), где оценки человека
идут почти на каждой реплике.

| Реплика | Что сделал человек | Можно ли трактовать как оценку |
| --- | --- | --- |
| [2] | Подал глоссарий и исходные ФТ | нет — выполнение запроса модели из [1] |
| [4] | Перешёл к новому пункту 6.1.8, не ответив ни на один из 4 вопросов согласования из [3] | косвенно: отчёт по аудиту не отклонён, но и не принят |
| — | Ответа на 3 вопроса из [5] нет: сессия оборвана | результат не оценён |

Ни принятия, ни отклонения, ни жалоб. Поэтому вердикт прогона выставлен **по
БА-разбору транскрипта**, а не по реакции человека:
`works-with-edits` — результат применим после правок, галлюцинаций,
блокирующих работу, нет.

**Следствие для метрики.** Шкала «принято человеком», применённая в RUN-0020
(`success_rate` = доля принятых эпизодов), здесь неприменима. Использована
другая база: доля эпизодов без выявленных галлюцинаций и недоказанных
утверждений — 1 из 3. База явно указана в `metadata.yaml`
(`success_rate_basis`), сравнение с RUN-0020 «в лоб» по этому числу
**некорректно**.

## Решения по итогам фиксации

1. Прогон зафиксирован как `run_type: statistics` — цель issue #278
   «зафиксировать прогон … для сбора статистики и анализа БА». Артефакты диалога
   **не переносятся** в `prompts/`, `kb/`, `patterns/`, `site/data/`: границы
   прогона это запрещают.
2. Наблюдение для библиотеки промптов: все три галлюцинации — **ссылки на
   непроверенный источник**. Кандидат на отдельную задачу: блок правил
   доказательности для `fr-validation-*` (цитата при ссылке на пункт; запрет
   подставлять значения и тексты, отсутствующие во входе; запрет цитировать
   документ, не поданный в контекст). Правка промптов — **только отдельной
   задачей от Пользователя**.
3. Наблюдение для статистики применения библиотеки: в реальном прогоне
   2026-05-25 использован промпт со статусом «устаревший»
   (`fr-validation-legacy` v1.0), а не `fr-validation-stepwise`. Прогон —
   свидетельство именно для v1.0.
4. Наблюдение о процессе: дисциплина «предлагать, а не править» удержана в 3 из
   3 эпизодов — на этой длине сессии режим согласования сбоев не даёт.
   Сопоставление с RUN-0020 (78 реплик, доминирующий отказ — самовольная
   перегенерация согласованного текста) даёт гипотезу: **отказ связан с длиной
   сессии, а не с промптом**. Гипотеза требует прогонов сопоставимой длины и
   в этой записи не проверяется.
