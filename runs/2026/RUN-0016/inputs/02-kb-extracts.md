## Очередь текстовых обращений «Текст» в КЦ (As-Is)

Источник: `kb/mango-product-docs/processed/mango-cc-manual/sections/09-tekst.md`
(PDF §2.3.2, с.29-30).

  поступления; счётчик показывает количество непринятых обращений.
- Для обращения отображается канал поступления, наименование контакта (имя из

  (канал) обращений в эту очередь.

(PDF §10.1, с.296-306).

  данным из HeadHunter.

## Текстовые коммуникации через API (As-Is, Манго Диалоги)

Источник: `kb/mango-product-docs/processed/mdialogi-api/sections/03-podderzhivaemye-kanaly-kommunikacii.md`
(PDF §1.2, с.6-7),
`.../38-api-upravleniya-sessiyami.md`, `.../40-vzyat-sessiyu-v-rabotu.md`,
`.../41-perevod-sessii-na-drugogo-sotrudnika-ili.md`, `.../42-zakryt-sessiyu.md`,
`.../43-otpravit-soobschenie-operatora-k-klientu.md`, `.../44-zagruzka-istorii-chata.md`,
`.../53-novoe-soobschenie-v-chate.md` (вебхук нового сообщения).

- Каждому каналу определён тип (`type`) и идентификатор (`channel_id`); поддержаны
  виджет «Чат на сайте», «ВКонтакте», Telegram, e-mail и другие каналы.
- API управления сессиями: создать сессию, взять сессию в работу, перевести
  сессию на другого сотрудника, закрыть сессию, отправить сообщение оператора,
  загрузить историю чата.
- Real-time вебхуки: новое сообщение в чате, изменение состояния сессии
  (ожидание, взята в работу, закрыта), статусы доставки и прочтения.
- Вывод: приём, синхронизация и обработка текстовых обращений через каналы и
  вебхуки — текущая функциональность; HeadHunter добавляется как источник
  сообщений и сессий по той же модели.

## Внешний источник по стороне HeadHunter

Источник: API HeadHunter <https://api.hh.ru/openapi/redoc#tag/Chaty> (документ
вне базы знаний; помечается как внешний источник в трассируемости).

- Чат HeadHunter автоматически создаётся только для менеджера, ответственного за
  вакансию; чат отображается в списке чатов только у этого менеджера.
- При записи в чат от имени другого пользователя он добавляется как участник
  чата (несколько акторов в одном чате).
- Доступны: получение `chat_id` из отклика, получение сообщений чата, получение
  списка чатов авторизованного пользователя, вебхук `CHAT_MESSAGE_CREATED` на
  новое сообщение.
