## Два формата вывода — почему

Постановка (контракт 3) требует: если отраслевая практика скорее использует другую форму, выдать **два** файла. Формат Пользователя (шесть таблиц) — это матрица покрытия требований: он полон и трассируем, но не даёт лицу, принимающему тендерное решение, ответа на первой странице. Отраслевая практика BA для тендерной оценки — **feasibility brief**: вердикт, опции, допущения, риски, открытые вопросы, а матрица покрытия идёт приложением. Поэтому выпущены оба файла; матрица — источник истины, brief — производный документ и не содержит утверждений, которых нет в матрице.

## Граница анализа

Анализ отвечает **только** на вопрос «предоставляет ли публичное API ВАТС Mango Office методы и параметры, необходимые для запрошенной интеграции». Он **не является** оценкой трудозатрат на разработку интеграционного шлюза: шлюз — отдельная разработка на стороне Заказчика, и если она выполняется силами Mango Office, требуется отдельная оценка.
