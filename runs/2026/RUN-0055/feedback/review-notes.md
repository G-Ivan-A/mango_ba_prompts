# Ограничения чтения прогона RUN-0055

- **Шкала.** Прогон `execution`: успех читается по качеству артефакта и выполнению acceptance criteria постановки, а не по покрытию выборки. Смешивать с прогонами `statistics` при выводах о промптах нельзя.
- **Приёмка.** Приёмка Пользователем не выполнена, поэтому `status: works-with-edits`, а не `success`: результат получен полностью, но содержит 10 исправлений относительно артефакта первичного исполнителя, которые требуют подтверждения БА.
- **`success_rate` считает утверждения об API**, а не требования ТЗ. Основание — [`../logs/metrics.md`](../logs/metrics.md); иная база расчёта даст иное число.
- **Раздел «Не для заказчика»** в [`../outputs/feasibility-assessment.md`](../outputs/feasibility-assessment.md) — служебный. Перед отправкой документа Заказчику раздел удаляется; при передаче внутрь компании он остаётся.
- **Границы оценки.** Документ отвечает только на вопрос «покрывается ли требование стандартными методами публичного REST API». Он не является оценкой трудозатрат на разработку интеграционного шлюза, не оценивает стоимость услуг и не даёт юридического заключения по 152-ФЗ.
- **Источники.** Использована исключительно база знаний `kb/processed/vpbx-api/` версии 1.9 и официальные адреса Mango Office из неё. Если в БЗ появится более новая версия документа, ссылки «раздел + страница» подлежат перепроверке: нумерация страниц версионно-зависима.
- **Пробел источника.** В §3.2.1 базы знаний помечен пробел извлечения на с.35 (страница без текстового слоя). Выводы на неё не опираются, но при спорах по диаграмме инициирования вызова страницу следует сверить в исходном PDF вручную.
- **Процесс не стандартизован.** Маршрут оценки выполнимости ТЗ в репозитории не зафиксирован; он смоделирован в рамках этого прогона ([`../logs/experiment-log.md`](../logs/experiment-log.md)). Прогон намеренно не пишет в `standards/` — закрепление стандарта требует отдельного решения Пользователя.
- **Содержимое исходного диалога** в записи отсутствует: восстановить его можно только из вложений issue #313 по провенансу в [`../inputs/README.md`](../inputs/README.md).
