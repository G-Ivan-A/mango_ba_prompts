# Эксперимент A/B: формирование/проверка требования с применением стандартов и без (ФТ-6)

Версия: 0.1 · Дата: 2026-06-16

## Назначение

Доказать (ФТ-6), что применение отраслевых стандартов (ISO/IEC/IEEE 29148:2018 —
характеристики качества требований; ГОСТ 34.602-2020 — структура ТЗ) повышает
качество результата по сравнению с ad-hoc формулировкой без стандартов.

> Воспроизводимый рассуждательный прогон (как
> [prompts-selftest-2026-05-26.md](../../RUN-0005/outputs/prompts-selftest-2026-05-26.md)), не вызов API.
> Критерии 29148 берутся из audit-профиля
> [taxonomy.md §4.2](../../../../docs/taxonomy.md): 9 индивидуальных + 5 для набора.

## Контролируемый вход

`RAW-1`: «Система должна быстро обрабатывать звонки и быть удобной, поддерживать
интеграцию с CRM.»

## Варианты

- **Вариант A (без стандартов):** требование переписывается «как звучит».
- **Вариант B (со стандартами):** применяются характеристики ISO/IEC/IEEE 29148
  (unambiguous, verifiable, singular, complete, …) и структура ГОСТ 34.602-2020
  (раздел «Требования к функциям»).

## Результаты

| Характеристика 29148 | Вариант A | Вариант B |
| --- | --- | --- |
| Singular (одно требование) | нет — слиты 3 требования (обработка, удобство, интеграция) | да — разбито на FR-1/FR-2/FR-3 |
| Unambiguous | нет — «быстро», «удобно» не определены | да — «время ответа ≤ N сек (значение — `needs-clarification`)» |
| Verifiable | нет — нельзя проверить «быстро» | да — измеримый критерий + ссылка на метрику |
| Complete | нет — нет условий/ограничений | да — добавлен раздел ограничений (ГОСТ) |
| Feasible-проверка | не выполнялась | выполнена; спорное помечено `needs-clarification` |

**Вариант B (фрагмент вывода):**

> **FR-1.** Система ДОЛЖНА обрабатывать входящий вызов за время ответа ≤ `N` сек
> (значение `N` — `needs-clarification`). Источник критерия:
> [ISO/IEC/IEEE 29148:2018](https://www.iso.org/standard/72089.html) (verifiable).
> **FR-2.** Система ДОЛЖНА предоставлять интеграцию с CRM по API (перечень
> операций — `needs-clarification`).
> **Ограничения.** Структура раздела — по
> [ГОСТ 34.602-2020](https://docs.cntd.ru/document/1200181804).

## Вывод

Применение стандартов (Вариант B) даёт атомарные, однозначные и проверяемые
требования с прослеживаемостью к источнику; без стандартов (Вариант A) дефекты
качества остаются. Это эмпирическое обоснование правил И1-И5
[industry-standards-standard.md](../../../../standards/industry-standards-standard.md) и
прямое доказательство ФТ-6.
