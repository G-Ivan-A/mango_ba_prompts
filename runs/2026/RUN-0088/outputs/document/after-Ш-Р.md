**Раздел 2. Бизнес-контекст — статус: needs-clarification**

**2.1 Контекст** (статус: draft): Сотрудники пользуются Манго Толкер (Д-3) и совершают исходящие звонки. «Виртуальная АТС может записывать — вручную или автоматически — нужный разговор (разговоры)» (LK §4.5.3). Сейчас сообщение о записи при исходящем звонке не озвучивается: наблюдение владельца продукта (В-4); в документации не описано.

**2.2 Проблема** (статус: needs-clarification): «Необходимо для соблюдения законодательства» (источник: S-02, реплика 2). Норма: «норма, которую назовёт Заказчик» (В-6); другого Заказчик не писал (Д-8). Последствия не называем (В-7). `[ТРЕБУЕТСЯ УТОЧНЕНИЕ: реквизиты нормы; В-6]`

**2.3 Цель** (статус: draft): При исходящих звонках озвучивается сообщение о том, что разговор будет записан, для соблюдения законодательства.

**2.4.1 Включено** (статус: needs-clarification):

- Озвучивание автоматического сообщения о том, что разговор будет записан, вызываемому абоненту при исходящих звонках (В-8).
- Только исходящие звонки через Манго Толкер для Windows и Mac: набор номера и заказ обратного звонка (В-14, В-15, В-39).
- Зависимость автоматического сообщения от настроек записи (В-18).
- Отсутствие сообщения, если записи не будет (В-30).
- Сохранение записи клиентского плеча (В-16, В-32).
- Документация.
- Тестирование.
- Вывод в эксплуатацию.
- Загрузка аудиофайла сообщения администратором (В-10).
- Настройка сообщения администратором (В-31).
- `[ТРЕБУЕТСЯ УТОЧНЕНИЕ: отсутствие или повреждение аудиофайла; В-45]`

**2.4.2 Не включено** (статус: needs-clarification):

- Исходящая кампания с участием автоинформатора со звуковым файлом (S-02; В-9, В-12).
- КЦ как продукт (Д-13).

- Подготовка полного текста сообщения: его пришлёт клиент (S-02, Д-9; В-11).
- Ограничение платформы: проигрывание файла через API «возможно только для входящего звонка» (VPBX API §3.2.6, с. 43–45).

Раздел 3. Функциональные требования — статус: needs-clarification — вариант: delta

3.1 Система должна предоставлять администратору возможность настроить автоматическое сообщение.
  3.1.1 Система должна предоставлять администратору возможность задать автоматическое сообщение загруженным аудиофайлом.
  3.1.2 Система должна предоставлять администратору возможность включать автоматическое сообщение.
  3.1.3 Система должна предоставлять администратору возможность отключать автоматическое сообщение.
3.2 Когда вызываемый абонент отвечает на исходящий звонок, на который распространяется автоматическая запись, система должна воспроизводить вызываемому абоненту автоматическое сообщение до начала разговора. [ТРЕБУЕТСЯ УТОЧНЕНИЕ: состав терминов; В-108]
  3.2.1 Система должна обеспечивать воспроизведение автоматического сообщения только для исходящих звонков через Манго Толкер для Windows и Mac: набор номера и заказ обратного звонка.
  3.2.2 Если на исходящий звонок не распространяется автоматическая запись, то система не должна воспроизводить автоматическое сообщение. [ТРЕБУЕТСЯ УТОЧНЕНИЕ: состав терминов; В-108]
  3.2.11 Если включён режим «Не хранить», то система не должна воспроизводить автоматическое сообщение. [ТРЕБУЕТСЯ УТОЧНЕНИЕ: состав терминов; В-108]
  3.2.3 Когда исходящий звонок выполняется заказом обратного звонка, система должна воспроизводить автоматическое сообщение только вызываемому абоненту. [ТРЕБУЕТСЯ УТОЧНЕНИЕ: внутренний вызываемый номер; В-110]
  3.2.4 Если места в облачном хранилище для сохранения записи разговора не хватает, то система должна воспроизводить автоматическое сообщение при исходящем звонке, на который распространяется автоматическая запись. [ТРЕБУЕТСЯ УТОЧНЕНИЕ: когда ВАТС узнаёт о нехватке места; В-75] [ТРЕБУЕТСЯ УТОЧНЕНИЕ: хранение на внешнем ftp-сервере; В-109]
  3.2.5 Система должна обеспечивать отсутствие автоматического сообщения в записи разговора.

Раздел 5. Описание решения — уровень: L1 — статус: draft

5.1 L1 ФДР

Опора: ФТ раздела 3, UC раздела 7, решения 8.5. Слово «проект» отмечает предложение команды (Д-87): это не документация и не приёмка.

5.1.1 ФТ 3.1: Администратор открывает настройку автоматического сообщения `[ТРЕБУЕТСЯ УТОЧНЕНИЕ: где находится настройка; В-76]`. Он задаёт аудиофайл и включает или отключает сообщение. Система сохраняет настройку (UC-01; проект: «настройки»).

5.1.2 ФТ 3.1.1: Администратор загружает аудиофайл в разделе «Аудиофайлы» (LK §4.6.2, штатное поведение). Затем он задаёт этот файл для автоматического сообщения (В-57; проект: «файл из хранилища») `[ТРЕБУЕТСЯ УТОЧНЕНИЕ: как файл назначается сообщению; В-77]`. Результат: сообщение задано файлом.

5.1.3 ФТ 3.1.2: Администратор включает или отключает автоматическое сообщение. Система сохраняет выбор (UC-01).

5.1.4 ФТ 3.2: Вызываемый абонент слышит автоматическое сообщение до начала разговора.

1. Вход: вызываемый абонент отвечает на исходящий звонок (В-29).
2. Проверка: на звонок распространяется автоматическая запись, аудиофайл задан, сообщение включено (В-42, UC-02) `[ТРЕБУЕТСЯ УТОЧНЕНИЕ: как и когда определяется автоматическая запись; В-74]`.
3. Действие: ВАТС воспроизводит сообщение вызываемому абоненту (В-23, решение архитектора; проект: «воспроизведение абоненту») `[ТРЕБУЕТСЯ УТОЧНЕНИЕ: воспроизведение при исходящем звонке без доработки API; В-71]`.
4. Ожидание: проект называет этот этап «ожидание оператора» `[ТРЕБУЕТСЯ УТОЧНЕНИЕ: кто и чего ждёт; В-69]`.
5. Результат: после сообщения система соединяет сотрудника с вызываемым абонентом (UC-02; проект: «последующее соединение»). Дальше идёт штатный разговор.

Завершение: вызываемый абонент не отвечает или занят — сообщения нет (UC-02, А1). `[ТРЕБУЕТСЯ УТОЧНЕНИЕ: абонент завершил звонок во время сообщения; В-70]`

5.1.5 ФТ 3.2.1: Сообщение звучит только при исходящих звонках через Манго Толкер для Windows и Mac: набор номера и заказ обратного звонка. Манго Толкер только инициирует звонок (В-23). Другие исходящие звонки идут без сообщения (UC-09). `[ТРЕБУЕТСЯ УТОЧНЕНИЕ: как ВАТС отличает такой звонок; В-73]`

5.1.7 ФТ 3.2.3: При заказе обратного звонка ВАТС звонит сотруднику, затем вызываемому абоненту (MTALKER §6.3). Вызываемый абонент отвечает и слышит сообщение, сотрудник его не слышит (В-53). Затем ВАТС соединяет их (UC-10).
