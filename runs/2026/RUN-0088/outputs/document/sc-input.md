Раздел 3. Функциональные требования — статус: needs-clarification — вариант: delta

3.1 Система должна предоставлять администратору возможность настроить автоматическое сообщение.
  3.1.1 Система должна предоставлять администратору возможность задать автоматическое сообщение загруженным аудиофайлом.
  3.1.2 Система должна предоставлять администратору возможность включать автоматическое сообщение.
  3.1.3 Система должна предоставлять администратору возможность отключать автоматическое сообщение.
3.2 Когда вызываемый абонент отвечает на исходящий звонок, на который распространяется автоматическая запись, система должна воспроизводить вызываемому абоненту автоматическое сообщение до начала разговора. [ТРЕБУЕТСЯ УТОЧНЕНИЕ: состав терминов; В-108]
  3.2.1 Система должна обеспечивать воспроизведение автоматического сообщения только для исходящих звонков через Манго Толкер для Windows и Mac: набор номера и заказ обратного звонка.
  3.2.2 Если на исходящий звонок не распространяется автоматическая запись, то система не должна воспроизводить автоматическое сообщение. [ТРЕБУЕТСЯ УТОЧНЕНИЕ: состав терминов; В-108]
  3.2.11 Если включён режим «Не хранить», то система не должна воспроизводить автоматическое сообщение. [ТРЕБУЕТСЯ УТОЧНЕНИЕ: состав терминов; В-108]
  3.2.3 Когда исходящий звонок выполняется заказом обратного звонка, система должна воспроизводить автоматическое сообщение только вызываемому абоненту. [ТРЕБУЕТСЯ УТОЧНЕНИЕ: внутренний вызываемый номер; В-110]
  3.2.4 Если места в облачном хранилище для сохранения записи разговора не хватает, то система должна воспроизводить автоматическое сообщение при исходящем звонке, на который распространяется автоматическая запись. [ТРЕБУЕТСЯ УТОЧНЕНИЕ: когда ВАТС узнаёт о нехватке места; В-75] [ТРЕБУЕТСЯ УТОЧНЕНИЕ: хранение на внешнем ftp-сервере; В-109]
  3.2.5 Система должна обеспечивать отсутствие автоматического сообщения в записи разговора.
  3.2.6 Если на исходящий звонок распространяется автоматическая запись, а заданный аудиофайл сообщения стал недоступен, то система должна соединять сотрудника с вызываемым абонентом без автоматического сообщения.
  3.2.12 Если на исходящий звонок распространяется автоматическая запись, а заданный аудиофайл сообщения не воспроизводится при звонке, то система должна соединять сотрудника с вызываемым абонентом без автоматического сообщения.
  3.2.7 Если на исходящий звонок распространяется автоматическая запись, а заданный аудиофайл сообщения стал недоступен, то система не должна автоматически записывать разговор.
  3.2.13 Если на исходящий звонок распространяется автоматическая запись, а заданный аудиофайл сообщения не воспроизводится при звонке, то система не должна автоматически записывать разговор.
  3.2.8 Если на исходящий звонок распространяется автоматическая запись, а заданный аудиофайл сообщения стал недоступен, то система должна один раз при возникновении показывать администратору ошибку.
  3.2.14 Если на исходящий звонок распространяется автоматическая запись, а заданный аудиофайл сообщения не воспроизводится при звонке, то система должна один раз при возникновении показывать администратору ошибку.
  3.2.9 Если администратор не задал аудиофайл сообщения, то система не должна воспроизводить автоматическое сообщение.
  3.2.10 Если администратор отключил автоматическое сообщение, то система не должна воспроизводить автоматическое сообщение. [ТРЕБУЕТСЯ УТОЧНЕНИЕ: запись разговора при отключённом сообщении; В-65]
3.3 Система должна предоставлять администратору возможность выбрать для абонента ВАТС сохранение только дорожки клиентского плеча записи разговора. [ТРЕБУЕТСЯ УТОЧНЕНИЕ: состав терминов; В-108] [ТРЕБУЕТСЯ УТОЧНЕНИЕ: хранение на внешнем ftp-сервере; В-109]

API: ФТ нет, «API не дорабатывается.» (Д-15).
