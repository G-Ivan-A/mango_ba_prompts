**Раздел 2. Бизнес-контекст — статус: needs-clarification**

**2.1 Контекст** (статус: draft): Сотрудники пользуются Манго Толкер (Д-3) и совершают исходящие звонки. «Виртуальная АТС может записывать — вручную или автоматически — нужный разговор (разговоры)» (LK §4.5.3). Сейчас сообщение о записи при исходящем звонке не озвучивается: наблюдение владельца продукта (В-4); в документации не описано.

**2.2 Проблема** (статус: needs-clarification): «Необходимо для соблюдения законодательства» (источник: S-02, реплика 2). Норма: «норма, которую назовёт Заказчик» (В-6); другого Заказчик не писал (Д-8). Последствия не называем (В-7). `[ТРЕБУЕТСЯ УТОЧНЕНИЕ: реквизиты нормы; В-6]`

**2.3 Цель** (статус: draft): При исходящих звонках озвучивается сообщение о том, что разговор будет записан, для соблюдения законодательства.

**2.4.1 Включено** (статус: needs-clarification):

- Озвучивание автоматического сообщения о том, что разговор будет записан, вызываемому абоненту при исходящих звонках (В-8). `[ТРЕБУЕТСЯ УТОЧНЕНИЕ: какие звонки; В-42]`
- Только исходящие звонки через Манго Толкер для Windows и Mac: набор номера и заказ обратного звонка (В-14, В-15, В-39).
- Зависимость автоматического сообщения от настроек записи (В-18). `[ТРЕБУЕТСЯ УТОЧНЕНИЕ: конфликт; В-42]`
- Отсутствие сообщения, если записи не будет (В-30). `[ТРЕБУЕТСЯ УТОЧНЕНИЕ: случаи; В-42, В-43, В-44]`
- Сохранение записи клиентского плеча (В-16, В-32).
- Документация.
- Тестирование.
- Вывод в эксплуатацию.
- Загрузка аудиофайла сообщения администратором (В-10).
- Настройка сообщения администратором (В-31).
- `[ТРЕБУЕТСЯ УТОЧНЕНИЕ: отсутствие или повреждение аудиофайла; В-45]`

**2.4.2 Не включено** (статус: needs-clarification):

- Исходящая кампания с участием автоинформатора со звуковым файлом (S-02; В-9, В-12).
- КЦ как продукт (Д-13).
- Единая запись (Д-14; В-17).
- Доработка API (Д-15).
- Ручной режим: при ручном запуске записи сообщение не звучит (Д-18; В-19). `[ТРЕБУЕТСЯ УТОЧНЕНИЕ: конфликт; В-42]`
- Подготовка полного текста сообщения: его пришлёт клиент (S-02, Д-9; В-11).
- Ограничение платформы: проигрывание файла через API «возможно только для входящего звонка» (VPBX API §3.2.6, с. 43–45).
- Манго Толкер для Android (В-15).
- Автодозвон (В-39).
- Внешний телефон (В-39).
- Содержание текста сообщения (В-10).
