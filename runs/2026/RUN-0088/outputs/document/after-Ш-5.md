Раздел 2. Бизнес-контекст — статус: needs-clarification

**2.1 Контекст** (статус: needs-clarification): Сотрудники пользуются Манго Толкер (Д-3) и совершают исходящие звонки. «Виртуальная АТС может записывать — вручную или автоматически — нужный разговор (разговоры)» (LK §4.5.3). Что при исходящем звонке озвучивается о записи разговора сейчас: в документации не описано (В-4).

**2.2 Проблема** (статус: needs-clarification): «Необходимо для соблюдения законодательства» (источник: S-02, реплика 2). Другого Заказчик не писал (Д-8). `[ТРЕБУЕТСЯ УТОЧНЕНИЕ: норма законодательства и последствия не названы; В-6, В-7]`

**2.3 Цель** (статус: draft): При исходящих звонках озвучивается сообщение о том, что разговор будет записан, для соблюдения законодательства.

**2.4.1 Включено** (статус: needs-clarification):

- Озвучивание автоматического сообщения о том, что разговор будет записан, при исходящих звонках.
- Исходящие звонки через Манго Толкер: `[ТРЕБУЕТСЯ УТОЧНЕНИЕ: только они или все исходящие; В-14]`
- Зависимость автоматического сообщения от настроек записи: `[ТРЕБУЕТСЯ УТОЧНЕНИЕ: какие настройки; В-18]`
- Отсутствие сообщения, если записи не будет.
- Сохранение записи клиентского плеча: `[ТРЕБУЕТСЯ УТОЧНЕНИЕ: значение термина; В-16]`
- Документация.
- Тестирование.
- Вывод в эксплуатацию.

**2.4.2 Не включено** (статус: needs-clarification):

- Исходящая кампания с участием автоинформатора со звуковым файлом (S-02; В-12).
- КЦ как продукт (Д-13).
- Единая запись (Д-14; В-17).
- Доработка API (Д-15).
- Ручной режим (Д-18; В-19).
- Подготовка полного текста сообщения: его пришлёт клиент (S-02, Д-9; В-11).
- Ограничение платформы: проигрывание файла через API «возможно только для входящего звонка» (VPBX API §3.2.6, с. 43–45).
- Платформы и версии Манго Толкера: `[ТРЕБУЕТСЯ УТОЧНЕНИЕ; В-15]`
