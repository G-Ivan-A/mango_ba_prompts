# RUN-0088, поправка 2: набор сменился по ходу прогона

Записано и закоммичено **до запуска Ш-6**. Судьи не запускались, итогов A-WORK нет.

## Что случилось

Пока прогон шёл, другая сессия исполнителя в той же ветке завершила RUN-0089 и по его правилу R2 перевела
Ш-3…Ш-9 в `by-test`: комплект 0.7 (коммит `c915492b`). Правки разделов пакетов Ш-Р и записи гейта в Ш-2, Ш-5, Ш-8
вошли туда же. Основная кнопка теперь отдаёт другие тексты, чем пред-регистрация этого прогона. На проде при этом
комплект 0.6, деплой — действие владельца.

Это ровно тот случай, о котором спрашивает владелец: тесты идут, а набор движется. Поэтому он сам становится
наблюдением: что происходит с документом БА, у которого шаги до смены пройдены по старым текстам.

## Что меняется

| № | Правило | Почему |
| --- | --- | --- |
| A1 | Шаги Ш-0…Ш-5 и возврат остаются как пройдены (текст из `inputs/prompt-set.json`) | Документ БА не переделывают из-за смены набора |
| A2 | С Ш-6 цепочка идёт по **основной кнопке комплекта 0.7**, копии — `inputs/prompt-set-0.7.json` | Вывод должен относиться к текстам, которые получит БА |
| A3 | Парных плеч Т с Ш-6 **нет** | Режим уже решён R2 RUN-0089. Пара теперь сравнивала бы новый текст со снятым с кнопки |
| A4 | Пары Ш-3, Ш-4, Ш-5 и их возвраты судятся как задумано, но решают только как **повтор R2**: режим не откатывается и не подтверждается автоматически | Правило режима этого прогона не может отменить решение, принятое по другому прогону, без новой поправки |
| A5 | Вердикт по A-IN и A-CORE: стадия судится по документу на момент своего гейта и с пометкой «пройдена по текстам до 0.7». Вердикт A-WORK и пакетов — по текстам 0.7 | Без этого вердикт припишется не тому набору |
| A6 | На Ш-Р БА не присылает политику адресатов: карточка 0.7 просит её только «если отличается от стандартного», у Ш-Р v0.2 есть политика по умолчанию. Критерии P1–P5 пред-регистрации те же | Проверяем текст комплекта 0.7. Сценарный первый ответ раздела «Ш-Р» отбрасывается |
| A7 | На Ш-С БА называет шаг вызова («вызван после Ш-5»), как просит карточка 0.7 | То же |
| A8 | Ш-В и Ш-С — новый чат; Ш-В получает текст Ш-0 и стандарты 1–8 как вложения, как просит карточка 0.7. Ш-Р — новый чат по карточке 0.7; ему приложены стандарты 1–8 по A4 поправки 1 | Поправка 1 считала только Ш-В и Ш-С новым чатом; карточка 0.7 изменила это для Ш-Р |

## Что это значит для итога

Прогон не становится чистым замером одного набора. Он показывает: **цепочка, у которой первая половина пройдена по
одним текстам, а вторая по другим, дошла или не дошла до пакетов**. Сравнения A и T с Ш-6 нет. RUN-0089 сравнение
дал; этот прогон — независимый повтор на другом условии: новый чат на каждый шаг, возврат с Г-С1.
