## Что сработало (с цитатами)

- **Безопасная работа с документацией (Г1).** Агент не принял PDF за скоуп, а
  извлёк только факты As-Is: *«Я обработаю его в соответствии с правилом
  безопасной работы с документацией: Извлеку только те факты, которые относятся к
  текущему состоянию процессов… Покажу вам эту выжимку для сверки»* (раздел 1.1).
- **Реконструкция сценариев без готовых US/UC (позитив).** *«В текущей истории
  диалога отсутствуют явно сформулированные User Story (US) и Use Case (UC)»*
  (раздел 1.2) — после чего агент сам построил Happy Path, альтернативы и
  исключения Е1–Е4. Из Е2/Е4 выросли корректные пункты раздела 6.
- **Право оспаривать правки пользователя.** Агент отстоял формулировку п. 4.4.1
  со ссылкой на п. 4.3.5 руководства, как и просил пользователь: *«вы не должны
  исполнять мои комментарии, если есть обоснование… и корректировка пользователя
  может противоречить документации»* (раздел 1.2).

## Что не сработало / правки БА (с цитатами)

- **Канцелярит на уровне 4.x.1 (Г2).** Первый вывод: *«4.1.1. Инициация действия
  осуществляется Сотрудником посредством выбора специального элемента
  управления…»* (раздел 1.2). Пользователь потребовал читаемость и дал эталон:
  *«„Сотруднику доступна возможность выбора «Завершить без ответа»…“»* (раздел
  1.2). → правка P2.
- **Нет канонического текста 6.1.1–6.1.3 в oneshot (Г3).** Агент придумал свои
  формулировки; пользователь заменил на канон: *«6.1.1. Функциональные
  возможности разрабатываемого решения ограничены функциональными возможностями
  продуктов MANGO OFFICE…»* (раздел 1.3). → правка P3.
- **Избыточные ограничения (Г4).** Пользователь отклонил 3 пункта: *«это текущее
  поведение системы, излишне вносить в ограничения»*, *«излишнее, покрыто явно в
  ФТ?»* (раздел 1.3). → правка P4.
- **Поздняя сверка с As-Is (доп. находка).** Противоречие п. 4.1.3 правилу
  «переоткрытие не допускается» агент поймал поздно, хотя сам цитировал факт в
  Е1 (раздел 1.2). → правка P5.
