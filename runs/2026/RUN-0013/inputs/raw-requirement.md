1. Термины и определения
Система - совокупность интегрированных продуктов Mango Office.

КЦ - контакт-центр MANGO OFFICE. 

АК - адресная книга, справочник контактов в системе Mango Office.

Контакт - сизическое лицо, с которым сотрудник Заказчика осуществляет коммуникацию через каналы коммуникации (телефон, SMS, email и др.) с использованием КЦ или других сервисов Mango Office. Контакт может быть как зарегистрированным в адресной книге КЦ, так и не сохраненным в ней.

Карточка контакта - это интерфейсный элемент (окно) в КЦ, содержащий всю информацию о контакте (физическом или юридическом лице): ФИО, организация, способы связи (телефоны, email, аккаунты мессенджеров и соцсетей) и другие данные, а также связанные с ним данные: история обращений, задачи, сделки и документы. 

Пользователь - сотрудник Заказчика, наделенный определенной бизнес-ролью, который имеет (или имел, либо потенциально получит) доступ к системе для выполнения операций в соответствии с правами, назначенными через Личный кабинет Mango Office.

Идентификатор мессенджера - уникальный текстовый или цифровой идентификатор аккаунта клиента в мессенджере (Max, Telegram) в Системе.

Канал коммуникации - канал, предварительно настроенный в модуле "Текстовые коммуникации → Каналы" 

2. Проблема, цель, задачи
2.1. Проблема

В разделе "КЦ → Клиенты → Контакты" механизм глобального поиска не индексирует идентификаторы мессенджеров (Max, Telegram). Пользователи не могут оперативно находить Контакты по известному идентификатору мессенджера.

2.2. Цель

Обеспечить возможность поиска контактов в адресной книге КЦ по идентификаторам мессенджеров (Max, Telegram) через механизм глобального поиска с сохранением текущей логики отображения данных в общем списке.

2.3. Задачи

2.3.1. Расширение области индексации глобального поиска в разделе "КЦ → Клиенты → Контакты".

2.3.2. Обеспечение поиска по вхождению в значения идентификаторов мессенджеров (Max, Telegram) при вводе символов в поле глобального поиска.

2.3.3. Унификация логики поиска с учётом ролевых ограничений доступа к персональным контактам.

2.3.4. Обеспечение корректной работы поиска по идентификаторам мессенджеров при активированной функции "Конфиденциальность контактных данных" (маскирование значений идентификаторов мессенджеров).

3. Описание разрабатываемого решения
3.1. - 3.4. #в работе, будет зафиксировано в процессе оценки 

3.5. Обновление разделов документации.

3.6. Стабилизацию, тестирование и отладку.

3.7. Доставку на продуктивную среду.

4. Функциональные требования и сценарии использования
4.1. Система должна предоставлять Пользователю возможность применения глобального поиска Контактов в разделе "КЦ → Клиенты → Контакты" по Идентификаторам мессенджеров.

4.1.1. Поиск должен осуществляться по значениям полей подраздела "Дополнительные каналы" карточки Контакта.
4.1.2. Поиск должен поддерживаться для каналов коммуникации: MAX, Telegram.
4.1.3. Поиск должен выполняться по частичному вхождению цепочки символов строки запроса в значение Идентификатора мессенджера без учёта регистра символов (регистронезависимо). 
4.1.4. Специальные символы (если они присутствуют в идентификаторе) должны учитываться как часть строки при поиске.
4.1.5. Система должна запускать поиск при вводе не менее одного символа в поле глобального поиска.
4.2. Система должна обеспечивать вывод результатов поиска в табличных данных в разделе  "КЦ → Клиенты → Контакты" в соответствии с текущей функциональностью Системы.

4.3.1. Отображение данных реализуется построчно с учетом сохраненных Пользовательских настроек отображения и сортировки данных по колонкам. 
4.3.2. Результаты глобального поиска по Идентификаторам мессенджеров должны формироваться с учетом прав доступа Пользователя к Адресной книге.
4.3.3. Если доступ к Контакту запрещён, такой Контакт не включается в результаты поиска, а его Идентификатор мессенджера не отображается ни в списке, ни во всплывающих подсказках.
4.3. Система должна обеспечивать визуальную идентификацию Канала коммуникации, указанного в Карточке контакта, в общем списке без открытия карточки Контакта.

4.3.1. При наведении курсора мыши на пиктограмму Канала коммуникации в строке списка Контактов система должна отображать всплывающую подсказку.
4.3.2. Всплывающая подсказка должна содержать текстовое значение Идентификатора мессенджера (например: MAX, Telegram), сохраненного в карточке Контакта.

6.1. Ограничения
6.1.1. Функциональные возможности разрабатываемого решения ограничены функциональными возможностями продуктов MANGO OFFICE.

6.1.2. Разработка не предполагает процессы, связанные с иными настройками работы Продуктов MANGO OFFICE.

6.1.4. При активированной функции маскирования данных поиск по маскированным значениям идентификаторов мессенджеров не производится; поиск осуществляется по полным (немаскированным) данным.

6.1.5. Система не проверяет корректность введённых в Адресную книгу Идентификаторов мессенджеров (в том числе наличие пробелов, специальных символов и регистра). Ответственность за достоверность и формат данных, внесённых в Карточку Контакта, лежит на Пользователе, вводящем эти данные.

6.2.1. Используются языки программирования, библиотеки, фреймворки и базы данных на усмотрение разработчиков MANGO OFFICE.
