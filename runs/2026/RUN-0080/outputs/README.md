# Результат RUN-0080

Прогон в режиме проверщика по golden set этапа 1 — измерение для BL-156
(issue #438). Сравниваются опубликованный промпт Ш-В v0.1 (A) и его
черновик «по тесту», собранный сборщиком BL-156 (D). Сравнение слепое: 62
кейса RUN-0079, бинарная рубрика K1–K6.

Итог: D и A сдали по 55 из 62 кейсов, ядро 10 из 11 у обоих, ложных
дефектов на негативных кейсах нет. Каждая версия провалила по четыре
кейса, которые другая сдала. RUN-0079 дал A 49 из 62. Условие DEC-427-11
(«не хуже базовой линии») выполнено против обеих опор. Это оценка
модели-судьи без подтверждения человеком. Решение о публикации — в
[отчёте](golden-set-report.md#решение-о-публикации).
