# Слепая оценка, пакет 2

## T-32

**Вход:** «Запись разговоров доступна для всех исходящих звонков на любом тарифе.»

**Контекст:** Руководство: «Запись разговоров доступна на тарифе „Бизнес“ для входящих звонков».

**Эталонный вердикт:** дефект

**Тип кейса:** дефектный

**Правило урока:** Факт применяется только к объекту, версии, тарифу и условиям, о которых он написан. Перенос на соседний объект — открытый вопрос.

**Обоснование эталона:** Факт перенесён на другой тип звонков и на все тарифы.

### Выход X

- **verdict:** дефект
- **violation:** АД-1/АД-6, утверждение противоречит источнику — расширены тариф (на «любом» вместо «Бизнес») и направление звонков (исходящие вместо входящих); область и исключения источника не сохранены. Критичность: важно.
- **quote:** «Запись разговоров доступна для всех исходящих звонков на любом тарифе.» Руководство: «Запись разговоров доступна на тарифе „Бизнес“ для входящих звонков»
- **fix:** «Запись разговоров доступна на тарифе „Бизнес“ для входящих звонков (Руководство, <раздел>). Для исходящих звонков и других тарифов — [ТРЕБУЕТСЯ УТОЧНЕНИЕ], вопрос в 8.4.»

### Выход Y

- **verdict:** дефект
- **violation:** АД-1/АД-6: утверждение о продукте опровергнуто источником — в руководстве запись доступна только на тарифе «Бизнес» и для входящих звонков; «всех исходящих» и «любом тарифе» — домысел. Критичность: блокирует гейт.
- **quote:** Запись разговоров доступна для всех исходящих звонков на любом тарифе.
- **fix:** «Запись разговоров доступна на тарифе „Бизнес“ для входящих звонков (Руководство, <пункт>)»; доступность для исходящих и других тарифов — [ТРЕБУЕТСЯ УТОЧНЕНИЕ] в 8.4.

- **fix:** Исключить ФТ-5 из раздела 3; если интеграция с оплатой нужна — вопрос БА в 8.4 о расширении границы.

### Выход Y

- **verdict:** дефект
- **violation:** Трассировка 2.4.1 → ФТ разорвана и АД-6: ФТ об онлайн-оплате не опирается ни на один вход задачи об уведомлении о пропущенном звонке — требование вне границ задачи.
- **quote:** ФТ-5. Система должна передавать данные звонка в сервис онлайн-оплаты.
- **fix:** Исключить ФТ-5; если связь с оплатой предполагается — вынести вопрос в 8.4 на решение БА.

- **verdict:** дефект

- **quote:** Уведомления поддерживаются в каналах: email, SMS, Telegram.
- **fix:** Указать источник и пункт для каждого канала; неподтверждённые каналы — [ТРЕБУЕТСЯ УТОЧНЕНИЕ: перечень каналов уведомлений] в 8.4.

Слияние — по решению автора.
