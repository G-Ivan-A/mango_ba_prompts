# Слепая оценка, пакет 1

## T-01

**Вход:** «ФТ-4. CRM Заказчика должна создавать задачу при пропущенном звонке.»

**Контекст:** CRM Заказчика — внешняя система, команда её не дорабатывает.

**Эталонный вердикт:** дефект

**Тип кейса:** дефектный

**Правило урока:** Чтение и интеграция отделяются от изменения внешней системы. Поведение системы, которой команда не управляет, — зависимость или ограничение, а не требование.

**Обоснование эталона:** Поведение внешней системы записано как требование. Это зависимость или ограничение.

### Выход X

- **verdict:** дефект
- **violation:** AN-05: смежная система не добавляется в поставку. ФТ возлагает обязанность на внешнюю CRM Заказчика, которую команда не дорабатывает; требование не к системе поставки. Критичность — важно.
- **quote:** ФТ-4. CRM Заказчика должна создавать задачу при пропущенном звонке.
- **fix:** ФТ-4. Система должна передавать в CRM Заказчика сведения о пропущенном звонке для создания задачи; создание задачи на стороне CRM — зависимость, вынести в 8.4/8.1 с владельцем.

### Выход Y

- **verdict:** дефект
- **violation:** Чек-лист раздела 3 стыковые ФТ по К4 (Г-W.2): субъект ФТ — внешняя CRM Заказчика, которую команда не дорабатывает; требование к чужой системе нельзя реализовать и проверить в рамках BCREQ. Критичность: блокирует гейт.
- **quote:** ФТ-4. CRM Заказчика должна создавать задачу при пропущенном звонке.
- **fix:** ФТ-4. Система должна передавать в CRM Заказчика событие о пропущенном звонке с данными, достаточными для создания задачи; создание задачи на стороне CRM — зависимость Заказчика в 8.1/8.4.

## T-08
