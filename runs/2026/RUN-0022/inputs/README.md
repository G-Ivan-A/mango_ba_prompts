Особенности формата экспорта, из-за которых нужен скрипт, а не «просто открыть
JSON»:

- сообщения лежат в `[0].chat.history.messages` словарём по id, линейная ветка
  восстанавливается обходом от `currentId` вверх по `parentId`;
- текст ответа ассистента находится **не** в поле `content` (оно пустое), а в
  элементах `content_list` с `phase == "answer"` (рядом лежит
  `phase == "thinking_summary"`);
- метрики токенов — в `content_list[*].usage`
  (`input_tokens`, `output_tokens`, `output_tokens_details.reasoning_tokens`).

Транскрипт и `logs/turn-metrics.md` — производные файлы: их можно пересобрать из
JSON в любой момент, frontmatter в них намеренно не добавляется, чтобы
пересборка была побайтово детерминированной.
