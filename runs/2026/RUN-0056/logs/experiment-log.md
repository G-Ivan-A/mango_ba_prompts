Тип прогона — `execution`: постановка требует получить артефакт («провести gap-анализ», «предложить структуру артефактов», «выдать документ в `outputs/`»), а не зафиксировать статистику коммуникации. См. [«Критерий выбора типа прогона»](../../../../standards/runs-contract-standard.md#критерий-выбора-типа-прогона).

2. **Разбор ФТ.** Выделены ФТ-01…ФТ-10 и их детализация (§4.1–4.10). Зафиксировано: §5 (НФТ) пуст.

## Ключевой результат

Продуктовая часть требований воспроизводит существующий канал «Авито Работа» и осуществима. Интеграционное ядро (ФТ-05…ФТ-08) опирается на методы hh.ru, которые в официальной документации помечены как устаревшие с прямым предупреждением, что новые возможности чатов в них поддерживаться не будут. Публичного API чатов в индексе документации нет.

## Вердикт
