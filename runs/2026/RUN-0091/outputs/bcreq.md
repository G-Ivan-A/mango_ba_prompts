### Запрос Заказчика дословно

Описание кейса, который хочет решить клиент на языке бизнес-потребности, а не только список доработок.
Необходимо создать настройку доступа к разделу Интеграции в Коллтрекинге, а именно интеграции с Яндекс Директом. С учетом того, что остальные аккаунты, подключенные в интеграции не будет видно. 
Клиенту важно подключить аккаунт к интеграции для сбора данных из Яндекс Директа. Но владелец аккаунта это партнер. Партнер не должен видеть, какие аккаунты уже подключены. И не должен видеть всю остальную информацию по Коллтрекингу или остальным продуктам.
Создадут сотрудника для партнера, доступ должен быть только к интеграции Яндекс Директа в Коллтрекинге, и уже подключенные аккаунты он ** не в коем случае видеть не должен.
