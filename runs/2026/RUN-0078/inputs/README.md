# Вход нового прогона

Задача: предварительное голосовое уведомление о записи при исходящем
контакте, предпочтительно через Mango Talker; исходящая кампания с
автоинформатором не заменяет эту потребность. Вход взят из задачи RUN-0074,
а не из придуманных требований к другому продукту. Клиентские имена, файлы
и полная переписка повторно не публикуются. [seed.json](seed.json) содержит
обезличенные смысловые атомы и проверяемые локаторы сообщений. Сырой
запрос сохранён дословно в raw_verbatim; body_type отличает его от
авторских пересказов остальных исторических сообщений.

Экспорт прочитан существующим `linear_chain/answer_text` с `python3 -I`:
214 сообщений; дополнительно перечитаны 2, 8, 56, 110, 142, 196, 200.
Метаданные RUN-0074 и все 28 критериев прочитаны до имитации. Нумерация
реплик нулевая, как у исходного золотого набора. SHA-256 экспорта:
`5eddd393276aa3e6e95088d2cf5bacb7464aee22da2cf5b3ce6b4f5da87f54b7`.
Вложение: [исходный экспорт](https://github.com/user-attachments/files/33668084/chat-export-1106.json).

Приоритет приложенных руководств — решение БА из р.8. Их тела не входят в
этот опубликованный seed; текущие продуктовые As-Is по ним не перепроверены.
Р.200 — человеческий проект решения, **не** независимое описание действующей
системы и **не** финальная приёмка. Поэтому источник design не повышается до
verified_product_fact. Таксономия — реальный локальный снимок
`docs/taxonomy/products.json`, catalog_version=2026-10-28.1; она также не
доказывает доступность функции.

Найден конфликт: р.56 исключает КЦ из задачи, р.200 включает вызовы из КЦ
в определение контакта; р.200 исключает BPMsoft. Это вынесено в CF-01/Q-01,
не разрешено по правилу «последнее сообщение всегда верно». Неизвестная
обработка отсутствующего файла из р.200 сохранена как Q-02.

Вызовы выполняет текущий LLM-автор, последовательно применяя контракты
к данным и сохраняя новые результаты. Это имитация ручного чата в одной
сессии, без субагентов и без API-вызовов к исходным Qwen-моделям. Роль
«Архитектор» в ревью выполняется тем же автором; независимость ограничена.
Реальных ответов заказчика/владельца продукта в новом прогоне нет. Можно
подготовить зависимые draft-разделы для обсуждения, но пройти гейт или
объявить выпуск нельзя. Контрольные ветви C17/C22/C37/C38 выполняются как
отдельные явно синтетические probes или получают обоснованный skip.
