# Слепая оценка, пакет 1

## T-01

**Вход:** «ФТ-4. CRM Заказчика должна создавать задачу при пропущенном звонке.»

**Контекст:** CRM Заказчика — внешняя система, команда её не дорабатывает.

**Эталонный вердикт:** дефект

**Тип кейса:** дефектный

**Правило урока:** Чтение и интеграция отделяются от изменения внешней системы. Поведение системы, которой команда не управляет, — зависимость или ограничение, а не требование.

**Обоснование эталона:** Поведение внешней системы записано как требование. Это зависимость или ограничение.

### Выход X

- **verdict:** дефект
- **violation:** Раздел 3, ФТ-4: требование адресовано внешней системе (CRM Заказчика), которую команда не дорабатывает; ФТ формулируется только для дорабатываемой системы, стыковое требование оформляется по К4 (критерий Г-W.2), иначе ФТ невыполнимо и не трассируется в ОРР. Критичность: блокирует гейт.
- **quote:** ФТ-4. CRM Заказчика должна создавать задачу при пропущенном звонке.
- **fix:** ФТ-4. Система должна передавать в CRM Заказчика событие о пропущенном звонке с данными, достаточными для создания задачи; создание задачи на стороне CRM вынести в допущения/зависимости 8.4 как стык по К4.

### Выход Y

- **verdict:** дефект
- **violation:** AN-05: смежная система не добавляется в поставку. ФТ возлагает обязанность на внешнюю CRM Заказчика, которую команда не дорабатывает; требование к чужой системе не может быть ФТ продукта (важно).
- **quote:** ФТ-4. CRM Заказчика должна создавать задачу при пропущенном звонке.
- **fix:** ФТ-4. Система должна передавать в CRM Заказчика событие о пропущенном звонке для создания задачи; создание задачи на стороне CRM — зона ответственности Заказчика (вынести в допущения/стыковые требования по К4).
