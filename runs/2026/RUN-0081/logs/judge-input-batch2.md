# Слепая оценка, пакет 2

## T-32

**Вход:** «Запись разговоров доступна для всех исходящих звонков на любом тарифе.»

**Контекст:** Руководство: «Запись разговоров доступна на тарифе „Бизнес“ для входящих звонков».

**Эталонный вердикт:** дефект

**Тип кейса:** дефектный

**Правило урока:** Факт применяется только к объекту, версии, тарифу и условиям, о которых он написан. Перенос на соседний объект — открытый вопрос.

**Обоснование эталона:** Факт перенесён на другой тип звонков и на все тарифы.

### Выход X

- **verdict:** дефект
- **violation:** АД-1 и: утверждение противоречит источнику. Руководство ограничивает запись тарифом „Бизнес“ и входящими звонками, а в документе стоят «исходящие» и «любой тариф». Область применимости и ограничение не сохранены, факт опровергнут цитатой. Критичность: важно.
- **quote:** Запись разговоров доступна для всех исходящих звонков на любом тарифе.
- **fix:** «Запись разговоров доступна на тарифе „Бизнес“ для входящих звонков (Руководство, <раздел>)»; запись исходящих и других тарифов вынести вопросом в 8.4 [ТРЕБУЕТСЯ УТОЧНЕНИЕ].

### Выход Y

- **verdict:** дефект
- **violation:** АД-1/АД-6: утверждение о продукте опровергнуто источником — руководство ограничивает запись тарифом «Бизнес» и входящими звонками; во фрагменте расширены и тариф, и направление звонков. Опровергнутый факт (доп. проверка источников). Критичность: блокирует гейт.
- **quote:** Запись разговоров доступна для всех исходящих звонков на любом тарифе.
- **fix:** «Запись разговоров доступна на тарифе „Бизнес“ для входящих звонков (Руководство, <пункт>)»; запись исходящих и другие тарифы — вопрос в 8.4 [ТРЕБУЕТСЯ УТОЧНЕНИЕ].

## T-33

**Вход:** «ФТ-5. Система должна передавать данные звонка в сервис онлайн-оплаты.»

**Контекст:** Текущая задача — уведомление о пропущенном звонке. Об оплате во входах задачи нет ни слова.

**Эталонный вердикт:** дефект

**Тип кейса:** дефектный

**Правило урока:** Сверить ID задачи и происхождение каждого входа. Факты, решения и память из другой задачи или диалога не переносятся.

**Обоснование эталона:** Интеграция не следует ни из одного входа текущей задачи.

### Выход X

- **verdict:** дефект
- **violation:** AN-05 и (unsupported_additions): ФТ выходит за границу задачи. Интеграции с онлайн-оплатой нет ни во входах, ни в решениях БА. АД-1: у требования нет источника. Критичность: блокирует гейт (Г-W.2, трассировка ФТ к 2.4.1 разорвана).
- **quote:** ФТ-5. Система должна передавать данные звонка в сервис онлайн-оплаты.
- **fix:** Удалить ФТ-5 из раздела 3. Если БА считает интеграцию нужной, вынести её рекомендацией на решение БА или вопросом в 8.4 и не включать в ФТ без решения.

### Выход Y

- **verdict:** дефект
- **violation:** АД-1/АД-6 и трассировка 2.4.1 → ФТ: требование не имеет источника во входе и не связано с задачей (уведомление о пропущенном звонке); цепочка обрывается на ФТ-5.
- **quote:** ФТ-5. Система должна передавать данные звонка в сервис онлайн-оплаты.
- **fix:** Исключить ФТ-5 из раздела 3; если нужна интеграция с оплатой — вынести вопрос БА в 8.4 со ссылкой на источник.

- **quote:** Уведомления поддерживаются в каналах: email, SMS, Telegram.
