# Результат RUN-0081

Прогон в режиме проверщика по golden set этапа 1 — замер для BL-156а
(issue #444). Сравниваются промпт Ш-В v0.1 с 15 подстановками типа гейта и
ссылками по SHA (A) и черновик «по тесту» на реестре справочников 0.4 (D).
Сравнение слепое: 62 кейса RUN-0079, бинарная рубрика K1–K6.

Итог: A сдал 56 из 62, D — 51 из 62; ядро 9 из 11 у обоих, ложных
дефектов нет. RUN-0079 дал A 49 из 62 и ядро 10 из 11. По правилу
DEC-427-11 ни A, ни D не прошли: у A ниже ядро, у D ниже ядро против
RUN-0079 и меньше сданных кейсов против A. Типизация гейтов в `prompts/`
не опубликована, черновики остаются в `prompts/drafts/`. Это оценка
модели-судьи без подтверждения человеком. Решение — в
[отчёте](golden-set-report.md#решение).
