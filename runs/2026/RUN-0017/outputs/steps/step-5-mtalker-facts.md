# Эпизод 5 (реплики 24–28) — проверка фактов по руководству MTalker

## Задание БА (реплика 24)

«проанализируйте руководство по манго толкеру и управления артефактами ВКС,
проверьте что в руководстве это явно описано (**не придумывать**)».

## Что извлекла модель (реплика 25)

Источник — MTalker, **п. 7.3 «Расшифровка и конспектирование записей встреч»**:

- терминологическая привязка: «Расшифровка» = Транскрибация ВКС, «Конспект» =
  Резюме ВКС; конспект формируется **на основе готовой расшифровки**;
- фоновой автогенерации по умолчанию нет: в MTalker требуется явное действие
  («Расшифровать» / «Получить конспект»);
- ресурсное ограничение — «минуты для обработки»;
- статусная модель: во время генерации отображается статус выполнения.

Краевые случаи, зафиксированные дословными цитатами из руководства:

1. **Запись не велась** — «Здесь будут запись, конспект и расшифровка, если
   участники включат запись встречи».
2. **Исчерпан лимит минут** — «Нет доступных минут для расшифровки или конспекта.
   Обратитесь к администратору…».
3. **Услуга «Групповая видеоконференция» не подключена** — информационный блок с
   предложением подключить тариф.

## Решение БА (реплика 26)

Функциональность MTalker **не ограничивает** проектируемое решение: допускается
автогенерация артефактов по событию готовности записи, даже если в нативном
интерфейсе MTalker такого режима нет. Модель зафиксировала это как осознанное
расширение относительно As-Is, а не как факт документации.

относительно As-Is выполнено по явному решению человека.
