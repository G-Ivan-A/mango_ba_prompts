## 2. Словарь продуктов `taxonomy/products.yaml`

- ВАТС / ЛК ВАТС (`lk`, 102 вхождений) и Mango Talker (`talker`, 6 вхождений) относятся к `voice-ucaas`, который отмечен `in_slice: false`: золотые кейсы задачи 1106 сейчас вне среза runtime. Предложение: включить `voice-ucaas` в срез и добавить граф навыков для него — в прогоне модель вынужденно шла по навыкам `-contact-center` (реплики 53–57).
- Контакт-центр (`cc`, 9 вхождений) — `contact-center`, в срезе, но в задаче 1106 вне скоупа (кампании ИО исключены Заказчиком).
- BPMSoft (`bpmsoft`, 1 вхождений) — внешняя система; в итоговом документе БА исключил её (реплика 200).

## 3. Золотые кейсы `golden/cases.yaml`

Сейчас набор runtime синтетический (`origin: synthetic`, `structural_only: true`). Предложение: принять кейсы [`golden-set-candidates.json`](golden-set-candidates.json) со значением `origin: run-observed`, где `confirmed_by: user` — реакция БА в диалоге; `expect.outcome: refused` с `defect_class` для дефектных кейсов и `expect.outcome: completed` для негативных.

## 4. Маршрутизация в КБ для настроек продукта

4 вхождений категорий C15/C18 касаются настроек продукта, описанных в КБ runtime. Предложение: при генерации раздела ФТ для каждой упомянутой настройки выписывать ограничения из КБ (журнал — [`../logs/kb-verification.md`](../logs/kb-verification.md)).
