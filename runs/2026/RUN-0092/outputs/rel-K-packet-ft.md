# ФТ на согласование. Уведомление о записи разговора при исходящих звонках

Ревизия 1. Статус: draft.

## Раздел 1. Глоссарий

| Термин | Определение |
| --- | --- |
| Сообщение о том, что разговор будет записан | Озвучиваемый текст, предупреждающий при исходящем звонке о предстоящей записи разговора. |
| Автоматическое сообщение | Сообщение о том, что разговор будет записан, озвучивание которого зависит от настроек записи. |
| Исходящий звонок | Вызов направления «Исходящие» в режимах записи ВАТС. |
| Запись разговора | Функция ВАТС, фиксирующая звук разговора вручную или автоматически для дальнейшего использования. |
| Настройки записи | Параметры ВАТС, определяющие запись разговоров. |
| Запись клиентского плеча | Часть записи разговора, относящаяся к клиентскому плечу соединения. |
| Единая запись | Запись разговора, не разделённая по плечам. |
| Ручной режим | Режим, исключённый БА из границ задачи. |
| API | Программный интерфейс, названный БА без указания продукта и состава. |
| ВАТС | Продукт MANGO OFFICE, обозначенный в Справочнике как «Виртуальная АТС MANGO OFFICE». |
| Манго Толкер | Софтфон, используемый сотрудниками. |
| КЦ | Продукт, названный Заказчиком как допустимый способ реализации и исключённый БА из границ задачи. |
| Исходящая кампания с участием автоинформатора со звуковым файлом | Способ исходящих звонков, названный Заказчиком неподходящим. |
| Клиент | Роль, присылающая полный текст сообщения. |

## Раздел 2. Бизнес-контекст

**2.1 Контекст**

Сотрудники пользуются Манго Толкер. Заказчик просит озвучивать при исходящих звонках сообщение о том, что разговор будет записан.

**2.2 Проблема**

«Необходимо для соблюдения законодательства.»

Норма и последствия Заказчик не назвал.

**2.3 Цель**

При исходящих звонках звучит сообщение о том, что разговор будет записан, для соблюдения законодательства.

**2.4.1 Включено**

- Озвучивание сообщения о том, что разговор будет записан, при исходящих звонках.
- Полный текст сообщения присылает клиент.
- Озвучивание через Манго Толкер (предпочтение Заказчика: «в идеале»).
- Автоматическое сообщение зависит от настроек записи.
- Если записи не будет, сообщение не проигрывается.
- Сохраняется запись клиентского плеча, а не единая запись.
- Документация.
- Тестирование.
- Вывод в эксплуатацию.
- Если файла нет или он повреждён, вызов соединяется без сообщения и без записи клиентского плеча.

**2.4.2 Не включено**

- Исходящая кампания с участием автоинформатора со звуковым файлом.
- КЦ как продукт.
- Единая запись.
- Доработка API.
- Ручной режим исключён.
- BPMsoft

## Раздел 3. Функциональные требования

3.1 Система должна предоставлять возможность выбирать из хранилища звуковой файл сообщения о том, что разговор будет записан.

  3.2.1 Если записи не будет, то система не должна проигрывать сообщение.

  3.2.3 Если файла сообщения нет или он повреждён, то система должна соединять вызов без сообщения.

3.3 Когда исходящий звонок записывается, система должна сохранять запись клиентского плеча, а не единую запись.

  3.3.1 Если файла сообщения нет или он повреждён, то система не должна сохранять запись клиентского плеча.

## Раздел 4. Нефункциональные требования

Пунктов нет.
