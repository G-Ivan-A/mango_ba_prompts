# Техническое задание № <номер ТЗ>

Уведомление о записи разговора при исходящих звонках

## Раздел 1. Глоссарий

| Термин | Определение |
| --- | --- |
| Сообщение о том, что разговор будет записан | Озвучиваемый текст, предупреждающий при исходящем звонке о предстоящей записи разговора. |
| Автоматическое сообщение | Сообщение о том, что разговор будет записан, озвучивание которого зависит от настроек записи. |

## Раздел 2. Бизнес-контекст

**2.1 Контекст**

Сотрудники пользуются Манго Толкер. Заказчик просит озвучивать при исходящих звонках сообщение о том, что разговор будет записан.

**2.2 Проблема**

«Необходимо для соблюдения законодательства.»

Норма и последствия Заказчик не назвал.

**2.3 Цель**

При исходящих звонках звучит сообщение о том, что разговор будет записан, для соблюдения законодательства.

**2.4.1 Включено**

- Озвучивание сообщения о том, что разговор будет записан, при исходящих звонках.
- Полный текст сообщения присылает клиент.
- Озвучивание через Манго Толкер (предпочтение Заказчика: «в идеале»).
- Автоматическое сообщение зависит от настроек записи.
- Если записи не будет, сообщение не проигрывается.
- Сохраняется запись клиентского плеча, а не единая запись.
- Документация.
- Тестирование.
- Вывод в эксплуатацию.

**2.4.2 Не включено**

- Исходящая кампания с участием автоинформатора со звуковым файлом.
- КЦ как продукт.
- Единая запись.
- Доработка API.
- Ручной режим исключён.

## Раздел 3. Функциональные требования

3.1 Система должна предоставлять возможность настраивать автоматическое сообщение о том, что разговор будет записан.

  3.1.1 Где настройки записи определяют запись исходящего звонка, система должна определять по ним воспроизведение автоматического сообщения.

3.2 Система должна предоставлять возможность выбирать из хранилища файл сообщения.

3.3 Система должна обеспечивать воспроизведение автоматического сообщения о том, что разговор будет записан, при исходящем звонке.

  3.3.1 Если записи не будет, то система не должна воспроизводить сообщение.

  3.3.2 Где исходящий звонок совершается через Манго Толкер, система должна воспроизводить сообщение при этом звонке.

  3.3.3 Если аудиофайла нет, то система должна соединять вызов без сообщения.

  3.3.4 Если аудиофайл повреждён, то система должна соединять вызов без сообщения.

3.4 Система должна обеспечивать сохранение записи клиентского плеча, а не единой записи.

  3.4.1 Если аудиофайла нет, то система не должна записывать клиентское плечо.

  3.4.2 Если аудиофайл повреждён, то система не должна записывать клиентское плечо.

## Раздел 5. Особенности реализации и ограничения

**5.1 Особенности**

| ID | Особенность | Последствие |
| --- | --- | --- |
| ОС-1 | Автозапись задаётся общими правилами и отдельно для сотрудников, групп, номеров. | |
| ОС-2 | При загрузке описана проверка формата по расширению. | Повреждение при этом может не определяться. |
| ОС-3 | Запись в Манго Толкер включена или отключена настройками ВАТС. | |

**5.2 Ограничения**

| ID | Ограничение | Последствие |
| --- | --- | --- |
| ОГ-1 | Публичная команда проигрывания описана только для входящего звонка. | Для исходящего нельзя опираться на неё. |
| ОГ-2 | Публичная команда записи идентифицирует только сотрудника ВАТС. | Параметр клиентского плеча не описан. |
| ОГ-3 | Нет места в облачном хранилище: запись не сохраняется. | |
| ОГ-4 | Режим «Не хранить»: записи разговоров не сохраняются. | |
| ОГ-5 | Многоканальный режим доступен на определённых тарифах. | Сохранение плеча на всех тарифах не подтверждено. |
| ОГ-6 | Звуковой файл ограничен форматом и размером 20 Мб. | Для файла сообщения не подтверждено. |
| ОГ-7 | Запись короче минимальной не сохраняется. | Сообщение может прозвучать, а записи не будет. |
