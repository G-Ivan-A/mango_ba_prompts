## Решения по итогам фиксации

1. Прогон зафиксирован как `run_type: statistics` — для сбора статистики по
   процессам БА, операциям и результативности промптов. Артефакты диалога
   **не переносятся** в `prompts/`, `kb/`, `patterns/` и `site/data/`: границы
   прогона по issue #273 это запрещают.
2. Правила, заданные человеком по ходу диалога (см.
   [`../outputs/prompts-chain.md`](../outputs/prompts-chain.md), раздел
   «Правила, заданные человеком»), — кандидаты на перенос в промпт
   `glossary-context-understanding-stepwise` **отдельной задачей**, прежде всего:
   - субъективное заявление Заказчика не документируется как дефект продукта;
   - согласованный текст не перегенерируется без явного запроса;
   - фрагмент, удалённый человеком, не возвращается;
   - утверждение о функционале требует ссылки на страницу документации.
3. Наблюдение для методологии: приём «запиши в долгосрочную память» в рамках
   одной сессии удержания правил не обеспечил (4 нарушения из 9 правил после
   фиксации). Требуется механизм повторной подачи ограничений в каждой итерации
   вывода, а не однократная запись.
