# Фрагменты

## F1

```
3.1 Функциональные требования
ФТ-1. Система отправляет оператору уведомление о пропущенном звонке.
Источник: запрос Заказчика, п. 2.

Отраслевая практика — на решение БА
| Практика | Источник | Что даст | Статус |
| Повторная доставка уведомления при сбое канала | RFC 9110, раздел 15.6 | не теряются уведомления при временном сбое; при отказе возможна потеря | в раздел не включено |
```

## F2

```
3.1 Функциональные требования
ФТ-1. Система отправляет оператору уведомление о пропущенном звонке и повторяет отправку при сбое канала с экспоненциальной задержкой, как принято в отрасли.
Источник: запрос Заказчика, п. 2. В запросе о повторной отправке не сказано. Решения БА в 8.5 нет.
```
