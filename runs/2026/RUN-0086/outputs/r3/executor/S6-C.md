Источники и режим
- Правила: fallback. Режим fallback: детальные стандарты недоступны — Промпт 0, мета-стандарт раздела 5 и правила композиции по ссылкам из промпта (внешние ссылки в этой сессии не открываются); текст конституции во входе отсутствует, поэтому применены только прочитанные правила текущего промпта.
- Таксономия: требует доработки. Продуктовая принадлежность: [ТРЕБУЕТСЯ УТОЧНЕНИЕ] — требует доработки. Подтверждённых уровней нет, таксономия не прочитана, продукт во входе не назван. Временная запись: продукт из входа БА не указан · класс поиска не определён · неподтверждённые уровни — [ТРЕБУЕТСЯ УТОЧНЕНИЕ].
- Класс поиска: не определён, основание — нет названия продукта и карты БЗ.
- Режим БЗ: auto, дополнение БА — текст задачи. Авто-БЗ недоступна — README docs/kb и MAP.json, внешние ссылки в этой сессии не открываются. Можно прикрепить файлы БЗ, ввести текст или продолжить без БЗ. Если дополнение не передано, по умолчанию — без БЗ.
- Прочитано: сообщение БА, включая цитату «настройка есть, значения 30, 90 и 180 дней» (дополнение БА, не документ поставщика; версия и локатор не указаны).
- Непроверяемые критерии: соответствие конституции и мета-стандарту раздела 5; применение срока к уже сохранённым записям.
- Вопросы 8.4: В-1…В-3. Решения БА о расширении поиска не требуется.
