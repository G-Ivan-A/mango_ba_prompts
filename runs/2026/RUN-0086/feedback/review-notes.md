# Замечания к RUN-0086

## Статус проверки человеком

Оценка модели-судьи без подтверждения человеком (`ba_reviewed: false`), судья не калиброван по БА. Это не приёмка: приёмка возможна только по реальному прогону БА (BL-157в).

## Что осталось открытым

S6-a1 падает 3/3 в обоих плечах: на Ш-6 практика в этом кейсе не предлагается и с блоком, открытый дефект. Проверка Ш-В: чистая подача — в 3 из 3 повторов ожидаемый вердикт (`outputs/shv-check/`): практика вне требований не считается дефектом (F1), практика внутри ФТ считается (F2); правило снятия блока не сработало.
