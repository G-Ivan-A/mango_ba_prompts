# Corrections

> Исправления результирующего артефакта RUN-0014 по ревью issue
> [#235](https://github.com/G-Ivan-A/mango_ba_prompts/issues/235).
> Версия артефакта поднята с 0.1 до 0.2.

## Применённые исправления

- Из предмета доработки исключены инсайты: удалены термины «Ловец инсайтов» и
  «Инсайт», задача 2.3.3 и эффект по инсайтам, FR-03 (фильтрация «Ловца
  инсайтов»), блок 4.3 прошлой версии. Обоснование исключения зафиксировано в
  `outputs/analysis-bcreq-1040-scope-2026-06-24.md`.
- Удалён единый дашборд: удалены термин «Дашборд», задача 2.3.4, FR-04 и блок 4.4
  прошлой версии. Причина — выход за границы целесообразной доработки и
  отсутствие явного требования Заказчика (отчёты доступны «из коробки»).
- Название документа и метаданные приведены к scope «по чек-листам» (без
  инсайтов).
- Раздел 1 (термины) и раздел 3.6 (ФТ верхнего уровня) приведены к
  исправленному Заказчиком виду.
- FR-01 уточнён по ролевой модели ВАТС: роль «Администратор» или пользовательская
  роль на её базе; настройка выполняется в Личном кабинете ВАТС. Источник —
  `kb/mango-product-docs/processed/Rolevaya-model-vats`.
- Раздел 4 детализирован по принципу приёмки:
  - состояние по умолчанию (4.1.7, 4.2.3);
  - атомарность CRUD-операций групп-направлений (4.1.1–4.1.5);
  - целостность данных: номер только в одной группе (4.1.6), сохранение номеров
    при удалении группы (4.1.5.1).
- Список направлений «мини-брус», «ПРЕКАТ», «ПРЕФАБ» зафиксирован как текущие
  направления Заказчика (пример), а не как правило валидации; правилом валидации
  оставлена уникальность названия группы-направления.
- Таблица трассируемости и блок валидации обновлены под FR-01…FR-03 и новые
  источники.

## Оставшиеся ограничения и открытые вопросы

- Источник автоматического сопоставления номера ВАТС направлению (вариант Target)
  не подтверждён.
- Требуется согласовать состав номеров ВАТС для каждой группы-направления.
- Требуется подтвердить требуемый способ сохранения результатов по
  группе-направлению (сохранённый параметр отчёта и/или выгрузка) для FR-03.
