# Отчёт RUN-0085: Ш-В: уточнение правила против избыточной декомпозиции (A3) против контроля A2 (v0.2)

Решение BL-156г по Р-03 (одновременный контроль, N = 3, медиана) и Р-18 (issue [#450](https://github.com/G-Ivan-A/mango_ba_prompts/issues/450)).

| Плечо | Сдано (медиана) | Ядро | Ложные дефекты | Повторы |
| --- | --- | --- | --- | --- |
| A2 | 58/62 | 10/11 | 0/10 | 58, 57, 60 |
| A3 | 59/62 | 11/11 | 0/10 | 58, 59, 60 |

Частота падений кейсов по плечам: `{"A2": {"GS-BCREQ-26": 3, "GS-BCREQ-01": 2, "GS-BCREQ-27": 2, "GS-BCREQ-25": 1, "GS-BCREQ-37": 1, "GS-BCREQ-41": 1, "GS-BCREQ-47": 1}, "A3": {"GS-BCREQ-26": 3, "GS-BCREQ-41": 2, "GS-BCREQ-08": 1, "GS-BCREQ-12": 1, "GS-BCREQ-50": 1, "GS-BCREQ-N07": 1}}`.

**Решение.** A3 не хуже контроля, сторож Р-18 пуст — публикуется как Ш-В v0.3.

GS-BCREQ-25: A2 1/3 → A3 0/3. GS-BCREQ-12: A2 0/3 → A3 1/3. GS-BCREQ-26 падает 3/3 в обоих плечах: не ядро сторожа, остаётся открытым; A3 его не лечит и не вызывает.
