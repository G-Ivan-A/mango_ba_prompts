## TL;DR

- **Что делали.** БА документировал доработку интеграции MANGO OFFICE ↔ amoCRM:
  при входящем звонке открывать Карточку сделки клиента в новой вкладке
  браузера. За 19 эпизодов диалога собрали раздел 4 «Функциональные требования»
  (в финале БА — только 4.1–4.3) и раздел 6 «Ограничения».
- **Что сработало.** Модель верно отметила, что автооткрытие Карточки сделки на
  входящем — не штатная функция интеграции; провела инвентаризацию настроек
  интеграции, влияющих на создание сделки (принято БА, +7 ФТ); формализовала идею
  БА описывать поведение через **результат применения настроек**, а не через
  перечисление их значений.
- **Что не сработало.** Модель **молча заменила** наименования элементов
  интерфейса, которые БА просил «явно указывать»; сослалась на непроверяемые
  пункты инструкции и макет (их нет в архиве); придумала ограничения без
  источника (режим инкогнито, «расширенный пакет интеграции», `window.open`);
  в итоговом резюме приписала согласование разделам 4.4–4.5, которых нет в
  финальной редакции БА.
- **Итог по данным.** 19 эпизодов, 17 приняты БА → `success_rate ≈ 0.89`;
  4 дефекта достоверности, 3 из них дошли до финального текста, принятого БА.
