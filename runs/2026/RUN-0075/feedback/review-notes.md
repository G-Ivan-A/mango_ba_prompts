# Ограничения чтения прогона RUN-0075

- **Шкала.** Прогон `statistics`: результат — размеченный реестр ошибок ИИ и кандидаты в эталоны, а не артефакт требований. Явной приёмки документа в экспорте нет (реплика 116 — итоговая редакция БА без отметки о приёмке), поэтому `status: draft`, `success_rate` не выставлен.
- **Разметка — работа одного разметчика** (AI issue solver), человеком не перепроверена. Достоверность разделена: `confirmed` (68) — реакция БА, локатор КБ или прямое правило указывают на этот дефект; `plausible` (100) — прямого подтверждения нет. Частоты надёжнее читать по столбцу `confirmed` [`../outputs/error-statistics.md`](../outputs/error-statistics.md).
- **Единица учёта — вхождение.** Одна фраза может дать вхождения разных категорий; повторы не схлопываются («Запрещено суммаризировать или упрощать»). Число вхождений — не число «разных ошибок».
- **«Обнаружено при фиксации»** (108) не значит, что БА ошибку не заметил: в экспорте нет его реакции, которую можно процитировать.
- **Задержка обнаружения** считается до первой процитированной реакции БА; если он реагировал раньше другими словами, задержка завышена.
- **Эвристическая разметка операций БА** в [`../outputs/prompt-usage.md`](../outputs/prompt-usage.md) — по ключевым словам; 19 реплик (32%) не распознаны.

- **Продуктовая принадлежность.** SSOT — `taxonomy/products.yaml` runtime на SHA `91406e4`. ВАТС и VPBX API относятся к классу `voice-ucaas`, помеченному `in_slice: false`; значит, часть кейсов прогона сейчас вне среза runtime — см. Q2.
