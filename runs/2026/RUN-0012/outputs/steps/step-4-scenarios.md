# Шаг 4 — Сценарная декомпозиция (перед генерацией ФТ)

> **Промпт:** [`fr-documentation-stepwise`](../../../../../prompts/fr-documentation-stepwise.md),
> Шаг 2. Матрица сценариев строится до Раздела 4, чтобы ФТ покрывали не только
> Happy Path, но и альтернативы и исключения (правило 4 промпта — креативность
> направлена на выявление граничных случаев).

## Актёры

- **Пользователь** — администратор ЛК Клиента: создаёт и настраивает ограниченный
  ключ.
- **Сторонний сервис РА** — потребитель: предъявляет ключ и забирает записи.
- **ВАТС** — система, проверяющая область действия ключа при каждом обращении.

## Основной сценарий (Happy Path)

1. Пользователь в ЛК создаёт ограниченный API-ключ.
2. Пользователь задаёт область действия: выбирает группы и/или сотрудников —
   источники записей.
3. ВАТС фиксирует область: метод = только получение записей, источники = выбранное
   множество.
4. Сторонний сервис РА предъявляет ограниченный ключ и запрашивает записи.
5. ВАТС возвращает **только** записи разговоров сотрудников из области действия.

## Альтернативные сценарии

| № | Условие | Поведение |
| --- | --- | --- |
| A1 | Область задана «группой» | Доступ ко всем записям сотрудников группы (состав — по Д2, динамически). |
| A2 | Область задана «списком сотрудников» | Доступ к записям только перечисленных сотрудников. |
| A3 | Область = несколько групп + отдельные сотрудники | Доступ = объединение множеств источников. |
| A4 | Параллельно работает основной ключ | Основной ключ сохраняет полный доступ; ограничения нового ключа на него не влияют (В3). |

## Сценарии исключений (Exception Paths)

| № | Ситуация | Ожидаемое поведение |
| --- | --- | --- |
| E1 | Ограниченным ключом вызывается **другой** метод API (не получение записей) | В доступе отказано (В2 — прочие методы закрыты по умолчанию). |
| E2 | Запрошена запись сотрудника **вне** области действия | Запись не выдаётся; обращение отклонено как выход за область. |
| E3 | Сотрудник выведен из выбранной группы после выдачи ключа | По Д2 доступ к его новым/историческим записям прекращается (подтвердить В-ИЗМ). |
| E4 | Область действия пуста (не выбран ни один источник) | Ключ не выдаёт ни одной записи; создание с пустой областью — валидируется в ЛК. |
| E5 | Ограниченный ключ отозван/удалён | Любое обращение по нему отклоняется. |
| E6 | *(опция В6)* Ключ временно деактивирован | Обращения отклоняются, но настройки области сохраняются для повторной активации. |
