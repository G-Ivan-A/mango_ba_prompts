## Правило решения

1. Черновики A-IN включаются в run kit v0.3 как режим `by-test` (BL-157б),
   если T сдал **не меньше** критериев, чем P, **и** у T нет провала по
   критическим J03, J07, J11 (доказательства, вымысел, гейт).
2. Каждый провал T — дефект черновика: правится в `prompts/drafts/` в этом
   PR или переносится в бэклог с обоснованием.
3. Если условие п. 1 не выполнено, `by-test` для A-IN остаётся справочным,
   а на сайт идёт только v0.1.
4. N = 1: прогон — дымовой тест пригодности, а не замер качества; он не
   решает публикацию в `prompts/` (её решает только golden set по Р-03).
