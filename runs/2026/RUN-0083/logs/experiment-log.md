# Журнал RUN-0083

## Цель

Решить, идут ли черновики «по тесту» A-IN (Ш-0, Ш-1, Ш-2) в run kit
v0.3 как `by-test` (BL-157б). Основание — issue #446, пункт 4: «нужен
короткий путь к запуску тестирования при даже при использовании
синтетичсеких прогонов… как минимум на A-IN». Правило решения записано
до запуска: [`preregistration.md`](preregistration.md).

## Процедура

1. **Подготовка.** Клон runtime на `f31dcde3` (`/tmp/rt446`); промпты
   плеч скопированы в `/tmp/run83/P/` и `/tmp/run83/T/`; вход и сценарий
   БА — [`../inputs/`](../inputs/README.md).
2. **Исполнение.** Два изолированных подагента `claude-opus-5-5`, по
   одному на плечо, с одной и той же инструкцией
   ([`executor-instruction.md`](executor-instruction.md)). Каждый сыграл
   диалог Ш-0 → Ш-1 → Ш-2 по сценарию реплик БА и записал транскрипт —
   26 ходов у обоих плеч.
3. **Слепота.** `python3 experiments/issue_446/run0083/run.py blind /tmp/run83`:
   порядок X/Y по seed 8085 (X = P). Первая строка транскрипта и пути к
   промптам в журнале исполнителя (`/tmp/run83/P/`, `/tmp/run83/T/`)
   называют плечо. Сценарий заменяет их одинаковыми масками.
4. **Оценка.** Один изолированный слепой судья
   ([`judge-instruction.md`](judge-instruction.md)): 12 критериев J01–J12,
   вердикт pass/fail с цитатой и обоснованием, общий победитель.
5. **Пересчёт.** `run.py score /tmp/run83` → `summary.json`: сданные и
   проваленные критерии, решение по правилу, SHA-256 шести текстов.
6. **Фиксация.** `run.py fixate /tmp/run83`: вход, инструкции и выходы
   копируются в `runs/2026/RUN-0083/`, относительные ссылки
   пересчитываются под новое место.
