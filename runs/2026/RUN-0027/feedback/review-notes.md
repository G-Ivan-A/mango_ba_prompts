в контексте не создаёт заземления, его создаёт требование цитаты.

## 2. Дефект коммуникации: не запрошенное дополнение вошло в постановку

На реплике 3 модель по своей инициативе предложила: «Роль "Администратор" может
задать шаблон подписи для всей организации» — с собственной пометкой
«опционально, фаза 2». На реплике 6 БА воспроизводит это как условие задачи:
«Наша задача предусматривает: + Роль "Администратор" может задать шаблон подписи
для всей организации… без возможности редактирования оператором».

Механизм тот же, что породил Г1–Г2 (достраивание сверх запроса), но здесь
результат принят человеком и расширил объём задачи. Это не дефект модели в
чистом виде, а риск процесса: инициативные предложения модели не отделены
визуально от требований БА, поэтому на следующем такте неразличимы.

## 4. Предложения по промптам (не применяются в этом прогоне)

- **П1 — граница ответа на запрос-трассировку.** Если БА просит трассировку/
  сопоставление, отвечать только сопоставлением; новые требования выносить
  отдельным блоком «Предложения (не входят в ФТ)». Отсекает Г1, Г2 и снижает
  риск из раздела 2.
- **П2 — запрет достраивать числовые НФТ без источника.** Любое число
  (КБ, секунды, Мбит/с) допускается только с ссылкой на переданный документ или
  внешний источник; иначе — плейсхолдер «уточнить у БА». Отсекает Г1.
- **П3 — гейт заземления для приложенных файлов.** При ссылке на PDF требовать
  дословную цитату + страницу/раздел; без цитаты — статус «не подтверждено».
  Отсекает Г4 и Г5.
- **П4 — самопроверка на противоречие и разметка неопределённости.** Перед
  выводом проверять, не утверждаются ли в одном ответе обе стороны (Г4);
  утверждения о текущей реализации продукта помечать как гипотезу до проверки
  в интерфейсе.
- **П5 — визуальное разделение «требование БА» / «предложение модели»** во всех
  структурированных выводах, чтобы инициатива модели не переходила в постановку
  молча (раздел 2).

Правки в этом PR **не применяются**: границы прогона (issue #293) запрещают
изменять `prompts/`. Прогон фиксируется как есть.
