# Проверка заземления сносок (эпизод 3, реплика 5)

В реплике 5 модель проставляет сноски вида `[[10]]`, `[[31]]`. Сноска сама по
себе ничего не доказывает: проверяемо только то, встречается ли контрольный
термин утверждения в тексте, который инструмент **реально вернул** модели
(`content_list[*].extra.tool_result.tool_observation`). Тот же приём применён в
[`RUN-0024`](../../RUN-0024/logs/grounding-check.md).

## Метод

```bash
python3 experiments/signature_citation_grounding_probe.py 978-chat.json
```

Скрипт [`experiments/signature_citation_grounding_probe.py`](../../../../experiments/signature_citation_grounding_probe.py)
восстанавливает линейную ветку диалога, собирает выдачи инструментов и считает
вхождения контрольных терминов. Только stdlib, результат детерминирован.

## Выводы

1. **Все три числовых НФТ заземлены.** Контрольные строки найдены в выдаче
   инструмента дословно: «Gmail has a size limit of 102KB for each email
   message», «Set the signature | 30,000 characters | Body.setSignatureAsync»,
   «Outlook ranges from 20-34MB depending on the version».
2. **Рекомендация «≤80 КБ» — не выдумка модели, а цитата источника:** «a good
   rule of thumb is you should try to stay below 80KB» (Email on Acid).
3. **Число «~33 %» для Base64 не заземлено.** Источники `[[31]][[32]]`
   подтверждают только качественный рост размера при Base64-кодировании.
   Само число верно арифметически (4/3 от исходного объёма), но сноска на
   источник в этом месте не подтверждается его текстом.
4. **«200 КБ» из эпизода 2 не подтверждается ничем** — ни выдачей инструмента,
   ни переданным БА исследованием (там 100 КБ для Outlook, 2 МБ для Mail.ru).
   Веб-поиск в эпизоде 2 не вызывался, число появилось до любых источников.
5. **Ключевое наблюдение прогона:** заземление появляется ровно там, где БА
   попросил его явно («дай ссылки», реплика 4). Ни один другой такт диалога не
   сопровождается проверяемым источником — в эпизодах 4–5 модель ссылается на
   разделы и страницу приложенного PDF без проверяемой из выгрузки цитаты.
