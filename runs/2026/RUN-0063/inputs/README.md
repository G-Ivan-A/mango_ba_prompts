# Входы RUN-0063

## Постановка

- Issue [#343](https://github.com/G-Ivan-A/mango_ba_prompts/issues/343) — SSOT
  потребности Заказчика и обязательной структуры результата.
- Тип задачи: формирование артефакта ФТ, поэтому `run_type: execution`.
- Направление: `client-order`; целевой пакет — Feature Specification / ФТ КК.

## Факты Заказчика

- Клиенту нужна самостоятельная выгрузка из Личного кабинета за месяц для
  внутреннего распределения расходов между проектами в разрезе УПД.
- Запрошены поля: инициирующий номер, номер абонента, оператор связи,
  длительность, сумма, номер договора и название услуги.
- Граница — один Лицевой счет; при нескольких ЛС отчет формируется отдельно по
  каждому, а объединение выполняет пользователь на своей стороне.
