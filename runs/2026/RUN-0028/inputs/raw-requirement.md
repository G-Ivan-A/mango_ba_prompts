4.3.2. Система должна предоставлять мастер-выбор (мастер-чекбокс), отмечающий или снимающий отметку сразу со всех номеров ВАТС текущего результирующего списка поиска.
4.3.3. Система должна сохранять ранее отмеченные номера ВАТС при изменении строки поиска, чтобы Пользователь мог собрать выбор в несколько заходов по разным запросам.
4.3.4. Внутри фильтра по номерам ВАТС между выбранными номерами действует логика ИЛИ (в отчёт попадают разговоры по любому из выбранных номеров).
4.3.5. Система должна применять фильтр по выбранным номерам ВАТС при инициации Пользователем действия «Выбрать» и запоминать состояние выбранных номеров.
4.3.6. Система должна предоставлять возможность сбросить выбранные номера ВАТС и вернуть фильтр в состояние по умолчанию (4.1.4).
4.4. Результаты оценки по чек-листам по выбранным номерам (FR-04)
4.4. Система должна предоставлять Пользователю результаты оценки по чек-листам по выбранному набору номеров ВАТС.

4.4.1. Система должна включать в результат отчёта «Анализ по чек-листам» только разговоры по выбранным в фильтре номерам ВАТС.
4.4.2. Система должна отображать результаты оценки по выбранным номерам ВАТС на странице статистики отчёта «Анализ по чек-листам».
4.4.3. Состояние по умолчанию: при отсутствии выбранных номеров ВАТС фильтр по номерам не применяется, и отчёт показывает данные как в текущем поведении (As-Is).

6. Особенности реализации
6.1. Ограничения
6.1.1. Сотрудники Партнёров не заведены в ВАТС, поэтому фильтрация по сотрудникам и группам сотрудников не выделяет направление; признак направления выражается только номером ВАТС и его комментарием.

6.1.2. Номер 8-800 — внутренний канал Заказчика с отдельным чек-листом; он не относится к продуктовым направлениям (issue #220, Q2) и не помечается наименованием направления в комментарии.

6.1.3. Корректность разреза по направлению зависит от единообразия комментариев: во всех номерах одного направления в комментарии должно присутствовать одно и то же наименование направления. Это организационное соглашение Заказчика, а не системное правило валидации.

6.1.4. Длина комментария к номеру ограничена в текущей функциональности ЛК ВАТС (для номеров сторонних операторов — не более 50 символов, mango-lk-manual/sections/323-nomera.md); наименование направления добавляется в пределах этого ограничения.
