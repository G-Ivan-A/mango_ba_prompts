# Результат RUN-0079

Первый прогон в режиме проверщика по golden set этапа 1 (см. RFC уроков
прогонов, «Режимы прогона»). Один и тот же промпт проверки фрагмента
`prompts/bcreq-review-validation-oneshot.md` сравнивается в двух версиях:
0.1 (до блока «Уроки прогонов») и 0.2 (с блоком). Сравнение слепое, 62 кейса,
бинарная рубрика K1–K6.

| Файл | Что внутри |
| --- | --- |
| [`golden-set-report.md`](golden-set-report.md) | Версии, итог, профиль провалов по урокам, чувствительность, ограничения |
| [`executor-A.json`](executor-A.json), [`executor-B.json`](executor-B.json) | Ответы исполнителя по каждому T-NN: вердикт, нарушение, цитата, правка |
| [`judge-key.json`](judge-key.json) | Ключ слепоты: какая версия была X, а какая Y в каждом кейсе |
| [`judge-scores.json`](judge-scores.json) | Оценки судьи K1–K6 для X и Y с замечаниями |
| [`metrics.json`](metrics.json) | Сводка, пересчитанная `score.py` |

Итог: версия 0.2 сдала 61 из 62 кейсов и всё ядро, версия 0.1 — 49 из 62
и 10 из 11 в ядре. Ложных срабатываний на негативных кейсах нет ни у одной
версии. Это оценка модели-судьи без подтверждения человеком. Прогон не
является приёмкой промпта: порог назначает владелец.
