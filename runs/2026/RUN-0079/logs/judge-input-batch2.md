# Слепая оценка, пакет 2

## T-32

**Вход:** «Запись разговоров доступна для всех исходящих звонков на любом тарифе.»

**Контекст:** Руководство: «Запись разговоров доступна на тарифе „Бизнес“ для входящих звонков».

**Эталонный вердикт:** дефект

**Тип кейса:** дефектный

**Правило урока:** Факт применяется только к объекту, версии, тарифу и условиям, о которых он написан. Перенос на соседний объект — открытый вопрос.

**Обоснование эталона:** Факт перенесён на другой тип звонков и на все тарифы.

### Выход X

- **verdict:** дефект
- **violation:** /АД-8, Р1: факт перенесён на другой объект и условия. В источнике запись описана только для входящих звонков и только на тарифе «Бизнес», а во Входе сказано «для всех исходящих звонков на любом тарифе». Ограничители и область применения искажены.
- **quote:** Запись разговоров доступна на тарифе „Бизнес“ для входящих звонков
- **fix:** «Запись разговоров доступна на тарифе „Бизнес“ для входящих звонков (Руководство, <пункт>). Для исходящих звонков и других тарифов не описано — [ТРЕБУЕТСЯ УТОЧНЕНИЕ: владелец продукта], вопрос в 8.4».

### Выход Y

- **verdict:** дефект
- **violation:** АД-1/АД-6: утверждение противоречит источнику — руководство ограничивает запись тарифом «Бизнес» и входящими звонками, во Входе — все исходящие и любой тариф (опровергнуто цитатой).
- **quote:** Запись разговоров доступна на тарифе „Бизнес“ для входящих звонков
- **fix:** «Запись разговоров доступна на тарифе „Бизнес“ для входящих звонков (Руководство, <пункт>)»; применимость к исходящим и другим тарифам — [ТРЕБУЕТСЯ УТОЧНЕНИЕ] в 8.4.
