# Входы RUN-0067

## Постановка

- Issue [#355](https://github.com/G-Ivan-A/mango_ba_prompts/issues/355) — SSOT
  прогона: переработка ФТ BCREQ-1074 по результатам аудита прогона RUN-0063.
- Operating Mode: `Hybrid` — формат документа задан образцом ФТ (BCREQ-1025),
  анализ дельты внутри этих рамок выполняется исполнителем.
- Тип задачи — получение артефакта ФТ, поэтому `run_type: execution`.

## Вложения задачи

Сырые вложения в репозиторий не коммитятся (контракт прогонов и governance:
экспорт чата содержит идентификаторы сессии и пользователя). Фиксируются
provenance, размер и контрольная сумма; из экспорта в прогон переносятся только
проверяемые утверждения аудита.

Экспорт чата развёрнут в транскрипт локальным инструментом воспроизводимости
[`scripts/chat_export_to_markdown.py`](../../../../scripts/chat_export_to_markdown.py):

```bash
python3 scripts/chat_export_to_markdown.py chat-export-1788437279878.json \
    --transcript transcript.md --metrics turn-metrics.md
```

Полный текст образца ФТ BCREQ-1025 продублирован Заказчиком в реплике 18 того же
экспорта, поэтому структура эталона проверяется по обоим носителям.
