# Технический аудит RUN-0093

Ключевые риски (подробно — колонка 5 отчёта, «Аудит:»):

- **Объёмы (ТЗ-2 п. 1.2, 2.1):** 3000 / 2500 голосовых вызовов в день подтверждены только
  заявлением портала Mango («10 000 звонков за час» для голосового робота); БЗ и шаблон
  v4 лимитов не задают. Фактическая скорость зависит от числа каналов робота (платная
  услуга «Многоканальный робот»), рабочего времени кампании и услуги МАВ. Объём 3000 SMS
  в день (п. 1.5) не подтверждён — «Нет данных»: число контактов кампании рассылки
  «зависит от версии продукта».
- **Интеграция с БД Заказчика (п. 1.1, 2.7, 3.2, 4.1, 4.4):** у Mango есть API ВАТС
  (задания кампании, пользовательские поля, статистика) и HTTP-запросы робота к внешним
  системам, но обмен с базой данных Заказчика, реестр ремонтных заявок, итоговый план к
  15:00 и бронирование — проектная интеграция с отдельной оценкой сроков и стоимости.
- **Бизнес-логика Заказчика (п. 2.3, 2.5, 4.3, 5.1, 5.1.2):** планирование по трём
  временным интервалам, 12 участкам, бригадам, геозонам и сменам, несколько адресов в
  день, свободные слоты бригад, разбивка отчётов по участкам и «нераспределённые
  задания» в SSOT не описаны — `Нет` / `Частично`. Не подменять расписание кампании
  обзвона планированием бригад.
- **Попытки дозвона (п. 1.4, 2.4):** до 10 попыток, альтернативные номера клиента и
  интервал 3 ч при «не берёт трубку» / «недоступен» есть; при «занято» интервал не
  более 3600 с — условие 2–3 ч не выполняется (значения 7200 / 10800 с — только для
  событий АнтиРобота, отдельная услуга).
- **«Этикетка» (п. 1.3, 2.2):** функция ЛК ВАТС, отображается только абонентам Билайн,
  МегаФон, МТС с VoLTE; для массовых вызовов нужна услуга МАВ; наличие городского номера
  конкретного региона не проверялось.
- **MAX (документ 1):** канал MAX — платная опция Манго Диалоги; бот регистрирует
  руководитель организации на стороне MAX (модерация до 2 рабочих дней). Голосовые
  сообщения, колл-трекинг, файлы за 3 месяца, кнопки бота, приём контакта и геопозиции
  для MAX в SSOT не описаны — `Частично`.
- **Платные опции:** голосовые роботы и чат-боты, Многоканальный робот, Бизнес-аналитика,
  SMS-услуги («Индивидуальное имя отправителя СМС»), Манго Диалоги и канал MAX,
  колл-трекинг. `Да` не означает включения в базовый тариф.
- **Не подменять:** автоотправка SMS по v4 2.14.8.1 срабатывает только при неудачном
