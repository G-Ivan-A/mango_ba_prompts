## 2. Словарь продуктов `taxonomy/products.yaml`

- Сервис-коннектор (`connector`, 71 вхождений) — заказная разработка, а не продукт Mango; в словаре нет класса для заказных интеграционных сервисов. Предложение: решить, описывается ли такая разработка профилем `P-API` класса `voice-ucaas` или отдельным классом.
- ВАТС / VPBX API (`vpbx`, 24 вхождений) относится к `voice-ucaas`, который отмечен `in_slice: false`: золотые кейсы этого продукта сейчас вне среза runtime.
- Робот Фил 2.0 (`robot-fil`, 8 вхождений) — `contact-center`, в срезе.

## 3. Золотые кейсы `golden/cases.yaml`

Сейчас набор runtime синтетический (`origin: synthetic`, `structural_only: true`). Предложение: принять кейсы [`golden-set-candidates.json`](golden-set-candidates.json) со значением `origin: run-observed`, где `confirmed_by: user` — реакция БА в диалоге; `expect.outcome: refused` с `defect_class` для дефектных кейсов и `expect.outcome: completed` для негативных.

## 4. Маршрутизация в КБ для внешних API

11 вхождений категорий C15/C18 касаются механизмов внешнего API, описанных в КБ runtime. Предложение: при генерации S-INTEGRATION для каждого использованного метода выписывать ограничения из КБ (журнал — [`../logs/kb-verification.md`](../logs/kb-verification.md)).
