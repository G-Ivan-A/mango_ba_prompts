- «Ошибки ловит БА» — **подтвердилось частично**: 92 из 149 (62%); 57 вхождений БА не отметил.
- «Модель путает раздел 4 (функциональный дизайн) со спецификацией разработки» — **подтвердилось**: 19 из 21 вхождений C01 — в разделе 4; БА переносил детали в раздел 7 (реплики 74, 76).

- «У Робота Фил нет REST API» (утверждение модели, реплика 103) — **не подкреплено**: у робота есть блок «Отправить http-запрос» (ROBOTFIL §5.6); вывод модели об отсутствии API без локатора записан как C09.
