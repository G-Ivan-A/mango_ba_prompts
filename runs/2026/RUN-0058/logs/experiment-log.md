- Публичный API чатов hh.ru существует и покрывает обе стороны обмена; вердикт RUN-0056 «начинать разработку не рекомендуется» более не обоснован.

- Фактические лимиты и задержки: в спецификации для методов чатов не описаны, замеров нет.
