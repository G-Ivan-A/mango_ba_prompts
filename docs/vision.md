# Видение

**Требование без потери смысла.**

Бизнес-аналитик Манго получает полное и проверяемое требование — от
обращения заказчика до согласованного документа — быстрее, чем вручную, и
без потери смысла. Каждое решение прослеживается до источника. Исполнитель
процесса меняется: сначала чат LLM, затем агентный клиент, потоки n8n и
сервер. Шаги процесса, правила и решения человека при этом остаются
прежними.

| Раздел | Содержание |
| --- | --- |
| Миссия | Превращать практику БА Манго в проверенные шаги процессов, измерять каждый шаг статистикой прогонов и переносить шаги на всё более автоматических исполнителей. |
| Для кого | БА Манго ведут процессы. Заказчики и согласующие получают требования. Руководство оценивает ход автоматизации по сайту. |
| Ценность | Предсказуемый процесс, видимые ограничения качества, меньше доработок, решения, которые можно проверить. Численные цели задаёт владелец по базовой линии этапа 1. |
| Ключевая идея | Процесс не зависит от исполнителя. Одни и те же шаги, гейты и проверки работают в чате, в агентном клиенте и в n8n. Переход между этапами доказывается сравнением статистики. |
| Текущий фокус | Этап 1: процесс BCREQ в чате LLM по инструкции сайта и новая статистика прогонов. |
| Долгосрочная цель | Промышленная эксплуатация процессов БА на выделенном сервере в контуре Манго, с теми же гейтами и решениями человека. |

## Чего видение не обещает

- Не заявляет, что процесс уже автоматизирован: этапы 2–4 — план
  ([roadmap](roadmap.md)).
- Не обещает экономический эффект без замера.
- Не повторяет нормы мета-модели Хаба, а ссылается на них
  ([concept](concept.md)).
