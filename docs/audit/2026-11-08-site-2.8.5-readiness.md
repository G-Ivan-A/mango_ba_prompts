## Фактический baseline и границы

05.11.2026 23:44:33 UTC. Commit `gh-pages`
`268aee900e04e8888364c003d7a602cf573a148d` — публикация артефакта.

побайтно сверены с live JSON. Эти два SHA обозначают разные деревья;

и BL-175 этим техническим аудитом не измерены; Да/Нет/Частично сохранены,
provenance-пилот остаётся отложенным BL-182 по прежнему решению.

## Обнаруженные дефекты и изменения

1. При выборе «Архив» A-IN был недоступен: старые process labels не совпадали
   с четырьмя активными фильтрами. Теперь отдельное поле `filterProcesses`
   задаёт применимость, не переписывая исходные `processes`/frontmatter.
   Сбор, требования, решение соответствуют своим стадиям; управление сквозное,
   review относится к требованиям/решению/выпуску, сценарии — к требованиям/решению.
   Исходные операции сохранены; исторический `intake` анкеты проецируется в `ingestion`.
2. Заменённые draft-карточки не находились в Каталоге. Сохранены полные
   [четыре редакции 2.7.0](../../prompts/archive/a-in-v2.7.0/README.md)
   с проверяемым [manifest](../../prompts/archive/a-in-v2.7.0/manifest.json).
   Каталог по умолчанию по-прежнему показывает 39 классов; в архиве теперь 18
   редакций. «Другие архивные» не добавлен: все выбранные архивные тексты имеют
   действующий процесс и операцию. Исторические тексты вне текущего комплекта
   не объявлены заменёнными A-IN без основания.
3. Переходы AIN существовали в тексте, но не как ссылки карточек. Добавлены
   точные ссылки `#processes?ain=AIN-NN`, возвраты и переход к A-CORE; это
   просмотр карточки, не автоматический запуск/допуск. Служебная navigation
   модели остаётся скрытой. В прежний свёрнутый блок проверки добавлены
   операция, стандарты, инструкция, карта, состояние, БЗ и обратные ссылки в архив.
   Общий контракт состояния уже содержит действующий приоритет AIN-21/22/24
   из #474 для всех 39 операций; изменения тел промптов здесь не потребовались.
4. Стандарт раздела 2 предписывал сначала спрашивать БА, RFC §9/10 продолжал
   описывать проект 2.8.1/2.8.2. Добавлены явные актуальные правила с приоритетом:
   retrieval до технической эскалации, ACCESS_GAP, раздел 1 в AIN-14,
   допуск AIN-21 → отдельный AIN-22 → AIN-24/Г-IN. Стандарты и HTML берутся
   из одного текста overlay существующего сборщика. Исторические формулировки
   сохранены и явно обозначены как прежний порядок.

## Отсутствие деградации

Ни один прежний промпт не удалён, не сокращён и не перенумерован. Проверка
сравнивает **все файлы `prompts/` исходного merge #475** с текущими байтами,
а не только длины. Все 24 новых текста/поля маршрута сверяются с файлами и
SHA-256. Четыре архивных файла равны оригиналам merge #465 и телам live 2.7.0.
Физические пути прежних 14 промптов оставлены для RFC/стандартов/RUN.
Ш-0, ФТ, НФТ, UC, ОРР, ограничения, риски, review, выпуск и сценарии не удалены.
CSS, JS справочника и формат reader/переключателя сохранены.

Изменения UI ограничены содержимым карточек, архивной меткой и ссылками в
существующих блоках. Оснований для сокращения информации не понадобилось.

## Воспроизведение и автоматические проверки

```sh
python3 scripts/build_bcreq_a_in.py --check
python3 experiments/issue_423/port_site_v2.py --check
python3 scripts/validate_issue_476_site_readiness.py
make validate-full
```

Регрессия: открыть Каталог → «Архив» → процесс A-IN. До исправления процесс
недоступен (нулевой счётчик); после — видны применимые промпты и четыре snapshot.
`experiments/issue_476/catalog.test.cjs` исполняет настоящие функции app.js.
При `MANGO_APP_SOURCE`, указывающем на app.js merge #475, первая проверка падает;
на исправленном коде проходят OR/AND, процессы/операции, режимы, поиск и история.
Новый валидатор автоматически входит в существующий CI; новый workflow не нужен.

Полный стартовый набор: 102/103 проходят, единственный отказ — служебный
корневой `.gitkeep` стартового commit агента; он удалён по требованию проверки.
Итог локального полного набора: **104/104**, последовательно,
`python3 scripts/validate_all.py --full --jobs 1` (94.85 s). Генератор A-IN
и HTML `--check` подтверждают воспроизводимость. Пять новых Python-проверок,
три Node-регрессии фильтров и прежние тесты проходят. До исправления настоящий
app.js merge #475 даёт два отказа из трёх новых тестов: A-IN не находит
контекст, пересечение операций/режима даёт 0 вместо 4.

Playwright MCP в Chromium: **24/24** полных preview и буфера, **4/4** архивных
копий, **35** прежних по форме карточек, сравнение/копия старой редакции A-CORE,
поиск архива, ссылки в обе стороны и открытие нужной стадии/стандарта,
темы/390 px/отсутствие overflow, ошибка загрузки и восстановление проверены.
[Скрипт](../../experiments/issue_476/browser-smoke.js),
[результат](../../experiments/issue_476/browser-result.json).
