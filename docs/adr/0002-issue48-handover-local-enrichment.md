# ADR-0002: Локальное обогащение `AI_SESSION_HANDOVER_PROMPT.md` (issue #48)

> **Статус:** Accepted · **Дата:** 2026-06-10 · **Issue:**

## Контекст

Issue #48 просит обновить `AI_SESSION_HANDOVER_PROMPT.md`: переосмыслить роль ИИ в
чате (**член команды**, а не «исполнитель без доступа»), добавить разделы «Контекст
чата диалога» и «Проверка шаблонов», заменить «Ограничения чата диалога» на «Канал
взаимодействия с репо», разрешить формировать текст issue в чате и сослаться на
шаблон Хаба `templates/task-for-konard.md`. Issue приводит блоки «Было → Стало» и
полный «финальный текст файла».

**Ядро проблемы.** Структура «Было» в issue (`## 👥 Роль и Иерархия`, `## ⚠️
Ограничения чата диалога`, `## 📝 Формат постановки задач`, отдельный заголовок
`### Шаг 3: READBACK`) **никогда не существовала** в этом файле. Проверено:

1. `git log --all -p -- AI_SESSION_HANDOVER_PROMPT.md` не содержит ни одного из этих
   заголовков — файл всегда имел структуру `EXECUTION` (готовый prompt) /
   `EXPLANATION` (провенанс и источник истины).
2. Файл — **синхронизированный артефакт** из Хаба (issue #46, Хаб PR #208, см.
   [ADR-0001](0001-hub-sync-pr208.md)), закреплён permalink-ом на SHA `117e4a55`
   через `source_hub`/`source_sha`. Действует правило источника истины: «при
   расхождении приоритет у хабовой версии; правки вносятся сначала в Хаб, затем
   переносятся сюда».
3. Текущий шаблон Хаба `templates/htom/AI_SESSION_HANDOVER_PROMPT.md` **не содержит**
   разделов из issue; версии в `main` и на закреплённом SHA `117e4a55` **идентичны**
   (проверено побайтно). То есть желаемых разделов нет и в источнике истины.
4. Файл `templates/task-for-konard.md` в Хабе **отсутствует** (HTTP 404).
5. Каталоги `.github/ISSUE_TEMPLATE/`, `.github/PULL_REQUEST_TEMPLATE.md`,
   `templates/` в mango **отсутствуют**.

Буквальная замена файла «финальным текстом» из issue **стёрла бы** YAML-провенанс
(`source_hub`/`source_sha`), семантическое разделение `EXECUTION ↔ EXPLANATION`,
permalink-провенанс (культура mango, D8 в ADR-0001) — то есть откатила бы результат
issue #46 / PR #47. Это активирует маршрут эскалации `AI_GOVERNANCE.md` («требования
противоречат правилу Хаба → human guidance») и требование чек-листа `CONTRIBUTING.md`
(«отклонение от правила Хаба → ADR»).

## Решение

1. Доставить **намерение** issue (7 содержательных изменений), но **аддитивно**,
   поверх текущего синхронизированного файла, **сохранив** провенанс и структуру
   `EXECUTION/EXPLANATION`.
2. Поведенческое ядро (роль члена команды, проверка контекста чата, учёт канала и
   шаблонов) встроить **в сам готовый prompt** (блок `EXECUTION`), чтобы агент
   реально его получал; развёрнутые формулировки вынести в новые markdown-разделы
   ниже (для человека и как справку).
3. `version` 0.3 → 0.4; `status: draft` сохранён (по требованию issue).
4. Зафиксировать осознанное расхождение с Хабом здесь и в `CHANGELOG.md`; расширение
   подлежит переносу в Хаб (Hub-first) с последующей синхронизацией сюда.

- **Не трогали** промпты в `prompts/`.

  порядок — этот ADR и PR пересматриваются.
