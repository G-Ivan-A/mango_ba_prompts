# ADR-014: проверка полноты источника перед выбором веб-SSOT

## Контекст

Веб-доступность не гарантирует полноту текстового и визуального контекста.
Сравнение всех 194 разделов руководства КЦ 1.26.42 с двумя веб-источниками
даёт 25,31% и 25,09% лексического расхождения. Табличные и структурные
перестановки влияют на число; отсутствие сопоставления не доказывает
отсутствие функции. Источники существенно пересекаются по тексту.

Доказательства, ограничения метода и принципы:
https://github.com/konard/G-Ivan-A-mango_ba_prompts/blob/issue-401-be292b53210f/docs/taxonomy/documentation-audit.md

## Предлагаемое решение

Использовать карту документов как индекс адресного чтения. Порог issue —
≤5% для обоих источников; неизвестная метрика не проходит gate.
Результат выше порога ведёт к комбинированному плану HTML → соответствующий
локальный PDF → проверенный runtime-контекст. Для визуальной зависимости
и спорных прав этот путь нужен независимо от низкого процента текста.

Каждый выбранный фрагмент сохраняет продукт/интерфейс/коннектор/версию,
URL или страницу PDF, дату, хэш и ограничение извлечения. Runtime fallback
применяется только при фактическом наличии нужного описания и происхождения.
В случае недоступности HTML возможен первичный адресный план по подготовленной
runtime-БЗ. Неподтверждённый As-Is остаётся вопросом владельцу продукта,
а потребность Заказчика — вопросом Заказчику.

## Последствия и проверка

docs предпочтителен для первичного извлечения в текущем снимке, но один
снимок не измеряет долгосрочную надёжность. Дублированная статья второго
сайта не считается независимым подтверждением. PDF сохраняет версию и
пробелы сопоставления, но не назначается автоматически более актуальным.
Многократный обход позволяет позже установить частоту изменений.

Проверки пересчитывают опубликованные проценты, полноту PDF-разделов,
координаты операций и границы источников; они не являются LLM-eval.
Это proposed-политика исследования: внедрение нового router, перенос БЗ
и изменение действующих промптов данным решением не выполняются.
