## 1. Ручной процесс БА

### 1.1. Общие правила ручного прогона

| № | Правило |
| --- | --- |
| П-1 | Одна задача — один чат с моделью. Ш-В — исключение: новый чат без истории. |
| П-2 | Промпт копируется целиком кнопкой ⧉ на сайте; первая строка копии — комментарий с ID промпта, его не удалять. |
| П-3 | Входные материалы вставляются в тот же запрос после промпта: запрос Заказчика, ответы на вопросы, выдержки документации продукта. |
| П-4 | Каждый ответ модели заканчивается блоком «Состояние BCREQ». БА проверяет его и вставляет в начало следующего запроса, если чат начат заново. |
| П-5 | Модель только рекомендует следующий шаг и возврат. Шаг, возврат и гейт выбирает БА или согласующий из колонки «Кто решает». |
| П-6 | Пометку `[ТРЕБУЕТСЯ УТОЧНЕНИЕ]` и вопросы 8.4 БА закрывает ответом или переносит Заказчику, модель ответы не придумывает. |
| П-7 | Готовый раздел БА переносит в документ BCREQ; решения записывает в журнал 8.5 (кто, когда, основание). |
