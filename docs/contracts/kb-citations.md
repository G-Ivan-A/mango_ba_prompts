# Контракт атомарных ссылок на БЗ

Контракт запрещает генерировать номер страницы из памяти модели, поискового
сниппета или вручную составленного словаря. Источник истины для документа,
раздела, заголовка и страниц — frontmatter конкретного файла
`kb/processed/**/sections/*.md`, на который ведёт ссылка.

## Обязательный алгоритм

1. Найти кандидатов через `kb/processed/README.md`, `index.md` или `meta.json`.
2. Обрабатывать найденный контекст порциями не более **12 000 входных токенов**.
   После каждой порции сохранить только пути кандидатов и атомарные утверждения;
   длинный поисковый вывод не переносить в следующую порцию.
3. Для каждого утверждения выбрать один конкретный файл раздела и непосредственно
   перед эмиссией перечитать его frontmatter.
4. Собрать `[документ, §раздел «заголовок», с.страницы](путь)` только из полей
   `doc_code` (либо basename `source`), `pdf_section`, `title`, `pages` этого файла.
   Для документа без нумерованных разделов (`pdf_section: "-"`, `"0"` или пусто)
   использовать `[документ, «заголовок», с.страницы](путь)` без искусственного §.
5. Если идентичность раздела можно проверить, но поле `pages` в frontmatter
   отсутствует, номер страницы не угадывать. Разрешён только fallback
   `[документ, §раздел](путь)` без `с.`. Если frontmatter целиком недоступен,
   ссылку не публиковать и эскалировать проверку человеку.
6. Перед публикацией запустить post-processing gate. Любое расхождение документа,
   раздела, заголовка или страниц блокирует PR.

## Текст системного промта

Следующий блок должен добавляться в системный промт генераторов RUN, которые
эмитируют ссылки на БЗ:

```text
Ты формируешь атомарные ссылки только из frontmatter целевого файла
kb/processed/**/sections/*.md. Сначала найди путь через README/index/meta, затем
непосредственно перед каждой эмиссией перечитай frontmatter этого пути. Значения
document, pdf_section, title и pages запрещено брать из памяти, поискового
сниппета, соседнего раздела или захардкоженного словаря. Обрабатывай retrieval-
контекст порциями не более 12 000 входных токенов. Если поле pages отсутствует
во доступном frontmatter, выведи [документ, §раздел](путь) без "с." и явно
пометь страницу как непроверенную. Если сам frontmatter недоступен, не
публикуй ссылку и передай её на human review. После генерации обязательно выполни
python3 scripts/validate_pagination_shift.py <REPORT>; ненулевой код означает,
что артефакт публиковать нельзя.
```

## Машинная проверка

Проверка одного или нескольких отчётов:

```bash
python3 scripts/validate_pagination_shift.py path/to/report.md
python3 scripts/validate_pagination_shift.py report-a.md report-b.md
# Без аргументов: все outputs RUN-0066 и новее со ссылками на kb/processed.
python3 scripts/validate_pagination_shift.py
```

Валидатор разрешает нормализацию тире в диапазонах, но не допускает числового
сдвига. Fallback без страницы разрешён, чтобы недоступность источника не
превращалась в выдуманный номер. Скрипт `scripts/validate_issue_353_ab_rca.py`
вызывает этот валидатор для автоматически обнаруженного набора RUN-0066 и
новее и сам обнаруживается `make validate-full`; поэтому текущая или будущая
регрессия завершает CI ненулевым кодом.

## Запрещённые реализации

- словарь вида `EVIDENCE = {"feature": "..., с.123"}`;
- перенос номера страницы из предыдущего RUN;
- ссылка на общий `KB_index` вместо конкретного раздела;
- исправление сдвига арифметикой (`page + N`) без чтения frontmatter;
- подавление ошибки валидатора или замена страницы на `n/a`.
