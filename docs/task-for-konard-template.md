## Operating Mode

- `Structured`: Конард действует fail-closed и не расширяет scope без human review.
- `Creative`: Конард может выбрать оптимальное решение и сделать обоснованный
  обход scope, если это нужно для цели задачи. Обход фиксируется в PR.

## Специфика работы с Конардом

- **молчание = согласие:** если Пользователь мержит PR без комментариев, решения
  Конарда приняты;
- **комментарий + ручной перезапуск:** если Пользователь оставляет комментарий и
  перезапускает задачу, Конард дорабатывает тот же PR;
- **close:** закрытие PR означает отказ от решения;
- draft PR используется как место отложенной проверки до acceptance.

## Обоснованные обходы

Если задача в Creative режиме требует выйти за исходный scope, PR должен назвать:

- какое правило или ограничение обойдено;
- почему без обхода цель была бы недостигнута или возник бы долг;
- какой файл или решение создано;
- как проверено, что обход не нарушает жёсткие запреты.
