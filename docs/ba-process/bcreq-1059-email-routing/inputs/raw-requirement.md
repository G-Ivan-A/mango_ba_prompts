## Постановка заказчика (дословно)

Реализовать маршрутизацию email-ответов по Точке входа в КЦ: когда оператор
отвечает на входящее письмо, система должна автоматически использовать тот
почтовый ящик, на который это письмо пришло.

## Ключевые бизнес-параметры (из устных уточнений заказчика)

- Оператор КЦ отвечает на входящие email-обращения
- Входящее письмо приходит на один из нескольких настроенных ящиков (Точка входа)
- При ответе система должна автоматически подставлять ящик-источник (тот,
