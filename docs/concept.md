# Концепция

`mango_ba_prompts` — проект автоматизации процессов бизнес-анализа Манго
(телеком). Проект проходит четыре этапа ([roadmap](roadmap.md)). Нормы и
мета-модель БА берутся из Хаба
[`hybrid-Intelligence-lab`](https://github.com/G-Ivan-A/hybrid-Intelligence-lab)
и не противоречат ей.

## Аудитории и точки входа

| Роль | Что ищет | Точка входа |
| --- | --- | --- |
| БА Манго | Процесс, промпты, порядок работы | [Сайт](https://g-ivan-a.github.io/mango_ba_prompts/): «Процессы» и «Дорожная карта» |
| Руководство | Цель, этап, доказательства хода | Сайт: «Дорожная карта», «Дашборд»; [видение](vision.md) |
| AI-исполнитель задач репозитория | Правила работы и проверки | [`ai-governance/ai-governance.md`](../ai-governance/ai-governance.md), [`CONTRIBUTING.md`](../CONTRIBUTING.md) |
| Владелец | Что решить дальше | [Отчёт #413](report/2026-10-31-repository-action-plan.md), [RFC модернизации](rfc/2026-10-repository-modernization.md) |

## Принципы

1. **Статистика неизменна.** `runs/` не правится и не пересчитывается; новые
   требования дают новую статистику.
2. **Изменения — по RFC или ADR.** Решение владельца фиксируется в issue, PR
   или ADR. Слияние PR без комментариев означает принятие (`CONTRIBUTING.md`).
3. **Человек решает на гейтах** на любом этапе. Модель только рекомендует.
4. **Промпт — уровень паттернов.** Промпт содержит паттерны, классы и
   принципы. Вопросы и фразы конкретных задач уходят в golden set
   ([стандарт промптов](../standards/prompt-standard.md#обобщение-содержимого-промпта-issue-413)).
5. **Один источник истины на тип решения.** Сайт — проекция репозитория.
6. **Наследие — свидетельство, а не норма.** Старые артефакты не правятся;
   вывод из них оформляется как наблюдение с замером.

## Два трека улучшений

| Трек | Что входит | Где ведётся |
| --- | --- | --- |
| Проект | Стратегические документы, структура, сайт, валидаторы, стандарты экосистемы, этапы | [RFC модернизации](rfc/2026-10-repository-modernization.md), этот набор документов |
| Промпты и процессы | Содержание процессов (BCREQ и др.), промпты, классы, golden set | [#411](https://github.com/G-Ivan-A/mango_ba_prompts/issues/411) и RFC по промптам |

Трек «Проект» не рассматривает содержание процессов BCREQ (решение владельца
в #413). Он ссылается на процессы как на готовые единицы работы.
