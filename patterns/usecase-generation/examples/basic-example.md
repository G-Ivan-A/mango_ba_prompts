# Basic Example

## Input

```text
User Story: Как супервизор контакт-центра, я хочу видеть просроченные обратные
звонки операторов, чтобы контролировать выполнение SLA.
Product Layer: CCaaS callback control.
Commercial Layer: client-order.
```

## Expected Output Fragment

```markdown
## Overview
- Name: Просмотреть просроченные обратные звонки
- Primary actor: Супервизор
- Goal: Найти callback-задачи, по которым нарушен контрольный срок.

## Preconditions
- В системе есть callback-задачи с назначенным оператором и контрольным сроком.

## Main success scenario
1. Супервизор открывает список callback-задач.
2. Система показывает задачи со статусом "Просрочено".
3. Супервизор фильтрует список по оператору.
4. Система показывает просроченные задачи выбранного оператора.

## Open questions
- Кто задаёт контрольный срок?
- Нужен ли экспорт списка просрочек?
```
