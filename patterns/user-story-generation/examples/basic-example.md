# Basic Example

## Input

```text
Нужно, чтобы супервизор видел просроченные обратные звонки операторов.
Product Layer: CCaaS callback control.
Commercial Layer: internal-product.
```

## Expected Output Fragment

```markdown
## Story
Как супервизор контакт-центра, я хочу видеть просроченные обратные звонки
операторов, чтобы контролировать выполнение SLA и быстрее реагировать на
проблемные обращения.

## Acceptance criteria
- Given оператору назначен обратный звонок с контрольным сроком,
  When срок истек и звонок не выполнен,
  Then задача отображается супервизору как просроченная.
- Given супервизор открыл список просрочек,
  When он фильтрует список по оператору,
  Then система показывает только просрочки выбранного оператора.
```
