# Session Digests — Mango BA Prompts

Единая точка хранения **суммарий длинных сессий** с внешними агентами
(ChatGPT, Claude, другие LLM-чаты) для передачи контекста между чатами в
`mango_ba_prompts`. Файл создан в рамках Smart Sync issue #72 по механизму,
добавленному в Хабе PR #226.

> 🧭 **Назначение в одну строку.** Репозиторий — источник истины; суммарии
> сессий тоже живут в репозитории, а не только в памяти LLM или в пересказе
> Пользователя.

## Кому это нужно (и кому НЕ нужно)

| Роль | Использует механизм? | Почему |
| --- | --- | --- |
| **Пользователь** | Да | Решает, когда пора сохранить summary и какой контекст передать в новый чат. |
| **Внешний агент** | Да | Помогает Пользователю сжать длинный диалог и затем читает индекс перед продолжением. |
| **Исполнитель / агент-исполнитель** (например, Конард) | Нет | Получает задачу, исполняет её через issue → PR → review и не должен жечь токены на суммаризацию во время исполнения. |

> ⛔ **Явное ограничение.** Механизм суммаризации **НЕ влияет на работу
> Исполнителя** при исполнении задач. Если ты читаешь этот файл как
> агент-исполнитель в рамках задачи в репозитории — он для тебя справочный
> артефакт, а не триггер действий.

## Как пользоваться (экономия токенов)

1. При передаче контекста в новый чат читай сначала только **Индекс** ниже.
2. Полную суммарию читай только когда тема релевантна текущей задаче.
3. Не пересказывай контекст из памяти: ссылайся на якорь суммарии и на
   артефакты репозитория.

## Как добавить суммарию

1. Внешний агент спрашивает Пользователя, нужно ли суммаризировать сессию
   (ориентир из handover prompt: ~30 обращений или ~50К токенов).
2. При согласии формируется issue на сохранение суммарии; правки проходят через
   `issue → PR → review`.
3. Добавляется строка в **Индекс** и блок суммарии с якорем
   `## YYYY-MM-DD — тема`.
4. Структура блока: **Контекст**, **Решения**, **Открытые вопросы**,
   **Следующие шаги**. Все ссылки — на артефакты репозитория, не на обсуждения
   в чатах.

## Как удалять решённые вопросы (Traceability)

- Когда открытый вопрос зафиксирован в артефакте (стандарт, ADR, RFC,
  governance-файл), удали его из блока «Открытые вопросы» и оставь ссылку на
  артефакт в «Решениях».
- Когда вся суммария отражена в артефактах, её можно удалить из файла или
  пометить статусом `решено` со ссылкой на артефакты. Файл хранит актуальный
  контекст, а не архив.
