# Архивная версия A-IN — сайт 2.7.0

Здесь сохранены **полные неизменённые файлы** трёх карточек, которые заменены
24 отдельными вызовами A-IN, и совмещённого A-IN one-shot. Архив доступен в
Каталоге через существующий фильтр «Архив», по процессу A-IN и по операции.
Каждая карточка показывает «Архивная версия · сайт 2.7.0», исходную редакцию
на закреплённом SHA и ссылки на заменяющие шаги.

| Прежний вход | Полный файл | Замена |
| --- | --- | --- |
| Ш-А | [Анкета](bcreq-intake-questionnaire-stepwise.md) | AIN-02 после AIN-01 |
| Ш-1 | [Контекст](bcreq-context-understanding-stepwise.md) | AIN-01…24 вместо совмещённого выполнения |
| Ш-2 | [Продукты и стейкхолдеры](bcreq-products-impact-analysis-stepwise.md) | AIN-06…13, запись 2.5 в AIN-22 |
| A-IN one-shot | [Совмещённый приём](bcreq-in-understanding-oneshot.md) | AIN-01…24 отдельными вызовами |

[Manifest](manifest.json) содержит исходный путь/SHA, SHA-256 всего файла и тела,
версию сайта и явные замены. Источник — merge PR #465
`7152e499bac5d73c08f4ac59a0a714c577597e7e`; все четыре тела сверены с JSON,
реально отдаваемым сайтом 2.7.0 08.11.2026. Публикация `gh-pages` —
`268aee900e04e8888364c003d7a602cf573a148d`: это commit **артефакта**, не исходников.

Старые баннеры «редакция действует» внутри файлов — часть зафиксированной
истории; они не разрешают обход AIN-21/22/24. Применять
[текущую инструкцию](../../../docs/ba-processes/bcreq-a-in-execution.md).
Ш-0, ФТ и следующие стадии не заменены декомпозицией: их карточки и
сравнения редакций сохранены. 14 прежних архивных промптов остаются по старым
путям для ссылок из RFC, стандартов и RUN; переносить их физически нельзя
без потери трассировки. Новый каталог истории не скрывает ни один из них.

Текст snapshot копируется в прежнем формате с ID; исходный полный Markdown
доступен отдельной ссылкой. Метаданные Каталога не меняют исходный frontmatter:
для старого `operation: intake` Ш-А используется текущая операция `ingestion`,
а прежние названия стадий проецируются на четыре действующих фильтра.
Фильтр «Другие архивные» не добавлен: все эти редакции имеют применимый
действующий процесс и операцию. OR внутри группы и AND между группами сохранены.
