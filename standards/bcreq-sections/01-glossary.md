# Мета-стандарт раздела 1 «Глоссарий»

> Общие правила, стили и шаблон — в [README](README.md). Носитель —
> [ADR-012](../../docs/adr/2026-10-adr-012-bcreq-meta-standards.md).

## Назначение

Раздел 1 закрепляет один термин за одной сущностью задачи. Заказчик и команда
читают остальные разделы в одних и тех же значениях слов.

## Необходимо и достаточно

**Необходимо:**

- Каждый предметный термин, который встречается в разделах 2–6, есть в разделе 1.
- Определение — одно предложение по схеме «термин — родовое понятие — отличительный
  признак» (BABOK v3, техника 10.23 «Glossary»).
- Термин Заказчика или БА перенесён дословно; связь с термином продукта
  подтверждена локатором документации.
- Термин, найденный в индустриальном словаре с иным значением или иным
  названием, сопровождается блоком «Расхождение с индустриальной практикой»
  (см. ниже).

**Достаточно (лишнее удаляется):**

- Общеупотребительные слова («пользователь» без особого значения, «звонок» в
  бытовом смысле) не вносятся.
- Термин, который не встречается в разделах 2–6, не вносится.
- Аббревиатура без отдельного смысла вносится как ссылка на полный термин, а не
  как второе определение.

## Стиль

Бюрократический: правила БС1–БС5 [README §2.2](README.md#22-бюрократический-стиль-разделы-1-3-4).
Определение не содержит требований («должна»), примеров реализации и
ссылок на интерфейс.

Выбор словарей по продукту — в
[профилях композиции](../bcreq-composition-standard.md#4-профили-продуктов).
Минимальный набор для любой задачи: D1, D2, D11 и словари профилей задействованных
продуктов.

### Порядок источников истины

1. Термин БА или Заказчика — дословно (правило О3, А1.1 анализа 2026-10-20).
2. Глоссарий продукта и БЗ — по [kb-standard](../kb-standard.md) (K1: БЗ не
   переопределяет глоссарий; K2: новый термин — через issue в Хаб, до решения
   `⚠️ требует уточнения`).
3. Индустриальный словарь — **только для сверки**. Он не заменяет термин
   молча.

### Механизм сверки

1. Для каждого термина раздела 1 найти запись в словарях профиля (поиск по
   названию и по англоязычному аналогу из D11).
2. Классифицировать результат:

   | Класс | Что найдено | Критичность |
   | --- | --- | --- |
   | С0 | Совпадает название и значение. | нет |
   | С1 | Значение то же, название другое (синоним). | низкая |
   | С2 | Название то же, значение другое («ложный друг»). | высокая |
   | С3 | Значение уже или шире индустриального. | средняя |
   | С4 | Индустриального аналога нет (продуктовый термин). | нет, пометка «термин продукта» |

3. Для С1–С3 вывести блок «Расхождение с индустриальной практикой» **после**
   раздела 1, не внутри определения:

   ```text
   Термин БА: <термин> — <определение БА>
   Индустриальный термин: <термин> — <определение>, <словарь ID>, <локатор>
   Класс: С1 | С2 | С3
   Рекомендация: оставить с пояснением | заменить | добавить синоним в определение
   Решение: за БА
   ```

4. Решение БА переносится в журнал решений (раздел 8.5). Повторно расхождение
   по тому же термину не поднимается (правило О3).

Блок сверки не нарушает правило О10: название словаря стоит в блоке сверки и в
«Проверке решений», а не в тексте определения.

## Паттерны формулировок

| Корректно | Некорректно | Почему |
| --- | --- | --- |
| «Группа обзвона — набор сотрудников, которым ВАТС одновременно или по очереди направляет входящий вызов.» | «Группа обзвона — это когда звонок идёт сразу нескольким.» | Нет родового понятия; разговорный стиль. |
| «Транскрибация звонка — преобразование записи разговора в текст.» | «Транскрибация (расшифровка, распознавание, STT) — …» | Синонимы в определении запрещены (О9); синоним — в блоке сверки как С1. |
| «Webhook — HTTP-запрос, который система отправляет на адрес внешней системы при наступлении события.» | «Webhook — удобный способ интеграции.» | Оценка вместо признаков; размытое слово «удобный». |
| «Оператор — сотрудник Заказчика, который обрабатывает обращения в КЦ.» + блок сверки «С2: в 3GPP TR 21.905 operator — оператор связи» | «Оператор — оператор.» или молчаливая замена на «агент» | Расхождение С2 подсвечено, решение за БА. |

## Чек-лист валидации

- [ ] Каждый предметный термин разделов 2–6 есть в разделе 1, и каждый термин раздела 1 используется в разделах 2–6.
- [ ] Определение — одно предложение «родовое понятие + отличительный признак», без синонимов.
- [ ] Термины БА и Заказчика перенесены дословно, связь с термином продукта имеет локатор.
- [ ] Каждый термин сверен со словарями профиля; для С1–С3 есть блок расхождения с рекомендацией.
- [ ] Ни один термин не заменён на индустриальный без решения БА.
