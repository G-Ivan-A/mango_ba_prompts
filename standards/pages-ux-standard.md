# Стандарт UX GitHub Pages: дерево процессов/подпроцессов

> Контракт-носитель [ADR-010](../docs/adr/010-pages-ux.md).
> Нормативный словарь [RFC 2119](https://www.rfc-editor.org/info/bcp14)
> (**ДОЛЖНО** / **СЛЕДУЕТ** / **МОЖНО**). Версия `draft` до утверждения
> Пользователем (issue #97).

## Стороны и область

Контракт обязывает всех, кто формирует вид «процессы → подпроцессы → промпты» на
GitHub Pages-сайте репозитория. Источник истины — детальные карты
[docs/ba-processes/00-index.md](../docs/ba-processes/00-index.md) (9 процессов БА;
подпроцесс = строка-шаг карты). Контракт **НЕ вводит** новых операций, **НЕ
меняет и НЕ создаёт** промпты, **НЕ отменяет** `risk_analysis` — он только
визуализирует существующую карту (НФТ совместимости).

## 1. Полный список (слой данных)

- **Правило U1 (полнота источника).** Генератор
  ([scripts/generate-pages-data.mjs](../scripts/generate-pages-data.mjs))
  **ДОЛЖЕН** строить `site/data/process-tree.json` как **полный** список всех
  процессов и подпроцессов из 00-index.md. Каждому подпроцессу **ДОЛЖНЫ**
  присваиваться флаг `hasPrompts` и тип покрытия `kind`.

| `kind` | Условие | `hasPrompts` |
| --- | --- | --- |
| `direct` | есть активный промпт, шаг не помечен «вручную» | да |
| `support` | есть активный промпт + пометка «Выполняется вручную» | да |
| `gap` | нет активного промпта, есть «Требуется разработка промпта» | нет |
| `archive` | ссылка только на `prompts/archive/` | нет |
| `manual` | нет ссылок на промпты | нет |

- **Правило U3 (определение «есть промпт»).** Подпроцесс имеет промпт
  (`hasPrompts = true`) **тогда и только тогда**, когда есть ≥ 1 ссылка на
  **активный** файл `prompts/<name>.md`. Ссылки на `prompts/archive/` **НЕ
  ДОЛЖНЫ** считаться промптом (U3).

## 2. Жёсткое требование: только узлы с промптами (слой отображения)

- **Правило U2 (жёсткое требование ФТ-8).** Интерфейс **ДОЛЖЕН** выводить
  **только** те подпроцессы, у которых `hasPrompts === true`, и **только** те
  процессы, у которых есть хотя бы один такой подпроцесс (`subprocessShown > 0`).
  Процесс без промптов **ДОЛЖЕН** быть скрыт целиком.
- **Правило U9 (трассируемость узла).** Каждый показанный подпроцесс **ДОЛЖЕН**
  давать ссылку на свой файл(ы) промпта в репозитории (полный URL), чтобы
  утверждение «есть промпт» было проверяемым (НФТ прослеживаемости).

> Текущее состояние (сверено 2026-06-16): показано **25 из 38** подпроцессов в
> **8 из 9** процессов (процесс 7 «Статистика» скрыт). Обоснование чисел —
> [ADR-010 §2](../docs/adr/010-pages-ux.md).

## 3. Порог дерева (> 20 → раскрывающийся список)

- **Правило U4 (порог дерева ФТ-8).** Если число **показанных** подпроцессов
  `> 20` (`treeThreshold = 20`, задан issue #97), интерфейс **ДОЛЖЕН**
  использовать дерево (раскрывающийся список): узлы по умолчанию **свёрнуты**,
  **ДОЛЖНЫ** быть элементы управления «развернуть/свернуть». При `≤ 20`
  интерфейс **МОЖЕТ** рендерить плоский развёрнутый список.
- **Правило U8 (доступность).** Дерево **ДОЛЖНО** использовать нативную
  семантику раскрытия (`<details>`/`<summary>`) или паттерны ARIA
  Disclosure/TreeView, быть управляемым с клавиатуры (WCAG, ARIA APG).

## 4. Механизм незавершённых подпроцессов (жёсткое требование ФТ-7)

- **Правило U5 (сохранение и авто-появление).** Подпроцесс без промпта
  (`gap`/`manual`/`archive`) **НЕ ДОЛЖЕН** удаляться из `process-tree.json`. При
  добавлении активного промпта (правка 00-index.md) регенерация **ДОЛЖНА**
  автоматически перевести узел в `direct`/`support` и показать его — **без правки
  кода UI**. Это Pages-проекция процессного механизма незавершённости
  ([ADR-009](../docs/adr/009-bcreq-formation-process.md), B4-B7).

## 5. Совместимость, масштабируемость, анти-фабрикация

- **Правило U6 (без выдуманных данных).** Дерево **ДОЛЖНО** строиться только из
  00-index.md; рукописные процессы/подпроцессы/промпты в UI **ЗАПРЕЩЕНЫ**. Ссылки
  на промпты **ДОЛЖНЫ** разрешаться в реально существующие файлы `prompts/`.
  Выдуманные команды (KK, UCaaS, DIG, AI, ANL, HW, SEC) **НЕ ДОЛЖНЫ** появляться.
- **Правило U7 (масштабируемость).** Добавление процесса/подпроцесса/промпта/
  команды **ДОЛЖНО** требовать только правки markdown-источника и регенерации;
  код UI меняться **НЕ ДОЛЖЕН**. Это поддерживает рост 9 → больше процессов и
  2 → 10+ команд.

## Критерии соответствия (DoD)

- [ ] `process-tree.json` содержит полный список (все процессы/подпроцессы) с
      `hasPrompts` и `kind` (U1, U3).
- [ ] Интерфейс показывает только узлы с промптами; процессы без промптов скрыты
      (U2); каждый узел ссылается на файл промпта (U9).
- [ ] При > 20 показанных подпроцессах используется свёрнутое дерево с
      «развернуть/свернуть» (U4); дерево доступно с клавиатуры (U8).
- [ ] Узлы без промптов сохранены и авто-появляются после регенерации (U5).
- [ ] Дерево построено только из 00-index.md; нет выдуманных данных/команд (U6);
      добавление сущностей не требует правки кода UI (U7).
- [ ] `node scripts/generate-pages-data.mjs` отрабатывает без ошибок.
- [ ] `python3 scripts/validate_issue_97_ontology_standards.py` проходит.
