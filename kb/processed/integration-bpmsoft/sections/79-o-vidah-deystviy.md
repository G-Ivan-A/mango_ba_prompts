# О видах действий

> Трассировка: PDF §2.5 · сквозные стр. 58-60 · источники: ч.1 `kb/sources/integration-bpmsoft/Mango_office_integration_BPMSoft.pdf` с.58-60.

При настройке правил, Вам доступен следующий набор действий в BPMSoft:

| Действие | Пояснение |
| --- | --- |
| Загрузить сущности<br>из контекста | При исходящем звонке со страницы, формируется<br>контекст вызова, который может иметь ссылки на<br>различные сущности, которые можно будет связать<br>со звонком впоследствии. |
| Загрузить сущности,<br>привязанные к<br>сущности 2 | Сущность1, которая имеет отношение к сущности2<br>подгружаются в память обработчика. |
| Загрузить сущности,<br>связанные с<br>участниками звонка | В память обработчика загружаются сущности из БД,<br>которые имеют связь с каким-либо из<br>потенциальных участников звонка (отображены в<br>CTI). |

| Действие | Пояснение |
| --- | --- |
| Загрузить сущности,<br>связанные с<br>участниками звонка<br>с учетом<br>ответственного | В память обработчика загружаются сущности из БД,<br>которые имеют связь с каким-либо из<br>потенциальных участников звонка (отображены в<br>CTI) + оператор является ответственным в этой<br>сущности. |
| Задать переменную | Создать в памяти переменную и присвоить ей<br>значение. |
| Назначить<br>ответственным | Текущий пользователь, который снял трубку и ведет<br>звонок записывается в качестве ответственного в<br>сущность1 (поле OwnerId). |
| Ничего не делать | Не выполнять никаких действий в BPMSoft. |
| Открыть и создать | - |
| Открыть карточку<br>контрагента | Открыть карточку контрагента, связанного со<br>звонком. |
| Открыть последнюю<br>созданную сущность | Открывается самая свежая из сущностей, которая<br>участвовала в обработке и находится в данный<br>момент в памяти обработчика. |
| Открыть сущность | В BPMSoft открыть сущность. Пользователю<br>предлагается открыть окно сущности. |
| Перейти на другую<br>строку действий | Если правило истинно, то выполнить переход к<br>правилу, номер которого указан в поле “Значение”. |
| Привязать данные<br>карточки к звонку и<br>звонок ко всем | - |
| Привязать к звонку | Сущность1 привязывается к звонку (если в<br>обработке (стеке) несколько сущностей, то<br>привязывается самая последняя в обработке -<br>свежая). |
| Привязать первую<br>сущность ко второй | Сущность1 записывается в соответствующее поле<br>сущности2 (должна быть связь на уровне БД). |
| Проверить<br>переменную | Проверяет сущность, если не истина, то ничего не<br>происходит. Если истина, то происходит переход на<br>строку указанную в формуле<br><Переменная=значение;номер, куда переходим>. |
| Создать новую<br>сущность | Создается новая сущность и помещается в стек<br>обработчика, как самая последняя (свежая) запись<br>указанного типа. |
