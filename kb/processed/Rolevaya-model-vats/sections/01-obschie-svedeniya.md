# 1. Общие сведения

> Трассировка: PDF §1 · сквозные стр. 4-5 · источники: ч.1 `kb/sources/Rolevaya-model-vats/Rolevaya-model-VATS_1_26_08.pdf` с.4-5.

Ролевая модель предназначена для разграничения прав доступа пользователей в системе. Она определяет, какие действия пользователь может выполнять и какие разделы интерфейса ему доступны. Доступ пользователя определяется назначенной ему ролью. Роль представляет собой набор прав доступа. Каждое право отвечает за возможность выполнения конкретного действия в системе. Например, право может разрешать: • просмотр аналитики • редактирование карточек сотрудников • управление настройками системы • доступ к финансовым данным Если роль содержит соответствующее право, пользователь может выполнять это действие. Если право отсутствует, функция системы недоступна. Ролевая модель позволяет: • ограничивать доступ к функциям системы • разделять полномочия между сотрудниками • защищать административные функции • управлять доступом к конфиденциальной информации В Виртуальной АТС MANGO OFFICE используются роли и права доступа, которые хранятся и обрабатываются механизмом ролевой модели.
