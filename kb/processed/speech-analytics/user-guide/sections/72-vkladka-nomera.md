# Вкладка Номера

> Трассировка: PDF §10.4 · сквозные стр. 123-124 · источники: ч.1 `kb/sources/speech-analytics/RECHEVAYA-ANALITIKA_1.26.18.pdf` с.123-124.

![Изображение, стр. 123](../images/72-vkladka-nomera-1.png)

Заполните поля: Номер - если к вашей АТС подключены номера какого-то оператора связи, и вы хотите сделать их доступными через сип-транк, их необходимо указать здесь. Формат ввода номера - E.164 без пробелов, например 74951234567. Комментарий - информация произвольного характера, не более 50 символов. Поле не обязательно для заполнения; Укажите желаемые направление вызовов. В зависимости от выбора направления через SIP Trunk пользователь cможет: 1. Входящие - номер будет отображен в списке номеров других операторов связи в разделе “Номера, подключенные к АТС”. Это позволит настроить для него голосовое меню IVR и правила переадресации (распределения) звонков. 2. Исходящие - номер будет отображен в списке доступных для выбора исходящих линий в карточках сотрудников ВАТС. При выборе его в качестве исходящий линии и совершении сотрудником исходящего звонка, он будет направлен в сип-транк. Если номер используется (например, в схеме переадресации), при редактировании транка отключить чекбокс «звонить» невозможно. Речевая аналитика | v.1.26.18 123
