# Удалить участника

> Трассировка: PDF §— · сквозные стр. 29-30 · источники: ч.1 `kb/sources/mtalker/UserGuide_mTalker_4Mobile.pdf` с.29-30.

Вы можете удалить участника из чата, который ранее был создан вами и/или тот чат, в котором вам предоставлены права администратора. Вы НЕ можете удалить участника из чата, в котором вам предоставлены права участника. Mango Talker для ОС Android. Руководство пользователя | Версия от 23.08.2024 Для того чтобы удалить участника из чата, на закладке “Чаты” следует: 1) нажмите на строку с названием чата. Будет открыто окно чата; 2) нажмите на заголовок чата. Будут открыты данные чата;

![Изображение, стр. 30](../images/71-udalit-uchastnika-1.png)

3) нажмите кнопку в строке с данными участника, которого нужно удалить. Будет открыто окно с выбором действий над участником; 4) нажмите на пункт “Удалить из чата”.
