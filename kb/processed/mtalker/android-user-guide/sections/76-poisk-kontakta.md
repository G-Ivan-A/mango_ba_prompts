# Поиск контакта

> Трассировка: PDF §— · сквозные стр. 54-55 · источники: ч.1 `kb/sources/mtalker/UserGuide_mTalker_4Mobile 11.06.26.pdf` с.54-55.

В MTalker для поиска контакта можно использовать тот или иной параметр: • имя или фамилия собеседника; • номер / SIP-ID. Не допускается использование регулярных выражений для поиска контакта. Для того чтобы выполнить поиск контакта, на закладке “Контакты” следует:

![Изображение, стр. 54](../images/76-poisk-kontakta-1.png)

1) нажмите на кнопку ; 2) ввести параметр поиска (например, имя или его часть). По мере ввода параметра на закладке “Контакты” будут появляться строки с данными контактов, соответствующих параметру; Mango Talker для ОС Android. Руководство пользователя | Версия от 11.06.2026 3) посмотреть список контактов, соответствующих параметру поиска. Если в списке контактов не отображается нужный вам контакт, то повторите поиск с другими параметрами. Примечание. Нажмите на строку с данными контакта в списке результатов поиска. Будет показана карточка контакта.
