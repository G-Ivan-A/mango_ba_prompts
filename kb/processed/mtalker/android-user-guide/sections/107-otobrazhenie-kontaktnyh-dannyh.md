# Отображение контактных данных

> Трассировка: PDF §— · сквозные стр. 43-44 · источники: ч.1 `kb/sources/mtalker/UserGuide_mTalker_4Mobile.pdf` с.43-44.

В контакте может отображаться сначала имя, потом фамилия или сначала фамилия, а потом имя. Вы можете настроить отображение, для этого на закладке “Контакты” следует: 1) нажмите на аватар в левом верхнем углу. Будет открыт раздел “Настройки”; 2) нажмите на пункт “Контакты”.
