# Описание элементов интерфейса чата/канала

> Трассировка: PDF §— · сквозные стр. 30-31 · источники: ч.1 `kb/sources/mtalker/UserGuide_mTalker_4Mobile 11.06.26.pdf` с.30-31.

Для того чтобы открыть закладку “Чаты”, в основном окне программы следует нажать кнопку

![Изображение, стр. 30](../images/36-opisanie-elementov-interfeysa-chata-kana-1.png)

, затем нажать на строку с данными того или иного чата. Будет открыт чат с выбранным контактом. В общем случае, в окне чата отображаются следующие элементы интерфейса: 1) имя, фамилия собеседника / название чата / название канала, а также статус собеседника; 2) кнопки аудио / видеозвонка собеседнику; 3) история сообщений в чате, см. таблицу ниже; 4) поле для ввода текста сообщения. Mango Talker для ОС Android. Руководство пользователя | Версия от 11.06.2026 Видеоконференция из чата

![Изображение, стр. 31](../images/36-opisanie-elementov-interfeysa-chata-kana-4.png)

В окне чата рядом с кнопкой аудиозвонка доступна кнопка видеоконференции . При нажатии на кнопку выполняется переход к видеоконференции. При открытии чата может отображаться подсказка: «Позвоните с видео, чтобы продемонстрировать экран или увидеть коллегу». Подсказку можно закрыть.
