# Поиск и фильтрации записей

> Трассировка: PDF §— · сквозные стр. 48-49 · источники: ч.1 `kb/sources/mtalker/UserGuide_mTalker_4Mobile 11.06.26.pdf` с.48-49.

Общие сведения Вы можете в журнале вызовов искать записи двумя способами: вручную, автоматически. Поиск вручную выполняется путем просмотра всех подряд записей в журнале вызовов. Автоматический поиск по параметрам записи, в качестве параметра можно указать имя контакта или должность, или номер телефона и другое. Не допускается использование регулярных выражений в параметрах поиска. Поиск в ручном режиме Для того, чтобы провести поиск вручную, в окне MTalker следует:

![Изображение, стр. 48](../images/64-poisk-i-filtracii-zapisey-1.png)

1) нажмите кнопку . Будет открыт раздел “Журнал вызовов”; 2) в выпадающем списке “Все вызовы” (левый верхний угол экрана), выберите раздел журнала, в котором будет выполняться поиск. Рекомендуем выбрать раздел “Все вызовы”; 3) пролистайте список вызовов, чтобы найти нужный вам вызов. Автоматический поиск по параметрам Для того чтобы воспользоваться автоматическим поиском, в основном окне MTalker следует:

![Изображение, стр. 48](../images/64-poisk-i-filtracii-zapisey-2.png)

1) нажмите кнопку . Будет открыт раздел “Журнал вызовов”;

![Изображение, стр. 48](../images/64-poisk-i-filtracii-zapisey-3.png)

2) нажмите кнопку . Будет открыта экранная клавиатура; 3) введите параметр поиска: имя, фамилия, SIP-номер. Не допускается использование регулярных выражений в параметрах поиска. 4) Будут отображены записи журнала вызовов, соответствующие указанному параметру поиска. Mango Talker для ОС Android.
