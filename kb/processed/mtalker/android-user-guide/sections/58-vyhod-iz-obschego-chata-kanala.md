# Выход из общего чата / канала

> Трассировка: PDF §— · сквозные стр. 45 · источники: ч.1 `kb/sources/mtalker/UserGuide_mTalker_4Mobile 11.06.26.pdf` с.45.

Общие сведения Вы можете выйти из общего чата, при этом вы больше не будете получать сообщений и уведомлений из этого чата, а также строка с названием чата будет удалена с закладки “Чаты” из списка ваших чатов и каналов. Если вы являетесь подписчиком канала, то после выхода из чата / канала этот чат / канал НЕ будет удален из MTalker и в нем продолжится публикация сообщений. Если вы обладаете правами администратора, то после вашего выхода из чата / канала будут выполнены следующие действия: • удален канал из MTalker; • подписчики канала не будут получать уведомлений из этого канала. Порядок действий Для того чтобы выйти из общего чата / канала, на закладке “Чаты” следует: 1) нажмите на строку с названием чата или канала; 2) нажмите на заголовок чата или канала. Будут открыты данные чата или канала;

![Изображение, стр. 45](../images/58-vyhod-iz-obschego-chata-kanala-1.png)

3) нажмите кнопку в заголовке чата или канала; 4) нажмите кнопку “Покинуть”. Откроется окно подтверждения; 5) нажмите кнопку “Покинуть”. Будет выполнен выход из чата или канала.
