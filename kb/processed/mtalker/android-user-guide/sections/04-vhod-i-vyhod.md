# Вход и выход

> Трассировка: PDF §— · сквозные стр. 8-9 · источники: ч.1 `kb/sources/mtalker/UserGuide_mTalker_4Mobile 11.06.26.pdf` с.8-9.

Автоматический вход в MTalker Если после установки вы прошли авторизацию в MTalker, то при последующих запусках работы MTalker вход в вашу учетную запись будет выполнен автоматически. Примечание. Чтобы вход в MTalker выполнялся автоматически, вам нужно выходить из вашего профиля пользователя, когда прекращаете работу с MTalker. Выход из MTalker Чтобы выйти из MTalker, в основном окне MTalker следует: 1. нажмите на свой аватар в левом верхнем углу экрана. Будет открыт раздел “Настройки”; 2. нажмите на ваше имя в разделе “Настройки”. Будет открыт раздел “Профиль”; 3. нажмите на кнопку с тремя точками в правом верхнем углу экрана, в разделе “Профиль”. Будет открыто дополнительное меню; 4. нажмите на пункт “Выйти”. Будет выполнен выход из вашей учетной записи MTalker. Mango Talker для ОС Android. Руководство пользователя | Версия от 11.06.2026
