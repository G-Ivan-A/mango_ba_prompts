# Как сохранить номер в телефонной книге

> Трассировка: PDF §— · сквозные стр. 52 · источники: ч.1 `kb/sources/mtalker/UserGuide_mTalker_4Mobile 11.06.26.pdf` с.52.

Вы можете сохранить в телефонной книге тот или иной номер, указанный в журнале вызовов. Для этого, в журнале вызовов следует:

![Изображение, стр. 52](../images/70-kak-sohranit-nomer-v-telefonnoy-knige-1.png)

1) в строке с данными вызова нажмите на кнопку ; 2) нажмите на одну из ссылок: – Создать контакт. Будет предложено выбрать телефонную книгу, в которой будет создан новый контакт; – Добавить в имеющийся (чтобы добавить номер в имеющийся контакт). Будет предложено выбрать контакт, в который будет добавлен номер.
