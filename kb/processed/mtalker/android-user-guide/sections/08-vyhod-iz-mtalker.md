# Выход из MTalker

> Трассировка: PDF §— · сквозные стр. 8 · источники: ч.1 `kb/sources/mtalker/UserGuide_mTalker_4Mobile.pdf` с.8.

Чтобы выйти из MTalker, в основном окне MTalker следует: 1. нажмите на свой аватар в левом верхнем углу экрана. Будет открыт раздел “Настройки”; 2. нажмите на ваше имя в разделе “Настройки”. Будет открыт раздел “Профиль”; 3. нажмите на кнопку с тремя точками в правом верхнем углу экрана, в разделе “Профиль”. Будет открыто дополнительное меню; 4. нажмите на пункт “Выйти”. Будет выполнен выход из вашей учетной записи MTalker.
