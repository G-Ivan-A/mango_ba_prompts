# Конфиденциальность

> Трассировка: PDF §— · сквозные стр. 62-63 · источники: ч.1 `kb/sources/mtalker/UserGuide_mTalker_4Mobile 11.06.26.pdf` с.62-63.

Как удалить историю вызовов и/или сообщений Вы можете удалить следующие личные данные из MTalker: • сообщения: все ваши сообщения из всех чатов, выход из всех групповых чатов; • историю вызовов: удаление всех записей из журнала вызовов; • контакты: удаление всех контактов из группы “Личные” MTalker. Для того чтобы удалить историю вызовов и/или сообщений, в основном окне MTalker следует: 1) нажмите на аватар в левом верхнем углу. Будет открыт раздел “Настройки”; 2) нажмите “Данные и память”; 3) нажмите “Удалить сообщения”, если хотите удалить историю сообщений. Будет открыто окно с предупреждением об удалении данных, в котором нажмите кнопку “Удалить”; 4) нажмите “Очистить историю вызовов”, если хотите удалить историю звонков. Будет открыто окно с предупреждением об удалении данных, в котором нажмите кнопку “Удалить”. На каких устройствах выполнен вход в MTalker Вы можете посмотреть список устройств, на которых выполнен вход в MTalker при помощи вашего логина и пароля. Для этого, в основном окне MTalker следует: 1) нажмите на аватар в левом верхнем углу. Будет открыт раздел “Настройки”; 2) нажмите на пункт “Устройства” в разделе “Настройки”. Будет отображена следующая информация: – список устройств, на которых открыта ваша сессия пользователя; – даты, точное время и IP-адреса, с которых выполнен вход при помощи вашего логина и пароля. Примечание. Чтобы выйти из того или иного сеанса кроме текущего, выполните действия, описанные в “Удаленный выход”. Удаленный выход Если вы забыли выйти из MTalker на том или ином устройстве (например, на ПК), к которому у вас уже нет доступа, то вы можете сделать это удаленно. Для этого, в основном окне MTalker следует: 1) нажмите на аватар в левом верхнем углу. Будет открыт раздел “Настройки”; 2) нажмите “Устройства”; 3) нажмите и удерживайте нажатой строку с данными того устройства, из которого нужно выйти.
