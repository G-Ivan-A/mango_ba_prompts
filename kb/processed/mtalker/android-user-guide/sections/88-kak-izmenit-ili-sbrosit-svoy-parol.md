# Как изменить или сбросить свой пароль

> Трассировка: PDF §— · сквозные стр. 60-61 · источники: ч.1 `kb/sources/mtalker/UserGuide_mTalker_4Mobile 11.06.26.pdf` с.60-61.

Чтобы восстановить пароль для входа в MTalker, в основном окне MTalker следует: 1. выйдите из MTalker. Будет открыто окно “Авторизация”; 2. нажмите на ссылку “Забыли пароль?”. Будет открыто окно “Войдите в ваши аккаунт”. Чтобы войти в MTalker при помощи короткого кода, в окне “Войдите в ваши аккаунт” следует: 1) введите ваш e-mail или номер мобильного телефона, зарегистрированные в вашей ВАТС; 2) нажмите кнопку “Войти”. На вашу почту / телефон будет отправлен короткий код и на экране вашего устройства Android открыты поля для ввода короткого кода; 3) введите короткий код и нажмите кнопку “Войти”. Будет выполнен вход в MTalker. Если вы хотите создать новый пароль, в окне “Войдите в ваши аккаунт” следует: 1) нажать на кнопку “Войти с логином и паролем”. Будет открыто окно “Войти с паролем”; 2) нажать на кнопку “Забыли пароль?”. Будет открыто окно “Создать новый пароль”; 3) введите ваш e-mail или номер мобильного телефона, зарегистрированных в ВАТС; 4) нажмите кнопку “Войти”. На вашу почту / телефон будет отправлен короткий код и на экране вашего устройства Android открыты поля для ввода короткого кода; 5) введите короткий код и нажмите кнопку “Войти”. Будут открыты поля для создания нового пароля; 6) введите новый пароль; 7) нажмите кнопку “Готово”. Будет создан новый пароль для вашего профиля пользователя и показано окно “Авторизация”. Если вы не знаете e-mail или номер мобильного телефона, которые привязаны к вашей учетной записи, то нажмите ссылку “Я не знаю e-mail или номер мобильный”. Будет открыт сайт MANGO OFFICE, раздел “Поддержка”. Прочитайте, где найти логин и пароль в личном кабинете и, где их прописать для удобного входа. Mango Talker для ОС Android.
