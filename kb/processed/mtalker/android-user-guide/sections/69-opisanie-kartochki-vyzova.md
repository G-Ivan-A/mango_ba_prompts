# Описание карточки вызова

Чтобы открыть карточку вызова, в строке с данными вызова следует нажать на пиктограмму . Будет показана карточка вызова, которая, в общем случае, содержит следующие данные: 1) строка с данными абонента, с которым был совершен звонок. В строке отображаются: – имя абонента, загруженное из телефонной книги ВАТС или из вашего мобильного телефона; – номер телефона или sip id абонента; Примечание. Нажав на строку с данными абонента, вы перейдете к карточке абонента. 2) дата и время совершения звонка, а также длительность разговора (отображается опционально); 3) кнопка “Запись разговора” для работы с записью разговора (отображается опционально); 4) кнопка ”Сообщение” для перехода к чату с абонентом “один-на-один”, при регистрации абонента в вашей ВАТС; 5) кнопка ”Заказать обратный звонок” для заказа обратного звонка. Эта кнопка не отображается в записи о групповом звонке; 6) кнопка “Звонок по GSM” для совершения звонка через мобильную сеть. Отображается, если абонент зарегистрировал свой мобильный номер в вашей ВАТС и вызов был совершен на мобильный телефон; 7) кнопка “Отправить СМС” для отправки смс через мобильную сеть. Отображается, если абонент зарегистрировал свой мобильный номер в вашей ВАТС и вызов был совершен на мобильный телефон; 8) кнопка “Создать контакт” для сохранения номера в адресной книге ВАТС, если звонок был совершен на новый номер; 9) кнопка “Добавить к имеющийся” для сохранения номера в адресной книге ВАТС, если звонок был совершен на новый номер; 10) кнопка “Техническая информация” для просмотра технической информации о звонке (отображается опционально); Mango Talker для ОС Android.
