# Как зарегистрировать нового сотрудника и выдать ему логин и пароль для входа в MTalker

> Трассировка: PDF §— · сквозные стр. 3-4 · источники: ч.1 `kb/sources/mtalker/mTalker_User_Guide_ch3_Admin_Guide.pdf` с.3-4.

логин и пароль для входа в MTalker Если у вас есть доступ к Личному кабинету MANGO OFFICE и соответствующие права в ВАТС, Вы можете добавить нового сотрудника ВАТС. С регистрацией в ВАТС, сотрудник получает доступ к MTalker. Примечание. Подробнее о функциях Личного кабинета MANGO OFFICE, вы можете узнать в Справочнике абонента ВАТС. Чтобы зарегистрировать нового сотрудника, необходимо: 1) перейдите по ссылке https://lk.mango-office.ru/ 2) введите логин и пароль от личного кабинета ВАТС; 3) перейдите в раздел “Сотрудники” личного кабинета ВАТС; 4) нажмите на кнопку “Добавить сотрудника”. Будет открыто окно “Новый сотрудник”; 5) заполните данными поля, отмеченные звёздочкой, и нажмите кнопку “Создать”. Будет создан новый сотрудник и на экран выведено соответствующе сообщение; 6) нажмите кнопку “Открыть карточку”. Будет открыта карточка нового сотрудника ВАТС; 7) откройте закладку “Карточка; 8) в группе полей “Вход в продукты MANGO OFFICE” будут указаны – логин: логин для входа в MTalker. Скопируйте его и передайте новому пользователю MTalker; – пароль: поле для отображения пароля, в котором выполните: • нажмите ссылку “Сгенерировать”. В поле “Пароль” будет показан пароль для нового сотрудника; • скопируйте пароль и предайте его новому пользователю MTalker. • Прием звонков” будет указана SIP-адрес нового сотрудника. Нажмите на нее. Будет открыто окно “Учетная запись SIP”. Mango Talker для ОС Windows и Mac. Информация для администратора ВАТС Версия от 23.08.2024
