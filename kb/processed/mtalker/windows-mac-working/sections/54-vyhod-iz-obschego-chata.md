# 5.14. Выход из общего чата

> Трассировка: PDF §5.14 · сквозные стр. 59-60 · источники: ч.1 `kb/sources/mtalker/UserGuide_Windows_mTalker_ch1_Working.11.06.26.pdf` с.59-60.

Общие сведения Вы можете выйти из общего чата, при этом вы больше не будете получать сообщений и уведомлений из этого чата, а также строка с названием чата будет удалена из раздела “Чаты” из списка ваших чатов и каналов. После выхода из общего чата вашего / любого участника чата: • этот чат не будет удален из MTalker и в нем продолжится переписка участников; • для всех участников чата в истории сообщений будет показано уведомление “_имя _пользователя,вышедшего из группы удален(а) из чата”. Порядок действий

Для того чтобы выйти из общего чата, в разделе ”Чаты” следует: 1) кликнуть на строку с названием общей группы, из которой нужно выйти. Будет открыта история сообщений выбранной группы; 2) навести курсор на строку с названием общего чата и нажать правую кнопку мыши. Будет открыто контекстное меню; Mango Talker для сред ОС Windows и Mac. Руководство пользователя | Версия от 11.06.2026 3) выбрать пункт “Удалить и выйти”. Будет открыто окно “Удаление чата”; 4) нажать на кнопку “Удалить и выйти”. Будет выполнен ваш выход из общего чата, будет удален чат из вашего списка чатов и каналов.
