# 8.3. Как начать аудио конференцию

> Трассировка: PDF §8.3 · сквозные стр. 73 · источники: ч.1 `kb/sources/mtalker/mTalker_User_Guide_ch1_Working.pdf` с.73.

![Изображение, стр. 73](../images/174-kak-nachat-audio-konferenciyu-1.png)

Для этого, в основном окне MTalker в разделе “Конференции” следует:

![Изображение, стр. 73](../images/174-kak-nachat-audio-konferenciyu-2.png)

1) нажмите на пункт “Начать аудиоконференцию” ; 2) выбрать участников конференции из списка сотрудников, либо из списка личных контактов. Не более 8; 3) нажмите на кнопку “Позвонить”. Когда абоненты примут звонок, начнется аудио конференция.
