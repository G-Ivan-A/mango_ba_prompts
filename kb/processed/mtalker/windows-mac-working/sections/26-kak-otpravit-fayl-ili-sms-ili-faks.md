# 4.4. Как отправить файл или смс, или факс

> Трассировка: PDF §4.4 · сквозные стр. 33-34 · источники: ч.1 `kb/sources/mtalker/UserGuide_Windows_mTalker_ch1_Working.11.06.26.pdf` с.33-34.

Отправка файлов и изображений Вы можете передавать в чат документы, фотографии и другие файлы. Существуют следующие ограничения: • отправить файл можно только собеседнику, зарегистрированному в вашей ВАТС; • отправка файлов удаленным (уволенным) сотрудникам не поддерживается. Возможно отправить файл как с сопровождающим текстовым сообщением, так и без него. Отправка без сопровождающего сообщения

![Изображение, стр. 33](../images/26-kak-otpravit-fayl-ili-sms-ili-faks-1.png)

Для того чтобы отправить файл без сопровождающего текста, в разделе”Чаты” следует: 1) кликнуть на название чата, в который нужно отправить файл; 2) выполните одно из следующих действий:

![Изображение, стр. 33](../images/26-kak-otpravit-fayl-ili-sms-ili-faks-2.png)

– нажмите на кнопку . Будет открыто окно “Выбрать файл”, в котором указать файл и нажать кнопку “Открыть”. Будет отправлен в чат выбранный вами файл; – методом “Drag&drop” перетащите файл из папки, в которой он хранится, на поле “Текст сообщения”. Будет отправлен в чат выбранный файл. Отправка с сопровождающим сообщением Для того чтобы отправить файл с сопровождающим текстовым сообщением в разделе”Чаты” следует: 1) файл, который нужно отправить, скопируйте в буфер обмена вашего ПК (Ctrl+C); 2) кликнуть на строку с данными чата, в который нужно передать файл. Будет открыта история сообщений в выбранном чате; 3) кликнуть на поле “Текст сообщения” и нажать на клавиатуре “Ctrl+V”. Будет открыто окно “Отправить”; 4) ввести сопровождающий текст в поле “Комментарий”;

![Изображение, стр. 33](../images/26-kak-otpravit-fayl-ili-sms-ili-faks-3.png)

5) нажать на кнопку “Отправить” . Будут отправлены в чат файл и сопровождающее сообщение. Mango Talker для сред ОС Windows и Mac. Руководство пользователя | Версия от 11.06.2026 Отправка СМС и факса Отправить смс и/или факс возможно: • на номер телефона, ранее зарегистрированный в вашей ВАТС; • на произвольный номер телефона. Отправка на номер, зарегистрированный в вашей ВАТС Для того чтобы отправить СМС или факс на номер телефона, зарегистрированный в вашей ВАТС, в основном окне MTalker следует:

![Изображение, стр. 34](../images/26-kak-otpravit-fayl-ili-sms-ili-faks-4.png)

1) нажать на кнопку . Будет открыт раздел “Контакты”; 2) найдите контакт, которому нужно передать СМС / факс и кликните на строку с данными контакта. Будет открыт профиль контакта; 3) проверить наличие номера телефона в профиле: – если в профиле контакта указан номер телефона, то этому пользователю возможно отправить СМС / факс; – если в профиле нет номера телефона, то этому пользователю нельзя отправить СМС / факс. Примечание. Рекомендуется зарегистрировать ваш номер мобильного телефона в вашей ВАТС. Вам будет доступна возможность совершать и принимать звонки, сообщения и факсы через вашу ВАТС при помощи MTalker. 4. наведите курсор на строку с данному номера телефона. Будет показана дополнительная

![Изображение, стр. 34](../images/26-kak-otpravit-fayl-ili-sms-ili-faks-5.png)

кнопка ; 5. нажмите на нее и выберите один из следующих пунктов: – пункт “Написать SMS”, если нужно отправить СМС. Будет открыт раздел “Чаты”. Далее, следует: • ввести текст СМС в поле “Текст сообщения” и нажать на кнопку “Enter”. Будет отправлено СМС выбранному ранее контакту, текст отправленной СМС показан в истории сообщений; – пункт “Написать сообщение”, если нужно отправить факс. Будет открыто окно программы “Проводник”. Далее, следует • выбрать файл для отправки. Будет открыто окно “Отправка файла”, в котором выбрать отправку немедленно или укатите время отправки факса. Затем,нажмите кнопку “Отправить”.
