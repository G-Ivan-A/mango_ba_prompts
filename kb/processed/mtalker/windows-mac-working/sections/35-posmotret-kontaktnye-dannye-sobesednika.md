# 4.13. Посмотреть контактные данные собеседника

> Трассировка: PDF §4.13 · сквозные стр. 42 · источники: ч.1 `kb/sources/mtalker/UserGuide_Windows_mTalker_ch1_Working.11.06.26.pdf` с.42.

Вы можете быстро перейти из чата в карточку вашего собеседника. Будет выведена на экран карточка вашего собеседника, в которой указаны его контактные данные: имя, фамилия, телефоны, адрес электронной почти и прочее.
