# 5.2. Как создать общий чат или канал

> Трассировка: PDF §5.2 · сквозные стр. 49-50 · источники: ч.1 `kb/sources/mtalker/UserGuide_Windows_mTalker_ch1_Working.11.06.26.pdf` с.49-50.

Общий чат Для того чтобы создать общий чат, в основном окне MTalker следует:

![Изображение, стр. 49](../images/42-kak-sozdat-obschiy-chat-ili-kanal-1.png)

1) нажать на кнопку “Чаты” . Будет открыт раздел “Чаты”;

![Изображение, стр. 49](../images/42-kak-sozdat-obschiy-chat-ili-kanal-2.png)

2) нажать на кнопку . Будет открыто дополнительное меню; 3) выбрать пункт “Создать чат”. Будет открыто окно “Выберите участников чата”; 4) в строке поиска введите имя собеседника, которого нужно добавить в чат или найдите имя собеседника в общем списке; 5) активировать переключатель в строке с именем каждого собеседника, который хотите добавить в чат; 6) нажать на кнопку “Далее”. Будет открыто окно “Создание группового чата”; 7) введите название общего чата, при необходимости добавьте описание чата, затем нажмите кнопку “Создать”. Канал Для того чтобы создать канал, следует:

1) нажать на кнопку . Будет открыт раздел “Чаты”;

<!-- изображение на стр. 49: байты не извлечены (PyMuPDF недоступен) -->

2) нажать на кнопку . Будет открыто дополнительное меню; 3) выбрать пункт “Создать канал”. Будет открыто окно “Новый канал”; 4) ввести название канала, при необходимости ввести описание канала; 5) выберите тип канала: открытый канал, закрытый канал; 6) нажмите кнопку “Далее”; 7) в строке поиска введите имя собеседника, которого нужно добавить в канал или найдите имя собеседника в общем списке; 8) активировать переключатель в строке с именем каждого собеседника, который хотите добавить в канал; 9) нажать на кнопку “Создать”.
