# 9.2. Поиск контактов по произвольному параметру

> Трассировка: PDF §9.2 · сквозные стр. 96 · источники: ч.1 `kb/sources/mtalker/UserGuide_Windows_mTalker_ch1_Working.11.06.26.pdf` с.96.

Для того чтобы выполнить поиск контакта, в основном окне MTalker следует:

![Изображение, стр. 96](../images/97-poisk-kontaktov-po-proizvolnomu-parametr-1.png)

1) нажать на кнопку . Будет открыт раздел “Контакты”; 2) при необходимости, выбрать группу контактов, в которой будем искать контакт, нажав

![Изображение, стр. 96](../images/97-poisk-kontaktov-po-proizvolnomu-parametr-2.png)

кнопку ;

![Изображение, стр. 96](../images/97-poisk-kontaktov-po-proizvolnomu-parametr-3.png)

3) в поле “Поиск” ввести параметр поиска (например, имя или его часть). Будет выполнен поиск контакта и отображен список контактов, соответствующих параметру поиска; 4) посмотреть список контактов, соответствующих параметру поиска. Если в списке контактов не отображается нужный вам контакт, то повторите поиск с другими параметрами; 5) кликните на строку с данными контакта в списке контактов. Будет показана карточка контакта.
