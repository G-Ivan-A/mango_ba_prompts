# 5.4. Добавить участника

> Трассировка: PDF §5.4 · сквозные стр. 55-56 · источники: ч.1 `kb/sources/mtalker/UserGuide_Windows_mTalker_ch1_Working.11.06.26.pdf` с.55-56.

Вы можете добавить участника в общий чат / канал, если вам предоставлены соответствующие права доступа. Удалить участника может только администратор этого чата / канала. Для того чтобы добавить участника в общий чат, в разделе ”Чаты” следует: 1) кликнуть на строку с названием целевого чата / канала. Будет открыта история сообщений в данном чате / канале; 2) нажмите на перечень участников чата под названием чата. Будет открыто окно “Информация о чате”;

![Изображение, стр. 55](../images/44-dobavit-uchastnika-1.png)

3) нажмите на кнопку “Добавить участников” ; Mango Talker для сред ОС Windows и Mac. Руководство пользователя | Версия от 11.06.2026 4) установите “галочку” в строке с данными участников, которых надо добавить в чат; 5) нажмите кнопку “Добавить”. Выбранные участники будут добавлены в чат.
