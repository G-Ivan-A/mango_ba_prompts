# 9.5. Личные контакты

Добавление нового контакта Вы можете сохранить свой личный контакт во внутреннюю телефонной книгу MTalker. Для этого, в основном окне MTalker следует:

![Изображение, стр. 97](../images/100-lichnye-kontakty-1.png)

![Изображение, стр. 98](../images/100-lichnye-kontakty-2.png)

2) нажать на кнопку . Будет открыто дополнительное меню; 3) выбрать пункт “Личный контакт”: 4) заполните поля для ввода нового контакта; 5) нажмите кнопку “Сохранить”. Будет добавлен новый личный контакт. Редактирование Вы можете редактировать личный контакт во внутренней телефонной книге MTalker. Для этого, в основном окне MTalker следует:

![Изображение, стр. 98](../images/100-lichnye-kontakty-3.png)

1) нажать на кнопку . Будет открыт раздел “Контакты”;

![Изображение, стр. 98](../images/100-lichnye-kontakty-4.png)

2) нажмите кнопку и установите “галочку” в пункте “Личные”; 3) выполните одно из следующих действий:

![Изображение, стр. 98](../images/100-lichnye-kontakty-5.png)

– нажать на кнопку в строке с именем контакта. Будет открыто дополнительное меню, в котором выбрать пункт “Редактировать карточку”. Будут доступны для редактирования данные личного контакта; – навести курсор на строку с данными личного контакта и вызвать контекстное меню, далее, выбрать пункт “Редактировать карточку”. Будут доступны для редактирования данные личного контакта. 4) изменить данные личного контакта так, как вам нужно; 5) нажать на кнопку “Сохранить”.
