# 16.8. Звук

> Трассировка: PDF §16.8 · сквозные стр. 122-124 · источники: ч.1 `kb/sources/mtalker/UserGuide_Windows_mTalker_ch1_Working.11.06.26.pdf` с.122-124.

Изменение параметров звуковых устройства Для того чтобы настроить параметры динамиков и микрофона, следует:

![Изображение, стр. 122](../images/135-zvuk-1.png)

1) нажать на кнопку “Аватар” . Будет открыта закладка “Настройки”;

![Изображение, стр. 122](../images/135-zvuk-2.png)

2) нажать на пункт “Звук” . Будут отображены поля для настройки звука; 3) выбрать входное или выходное звуковое устройство (динамик вывода голоса или рингтона, или микрофон); 4) настроить громкость динамиков или микрофона при помощи ползунков регулировки громкости; 5) настроить громкость прочих приложений во время звонка; 6) если вы хотите, чтобы во время звонка MTalker автоматически регулировал уровень громкости микрофона, то активируйте переключатель “Автоматическая регулировка уровня микрофона”. Как быстро переключить вывод звука на стороннюю гарнитуру С помощью настройки “Автоматически использовать подключенные гарнитуры” можно быстро перенаправить звук с гарнитуры по умолчанию на гарнитуру, вновь подключенную к вашему ПК. Автоподнятие трубки для исходящих звонков Данная настройка влияет на обработку звонка при клике по номеру телефона. В MTalker есть следующие настройки автоподнятия трубки: • Автоподнятие трубки через 3 секунды: если настройка включена, то при клике по номеру телефона, звонок будет обрабатываться в MTalker после 3-х секундной паузы; • Автоподнятие трубки для исходящих звонков из CRM-систем: эта настройка удобна при интеграции ВАТС с amoCRM и Битрикс24. Если эта настройка включена, то все клики по номеру телефона в вашей CRM-системе будут обрабатываться в MTalker. То есть, в MTalker будет выполняться вызов номера, по которому вы кликнули в CRM-системе. Для того чтобы настроить автоподнятие трубки для исходящих звонков, следует:
