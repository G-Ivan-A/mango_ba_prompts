# 4.12. Цитирование сообщений

> Трассировка: PDF §4.12 · сквозные стр. 42 · источники: ч.1 `kb/sources/mtalker/UserGuide_Windows_mTalker_ch1_Working.11.06.26.pdf` с.42.

В MTalker вы можете пересылать сообщения своему собеседнику в чате. Для этого, в

![Изображение, стр. 42](../images/34-citirovanie-soobscheniy-1.png)

разделе”Чаты” следует: 1) навести курсор на сообщение, которое надо процитировать и нажмите правую кнопку мыши, чтобы вызвать контекстное меню; 2) выберите пункт “Ответить”. Будет показан текст выбранного вами сообщения в поле “Текст сообщения”; 3) введите текст исходящего сообщения и нажмите на кнопку “Enter”. Будет отправлено исходящее сообщение, содержащее выбранную вами цитату.
