# 17.14. Как посмотреть свой исходящий номер

> Трассировка: PDF §17.14 · сквозные стр. 121 · источники: ч.1 `kb/sources/mtalker/mTalker_User_Guide_ch1_Working.pdf` с.121.

Вы можете узнать свой исходящий номер, то есть номер, с которого вы совершаете внешние звонки (звоните Клиенту). Примечание. Исходящий номер, это настраиваемый параметр. Для настройки исходящего номера у вас должны быть соответствующие права. Для этого: 1) нажать на кнопку “Аватар”. Будет открыт раздел “Настройки”; 2) нажать пункт “Настройки телефонии”; 3) в поле “Исходящий номер” вы можете видеть номер, с которого вы совершаете исходящие звонки.
