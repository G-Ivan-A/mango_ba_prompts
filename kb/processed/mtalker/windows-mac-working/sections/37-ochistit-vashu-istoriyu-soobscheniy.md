# 4.15. Очистить вашу историю сообщений

> Трассировка: PDF §4.15 · сквозные стр. 43 · источники: ч.1 `kb/sources/mtalker/UserGuide_Windows_mTalker_ch1_Working.11.06.26.pdf` с.43.

Чтобы удалить все сообщения из вашей истории сообщений в том или ином чате, в

![Изображение, стр. 43](../images/37-ochistit-vashu-istoriyu-soobscheniy-1.png)

разделе”Чаты” следует: 1) навести курсор на строку с названием чата, историю сообщений которого нужно удалить, и нажать правую кнопку мыши. Будет открыто контекстное меню; 2) выбрать пункт “Удалить историю общения”. Будет открыто окно “Удаление истории”; 3) нажать кнопку “Удалить”. Будет удалена история сообщений в этом чате.
