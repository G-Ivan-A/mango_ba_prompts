# Загрузка настроек кодеков с сервера

> Трассировка: PDF §17.11 · сквозные стр. 120 · источники: ч.1 `kb/sources/mtalker/mTalker_User_Guide_ch1_Working.pdf` с.120.

Чтобы включить загрузку кодеков с севера, следует:

![Изображение, стр. 120](../images/310-zagruzka-nastroek-kodekov-s-servera-1.png)

1) нажать на кнопку “Аватар” . Будет открыта закладка “Настройки”;

![Изображение, стр. 120](../images/310-zagruzka-nastroek-kodekov-s-servera-2.png)

2) нажать на пункт “Звук” ; 3) активировать переключатель “Автоматически получать настройки кодеков с сервера (Autoprovision)”.
