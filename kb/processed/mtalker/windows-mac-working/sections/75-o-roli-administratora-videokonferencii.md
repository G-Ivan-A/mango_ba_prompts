# 7.4. О роли администратора видеоконференции

> Трассировка: PDF §7.4 · сквозные стр. 74-75 · источники: ч.1 `kb/sources/mtalker/UserGuide_Windows_mTalker_ch1_Working.11.06.26.pdf` с.74-75.

Сотрудник, создавший видеоконференцию в MTalker, автоматически становится ее администратором. Администратор видеоконференции может: Mango Talker для сред ОС Windows и Mac. Руководство пользователя | Версия от 11.06.2026 • удалять участников из видеоконференции; • выключать камеру и/или микрофон участников .
