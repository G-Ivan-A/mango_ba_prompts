# Отправка с сопровождающим сообщением

> Трассировка: PDF §4.4 · сквозные стр. 29-30 · источники: ч.1 `kb/sources/mtalker/mTalker_User_Guide_ch1_Working.pdf` с.29-30.

Для того чтобы отправить файл с сопровождающим текстовым сообщением в разделе”Чаты” следует: 1) файл, который нужно отправить, скопируйте в буфер обмена вашего ПК (Ctrl+C); 2) кликнуть на строку с данными чата, в который нужно передать файл. Будет открыта история сообщений в выбранном чате; 3) кликнуть на поле “Текст сообщения” и нажать на клавиатуре “Ctrl+V”. Будет открыто окно “Отправить”; 4) ввести сопровождающий текст в поле “Комментарий”;

![Изображение, стр. 29](../images/61-otpravka-s-soprovozhdayuschim-soobscheni-1.png)
