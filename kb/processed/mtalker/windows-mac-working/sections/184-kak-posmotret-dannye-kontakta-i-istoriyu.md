# 9.4. Как посмотреть данные контакта и историю вызовов

> Трассировка: PDF §9.4 · сквозные стр. 79-80 · источники: ч.1 `kb/sources/mtalker/mTalker_User_Guide_ch1_Working.pdf` с.79-80.

Для этого, в MTalker в разделе “Контакты” следует найдите строку с данными нужного вам контакта и нажмите на нее. Будет открыта карточка контакта, в которой отображаются следующие элементы интерфейса: 1) аватар контакта, автоматически формируется из заглавных букв имени и фамилии; 2) имя и фамилия контакта, должность (если указано при добавлении контакта); 3) иконки для совершения видео и аудио вызова, передачи сообщения; 4) настройки уведомлений контакта и файлы, которыми вы обменивались с этим контактом; 5) ссылка “Общие файлы и ссылки”, нажав которую, будет открыт список общих файлов и ссылок; 6) контактные данные: номера телефонов, SIP-учетная запись, адрес электронной почты; Mango Talker для сред ОС Windows и Mac.
