# 5.6. Отображение списка участников

> Трассировка: PDF §5.6 · сквозные стр. 44 · источники: ч.1 `kb/sources/mtalker/mTalker_User_Guide_ch1_Working.pdf` с.44.

Вы можете посмотреть имена и фамилии участников чата / канала, в котором вы состоите. Для того чтобы посмотреть список участников в разделе”Чаты”

![Изображение, стр. 44](../images/102-otobrazhenie-spiska-uchastnikov-1.png)

следует: 1) кликнуть на строку с названием целевого чата / канала. Будет открыта история сообщений в данном чате / канале; 2) нажмите на перечень участников чата под названием чата. Будет открыто окно “Информация о чате”; 3) ознакомиться с полным перечнем участников чата / канала. Под именами участников указаны их роли в этом чате / канале.
