Если количество участников видеоконференции превышает лимит, установленный тарифом, отображаются следующие уведомления. Организатору: Mango Talker для сред ОС Windows и Mac. Руководство пользователя | Версия от 11.06.2026  отображается pop-up уведомление;  уведомление показывается один раз за конференцию;  в списке участников отображается сообщение с информацией об ограничении.
