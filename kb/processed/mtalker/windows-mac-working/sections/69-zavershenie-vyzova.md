# 6.13. Завершение вызова

> Трассировка: PDF §6.13 · сквозные стр. 66-67 · источники: ч.1 `kb/sources/mtalker/UserGuide_Windows_mTalker_ch1_Working.11.06.26.pdf` с.66-67.

![Изображение, стр. 66](../images/69-zavershenie-vyzova-1.png)

Для того чтобы завершить вызов, в окне проведения сеанса связи нажмите кнопку . Будет выполнено одно из следующих действий: • если проводился групповой сеанс связи, то вы выйдете из сеанса связи, при этом остальные собеседники продолжат общение; • если проводился звонок абоненту в режиме “один-на-один”, то будет завершен сеанс связи.
