# 1.6. Создать новый пароль

> Трассировка: PDF §1.6 · сквозные стр. 19-20 · источники: ч.1 `kb/sources/mtalker/mTalker_User_Guide_ch1_Working.pdf` с.19-20.

Чтобы создать новый пароль для входа, в окне входа в Mango Talker необходимо: 1) нажмите на ссылку “Войти по коду или создать новый пароль”. Будет открыто окно “Войти по коду”; 2) нажмите на кнопку “Создать новый пароль”; 3) введите ваш номер мобильного телефона либо адрес электронной почты, затем нажмите на кнопку “Получить код”. Если такого номера телефона либо адреса электронной почты нет в вашей ВАТС, появится соответствующее сообщение. Если введенный вами номер телефона Mango Talker для сред ОС Windows и Mac. Руководство пользователя | Версия от 23.08.2024 либо адрес электронной почты сохранен в ВАТС, то ВАТС отправит вам сообщение с проверочным кодом; 4) введите проверочный код в поле в одноименное поле в окне входа в Mango Talker. Затем нажмите кнопку “Далее”; 5) введите новый пароль и нажмите кнопку “Готово”. Будет выполнена смена пароля, а также вы войдете в Mango Talker.
