# 1.4. Фоновый режим работы MTalker

> Трассировка: PDF §1.4 · сквозные стр. 20-21 · источники: ч.1 `kb/sources/mtalker/UserGuide_Windows_mTalker_ch1_Working.11.06.26.pdf` с.20-21.

Обзор По умолчанию MTalker работает в обычном режиме, когда основное окно MTalker отображается на экране вашего ПК. Чтобы MTalker не отображался на экране ПК, можно использовать фоновый режим работы. При работе в фоновом режиме, основное окно MTalker скрыто, при этом в окне системных уведомлений ОС Windows, отображается иконка MTalker.

Как переключаться между обычным и фоновым режимами работы Чтобы из обычного режима работы перейти в фоновый, нужно в основном окно MTalker нажать

![Изображение, стр. 21](../images/05-fonovyy-rezhim-raboty-mtalker-7.png)

кнопку “Крестик” , то есть закрыть окно. MTalker будет переведен в фоновый режим работы. Чтобы из фонового режима перейти в обычный режим работы MTalker, нужно в области уведомлений (системном трее) ОС Windows навести курсор на иконку MTalker и вызвать контекстное меню, в котором нажать на кнопку “Открыть”. MTalker будет переведен в обычный режим работы.
