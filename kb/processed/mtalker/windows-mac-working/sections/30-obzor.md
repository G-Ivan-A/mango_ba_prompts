# Обзор

> Трассировка: PDF §1.4 · сквозные стр. 18-19 · источники: ч.1 `kb/sources/mtalker/mTalker_User_Guide_ch1_Working.pdf` с.18-19.

По умолчанию MTalker работает в обычном режиме, когда основное окно MTalker отображается на экране вашего ПК. Чтобы MTalker не отображался на экране ПК, можно использовать фоновый режим работы. При работе в фоновом режиме, основное окно MTalker скрыто, при этом в окне системных уведомлений ОС Windows, отображается иконка MTalker.

| Обычный режим работы | Фоновый режим работы |
| --- | --- |
|  |  |
