# 13.2. Обращения в Манго Диалоги

> Трассировка: PDF §13.2 · сквозные стр. 109 · источники: ч.1 `kb/sources/mtalker/UserGuide_Windows_mTalker_ch1_Working.11.06.26.pdf` с.109.

Раздел предназначен для работы с обращениями в сервисе Манго Диалоги. Пользователь может: 1. Просматривать список обращений. 2. Открывать обращение. 3. Просматривать историю сообщений. Обращения отображаются в виде списка. Для каждого обращения отображается:  наименование;  дата;  последнее сообщение. При открытии обращения отображается история переписки.
