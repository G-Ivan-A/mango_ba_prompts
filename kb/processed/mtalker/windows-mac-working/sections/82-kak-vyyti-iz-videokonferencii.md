# 7.11. Как выйти из видеоконференции

> Трассировка: PDF §7.11 · сквозные стр. 82 · источники: ч.1 `kb/sources/mtalker/UserGuide_Windows_mTalker_ch1_Working.11.06.26.pdf` с.82.

Для того, чтобы выйти из видеоконференции, в окне проведения видеозвонка нажмите кнопку

![Изображение, стр. 82](../images/82-kak-vyyti-iz-videokonferencii-1.png)

. Будет выполнено одно из следующих действий: • если проводился групповой видеозвонок, то вы выйдете из сеанса связи, при этом остальные собеседники продолжат общение; • если выполнялся звонок абоненту, то будет завершен сеанс связи.
