# 5.5. Пригласить по ссылке нового участника

> Трассировка: PDF §5.5 · сквозные стр. 56 · источники: ч.1 `kb/sources/mtalker/UserGuide_Windows_mTalker_ch1_Working.11.06.26.pdf` с.56.

Вы можете создать ссылку на чат и передать ее тому или иному сотруднику. Сотрудник, получив ссылку, нажмет на нее и увидит история сообщений в данном чате / канале. Для того чтобы пригласить по ссылке нового участника в общий чат, в разделе ”Чаты” следует: 1. кликнуть на строку с названием целевого чата / канала. Будет открыта история сообщений в данном чате / канале; 2. нажмите на перечень участников чата под названием чата. Будет открыто окно “Информация о чате”;

![Изображение, стр. 56](../images/45-priglasit-po-ssylke-novogo-uchastnika-1.png)

3. нажмите на кнопку “Пригласить по ссылке” . Будет открыто окно “Пригласить по ссылке”; 4. нажмите кнопку “Копировать”. Будет скопирована на ваш ПК ссылка на данный чат / канал; 5. нажмите кнопку “Ок”, чтобы закрыть окно “Пригласить по ссылке”; 6. отправьте скопированную ссылку через чат MTalker сотруднику, которого хотите пригласить в чат.
