# История вызовов

> Трассировка: PDF §1.3 · сквозные стр. 15-16 · источники: ч.1 `kb/sources/mtalker/mTalker_User_Guide_ch1_Working.pdf` с.15-16.

Раздел “История вызовов” предназначен для отображения журнала учета входящих и исходящих вызовов, совершенных при помощи вашей SIP-учетной записи. Чтобы открыть раздел “История вызовов”, следует в основном окне

![Изображение, стр. 15](../images/24-istoriya-vyzovov-1.png)

MTalker нажать на кнопку . Будет открыт раздел “История вызовов”, в котором отображаются следующие элементы интерфейса:

![Изображение, стр. 15](../images/24-istoriya-vyzovov-2.png)

1) настройка отображения разделов истории вызовов: – Все вызовы: список всех вызовов, относящихся к вашей SIP- учетной записи: входящие, исходящие, пропущенные и проч.; – Пропущенные: список пропущенных вызовов, поступивших на вашу SIP-учетную запись; Mango Talker для сред ОС Windows и Mac. Руководство пользователя | Версия от 23.08.2024 – Записи разговоров: список данных о звонках, которые были записаны сервисом записи разговоров ВАТС; – Голосовая почта: список данных о полученных сообщениях голосовой почты;

![Изображение, стр. 16](../images/24-istoriya-vyzovov-3.png)

2) кнопка фильтрации записей о вызовах по отчетному периоду;

![Изображение, стр. 16](../images/24-istoriya-vyzovov-4.png)

3) строка поиска по журналу вызовов; 4) список всех вызовов на вашей SIP-учетной записи за разные отчетные периоды; 5) подробные сведения о выбранной записи в истории вызовов с кнопками управления записью разговора (отображаются опционально).
