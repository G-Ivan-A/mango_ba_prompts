# 16.12. Сессии пользователя

> Трассировка: PDF §16.12 · сквозные стр. 126-127 · источники: ч.1 `kb/sources/mtalker/UserGuide_Windows_mTalker_ch1_Working.11.06.26.pdf` с.126-127.

Как узнать, на каких устройствах открыты сессии пользователей Вы можете посмотреть список устройств, на которых выполнен вход в MTalker при помощи ваших логина и пароля. Для того чтобы посмотреть список устройств, на которых выполнен вход в MTalker, следует: Mango Talker для сред ОС Windows и Mac. Руководство пользователя | Версия от 11.06.2026

![Изображение, стр. 127](../images/139-sessii-polzovatelya-1.png)

1) нажать на кнопку “Аватар” . Будет открыта закладка “Настройки”;

![Изображение, стр. 127](../images/139-sessii-polzovatelya-2.png)

2) нажать на пункт “Устройства” . Будет отображен список устройств, на которых открыта ваша сессия пользователя. Удаленный выход из MTalker Если вы забыли выйти из MTalker на ПК, к которому у вас уже нет доступа, то сделать это можно удаленно. Чтобы удаленно выйти из MTalker, в списке устройств, на которых открыта ваша сессия пользователя, следует: 1) нажать пиктограмму “Корзина”в строке с данными того или иного устройства, на котором выполнен вход в MTalker. Будет открыто окно “Завершение сессии”; 2) нажать на кнопку “Завершить”. Будет завершена ваше сессия пользователя MTalker на выбранном вами устройстве.
