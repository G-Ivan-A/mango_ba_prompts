# 10.7. Удаление записи из истории вызовов

> Трассировка: PDF §10.7 · сквозные стр. 104-105 · источники: ч.1 `kb/sources/mtalker/UserGuide_Windows_mTalker_ch1_Working.11.06.26.pdf` с.104-105.

Для того чтобы удалить ту или иную запись о вызове, в разделе”История вызовов” следует: 1) навести курсор мыши на строку, которую нужно удалить и нажать правую кнопку мыши. Будет открыто контекстное меню; 2) выбрать пункт “Удалить вызов”. Будет открыто окно “Удаление вызова”; 3) нажать на кнопку “Удалить”. Будет удалена выбранная запись из истории вызовов.
