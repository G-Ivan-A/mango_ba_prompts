# Очистить вашу историю сообщений

> Трассировка: PDF §4.9 · сквозные стр. 37 · источники: ч.1 `kb/sources/mtalker/mTalker_User_Guide_ch1_Working.pdf` с.37.

Чтобы удалить все сообщения из вашей истории сообщений в том или ином

![Изображение, стр. 37](../images/81-ochistit-vashu-istoriyu-soobscheniy-1.png)

чате, в разделе”Чаты” следует: 1) навести курсор на строку с названием чата, историю сообщений которого нужно удалить, и нажать правую кнопку мыши. Будет открыто контекстное меню; 2) выбрать пункт “Удалить историю общения”. Будет открыто окно “Удаление истории”; 3) нажать кнопку “Удалить”. Будет удалена история сообщений в этом чате.
