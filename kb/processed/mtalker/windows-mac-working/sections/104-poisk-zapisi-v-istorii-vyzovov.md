# 10.2. Поиск записи в истории вызовов

> Трассировка: PDF §10.2 · сквозные стр. 100-101 · источники: ч.1 `kb/sources/mtalker/UserGuide_Windows_mTalker_ch1_Working.11.06.26.pdf` с.100-101.

Общие сведения Вы можете искать записи в истории вызовов двумя способами: вручную, автоматически. Поиск вручную выполняется путем просмотра всех подряд записей в истории вызовов. Автоматический поиск по параметрам записи. В качестве параметра можно указать имя контакта или должность, или номер телефона и другие. Не допускается использование регулярных выражений в параметрах поиска. Поиск в ручном режиме

![Изображение, стр. 100](../images/104-poisk-zapisi-v-istorii-vyzovov-1.png)

Для того, чтобы провести поиск вручную, в разделе”История вызовов” следует:

![Изображение, стр. 100](../images/104-poisk-zapisi-v-istorii-vyzovov-2.png)

1) в списке разделов истории вызовов выбрать нужный вам раздел истории: – Все вызовы: в этот раздел вносятся все записи о звонках (пропущенные, входящие и т.д.). – Пропущенные: в этот раздел вносятся записи о пропущенных звонках; – Записи разговоров: в этот раздел вносятся записи о звонках, которые были записаны в файл, который вы можете прослушать; – Голосовая почта: в этот раздел вносятся записи голосовой почты; 2) просмотреть записи о вызовах и найти запись о нужном вам вызове. Список вызовов можно прокрутить вверх и вниз наведя курсор на список вызовов и прокрутив колесико мыши. Mango Talker для сред ОС Windows и Mac. Руководство пользователя | Версия от 11.06.2026 Автоматический поиск по параметрам

![Изображение, стр. 101](../images/104-poisk-zapisi-v-istorii-vyzovov-3.png)

Для того чтобы выполнить автоматический поиск записи, в разделе”История вызовов” в поле “Поиск” ввести параметр поиска, например, номер телефона. Будет выполнен автоматический поиск по указанному вами параметру. Результаты поиска – список номеров, соответствующих введенному параметру – отображен в разделе”История вызовов”.

![Изображение, стр. 101](../images/104-poisk-zapisi-v-istorii-vyzovov-4.png)

При необходимости уточнить поиск, вы можете выбрать нужный вам раздел истории: Все вызовы, Пропущенные, Записи разговоров, Голосовая почта.
