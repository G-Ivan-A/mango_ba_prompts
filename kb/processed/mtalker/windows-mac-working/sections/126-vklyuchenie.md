# 15.2. Включение

> Трассировка: PDF §15.2 · сквозные стр. 113-114 · источники: ч.1 `kb/sources/mtalker/UserGuide_Windows_mTalker_ch1_Working.11.06.26.pdf` с.113-114.

Для того чтобы включить автодозвон, в основном окне MTalker следует:

![Изображение, стр. 113](../images/126-vklyuchenie-1.png)

1) нажмите на иконку “Телефон” ; 2) наберите номер вызываемого абонента при помощи экранной клавиатуры;

![Изображение, стр. 113](../images/126-vklyuchenie-2.png)

3) нажмите на кнопку “Еще”. Будет открыто дополнительное меню; 4) выберите пункт “Автоматический дозвон”. Будет включена функция автоматического набора номера “Автодозвон”. Mango Talker для сред ОС Windows и Mac. Руководство пользователя | Версия от 11.06.2026
