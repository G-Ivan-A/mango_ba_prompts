# Как переключаться между обычным и фоновым режимами работы

> Трассировка: PDF §1.4 · сквозные стр. 19 · источники: ч.1 `kb/sources/mtalker/mTalker_User_Guide_ch1_Working.pdf` с.19.

Чтобы из обычного режима работы перейти в фоновый, нужно в основном

![Изображение, стр. 19](../images/31-kak-pereklyuchatsya-mezhdu-obychnym-i-fo-1.png)

окно MTalker нажать кнопку “Крестик” , то есть закрыть окно. MTalker будет переведен в фоновый режим работы. Чтобы из фонового режима перейти в обычный режим работы MTalker, нужно в области уведомлений (системном трее) ОС Windows навести курсор на иконку MTalker и вызвать контекстное меню, в котором нажать на кнопку “Открыть”. MTalker будет переведен в обычный режим работы.
