# 2.4. Удаление MTalker

> Трассировка: PDF §2.4 · сквозные стр. 23-24 · источники: ч.1 `kb/sources/mtalker/mTalker_User_Guide_ch1_Working.pdf` с.23-24.

Удаление MTalker в среде ОС MacOS выполняется стандартным методом удаления программ с компьютеров Mac. Прочитайте описание метода удаления программ: https://support.apple.com/ru-ru/HT202235 и выполните, в соответствии с этим описанием, удаление MTalker с вашего компьютера Mac. Для того чтобы удалить MTalker в среде ОС Windows следует: 1) открыть окно “Удаление или изменение программы”; 2) навести курсор мыши на строку с данными MTalker и вызвать контекстное меню, в котором выбрать пункт “Удалить”. Будет открыто окно “Удаление MTalker”; 3) при необходимости удалить пользовательские данные, активируйте переключатель “Удалить пользовательские данные”; 4) нажмите кнопку “Удалить”. Будет удален MTalker , после этого отображено окно “Программа удалена”. Mango Talker для сред ОС Windows и Mac. Руководство пользователя | Версия от 23.08.2024
