# Прокси-сервер

> Трассировка: PDF §17.10 · сквозные стр. 117-118 · источники: ч.1 `kb/sources/mtalker/mTalker_User_Guide_ch1_Working.pdf` с.117-118.

Если ваш ПК подключен к информационной сети, в которой необходима авторизация на прокси-сервере, то вы можете в настройках программы включить соответствующую функцию и указать данные авторизации. По умолчанию, в MTalker выключена функция использования прокси-сервера. Для того чтобы настроить подключение к сети через прокси-сервер, следует:
