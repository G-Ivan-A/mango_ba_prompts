# 5.13. Удалить участника

> Трассировка: PDF §5.13 · сквозные стр. 59 · источники: ч.1 `kb/sources/mtalker/UserGuide_Windows_mTalker_ch1_Working.11.06.26.pdf` с.59.

Если вам предоставлены права администратора в общем чате/канале, то вы можете удалить участника.

![Изображение, стр. 59](../images/53-udalit-uchastnika-1.png)

Для того чтобы удалить участника из чата, в разделе”Чаты” следует: 1) кликнуть на строку с названием целевого чата / канала. Будет открыта история сообщений в данном чате / канале; 2) нажмите на перечень участников чата под названием чата. Будет открыто окно “Информация о чате”; 3) навести курсор на имя участника, которого нужно удалить из чата. Будут показаны дополнительные кнопки управления;

<!-- изображение на стр. 59: байты не извлечены (PyMuPDF недоступен) -->

4) нажать на кнопку . Будет открыто дополнительное меню; 5) выбрать пункт “Удалить”. Участник будет удален из чата.
