# 5.3. Добавить участника

> Трассировка: PDF §5.3 · сквозные стр. 43 · источники: ч.1 `kb/sources/mtalker/mTalker_User_Guide_ch1_Working.pdf` с.43.

Вы можете добавить участника в общий чат / канал, если вам предоставлены соответствующие права доступа. Удалить участника может только администратор этого чата / канала. Для того чтобы добавить участника в общий чат, в разделе”Чаты” следует: 1) кликнуть на строку с названием целевого чата / канала. Будет открыта история сообщений в данном чате / канале; 2) нажмите на перечень участников чата под названием чата. Будет открыто окно “Информация о чате”;

![Изображение, стр. 43](../images/99-dobavit-uchastnika-1.png)

3) нажмите на кнопку “Добавить участников” ; 4) установите “галочку” в строке с данными участников, которых надо добавить в чат; 5) нажмите кнопку “Добавить”. Выбранные участники будут добавлены в чат.
