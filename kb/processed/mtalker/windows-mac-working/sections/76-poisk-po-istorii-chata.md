# Поиск по истории чата

> Трассировка: PDF §4.9 · сквозные стр. 35 · источники: ч.1 `kb/sources/mtalker/mTalker_User_Guide_ch1_Working.pdf` с.35.

Для того чтобы найти сообщение в истории проведения чата / канала, в

![Изображение, стр. 35](../images/76-poisk-po-istorii-chata-1.png)

разделе ”Чаты” следует: 1) кликнуть на строку с данными чата, в котором будет выполнен поиск;

![Изображение, стр. 35](../images/76-poisk-po-istorii-chata-2.png)

2) нажать на кнопку . Будет открыто поле для ввода параметра поиска; 3) ввести искомое слово в поле для поиска по вашим чатам и каналам. Достаточно указать первые 3 буквы слова. Будет выполнен поиск целевого слова в выбранном чате, а сообщения, соответствующие параметру поиска будут выделены цветом.

![Изображение, стр. 35](../images/76-poisk-po-istorii-chata-3.png)

Примечание. Чтобы скрыть результаты поиска, нужно нажать на кнопку в поле для ввода параметра локального поиска.
