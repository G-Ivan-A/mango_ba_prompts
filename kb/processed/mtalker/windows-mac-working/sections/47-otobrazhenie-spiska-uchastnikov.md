# 5.7. Отображение списка участников

> Трассировка: PDF §5.7 · сквозные стр. 56-57 · источники: ч.1 `kb/sources/mtalker/UserGuide_Windows_mTalker_ch1_Working.11.06.26.pdf` с.56-57.

Вы можете посмотреть имена и фамилии участников чата / канала, в котором вы состоите. Для

![Изображение, стр. 56](../images/47-otobrazhenie-spiska-uchastnikov-1.png)

того чтобы посмотреть список участников в разделе ”Чаты” следует: 1) кликнуть на строку с названием целевого чата / канала. Будет открыта история сообщений в данном чате / канале; 2) нажмите на перечень участников чата под названием чата. Будет открыто окно “Информация о чате”; 3) ознакомиться с полным перечнем участников чата / канала. Под именами участников указаны их роли в этом чате / канале.
