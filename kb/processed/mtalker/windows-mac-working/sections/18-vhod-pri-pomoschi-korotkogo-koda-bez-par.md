# 3.3. Вход при помощи короткого кода (без пароля)

> Трассировка: PDF §3.3 · сквозные стр. 26 · источники: ч.1 `kb/sources/mtalker/UserGuide_Windows_mTalker_ch1_Working.11.06.26.pdf` с.26.

Важно. Вы можете войти в MTalker без пароля, если к вашей учетной записи ВАТС привязан мобильный телефон или электронная почта. Чтобы войти по короткому коду, в окне входа в MTalker необходимо: 1) нажмите на ссылку “Войти по коду”. Будет открыто окно “Войти по коду”; 2) введите ваш номер мобильного телефона, либо адрес электронной почты, затем нажмите на кнопку “Получить код”. Если такого номера телефона либо адреса электронной почты нет в вашей ВАТС, появится соответствующее сообщение. Если введенный вами номер телефона, либо адрес электронной почты сохранен в ВАТС, то ВАТС отправит вам сообщение с коротким кодом; 3) введите короткий код в окне “Короткий код”. Будет выполнен вход в MTalker.
