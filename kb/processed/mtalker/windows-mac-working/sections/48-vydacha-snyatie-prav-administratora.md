# 5.8. Выдача/снятие прав администратора

> Трассировка: PDF §5.8 · сквозные стр. 57 · источники: ч.1 `kb/sources/mtalker/UserGuide_Windows_mTalker_ch1_Working.11.06.26.pdf` с.57.

Если вам предоставлены права администратора в общем чате/канале, то вы можете менять права других участников этого чата/канала, путем присвоения или снятия прав администратора. Для того чтобы изменить права участника, откройте список участников чата. Чтобы участнику выдать права администратора, в разделе ”Чаты” следует: 1) кликнуть на строку с названием целевого чата / канала. Будет открыта история сообщений в данном чате / канале; 2) нажмите на перечень участников чата под названием чата. Будет открыто окно “Информация о чате”; 3) навести курсор на строку с именем участника. Будут показаны дополнительные кнопки управления;

![Изображение, стр. 57](../images/48-vydacha-snyatie-prav-administratora-1.png)

4) нажать на кнопку . Будет открыто дополнительное меню; 5) выбрать пункт “Назначить администратором”. Будут присвоены права администратора Чтобы снять права администратора чата, в разделе ”Чаты” следует: 1) кликнуть на строку с названием целевого чата / канала. Будет открыта история сообщений в данном чате / канале; 2) нажмите на перечень участников чата под названием чата. Будет открыто окно “Информация о чате”; 3) навести курсор на строку с именем администратора чата. Будут показаны дополнительные кнопки управления;

4) нажать на кнопку . Будет открыто дополнительное меню; 5) выбрать пункт “Снять администратора”. Будут сняты права администратора чата с данного сотрудника.
