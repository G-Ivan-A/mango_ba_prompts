# Когда лучше использовать правило «По маске»

> Трассировка: PDF §4.5.19.4 · сквозные стр. 422-424 · источники: ч.1 `kb/sources/mango-lk-manual/LK_manual_v-123.pdf` с.422-424.

Правило «По маске» удобно, когда вы хотите, чтобы система автоматически подбирала нужный исходящий номер в зависимости от структуры номера клиента — например, по коду города, оператора или диапазону. Когда применять на практике 1. Для региональных звонков по кодам городов Если вы работаете по всей России и хотите, чтобы клиенты видели знакомый код города. Пример: o Маска 7495\d* — звонки в Москву выполняются с московского номера. o Маска 7812\d* — звонки в Санкт-Петербург идут с петербургского номера. Клиент видит «свой» номер и с большей вероятностью ответит.

![Изображение, стр. 423](../images/260-kogda-luchshe-ispolzovat-pravilo-po-mask-1.jpeg)

2. Для отдельных направлений или филиалов Если у вас несколько филиалов или отделов продаж, можно задать разные маски под их зоны ответственности. Пример: o Маска 74212\d* — номера клиентов Дальнего Востока; o Маска 7863\d* — Краснодарский край. Таким образом, каждый отдел работает только со «своими» регионами, а система сама подставляет нужный номер. 3. Для обработки федеральных или сервисных номеров Если нужно выделить звонки по определённым типам номеров (например, 8-800). Пример: o Маска 7800\d* — все вызовы на бесплатные номера проходят через отдельную карусель. Это позволяет анализировать такие звонки отдельно или применять собственные сценарии дозвона. 4. Для фильтрации по оператору связи Можно задать маску по коду оператора (например, +7 999, +7 929 и т. д.) Пример: o Маска 7999\d* — для клиентов на МТС; o Маска 7929\d* — для клиентов на Мегафоне. Это удобно для тестирования, мониторинга или работы с партнерскими базами. 5. Для сложных шаблонов и диапазонов номеров Маски поддерживают регулярные выражения, что позволяет задавать точные диапазоны. Примеры: o 7495\d{7} — все 11-значные номера с кодом +7 495; o 7495\d*|7499\d* — номера, начинающиеся с +7 495 или +7 499; o 7495[5–7][5–7][5–7] — диапазон номеров от +7 495 555-00-00 до +7 495 777-99-99. Такие шаблоны полезны для компаний, работающих с крупными сегментами номеров. Почему это удобно ● Не нужно вручную выбирать исходящий номер — система делает это сама.

● Можно точно контролировать, какие клиенты получают звонки с каких номеров. ● Повышается дозвон и доверие клиентов, так как им звонят с локальных номеров. ● Упрощается анализ статистики — каждая маска может представлять отдельную кампанию или проект. Советы по настройке масок ● Используйте маски, если один префикс охватывает несколько направлений, а правила по регионам недостаточны. ● Для надёжности создавайте запасную карусель без маски — на случай, если номер не подходит ни под одно правило. ● Не используйте слишком общие маски (7\d*) — это приведёт к тому, что карусель будет срабатывать почти всегда.
