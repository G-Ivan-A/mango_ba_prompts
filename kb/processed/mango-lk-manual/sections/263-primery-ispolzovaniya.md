# 4.5.19.6. Примеры использования

> Трассировка: PDF §4.5.19.6 · сквозные стр. 433-434 · источники: ч.5 `kb/sources/mango-lk-manual/LK_manual_v-121часть-5.pdf` с.29-30.

Кейс 1. Разные проекты и кампании Задача: Отдел продаж ведёт несколько независимых проектов (например, банковские продукты и страховые услуги). Нужно, чтобы звонки по каждой кампании шли «со своих» номеров. Решение: ● для каждого проекта создается отдельная карусель, ● в нее добавляются только сотрудники и номера, относящиеся к этой кампании, ● при звонках автоматически подставляются правильные номера. Польза: проекты не пересекаются, проще вести аналитику, а сотрудники работают только в рамках своих задач. Кейс 2. Приоритетный префикс для служебных звонков Задача: в компании нужно быстро различать служебные и клиентские звонки. Решение: ● создаётся карусель с правилом «По префиксу» (например, 45), ● сотрудники набирают служебные номера с этого префикса, ● такие звонки всегда идут через заданную карусель, независимо от региона или маски. Польза: гибкая маршрутизация: служебные звонки обрабатываются отдельно, что облегчает администрирование и анализ. Кейс 3. Обход блокировок операторов Задача: при массовых исходящих вызовах операторы могут ограничивать или блокировать номера, с которых идёт слишком большой поток звонков. Решение: ● администратор создаёт одну или несколько каруселей с разными номерами, ● исходящие вызовы распределяются между ними автоматически, ● нагрузка равномерно распределяется по номерам. Польза: снижается риск блокировки, повышается стабильность дозвона. Кейс 4. Определение номера линии при наличии карусели номеров и правила автоподстановки (сотрудник включён в карусель)

Сценарий: Клиент создал карусель номеров по правилу маски 7495\d* (сотрудник включён в эту карусель), а также правило автоподстановки по той же маске, но с номером линии, не входящим в карусель. У сотрудника установлен флажок «Автоматическая подстановка номера». При звонке на номер 7-495-666-66-66 вызов будет совершен с номера, который входит в карусель. Кейс 5. Определение номера линии при наличии карусели номеров и правила автоподстановки (сотрудник не включен в карусель) Сценарий: Клиент создал карусель номеров по правилу маски 7495\d* (сотрудник не включён в нее) и правило автоподстановки по этой же маске с номером линии, не входящим в карусель. У сотрудника установлен флажок «Автоматическая подстановка номера». При звонке на номер 7-495-666-66-66 вызов будет совершен с номера, указанного в правиле автоподстановки. Кейс 6. Определение номера линии при наличии нескольких каруселей и правила автоподстановки (сотрудник включён в несколько каруселей) Сценарий: Клиент создал две карусели номеров: ● Карусель_1 с приоритетом «3»; ● Карусель_2 с приоритетом «6». Обе карусели настроены по маске 7495\d*, в обе включён сотрудник, но списки номеров различаются. Дополнительно создано правило автоподстановки по той же маске с номером линии, не входящим в карусели. У сотрудника установлен флажок «Автоматическая подстановка номера». При звонке на номер 7-495-666-66-66 вызов будет совершен с номера, входящего в Карусель_1 (так как у неё выше приоритет).
