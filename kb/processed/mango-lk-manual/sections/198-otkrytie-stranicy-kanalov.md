# 2. Открытие страницы каналов

> Трассировка: PDF §2 · сквозные стр. 325 · источники: ч.1 `kb/sources/mango-lk-manual/LK_manual_v-123.pdf` с.325.

1. Авторизуйтесь в Личном кабинете Mango Office. 2. В панели навигации выберите: Инструменты → «Текстовые коммуникации» . 3. На странице «Группы каналов» найдите плитку «Max», нажмите кнопку Подключить.

![Изображение, стр. 325](../images/198-otkrytie-stranicy-kanalov-1.png)

![Изображение, стр. 325](../images/198-otkrytie-stranicy-kanalov-2.jpeg)

Откроется страница «О канале». Здесь пользователь может ознакомиться с назначением канала Max, его преимуществами для общения с клиентами, стоимостью подключения, а также получить пошаговые указания по подготовке доступов, созданию чат-бота Max и вводу токена, необходимого для интеграции канала в систему.
