# 5.22. Блок Вернуться

> Трассировка: PDF §5.22 · сквозные стр. 133-134 · источники: ч.1 `kb/sources/cov-robot-fil/Модуль ЦОВ Робот Фил 2,0_manual_v7.26.28.pdf` с.133-134.

Блок доступен только при создании скрипта для Голосовых роботов. Блок Вернуться используется для завершения фонового сценария и возврата в основной скрипт. Когда робот достигает данного блока, выполнение фонового скрипта прекращается, и звонок автоматически возвращается к тому месту, где был осуществлен переход на Фоновые события.

Элементы настройки блока: 1. Название блока – недоступно для редактирования. Логика работы блока:  При срабатывании фонового скрипта робот выполняет предусмотренные в нем действия до блока «Вернуться».  Блок «Вернуться» не может быть связан с другими блоками в качестве исходящей точки.  Один фоновый скрипт может содержать только один блок «Вернуться». Данный блок повышает управляемость сложными сценариями, позволяя организовать временные переходы между основным и фоновым скриптами без нарушения структуры основного сценария.
