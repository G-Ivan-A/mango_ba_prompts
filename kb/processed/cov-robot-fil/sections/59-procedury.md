# 9. Процедуры

> Трассировка: PDF §9 · сквозные стр. 172 · источники: ч.1 `kb/sources/cov-robot-fil/Модуль ЦОВ Робот Фил 2,0_manual_v7.26.28.pdf` с.172.

Используя «Процедуры» пользователь может создать фрагмент скрипта, который впоследствии можно встраивать в скрипт несколько раз, для повторяющихся действий. Процедуры позволяют упорядочить скрипт, а также превысить лимит в 150 блоков для одного скрипта. Пользователь может сохранять процедуры независимо от основного скрипта, и далее работать с ними как с отдельными процессами, встраивая в скрипт при помощи блока Вход в процедуру. Максимальное количество процедур для одного скрипта – 10. Процедуры можно редактировать, перемещать, копировать и удалять.
