# 11.2. Пример создания и настройки Справочника NLU

> Трассировка: PDF §11.2 · сквозные стр. 180-182 · источники: ч.1 `kb/sources/cov-robot-fil/Модуль ЦОВ Робот Фил 2,0_manual_v7.26.28.pdf` с.180-182.

Задача: Необходимо создать Справочник NLU для обработки запросов о корпоративных мероприятиях.

![Изображение, стр. 181](../images/68-primer-sozdaniya-i-nastroyki-spravochnik-1.png)

Шаг 1. Создание робота 1. Перейдите в раздел Справочники NLU 2. Нажмите Создать 3. Укажите название, например: Корпоративные мероприятия На этом этапе Справочник создан, но ещё не обучен и не включён в сценарии. Шаг 2. Добавление категории 1. Откройте вкладку Категории 2. Нажмите Добавить категорию 3. Заполните следующие поля: o Название: Корпоративные мероприятия o Описание: «Информация для сотрудников о тренингах, мастер-классах, праздниках, лекциях» Шаг 3. Добавление фраз-примеров В поле Фразы добавьте не менее 10 типовых обращений, например:  «Какие последние новости по обучению?»  «Какие ивенты будут на выходных?»  «Как узнать про лекции?»  «Куда пойти для повышения квалификации?» Чем больше примеров, тем выше точность классификации запросов.

![Изображение, стр. 181](../images/68-primer-sozdaniya-i-nastroyki-spravochnik-2.png)

Фразы можно импортировать и экспортировать с помощью кнопок в виде csv-файла. Шаг 4. Обучение 1. После добавления фраз нажмите Обучить 2. Статус Справочника изменится на Обучена 3. В карточке появится информация о числе категорий и фраз, использованных при обучении Шаг 5. Тестирование 1. Перейдите во вкладку Тестирование 2. Введите пример запроса, например: «Какие мастер-классы планируются осенью?» 3. Нажмите Протестировать 4. Система покажет: o категорию, с которой запрос совпадает максимально o пример автоответа o процент совпадения по другим категориям

![Изображение, стр. 182](../images/68-primer-sozdaniya-i-nastroyki-spravochnik-3.png)

Шаг 6. Использование в сценариях После обучения Справочник может быть добавлен в сценарии обработки запросов. Например:  если запрос соответствует категории «Корпоративные мероприятия», пользователь направляется к нужному блоку сценария  если совпадение ниже заданного порога – запрос переадресуется оператору Итог Созданный Справочник NLU способен точно распознавать намерения клиентов, направлять диалог по соответствующему сценарию и тем самым делать взаимодействие с пользователем быстрее, понятнее и комфортнее.
