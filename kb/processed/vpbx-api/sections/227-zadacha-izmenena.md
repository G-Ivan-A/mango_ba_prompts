# 4.9.2.2. Задача изменена

> Трассировка: PDF §4.9.2.2 · сквозные стр. 310-311 · источники: ч.1 `kb/sources/vpbx-api/MangoOffice_VPBX_API_v1.9.pdf` с.310-311.

Событие, вызываемое при изменении задачи. В событии отправляются все поля, включая поля: - в которых нет данных (null); - по которым не было изменения.

| № | Параметр | Тип | Обязате-<br>льный | Описание |
| --- | --- | --- | --- | --- |
| 1 | task_id | Число | Да | ID задачи |
| 2 | status | Число | Да | Доступные значения: 0 - Открыта (создана); 1 - Выполнена<br>(завершена); 2 - Отменена; 3 - Подтверждена |
| 3 | event_type | Число | Да | Тип задачи. Значения: 1 – Позвонить; 2 – Написать;<br>3 – Встретиться; 4 - Сделать |
| 4 | start_time | Временная<br>метка | Да | Дата/время начала события. |
| 5 | duration | Число | Да | Длительность события. В минутах |
| 6 | priority | Число | Да | Важность. Доступные значения: null - не важная;<br>1 – обычная; 2 - важная |
| 7 | contact_id | Число | Да | ID контакта адресной книги |

| № | Параметр | Тип | Обязате-<br>льный | Описание |
| --- | --- | --- | --- | --- |
| 8 | source_id | Число | Да | Источника контакта |
| 9 | source_type | Строка | Да | Тип источника контакта |
| 10 | from_user_id | Число | Да | ID сотрудника, от чьего имени поставлена задача |
| 11 | to_user_id | Число | Да | ID сотрудника, которому назначена задача |
| 12 | description | Строка | Да | Описание задачи |
| 13 | is_auto_call | Булево | Да | Одно из двух состояний в измененной задаче: true, false |
| 14 | phone | Строка | Да | Номер телефона. Внешняя система контролирует<br>самостоятельно корректность указания номера и контакта |
| 15 | theme | Строка | Да | Тема задачи |
| 16 | deal_id | Число | Да | ID сделки Контакт-центра |
