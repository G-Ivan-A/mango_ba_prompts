# 3.4.1.2. Получение статистики вызовов

> Трассировка: PDF §3.4.1.2 · сквозные стр. 69-71 · источники: ч.1 `kb/sources/vpbx-api/MangoOffice_VPBX_API_v1.9.pdf` с.69-71.

Подготовленные данные хранятся до обращения за ними не менее 1 минуты. API предусматривает две стратегии получения результата: ожидание получения специального события API о завершении построения и периодический опрос сервиса. API генерирует специальное событие (запрос к внешней системе) о готовности данных вида: POST /vpbx/result/stat Параметры события (запроса к внешней системе):

| № | Параметры | Тип | Обяза-<br>тель-<br>ный | Описание |
| --- | --- | --- | --- | --- |
| 1 | key |  |  | Ключ, созданный при обработке запроса от внешней системы на<br>получение статистики. |
| 2 | request_id |  |  | Значение request_id, полученное от внешней системы при<br>обработке запроса на построение статистики. |

Обращаться к сервису за готовыми данными следует запросом вида: POST /vpbx/stats/result Возможны следующие HTTP коды ответа:

| Результат | Описание |
| --- | --- |
| 204 No Content | Данные еще не подготовлены. Запрос данных следует повторить<br>(рекомендуется обращаться к сервису не чаше одного раза в 5 сек). |
| 404 Not Found | Данные не найдены, передан неправильный/устаревший ключ key. |
| 200 OK | Данные сформированы и возвращаются в формате CSV. |

В ответе возможно получение следующих данных (управляется полем fields запроса):

| № | Параметры | Тип | Обяза-<br>тель-<br>ный | Описание |
| --- | --- | --- | --- | --- |
| 1 | records |  |  | Идентификаторы записей разговоров в виде [rec1,rec2,rec3]. |
| 2 | start |  |  | Время начала разговора. Формат данных идентичен date_from. |
| 3 | finish |  |  | Время окончания разговора. Формат данных идентичен<br>date_from. |

| № | Параметры | Тип | Обяза-<br>тель-<br>ный | Описание |
| --- | --- | --- | --- | --- |
| 4 | answer |  |  | Время ответа на вызов. Если снятия трубки не было, передается<br>значение 0. Формат данных идентичен date_from. |
| 5 | from_extension |  |  | Идентификатор сотрудника ВАТС для вызывающего абонента. Не<br>передается в случае, если ВАТС не удалось идентифицировать<br>вызывающего абонента как сотрудника ВАТС, либо у сотрудника<br>ВАТС нет идентификатора (внутреннего номера). |
| 6 | from_number | string | Нет | Номер вызывающего абонента (строка), в случае, если ВАТС<br>удалось определить номер. |
| 7 | to_extension |  | Нет | Идентификатор сотрудника ВАТС для вызываемого абонента. Не<br>передается в случае, если ВАТС не удалось идентифицировать<br>вызываемого абонента как сотрудника ВАТС, либо у сотрудника ватс<br>нет идентификатора (внутреннего номера). |
| 8 | to_number | string |  | Номер вызываемого абонента (строка). |
| 9 | disconnect_reas<br>on |  |  | Причина завершения вызова. |
| 10 | entry_id |  |  | Внутренний идентификатор группы вызовов. Не имеет<br>отношения к CALL-ID из SIP-протокола. |
| 11 | line_number |  |  | Линия (номер) ВАТС, использованная для<br>обработки/размещения вызова. |
| 12 | location |  |  | Расположение вызова в ВАТС в момент завершения вызова, список<br>возможных значений указан в разделе "Уведомление о вызове". |
| 13 | сreate |  |  | Время создания группы вызовов. Формат данных идентичен<br>date_from. |

Описание формата возвращаемых данных: - данные возвращаются в теле ответа в виде сплошной строки текста в формате CSV-файла; - в качестве разделителя полей — точка с запятой (;); - в качестве разделителя строк — символ перевода строки (\n); - значения полей не могут содержать зарезервированные символы (двойная кавычка, запятая, точка с запятой, новая строка), поэтому экранирование не предполагается.
