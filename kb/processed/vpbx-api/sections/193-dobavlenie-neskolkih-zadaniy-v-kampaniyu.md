# 4.6.7. Добавление нескольких заданий в кампанию (асинхронный метод)

> Трассировка: PDF §4.6.7 · сквозные стр. 272-274 · источники: ч.1 `kb/sources/vpbx-api/MangoOffice_VPBX_API_v1.9.pdf` с.272-274.

POST /vpbx/tasks/push Асинхронный метод. Позволяет добавлять задания кампании исходящего обзвона. На вход принимает несколько заданий. Не возвращает в ответе ID заданий. Важно. Добавлять задания можно во всех статусах кампании исходящего обзвона, кроме статуса "Завершена". Параметры:

| № | Параметры |  |  | Тип | Обяза-<br>тель-<br>ный | Описание |
| --- | --- | --- | --- | --- | --- | --- |
|  | 1 уровень | 2 уровень | 3 уровень |  |  |  |
| 1 | campaign_id |  |  | Число | Да | ID кампании |
| 2 | tasks [] |  |  | Массив | Да | Список задач для кампании, массив JSON-<br>объектов |
| 2.1 |  | name |  | Строка | Нет | Имя клиента, которому адресован звонок.<br>Ограничение - 255 символов |
| 2.2 |  | number |  | Строка | Да | Номер для выполнения звонка.<br>Ограничение - 64 символа |
| 2.3 |  | priority |  | integer |  | Приоритет выполнения звонка.<br>Может иметь значение от 1 до 1000 |
| 2.4 |  | organizati<br>on |  | Строка | Нет | Название организации, которой адресован<br>звонок. Ограничение - 255 символов |
| 2.5 |  | position |  | Строка | Нет | Должность человека, которому адресован<br>звонок. Ограничение - 255 символов |
| 2.6 |  | comment |  | Строка | Нет | Комментарий. Ограничение - 1024 символов |
| 2.7 |  | due_date |  | Число | Нет | Дата и время, до которого необходимо<br>произвести попытку выполнения задачи в<br>формате "YYYY-MM-DD HH:MM:SS" (UTC) |
| 2.8 |  | blocked_u<br>ntil |  | Строка | Нет | Заблокировано до (какого-то времени) в<br>формате "YYYY-MM-DD HH:MM:SS"<br>(UTC) |
| 2.9 |  | custom_fi<br>elds |  | Объект -<br>ключ-<br>значение | Нет | Значение пользовательских полей. Для<br>получения списка пользовательских полей,<br>используется метод "Получение списка<br>пользовательских полей". Обязательность<br>заполнения пользовательского поля зависит<br>от настройки |
| 2.9.1 |  | subtasks [] |  | Массив | Нет | Массив подзадач (JSON-объектов) с<br>альтернативными номерами<br>клиента, необходимый для того, чтобы в<br>кампанию Исходящего Обзвона можно было<br>добавить информацию о нескольких номерах<br>клиента. В процессе обзвона, случае дозвона<br>по хотя бы одному из номеров клиентов -<br>обзвон будет остановлен |
| 2.9.2 |  |  | number | Строка | Да | Номер для выполнения звонка.<br>Ограничение - 64 символа |

| № | Параметры |  |  | Тип | Обяза- | Описание |
| --- | --- | --- | --- | --- | --- | --- |
| 2.9.3 |  |  | priority | Число |  | Приоритет выполнения звонка.<br>Допустимые значения: от 1 до 999.<br>По умолчанию - 1000. |
| 2.9.4 |  |  | order | Число | Да | Порядковый номер исполнения подзадачи,<br>номера в запросе могут идти в любом<br>порядке, отсчет нумерации всегда начинается<br>с нуля (0) |
| 2.9.5 |  |  | type | Число | Да | Фиксированное значение поля - ноль (0),<br>другие значения не принимаются.<br>Ограничение - 255 символов |

Пример запроса: POST https://app.mango-office.ru/vpbx/tasks/push vpbx_api_key = 1234567890qwerty, sign = 1234567890qwerty, json = { "campaign_id": 56919, "tasks": [ { "name": "Евгеньев Евгений Евгеньевич", "number": "+375291111111", "priority": 1, "organization": "АБВ", "position": "Руководитель", "due_date": "2021-07-20 19:50:00", "custom_fields": { "5781": "Салют" }, "subtasks": [ { "number": "+7007372527954818", "order": 1, "type": 0 }, { "number": "+72527954828", "order": 0, "type": 0 }, { "number": "sip:admin@test.mangosip.ru", "order": 2, "type": 0 } ] } ] } В результате обработки запроса, формируются и передаются JSON-данные, содержащие следующие параметры:

| --- | --- | --- | --- | --- |
