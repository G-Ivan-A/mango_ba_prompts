# 3.2.4. Отправка SMS

> Трассировка: PDF §3.2.4 · сквозные стр. 39-41 · источники: ч.1 `kb/sources/vpbx-api/MangoOffice_VPBX_API_v1.9.pdf` с.39-41.

POST /vpbx/commands/sms Команда инициирует отправку смс с текстом на адрес, указанный для отправки. Входные параметры:

| № | Параметры | Тип | Обяза-<br>тель-<br>ный | Описание |
| --- | --- | --- | --- | --- |
| 1 | command_id | string |  | Идентификатор команды (строка не более 128 байт).<br>Формируется внешней системой. ВАТС никак не обрабатывает<br>этот идентификатор, не анализирует и не полагается на<br>уникальность его значения. Идентификатор можно<br>использовать для связи команды с результатом ее выполнения и<br>возможными последующими событиями, которые появляются в<br>результате выполнения команды. |
| 2 | text | string |  | Текст сообщения. Ограничение поля — 612 символов для латиницы и<br>268 для кириллицы (4 сегмента по 153 и 67 символов соответственно). |

| № | Параметры | Тип | Обяза-<br>тель-<br>ный | Описание |
| --- | --- | --- | --- | --- |
| 3 | from_extension |  | Да | Идентификатор сотрудника. Если у сотрудника ВАТС нет<br>идентификатора (внутреннего номера), выполнение команды от<br>его имени невозможно. За счет данного абонента будет<br>выполняться тарификация.<br>Примечание:<br>● если указан короткий номер сотрудника, будет отправлено на<br>номер по умолчанию для данного сотрудника (первый номер в<br>списке в настройках карточки сотрудника);<br>● если указан не короткий номер сотрудника, то может быть,<br>как sip-номером, так и ТфОП номером. |
| 4 | to_number |  |  | Номер вызываемого абонента (строка не более 128 байт). Может<br>быть любым номером, кроме коротких номеров сотрудников<br>ВАТС. К номеру будут применены правила преобразования<br>номеров ВАТС. |
| 5 | sms_sender | string | Нет | Имя отправителя SMS-сообщения. Строка не более 128 байт.<br>Если в этом поле указано значение, то ВАТС будет<br>использовать указанное в этом параметре имя отправителя.<br>Примечание. Возможны следующие варианты использования:<br>● если у Клиента в ЛК доступно к выбору только имя по<br>умолчанию, допускается в данном поле передать только имя по<br>умолчанию;<br>● если у Клиента в ЛК доступно к выбору имя по умолчанию<br>либо отраслевое, допускается в данном поле передать имя по<br>умолчанию либо любое доступное отраслевое имя;<br>● если у Клиента в ЛК доступно к выбору имя по умолчанию,<br>либо отраслевое имя, либо подтвержденное уникальное имя, то<br>допускается в данном поле передать имя по умолчанию либо<br>любое доступное отраслевое имя, либо уникальное имя. |

Пример запроса: POST https://app.mango-office.ru/vpbx/commands/sms vpbx_api_key = 1234567890qwerty, sign = 1234567890qwerty, json = { "command_id":"smsmsmsm", "text":"Hello world!", "from_extension":"222", "to_number":"74955404444", "sms_sender":"PRO-TAXI" } Результат: POST /vpbx/result/sms В результате обработки запроса, формируются и передаются JSON-данные, содержащие следующие параметры:

| № | Параметры | Тип | Обяза-<br>тель-<br>ный | Описание |
| --- | --- | --- | --- | --- |
| 1 | command_id | string | Нет | Идентификатор команды (строка не более 128 байт). |
| 2 | result |  | Да | Результат выполнения команды инициирования вызова от<br>внешней системы. Ниже приведены возможные значения<br>результата (см. "Список кодов результатов"):<br>● 1000 - команда выполнена успешно;<br>● 2xxx - команда запрещена биллинговой системой ВАТС;<br>● 3100 - переданы неверные параметры команды либо<br>команда не может быть выполнена с этими параметрами;<br>● 4300 - SMS-сообщение отправить не удалось;<br>● 5ххх - ошибка сервера. |
