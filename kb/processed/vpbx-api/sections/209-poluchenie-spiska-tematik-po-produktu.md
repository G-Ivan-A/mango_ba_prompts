# 4.7.2. Получение списка тематик по продукту

> Трассировка: PDF §4.7.2 · сквозные стр. 291-293 · источники: ч.1 `kb/sources/vpbx-api/MangoOffice_VPBX_API_v1.9.pdf` с.291-293.

POST /vpbx/cc/tags/ Метод позволяет получить список тематик подробные сведения о тематиках КЦ: ID тематики, имя тематики, категория и т.д. Параметры запроса: пустой json. Примечание. Согласно модели взаимодействия, в запросах отправляются обязательные поля vpbx_api_key и sign. Пример запроса: POST https://app.mango-office.ru/vpbx/cc/tags/ vpbx_api_key = 1234567890qwerty, sign = 1234567890qwerty, json = { } В результате обработки запроса, формируются и передаются JSON-данные, содержащие следующие параметры:

| № | Параметры |  | Тип | Обяза-<br>тель-<br>ный | Описание |
| --- | --- | --- | --- | --- | --- |
|  | 1 | 2 |  |  |  |
| 1 | result |  |  |  | Результат выполнения запроса;<br>● 1000 - удачное выполнение;<br>● 3100 - переданы неверные параметры команды;<br>● 31хх - неверные параметры;<br>● 3300 - объект не существует;<br>● 5xxx – ошибка сервера |
| 2 | tags |  |  |  |  |
| 2.1 |  | id | integer |  | id тематики |
| 2.2 |  | parent | integer |  | Id тематики, в которую входят другие тематики (если<br>null - нет родительской тематики) |
| 2.3 |  | name | string |  | Имя тематики |

| 2.4 |  | category | integer |  | Категория:<br>■ -1 - ко всем категориям;<br>■ 0 - ни к каким категориям не относится;<br>■ 1 - входящий вызов, поступивший с группы;<br>■ 2 - входящий вызов, поступивший персонально на<br>сотрудника;<br>■ 4 - исходящий вызов в рамках кампании ИО / Заказ<br>обратного звонка;<br>■ 8 - исходящий вызов на внешний номер (не в<br>рамках кампании ИО);<br>■ 12 - исходящие (исходящий вызов в рамках<br>кампании ИО, исходящий вызов на внешний номер<br>(не в рамках кампании ИО);<br>■ 16 - внутренний вызов;<br>■ 19 - внешние (входящий вызов, поступивший с<br>группы, входящий вызов, поступивший персонально<br>на сотрудника, внутренний вызов). |
| --- | --- | --- | --- | --- | --- |
| 2.5 |  | groups | Array<br>[integer, ..] |  | Список ID групп, которым назначена тематика (0 -<br>если тематика назначена на группу "Общие<br>тематики") |
| 2.6 |  | campaigns | Array<br>[integer, ..] |  | Список ID кампаний, которым назначена тематика |
| 2.7 |  | is_folder | integer |  | Является ли папкой: 0 - нет; 1 – да |
