# 4.10.4. Как найти channelId

> Трассировка: PDF §4.10.4 · сквозные стр. 325-326 · источники: ч.1 `kb/sources/vpbx-api/MangoOffice_VPBX_API_v1.9.pdf` с.325-326.

Если вы хотите использовать методы для получения сообщений из внешних приложений в API Манго диалоги, то вам потребуется знать channelId – идентификатор нужного вам канала. Для этого, вы можете выполнить следующие действия: 1) зайти в Личный кабинет MANGO OFFICE. Перейти в раздел "Диалоги", выбрать пункт "Группы каналов"; 2) нажать на строку с данными нужного вам виджета. Важно, чтобы эта строка была

![Изображение, стр. 325](../images/244-kak-nayti-channelid-1.png)

отмечена иконкой "API Манго Диалоги"; 3) посмотреть и запомнить (либо сохранить в текстовый файл, например, в "Блокнот") номер вашего виджета, указанный в адресной строке в конце URL. Он потребуется вам далее; 4) открыть консоль браузера (нажмите F12); 5) открыть в раздел "Сеть" \ "Network"; 6) включить галочку "Предварительный просмотр" \ "Show overview"; Примечание. Проверить настройку фильтра в консоли. Включить фильтр и нажать на значение "Все" \ "All". 7) обновить страницу; 8) найти запрос с названием таким же, как номер виджета, указанный в адресной строке; Примечание. Запрос в поле "Type" имеет значение "xhr". 9) нажать на запрос; 10) в открывшемся с данными запроса, нажать на пункт "Предпросмотр" \ "Preview"; 11) нажать на блок "data"; 12) нажать на блок "channels"; 13) нажать на блок "10". В поле "channelId" указан нужный вам номер.
