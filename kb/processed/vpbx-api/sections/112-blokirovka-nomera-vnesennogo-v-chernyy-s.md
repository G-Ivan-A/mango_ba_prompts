# 3.8.3.4. Блокировка номера, внесенного в "черный" список ИО

> Трассировка: PDF §3.8.3.4 · сквозные стр. 153-154 · источники: ч.1 `kb/sources/vpbx-api/MangoOffice_VPBX_API_v1.9.pdf` с.153-154.

POST /vpbx/outbound_blacklist/enable_mode Включение режима блокировки номера. Примечание. Для вызова метода требуется в ВАТС наличие подключенной услуги "Черный и белый списки" и включенной опции запрета на исходящие коммуникации. Параметры запроса:

| Параметры | Тип | Обязательный | Описание |
| --- | --- | --- | --- |
| number | string | Да | Номер телефона |
| mode | integer | Да | Добавить номер для:<br>1 - прямые исходящие (требуется подключенная услуга<br>"Черный и белый списки" в ВАТС);<br>2 - компании исходящего обзвона (требуется<br>подключенная услуга Контакт-центра "Исходящий обзвон<br>PRO");<br>3 - прямые исходящие и компании исходящего обзвона<br>(требуется подключенные услуги ВАТС "Черный и белый<br>список" и услуги КЦ "Исходящий обзвон PRO"). |

Пример запроса: POST https://app.mango-office.ru/vpbx/outbound_blacklist/enable_mode vpbx_api_key = 1234567890qwerty, sign = 1234567890qwerty, json = { "number": "71234567890", "mode": 2 } В результате обработки запроса, формируются и передаются JSON-данные, содержащие код ошибки:
