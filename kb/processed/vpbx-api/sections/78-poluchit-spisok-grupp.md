# 3.7.2. Получить список групп

> Трассировка: PDF §3.7.2 · сквозные стр. 113-116 · источники: ч.1 `kb/sources/vpbx-api/MangoOffice_VPBX_API_v1.9.pdf` с.113-116.

POST /vpbx/groups Параметры запроса:

| № | Параметры | Тип | Обяза-<br>тель-<br>ный | Описание |
| --- | --- | --- | --- | --- |
| 1 | group_id |  | Нет | Если указано, то возвращается информаци о данной группе |
| 2 | operator_id |  | Нет | id сотрудника. Если указан, то возвращается только список групп,<br>куда включен сотрудник. Иначе - возвращаются все группы.<br>Получить значение operator_id можно запросом Запрос списка<br>сотрудников, в ответе на который возвращается параметр<br>general.user_id |
| 3 | operator_exte<br>nsion |  | Нет | Внутренний номер сотрудника. Если указан, то возвращается<br>только список групп, куда включен сотрудник. Иначе -<br>возвращаются все группы |
| 4 | show_users |  | Нет | Признак, выводить ли в ответет сотрудников в группах/группе.<br>Если указан (0 - нет / 1 - да), то в ответе возвращается вместе со<br>списком сотрудников. Иначе - только список групп |
