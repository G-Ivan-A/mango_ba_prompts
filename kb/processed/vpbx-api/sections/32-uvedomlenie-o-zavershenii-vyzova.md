# 3.1.6. Уведомление о завершении вызова

> Трассировка: PDF §3.1.6 · сквозные стр. 27-31 · источники: ч.1 `kb/sources/vpbx-api/MangoOffice_VPBX_API_v1.9.pdf` с.27-31.

POST https://external-system.com/events/summary Уведомление содержит основную информацию о звонке после его окончания и служит индикатором окончания разговора. Генерируется как финализирующее событие по звонку. После получения данного события вызов можно считать завершенным. Параметры уведомления:
