# 4.3.1. Создание задачи на автоперезвон

> Трассировка: PDF §4.3.1 · сквозные стр. 210-211 · источники: ч.1 `kb/sources/vpbx-api/MangoOffice_VPBX_API_v1.9.pdf` с.210-211.

POST /cc/task/add Метод предназначен для создания задачи на автоперезвон в КЦ со стороны внешней системы. Вы можете использовать данный метод, например, в следующем случае: во внешнюю систему поступила заявка, тогда внешняя система инициирует создание задачи на автоперезвон, указывая номер телефона. Важно! Вы можете передавать не более 5 запросов /task/add в 1 секунду. Параметры:

| № | Параметры | Тип | Обяза-<br>тель-<br>ный | Описание |
| --- | --- | --- | --- | --- |
| 1 | event_type |  | Да | Тип задачи:<br>● 1 - позвонить;<br>● 2 - написать;<br>● 3 - встретиться;<br>● 4 - сделать; |
| 2 | start_time |  | Да | Дата/время начала события, формат timestamp (время события<br>UTC+3) |
| 3 | duration | int |  | Длительность события. В минутах, не более 1440 (сутки) |
| 4 | contact_id |  | Нет | id контакта адресной книги. id контакта можно получить, используя<br>API для работы с адресной книгой |
| 5 | source_id |  | Нет | id - источника контакта. Если не указан, то контакт из внутренней<br>адресной книги. id контакта можно получить, используя API для<br>работы с адресной книгой |
| 6 | source_type |  | Нет | Тип источника контакта. Если не указан, то контакт из внутренней<br>адресной книги. Id контакта можно получить, используя api для<br>работы с адресной книгой |
| 7 | to_user_id |  | Да | id сотрудника, которому назначена задача. |
| 8 |  |  |  | Сотрудника идентичен id, используемом в API ВАТС, запрос списка<br>сотрудников |
| 9 | description | string | Нет | Максимальное количество символов - 1024, описание. |
| 10 | is_auto_call |  |  | Признак автозвонка, 1- true/ 0 – false.<br>● если true, то при создании задачи, создается задача на<br>автоматический звонок;<br>● если false, то при создании задачи, не создается задача на<br>автоматический звонок. Значение по умолчанию, если не указан<br>параметр; |
| 11 | phone | string | Нет | Номер. Внешняя система контролирует самостоятельно<br>корректность указания номера и контакта |

При выполнении данного запроса, в КЦ следующие параметры принимают значения: - Сделка - не заполняется. - Организация - не используется, поскольку не редактируемо и отображается по связи с контактом. - Время переноса - не используется при создании задачи. Пример запроса: POST https://app.mango-office.ru/cc/task/add vpbx_api_key = 1234567890qwerty, sign = 1234567890qwerty, json = { "event_type":1, "start_time":"1399906980", "duration":15, "importance":1, "to_user_id":300052408, "description":"Текст из заявки, которую оставил клиент", "is_auto_call":1, "phone":"79260297870" } В результате обработки запроса, формируются и передаются JSON-данные, содержащие следующие параметры:

| № | Параметры | Тип | Обяза-<br>тель-<br>ный | Описание |
| --- | --- | --- | --- | --- |
| 1 | result |  | Да | Код результата |
| 2 | task_id |  |  | id созданной задачи, если задача создана |
| 3 | auto_call_task_id |  |  | id созданной задачи на автоперезвон, если такая задача создана.<br>Этот параметр должен быть идентичен параметру task_id из<br>звонкового события по данной задаче автоперезвона |

Пример ответа: { "result": 1000, "task_id: " 402052290, "auto_call_task_id":2052290 }
