# Описание запроса на создание кампании ИО

> Трассировка: PDF §4.6.4 · сквозные стр. 259-263 · источники: ч.1 `kb/sources/vpbx-api/MangoOffice_VPBX_API_v1.9.pdf` с.259-263.

POST /vpbx/campaign/add Метод позволяет вам создать в вашем КЦ кампанию ИО, чтобы вы могли автоматически обзванивать нужную вам группу Клиентов. Этот метод содержит параметр did_abonent_ids, который позволяет вам вырать несколько исходящих номеров (прикрепленных к вашей ВАТС) для исходящего обзвона. Обзвон от нескольких исходящих номеров по списку контактов происходит случайным образом, алгоритм КЦ обеспечивает относительно равномерное распределение обзвона между всеми доступными исходящими номерами.
