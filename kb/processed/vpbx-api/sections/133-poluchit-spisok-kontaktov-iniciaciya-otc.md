| № | Параметры | Тип | Обяза-<br>тель-<br>ный | Описание |
| --- | --- | --- | --- | --- |
| 1 | limit_rows |  | Нет | Кол-во выбираемых строк (по умолчанию 10, ограничение 500) |
| 2 | query | string | Да | Строка поиска, допустима передача пустой строки для возврата<br>списка всех групп |
| 3 | order |  | Нет | Массив объектов вида [ { "field": "asc \| desc" }, ... ], - правило<br>сортировки; порядок следования объектов в массиве определяет |

| № | Параметры | Тип | Обяза-<br>тель-<br>ный | Описание |
| --- | --- | --- | --- | --- |
|  |  |  |  | порядок сортировки |
| 4 | contact_ext_fields |  |  | Признак необходимости возвращать значения пользовательских<br>полей (custom_values) и поля идентификатор персонального<br>сотрудника (user_id ) |
