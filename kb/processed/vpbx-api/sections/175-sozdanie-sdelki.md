# 4.5.1. Создание сделки

> Трассировка: PDF §4.5.1 · сквозные стр. 226-228 · источники: ч.1 `kb/sources/vpbx-api/MangoOffice_VPBX_API_v1.9.pdf` с.226-228.

POST /cc/deal/create Назначение: создает новую сделку Параметры:

| № | Параметры | Тип | Обяза-<br>тель-<br>ный | Описание |
| --- | --- | --- | --- | --- |
| 1 | contact_id | Число | Да | Уникальный номер контакта. Его можно получить согласно методу<br>API для работы с адресной книгой. Источник контакта - только<br>адресная книга КЦ, не рассматривается внешняя система работы с<br>адресной книгой (источник контакта и id источника всегда - КЦ) |
| 2 | name | Строка | Да | Название сделки |
| 3 | description | Текст | Нет | Описание сделки |
| 4 | amount | Число | Нет | Сумма сделки |
| 5 | abonent_id | Число | Да | Уникальный номер ответственного за сделку сотрудника<br>Примечание. Для получения id сотрудника или списка<br>сотрудников, используется метод запрос списка сотрудников ВАТС |
| 6 | funnel_id | Число | Да | Уникальный номер воронки, в которой необходимо создать сделку<br>Примечание. Для получения id воронки используется метод<br>получение списка воронок |

| № | Параметры | Тип | Обяза-<br>тель-<br>ный | Описание |
| --- | --- | --- | --- | --- |
| 7 | step_id | Число | Да | Уникальный номер этапа, на котором находится сделка<br>Примечание. Для получения id этапов используется метод<br>получение списка воронок |
| 8 | custom_fields | Дата | Нет | Обязательность заполнения пользовательского поля зависит от<br>настройки "required", см. Получение списка пользовательских<br>полей. Пользовательские поля, созданные на продукте для сделки<br>Примечание. Для получения списка и типов пользовательских<br>полей, используется метод получение списка пользовательских<br>полей |
| 9 | create_date | Строка | Нет | Дата создания сделки. При значении "null" дата равна текущей дате<br>создания |
| 10 | status | Строка | Нет | Доступен один из следующих статусов для выбора:<br>● "in_work" - в работе;<br>● "succeed" - состоялась;<br>● "failed" - не состоялась;<br>● "delete" – удалена |
| 11 | status_change<br>_reason | Строка | Нет | Причина, по которой не состоялась сделка. Доступно только при<br>изменении уже созданной сделки в статусе "не состоялась" - "failed"<br>или при переводе статуса сделки в статус "не состоялась" - "failed".<br>Доступна одна из причин для выбора:<br>● too_expensive - слишком дорого;<br>● bad_condition - не устроили условия;<br>● competitor - выбрали других;<br>● missing_demand - пропала потребность;<br>● alternative – другое |
| 12 | reason_comm<br>ent | Строка | Нет | Комментарий к причине отказа, по которой не состоялась сделка.<br>Доступно только при выбранной причине отказа |
