# 4.10.2.1. Отправка сообщения, либо файла, либо оценки обслуживания

> Трассировка: PDF §4.10.2.1 · сквозные стр. 316-318 · источники: ч.1 `kb/sources/vpbx-api/MangoOffice_VPBX_API_v1.9.pdf` с.316-318.

POST /cc/send_message Данный метод позволяет из вашего приложения отправлять в Контакт-центр MANGO OFFICE: - текстовое сообщение; - оценку качества обслуживания; - отправлять файл или изображение. Обратите внимание: - данный метод позволяет отправлять файл или изображение из внешнего истоничка (например, файлового хранилища) в Контакт-центр MANGO OFFICE. Загрузка файла выполняется по url, поэтому у вас должно быть файловое хранилище с файлами, которые вы хотите отправить. Отправка локально сохраняемых файлов не поддерживается. Тип сообщения "text"; - данный метод позволяет отправлять оценку качества обслуживания из внешнего приложения в Контакт-центр MANGO OFFICE. При этом, со стороны внешнего приложения необходимо убирать вопросы после того, как Клиент выставил оценку, в противном случае оценка будет некорректной. Также при выставлении оценки необходимо отправлять id вопроса, на который выставляется оценка. Важно! Со стороны внешнего приложения необходимо выставлять временное ограничение в 5 мин на выставление оценки. Параметры:

{ "result": 5000 } Примечание. Для того, чтобы добавление значений оценки работало, необходимо в системе Контроля качества MANGO OFFICE настроить правило для выставления оценки. Для настройки выставления оценки нужны следующие действия: 1. Перейти по ссылке https://qm.mango-office.ru/, 2. Добавить правило в настройках, указав, что нужна оценка качества в чатах. Что обеспечит возможность выставлять оценки после завершения обращения в КЦ. 3. Далее нужно подключить услугу "Омниканальная оценка диалогов" - включить галочку "Оценивать качество обслуживания по завершению диалога" 4. Если не настроить данный функционал, то попытка оценки будет приходить как новое обращение, в КЦ в виде нового чата.
