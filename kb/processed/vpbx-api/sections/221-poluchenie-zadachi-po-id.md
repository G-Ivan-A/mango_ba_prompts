# 4.9.1.3. Получение задачи по ID

> Трассировка: PDF §4.9.1.3 · сквозные стр. 304-306 · источники: ч.1 `kb/sources/vpbx-api/MangoOffice_VPBX_API_v1.9.pdf` с.304-306.

POST /cc/task/get Позволяет получить данные конкретной задачи по ID. В ответе отправляются все поля, включая поля в которых нет данных (null). Параметры метода:

| № | Параметр | Тип | Обязательный | Описание |
| --- | --- | --- | --- | --- |
| 1 | task_id | Число | Да | ID задачи |

Пример запроса: POST https://app.mango-office.ru/cc/task/get vpbx_api_key = 1234567890qwerty, sign = 1234567890qwerty, json = { "product_id":300023344, "task_id":45594 } В результате обработки запроса, формируются и передаются JSON-данные, содержащие следующие параметры:
