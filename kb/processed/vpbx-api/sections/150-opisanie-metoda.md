POST /vpbx/record/recognize Параметры:

| Параметры | Тип | Обяза-<br>тель-<br>ный | Описание |
| --- | --- | --- | --- |
| file |  |  | Звуковой файл должен соответствовать требованиям:<br>- формат *.wav, mp3, mp4, ogg;<br>- битрейт не ниже 128 кбит/с;<br>- размер файла не более 100 МБ;<br>- имя файла записано латиницей;<br>- длина имени файла не более 64 символов. |

Пример запроса: curl --request POST \ --url https://app.mango-office.ru/vpbx/record/recognize \ --header 'Content-Type: multipart/form-data; boundary=--- 011000010111000001101001' \ --form vpbx_api_key=97dqrthf3wvrw2ph317ce7 \ --form sign=e7dd880e77f1df9113a4c05173c0b9b5b071c36938a \ --form 'json={}' \ --form 'file=@/home/user/13688577079-503-341774074.wav' В результате обработки запроса, формируются и передаются JSON-данные, содержащие следующие параметры:

| № | Параметры | Тип | Обяза-<br>тель-<br>ный | Описание |
| --- | --- | --- | --- | --- |
| 1 | request_id |  |  | id-номер созданного задания на распознавание речи в загруженном<br>файле (тип integer). Этот параметр передается, только в случае<br>успешного выполнения запроса |

| № | Параметры | Тип | Обяза-<br>тель-<br>ный | Описание |
| --- | --- | --- | --- | --- |
| 2 | result |  | Да | Результат выполнения запроса. Ниже приведены возможные значения<br>результата:<br>1000 - Команда завершения вызова выполнена успешно<br>3104 - Параметр передан в неправильном формате<br>3109 - Значение больше ожидаемого (случай, когда размер файла<br>больше, чем определено в требоаниях)<br>3129 - Неверная канальность аудиозаписи (при попытке загрузить<br>одноканальную запись)<br>5000 - Ошибка сервера<br>5008 - Услуга недоступна |

Примечание. Код HTTP 413 Request Entity Too Large, указывает, что объект, переданный в запросе, больше, чем ограничения метода, то есть POST запрос (данные и файл) больше, чем ограничения метода. Пример ответа: { "result": 1000, "request_id": 174249520 }
