# 4.10.1. Общее

> Трассировка: PDF §4.10.1 · сквозные стр. 316 · источники: ч.1 `kb/sources/vpbx-api/MangoOffice_VPBX_API_v1.9.pdf` с.316.

API предназначен для отправки текстовых сообщений, изображений, файлов. Возможности, доступные через API: - Отправка текстового сообщения; - Отправка изображения или файла; - Отправка оценки качества обслуживания. Важно! Если вы хотите использовать данное API, то вам нужно к вашей ВАТС подключить сервис "Манго Диалоги" и настроить хотя бы один текстовый канал коммуникаций в данном сервисе. Подробнее о Манго Диалогах читайте в документации.
