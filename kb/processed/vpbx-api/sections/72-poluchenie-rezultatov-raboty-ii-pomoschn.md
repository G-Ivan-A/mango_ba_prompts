# 3.5.9. Получение результатов работы ИИ помощников

> Трассировка: PDF §3.5.9 · сквозные стр. 100-102 · источники: ч.1 `kb/sources/vpbx-api/MangoOffice_VPBX_API_v1.9.pdf` с.100-102.

POST /s2t/queries/recording_agents Метод предназначен для получения результатов работы ИИ помощников по одной или нескольким записям разговоров. Параметры запроса:

| № | Параметр | Тип | Обязательный | Описание |
| --- | --- | --- | --- | --- |
| 1 | json | string | Да | JSON-строка с<br>параметрами<br>запроса. |

Параметры объекта json:

| № | Параметр | Тип | Обязательный | Описание |
| --- | --- | --- | --- | --- |
| 1 | communication_id | array [string] | Да | Массив<br>идентификаторов<br>записей<br>разговоров. |

Заголовки запроса:

| № | Параметр | Обязательный | Описание |
| --- | --- | --- | --- |
| 1 | X-Point-Id | Да | Point ID продукта. |

Пример запроса:

| { |
| --- |
| "communication_id": [ |
| "MzAwMTMwMzIyMg==" |
| ] |
| } |

|  | 1 | 2 |  |  |  |

| 2.1 |  | recording_id | string | Да | Идентификатор записи<br>разговора. |
| 2.2 |  | assistant_id | integer | Да | Идентификатор ИИ<br>помощника. |
| 2.3 |  | processed_at | string | Да | Дата и время обработки в<br>формате ISO 8601. |

При ошибке валидации возвращается ответ со статусом 400. Эти JSON-данные содержат следующие параметры:

| № | Параметры с уровнями<br>вложенности |  | Тип | Обязательный | Описание |
| --- | --- | --- | --- | --- | --- |
|  | 1 | 2 |  |  |  |
| 1 | result |  | integer | Да | Код результата.<br>При ошибке<br>валидации<br>возвращается<br>значение 3000. |
| 2 | error |  | array | Да | Массив<br>сообщений об<br>ошибках. |
