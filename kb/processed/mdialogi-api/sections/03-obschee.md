# 1.1. Общее

> Трассировка: PDF §1.1 · сквозные стр. 7 · источники: ч.1 `kb/sources/mdialogi-api/Manual_API_Mango_Dialogi.pdf` с.7.

Система "Манго Диалоги" (далее по тексту - МД) предоставляет сервис коммуникации с Клиентами и партнерами в различные текстовые каналы. Работа с обращениями может осуществляться как из Контакт- центра MANGO OFFICE, так и из внешних систем, интегрированных с МД посредством API. С помощью МД вы можете организовать обмен текстовыми сообщениями между Клиентами и вашими операторами через различные каналы текстовых коммуникаций. Примечание.
