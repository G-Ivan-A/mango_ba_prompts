# 6.1.4. Получить список виджетов

> Трассировка: PDF §6.1.4 · сквозные стр. 85-87 · источники: ч.1 `kb/sources/mdialogi-api/Manual_API_Mango_Dialogi.pdf` с.85-87.

Метод возвращает список виджетов МД. Если необходимо получить данные только по одному определенному виджету, укажите его идентификатор во входных параметрах запроса. HTTP-запрос: POST https://app.mango-office.ru/cc/md/widgets Параметры запроса:

| Параметр | Тип | Обязательное | Описание |
| --- | --- | --- | --- |
| id | String | Да | Уникальный идентификатор вызова (например, UUID).<br>Формируется внешней системой. Манго Диалоги и<br>ВАТС никак не обрабатывают этот идентификатор, не<br>анализируют и не полагаются на его уникальность. |
| widget_id | Integer | Нет | Идентификатор виджета. Если не указан,<br>возвращается список всех виджетов. |

Примеры запроса. 1) Пример запроса списка всех виджетов.

| { |
| --- |
| "id": "fc30" |
| } |

2) Пример запроса информации о конкретном виджете.

|  | { |
| --- | --- |
|  | "id": "fc30", |
|  | "widget_id": 123 |
|  | } |

| Параметр | Тип | Обязательное | Описание |
| --- | --- | --- | --- |
| name | String | Да | Наименование статуса HTTPответа |
| status | Integer | Да | Код ответа HTTP |
| code | Integer | Да | Код результата (список) |
