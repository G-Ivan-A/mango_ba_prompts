# 3.1.2. Доступ к методам

> Трассировка: PDF §3.1.2 · сквозные стр. 17-18 · источники: ч.1 `kb/sources/mdialogi-api/Manual_API_Mango_Dialogi.pdf` с.17-18.

Вы можете использовать методы, описанные в данном разделе, если выполняются следующие условия: - Вы являетесь Клиентом MANGO OFFICE (юр.лицо или индивидуальный предприниматель), который приобрел продукт "Виртуальная АТС", а также использует расширенную версию Контакт-центра MANGO OFFICE; - Ваша Виртуальная АТС MANGO OFFICE должна быть разблокирована, а на лицевом счету должен быть положительный баланс; - к Вашей Виртуальной АТС подключена услуга "WhatsApp Business API (провайдер Edna)"; - имеется хотя бы один HSM-шаблон, созданный в WhatsApp Business API (провайдер Edna).
