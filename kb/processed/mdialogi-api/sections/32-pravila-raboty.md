# 3.2.2. Правила работы

> Трассировка: PDF §3.2.2 · сквозные стр. 25-26 · источники: ч.1 `kb/sources/mdialogi-api/Manual_API_Mango_Dialogi.pdf` с.25-26.

Чтобы выполнить массовую рассылку, необходимо комплексно применять следующие правила метода: 1) если у Клиента несколько номеров, то можно отправить сообщение на все номера Клиента. Например, Клиенту X можно отправить сообщение в WA на основной и дополнительный номер; 2) можно отправлять разные сообщения на разные номера телефонов одного Клиента (существуют ограничения по количеству символов). Например, Клиенту X можно отправить на основной номер сообщение "Text1", а на дополнительный номер сообщение "Text2"; Примечание. Для сообщений в WA используются настроенные текстовые HSM шаблоны. 3) в параметрах метода необходимо указать последовательность отправки сообщений Клиенту. Например, Клиенту X можно сначала отправить на основной номер сообщение "Text1", а затем отправить на дополнительный номер сообщение "Text2"; 4) ВАТС анализирует статус сообщений, отправленных через WA. В результате: - если сообщение имеет статус "Доставлено", либо статус "Прочитано", то ВАТС принудительно завершает рассылку данному Клиенту (даже, если в параметрах метода указано, что надо отправить еще сообщение); - если сообщение имеет статус "Ошибка", то ВАТС продолжит отправлять сообщения данному Клиенту согласно параметрам метода. Относительно приведенного выше примера, (в котором Клиенту X сначала отправляется на основной номер сообщение "Text1", а затем отправляется на дополнительный номер сообщение "Text2") анализ статусов сообщений в WA будет происходить так: - если отправленное на основной номер сообщение "Text1" имеет статус "Ошибка", то ВАТС отправит сообщение "Text2" на дополнительный номер; Манго Диалоги. Справочник по API | Версия от 27.02.2026 - если Клиент прочитал сообщение "Text1", отправленное на основной номер, то ВАТС не будет отправлять сообщение "Text2" на дополнительный номер. Примечание. Метод не возвращает статус сообщений, отправленных в WA или в виде SMS. 5) Обратите внимание, что если текстовое сообщение отправлено Клиенту в виде SMS, то ВАТС принудительно завершает рассылку данному Клиенту (даже, если в параметрах метода указано, что надо отправить еще сообщение). Например, если в параметрах метода указано, что Клиенту X сначала отправляется SMS, а затем сообщение WA, то ВАТС отправит Клиенту X только одно SMS, а затем принудительно завершит рассылку. Примечание. Статус отправленного sms-сообщения НЕ учитывается и ни как не влияет на правила рассылки; 6) Сообщения могут быть отправлены в любое время.
