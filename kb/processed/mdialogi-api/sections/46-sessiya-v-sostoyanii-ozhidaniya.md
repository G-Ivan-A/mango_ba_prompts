# 3.5.1. Сессия в состоянии ожидания

> Трассировка: PDF §3.5.1 · сквозные стр. 53-57 · источники: ч.1 `kb/sources/mdialogi-api/Manual_API_Mango_Dialogi.pdf` с.53-57.

Данный вебхук отправляется во внешнюю систему после того, как в МД будет создана новая сессия. Сессии автоматически присваивается статус "pending". Примечание. В МД новая сессия создается либо по запросу "Создать новую сессию", либо автоматически при получении первого сообщения от Клиента по тому или иному текстовому каналу коммуникации.
