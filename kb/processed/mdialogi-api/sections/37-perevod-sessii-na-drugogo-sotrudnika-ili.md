# 3.2.3. Перевод сессии на другого сотрудника или группу

> Трассировка: PDF §3.2.3 · сквозные стр. 38-41 · источники: ч.1 `kb/sources/mdialogi-api/Manual_API_Mango_Dialogi.pdf` с.38-41.

Этот метод позволяет передать диалог с Клиентом от одного оператора к другому. Получив данный запрос, МД выполнит перевод следующим образом: - будет закрыта сессия, ранее назначенная в работу определенному оператору; - будет открыта новая сессия, которая сразу будет передана в работу оператору или группе, указанной в запросе; - в параметрах новой сессии будет указан идентификатор родительской сессии parent_session_id (то есть, закрытой сессии); - сообщения диалога между оператором и Клиентом, ассоциированные с закрытой сессией, будут перемещены в новую сессию. Вы можете указать, переносить все сообщения в новую сессию или только выбранные вами сообщения. Метод обрабатывается асинхронно, то есть в результате обработки запроса будет сформирован и передан во внешнюю систему код ошибки, а информация о созданной сессии будет передана во внешнюю систему при помощи вебхука "Сессия взята в работу". Примечание. Подробнее о процессе перевода обращения на другого оператора вы можете узнать из Примера использования API.
