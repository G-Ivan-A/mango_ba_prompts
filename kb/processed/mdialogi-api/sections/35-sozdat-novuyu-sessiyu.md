# 3.2.1. Создать новую сессию

> Трассировка: PDF §3.2.1 · сквозные стр. 34-36 · источники: ч.1 `kb/sources/mdialogi-api/Manual_API_Mango_Dialogi.pdf` с.34-36.

Если Клиент ранее уже обращался в вашу компанию и у вас есть уникальный идентификатор пользователя в соц. сети (social_user_id) этого Клиента, то вы можете, от имени оператора, инициировать диалог с этим Клиентом. Данный метод позволяет: - в МД создать новую сессию, которой сразу будет присвоен статус "dialog", то есть сессия будет создана и передана в работу оператору, указанному в запросе; - при необходимости отправить первое сообщение Клиенту от оператора, указанного в запросе. Метод обрабатывается асинхронно. В ответе возвращается идентификатор созданной сессии. Если в запросе был передан параметр message, дополнительно возвращается информация об отправленном сообщении. Информация о созданной сессии также передается во внешнюю систему при помощи вебхука "Сессия взята в работу". Примечание. Подробнее о процессе инициирования диалога с Клиентом со стороны оператора вы можете узнать из Примера использования API. HTTP-запрос: POST https://app.mango-office.ru/cc/md/session/create Параметры запроса:

| Параметр | Тип | Обязательное | Описание |
| --- | --- | --- | --- |
| id | String | Да | Уникальный идентификатор вызова (например,<br>UUID). Формируется внешней системой. Манго<br>Диалоги и ВАТС никак не обрабатывают этот<br>идентификатор, не<br>анализируют и не полагаются на его уникальность |
| channel_id | Integer | Да | Уникальный идентификатор канала, через который<br>должен начаться диалог между Клиентом и<br>оператором.<br>Узнать идентификатор канала вы можете при<br>помощи запроса "Получить список виджетов"<br>или API Realtime |

Манго Диалоги. Справочник по API | Версия от 10.06.2026

| social_user_id | String | Да | Уникальный идентификатор пользователя<br>(Клиента) в соц. сети.<br>Узнать идентификатор пользователя вы<br>можете из вебхуков, которые передавались ранее<br>от API к внешней системе, в момент предыдущего<br>диалога Клиента и оператора |
| --- | --- | --- | --- |
| message | String | Нет | Текст сообщения оператора Клиенту. Если<br>параметр не передан, сессия будет создана без<br>отправки первого сообщения. |
