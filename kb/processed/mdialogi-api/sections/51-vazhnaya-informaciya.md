# 4.1. Важная информация

> Трассировка: PDF §4.1 · сквозные стр. 59 · источники: ч.1 `kb/sources/mdialogi-api/Manual_API_Mango_Dialogi.pdf` с.59.

1. Если запрос к API содержит ошибки, система возвращает ошибку с кодом 3XXX. Обратите внимание: • API допускает не более одного ошибочного запроса в течение двух минут. • При превышении данного ограничения система возвращает ошибку 401. • Если во внешнюю систему отправлено более одного ошибочного запроса, доступ к API блокируется до истечения двух минут с момента получения первой ошибки с кодом 3XXX. 2. Для API установлены ограничения на количество запросов в секунду. При превышении допустимого лимита система возвращает ошибку 429. Примечание. Если получена ошибка с кодом 3XXX, 401 или 429, рекомендуется уменьшить интенсивность отправки запросов, сделать паузу перед повторным обращением к API либо исключить лишние запросы. 3. При возникновении ошибок HTTP-протокола возвращаются стандартные коды HTTP 4xx или 5xx без дополнительных данных в теле ответа. 4. При возникновении ошибки доставки сообщения система передает код ошибки в параметре error вебхука: /events/cc/md/session/chat/on_error_message Полученный код рекомендуется использовать для отображения информации оператору либо для обработки ошибок во внешней системе.
