# 6.1.5. Получить список активных сессий

> Трассировка: PDF §6.1.5 · сквозные стр. 87-91 · источники: ч.1 `kb/sources/mdialogi-api/Manual_API_Mango_Dialogi.pdf` с.87-91.

Метод возвращает список сессий, находящихся в статусе: - pending — ожидает распределения на сотрудника или группу; - dialog — передана в работу сотруднику или группе. В ответе возвращается информация о сессии, включая данные о виджете, канале коммуникации, клиенте и состоянии сессии. При указании параметра chat_id метод возвращает только активную сессию, связанную с указанным чатом. HTTP-запрос: POST https://app.mango-office.ru/cc/md/sessions Параметры запроса:

| Параметр | Тип | Обязательное | Описание |
| --- | --- | --- | --- |
| id | String | Да | Уникальный идентификатор вызова (например, UUID).<br>Формируется внешней системой. Манго Диалоги и ВАТС<br>никак не обрабатывают этот идентификатор, не<br>анализируют и не полагаются на его уникальность |
| chat_id | String | Нет | Уникальный идентификатор чата. Используется как<br>фильтр результата. Если параметр указан, метод<br>возвращает массив "sessions", содержащий только<br>активную сессию, связанную с указанным чатом. |
