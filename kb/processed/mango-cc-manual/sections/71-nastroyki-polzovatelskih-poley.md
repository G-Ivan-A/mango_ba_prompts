# Настройки пользовательских полей

> Трассировка: PDF §10.3 · сквозные стр. 326-331 · источники: ч.1 `kb/sources/mango-cc-manual/CC_manual_1.26.28.1.pdf` с.326-331.

После выбора типа поля следует установить его настройки. Выбор типа пользовательского поля доступен только при создании. Изменение типа пользовательского поля в уже созданном поле – не доступно.

![Изображение, стр. 326](../images/71-nastroyki-polzovatelskih-poley-1.png)

Отмеченные * настройки поля не могут быть впоследствии изменены. В зависимости от типов полей доступны следующие настройки:

| № | Тип настройки | Описание настройки |
| --- | --- | --- |
| 1 | Название поля | Произвольное, уникальное имя. Не может повторять название<br>стандартных полей. Длина не более 30 символов.<br>Доступна для всех типов полей. |

![Изображение, стр. 327](../images/71-nastroyki-polzovatelskih-poley-2.png)

| 2 | Количество символов* | Настройка ограничения на количество вводимых символов в<br>содержимом поля.<br>Доступна для полей:<br>• Поле ввода<br>• Адрес<br>• Число<br>• Ссылка |
| --- | --- | --- |
| 3 | Проверка<br>заполненного<br>значения на<br>уникальность* | Проверка содержимого пользовательского поля на уникальность<br>при создании или изменении. Пустое значение на уникальность<br>не проверяется.<br>Доступна для полей:<br>• Поле ввода<br>• Адрес<br>• Число<br>• Денежный<br>• Ссылка |
| 4 | Только для чтения | Вне зависимости от прав и ролей пользователей, содержимое<br>поля будет не доступно для изменения, в случае включения<br>настройки.<br>Доступна для полей:<br>• Поле ввода<br>• Адрес<br>• Число<br>• Денежный<br>• Ссылка |
| 5 | Указать ограничение<br>для суммы* | Настройка ограничения на ввод суммы чисел.<br>Доступна для полей:<br>• Денежный |
| 6 | Валюта* | Список содержит иконки трех валют для выбора:<br>• Рубль<br>• Евро<br>• Доллар<br>Доступна для полей:<br>• Денежный |
| 7 | Доступно несколько<br>вариантов для<br>выбора* | Переключает список с единичным выбором значения, на список<br>с множественным выбором.<br>Доступна для полей:<br>• Выпадающий список |
| 8 | Показывать поиск по<br>значениям | Включает/отключает поисковое поле, с поиском по значениям<br>выпадающего списка.<br>Доступна для полей: |

![Изображение, стр. 328](../images/71-nastroyki-polzovatelskih-poley-3.png)

|  |  | • Выпадающий список<br>• Пользователь |
| --- | --- | --- |
| 9 | Действия со<br>значениями<br>выпадающего списка | Доступны следующие действия:<br>• Наименование значения списка – произвольное, уникальное<br>наименование значения выпадающего списка;<br>• Добавление значения списка – настройка, добавляющая плюс<br>еще одно значение выпадающего списка к существующему<br>одному значению, созданному системой автоматически;<br>• Изменение порядка расположения значений. Пользователю<br>доступно изменение порядка созданных значений, повышая<br>приоритет (перемещая выше), либо уменьшая приоритет<br>(перемещая ниже);<br>• Удаление значения списка – настройка, удаляющая значение<br>выпадающего списка без возможности восстановления.<br>Доступна для полей:<br>• Выпадающий список |

Дополнительные настройки для пользовательских полей:

| № | Наименование | Описание настройки |
| --- | --- | --- |
|  | настройки |  |
| 1 | Обязательность<br>заполнения | При включенном состоянии, включена проверка, которая не<br>позволяет создавать или изменять сделки, если содержимое поля<br>– пусто |
| 2 | Показывать в карточке | Включено или выключено отображение поля на интерфейсе<br>карточки сделки |
| 3 | Порядок полей | Настройка позволяет менять порядок расположения полей в<br>интерфейсе. Влияет только на порядок расположения поля, не<br>изменяет данные или содержимое пользовательского поля. |

Просмотр/редактирование полей адресной книги Для просмотра или редактирования пользовательского поля щелкните по названию поля и, при необходимости, внесите изменения в настройки поля. Для редактирования доступны только значения, выделенные оранжевым цветом.

![Изображение, стр. 329](../images/71-nastroyki-polzovatelskih-poley-4.png)

![Изображение, стр. 329](../images/71-nastroyki-polzovatelskih-poley-5.png)

Если чекбокс "Только для чтения" проставлен, пользовательское поле недоступно для заполнения. В графе "Обязательно для заполнения" значение "Нет" отображается оранжевым цветом. Настроить порядок полей Клик по кнопке Настроить порядок полей открывает окно, в котором пользователь может изменить порядок отображения пользовательских полей.

![Изображение, стр. 330](../images/71-nastroyki-polzovatelskih-poley-6.jpeg)

![Изображение, стр. 330](../images/71-nastroyki-polzovatelskih-poley-7.png)

![Изображение, стр. 330](../images/71-nastroyki-polzovatelskih-poley-8.png)

Для изменения порядка полей зафиксируйте левую кнопку мыши на пиктограмме и переместите поле вверх или вниз по списку. Сохраните внесенные изменения кнопкой Сохранить.

| Кнопка Настроить порядок полей недоступна, если на продукте имеется менее двух |
| --- |
| пользовательских полей. |

![Изображение, стр. 330](../images/71-nastroyki-polzovatelskih-poley-9.png)

Удаление пользовательских полей Для удаления поля кликните на наименование поля и в открывшемся окне нажмите кнопку Удалить. Подтвердите согласие на удаление.

| При удалении пользовательского поля удаляется поле и все содержимое поля, без |
| --- |
| возможности восстановления. |
