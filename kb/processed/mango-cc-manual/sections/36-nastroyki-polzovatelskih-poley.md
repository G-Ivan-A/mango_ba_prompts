# Настройки пользовательских полей

> Трассировка: PDF §5.6 · сквозные стр. 198-200 · источники: ч.1 `kb/sources/mango-cc-manual/CC_manual_1.26.28.1.pdf` с.198-200.

После выбора типа поля следует установить его настройки. Выбор типа пользовательского поля доступен только при создании. Изменение типа пользовательского поля в уже созданном поле – не доступно.

![Изображение, стр. 198](../images/36-nastroyki-polzovatelskih-poley-1.png)

Отмеченные * настройки поля не могут быть впоследствии изменены. В зависимости от типов полей доступны следующие настройки:

| № | Тип настройки | Описание настройки |
| --- | --- | --- |
| 1 | Название поля | Произвольное, уникальное имя. Не может повторять название<br>стандартных полей. Длина не более 30 символов.<br>Доступна для всех типов полей. |
| 2 | Количество символов* | Настройка ограничения на количество вводимых символов в<br>содержимом поля.<br>Доступна для полей:<br>• Поле ввода<br>• Адрес<br>• Число<br>• Ссылка |
| 3 | Проверка<br>заполненного<br>значения на<br>уникальность* | Проверка содержимого пользовательского поля на<br>уникальность при создании или изменении. Пустое значение<br>на уникальность не проверяется.<br>Доступна для полей:<br>• Поле ввода<br>• Адрес<br>• Число<br>• Денежный<br>• Ссылка |
| 4 | Только для чтения | Вне зависимости от прав и ролей пользователей, содержимое<br>поля будет не доступно для изменения, в случае включения<br>настройки.<br>Доступна для полей:<br>• Поле ввода<br>• Адрес<br>• Число<br>• Денежный |

|  |  | • Ссылка |
| --- | --- | --- |
| 5 | Указать ограничение<br>для суммы* | Настройка ограничения на ввод суммы чисел.<br>Доступна для полей:<br>• Денежный |
| 6 | Валюта* | Список содержит иконки трех валют для выбора:<br>• Рубль<br>• Евро<br>• Доллар<br>Доступна для полей:<br>• Денежный |
| 7 | Доступно несколько<br>вариантов для<br>выбора* | Переключает список с единичным выбором значения, на<br>список с множественным выбором.<br>Доступна для полей:<br>• Выпадающий список |
| 8 | Показывать поиск по<br>значениям | Включает/отключает поисковое поле, с поиском по значениям<br>выпадающего списка.<br>Доступна для полей:<br>• Выпадающий список<br>• Пользователь |
| 9 | Действия со<br>значениями<br>выпадающего списка | Доступны следующие действия:<br>• Наименование значения списка – произвольное, уникальное<br>наименование значения выпадающего списка;<br>• Добавление значения списка – настройка, добавляющая плюс<br>еще одно значение выпадающего списка к существующему<br>одному значению, созданному системой автоматически;<br>• Изменение порядка расположения значений. Пользователю<br>доступно изменение порядка созданных значений, повышая<br>приоритет (перемещая выше), либо уменьшая приоритет<br>(перемещая ниже);<br>• Удаление значения списка – настройка, удаляющая значение<br>выпадающего списка без возможности восстановления.<br>Доступна для полей:<br>• Выпадающий список |
