# 16.4. Подключенные каналы

Для клиентов, использующих оффлайновые источники аудиозаписей в "Речевой аналитике" предусмотрена возможность настроить один или несколько способов получения записей разговоров. Раздел содержит три вкладки: • Получение записей через FTP • Получение записей через API • Загрузка записей вручную
