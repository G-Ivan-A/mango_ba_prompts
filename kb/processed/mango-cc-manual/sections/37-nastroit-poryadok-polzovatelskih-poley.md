# Настроить порядок пользовательских полей

> Трассировка: PDF §5.6 · сквозные стр. 200 · источники: ч.1 `kb/sources/mango-cc-manual/CC_manual_1.26.28.1.pdf` с.200.

Клик по кнопке Настроить порядок полей открывает окно, в котором пользователь может изменить порядок отображения пользовательских полей.
