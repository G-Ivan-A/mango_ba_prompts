# Перед началом работы

> Трассировка: PDF §2.10 · сквозные стр. 81 · источники: ч.1 `kb/mango-product-docs/sources/integration-bitrix24/Mango_office_integration_Bitrix24.pdf` с.81.

Чтобы сохранять тематику и/или тексты разговоров, в Битрикс24 вам нужно подключить: 1. сервис Речевой аналитики; 2. сервис Записи разговоров; 3. расширенный пакет интеграции с Битрикс24. Важно! Если вы не подключите сервисы Записи разговоров и Речевой аналитики, а также расширенный пакет интеграции с Битрикс24, то сохранять тематики и/или тексты разговоров будет невозможно. Определять тематику и/или тексты можно в разговорах тех пользователей Битрикс24, которым указан сотрудник Виртуальной АТС.
