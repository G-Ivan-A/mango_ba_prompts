> Трассировка: PDF §— · сквозные стр. 42 · источники: ч.1 `kb/mango-product-docs/sources/mtalker/UserGuide_mTalker_4Mobile.pdf` с.42.

Чтобы добавить контакт, на закладку “Контакты” следует:

![Изображение, стр. 42](../images/101-dobavlenie-kontakta-1.png)
