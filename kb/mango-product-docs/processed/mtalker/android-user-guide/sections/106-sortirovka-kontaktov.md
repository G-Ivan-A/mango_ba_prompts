# Сортировка контактов

> Трассировка: PDF §— · сквозные стр. 43 · источники: ч.1 `kb/mango-product-docs/sources/mtalker/UserGuide_mTalker_4Mobile.pdf` с.43.

В телефонной книге можно упорядочивать контакты с помощью сортировки по имени или фамилии. Для этого, на закладке “Контакты” следует: 1) нажмите на аватар в левом верхнем углу. Будет открыт раздел “Настройки”; 2) нажмите на пункт “Контакты”. Будет открыт раздел “Контакты”; 3) нажмите на пункт “Сортировка”; 4) выберите сортировку по имени или по фамилии и нажмите кнопку “Ок”.
