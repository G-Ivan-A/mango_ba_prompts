# Автоматический поиск по параметрам

> Трассировка: PDF §— · сквозные стр. 34 · источники: ч.1 `kb/mango-product-docs/sources/mtalker/UserGuide_mTalker_4Mobile.pdf` с.34.

Для того чтобы воспользоваться автоматическим поиском, в основном окне MTalker следует:

![Изображение, стр. 34](../images/83-avtomaticheskiy-poisk-po-parametram-1.png)

1) нажмите кнопку . Будет открыт раздел “Журнал вызовов”;

![Изображение, стр. 34](../images/83-avtomaticheskiy-poisk-po-parametram-2.png)

2) нажмите кнопку . Будет открыта экранная клавиатура; 3) введите параметр поиска: имя, фамилия, SIP-номер. Не допускается использование регулярных выражений в параметрах поиска. 4) Будут отображены записи журнала вызовов, соответствующие указанному параметру поиска.
