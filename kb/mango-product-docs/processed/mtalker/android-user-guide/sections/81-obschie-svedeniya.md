# Общие сведения

> Трассировка: PDF §— · сквозные стр. 33 · источники: ч.1 `kb/mango-product-docs/sources/mtalker/UserGuide_mTalker_4Mobile.pdf` с.33.

Вы можете в журнале вызовов искать записи двумя способами: вручную, автоматически. Поиск вручную выполняется путем просмотра всех подряд записей в журнале вызовов. Автоматический поиск по параметрам записи, в качестве параметра можно указать имя контакта или должность, или номер телефона и другое. Не допускается использование регулярных выражений в параметрах поиска.
