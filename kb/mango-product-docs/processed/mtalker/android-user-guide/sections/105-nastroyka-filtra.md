# Настройка фильтра

> Трассировка: PDF §— · сквозные стр. 43 · источники: ч.1 `kb/mango-product-docs/sources/mtalker/UserGuide_mTalker_4Mobile.pdf` с.43.

Вы можете скрыть или показать те или иные разделы телефонной книги. Для этого в MTalker есть фильтр. Для того чтобы настроить фильтр, на закладке “Контакты” следует:

![Изображение, стр. 43](../images/105-nastroyka-filtra-1.png)

1) нажмите кнопку . Будет открыто окно “Адресные книги”; 2) выберите нужный вариант: – чтобы выключить показ раздела, деактивируйте (выключите)

![Изображение, стр. 43](../images/105-nastroyka-filtra-2.png)

переключатель в строке с названием нужного раздела; – чтобы разрешить показ раздела, активируйте (включите)

![Изображение, стр. 43](../images/105-nastroyka-filtra-3.png)

переключатель в строке с названием нужного раздела; 3) нажмите кнопку”Ок” . Будет открыта закладка “Контакты”, на которой показаны только выбранные вами разделы телефонной книги.
