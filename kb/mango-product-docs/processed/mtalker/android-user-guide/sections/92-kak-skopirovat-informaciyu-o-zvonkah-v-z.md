# Как скопировать информацию о звонках в журнале вызовов

> Трассировка: PDF §— · сквозные стр. 38 · источники: ч.1 `kb/mango-product-docs/sources/mtalker/UserGuide_mTalker_4Mobile.pdf` с.38.

Вы можете скопировать строку с данными о звонке из журнала вызовов, чтобы передать эту информацию. Порядок действий в журнале вызовов: 1) нажмите и удерживайте строку с данными вызова, которую следует скопировать. Будет открыто контекстное меню; 2) нажмите пункт “Скопировать”. Будет скопирована из журнала вызовов выбранная вами строка.
