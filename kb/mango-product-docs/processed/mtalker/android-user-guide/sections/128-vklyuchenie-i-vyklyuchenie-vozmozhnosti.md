# Включение и выключение возможности видео звонка. Настройка фона

> Трассировка: PDF §— · сквозные стр. 50-51 · источники: ч.1 `kb/mango-product-docs/sources/mtalker/UserGuide_mTalker_4Mobile.pdf` с.50-51.

По умолчанию, в MTalker включена функция “Видеозвонок”. Вы можете выключить эту функцию. Для этого, в основном окне MTalker следует: 1) нажмите на аватар в левом верхнем углу. Будет открыт раздел “Настройки”; 2) нажмите “Видеозвонки” в разделе “Настройки”; 3) выберите нужны вариант: – чтобы выключить функцию, деактивируйте переключатель “Использовать видеозвонки”; – чтобы разрешить функцию, активируйте переключатель “Использовать видеозвонки”. 4. чтобы настроить отображение фона, нажмите на пункт “Отображение фона”, затем выберите варианты фона : – размытие: размытие вашего фона, при проведении видеозвонка;
