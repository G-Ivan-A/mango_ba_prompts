# Описание журнала вызовов

> Трассировка: PDF §— · сквозные стр. 32 · источники: ч.1 `kb/mango-product-docs/sources/mtalker/UserGuide_mTalker_4Mobile.pdf` с.32.

Функция MTalker” Журнал вызовов” позволяет получать информацию о том, кто и когда звонил вам ранее. В журнале вызовов содержатся записи о звонках, прошедших через вашу SIP-учетную запись ВАТС и номер мобильного телефона (при его регистрации на ВАТС). Журнал вызовов содержит разделы: • Все вызовы; • Пропущенные; • Записи разговоров; • Голосовая почта. В общем случае, запись о звонке содержит следующие данные: • имя звонившего (загружается из телефонной книги при наличии); • тип вызова:
