# Общие сведения

> Трассировка: PDF §— · сквозные стр. 52 · источники: ч.1 `kb/mango-product-docs/sources/mtalker/UserGuide_mTalker_4Mobile.pdf` с.52.

Вы можете передать отзыв непосредственно из MTalker. В отзыве вы можете оценить работу MTalker, а также можете сообщить: • если MTalker сломался, работает не корректно или выдает ошибки; • свои предложения по улучшению работы MTalker. После сеанса связи пользователю, по умолчанию, показывается окно и предлагается оценить качество связи. Вы можете выключить данное уведомление.
