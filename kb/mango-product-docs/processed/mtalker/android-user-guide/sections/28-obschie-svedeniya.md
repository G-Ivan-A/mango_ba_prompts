# Общие сведения

> Трассировка: PDF §— · сквозные стр. 16 · источники: ч.1 `kb/mango-product-docs/sources/mtalker/UserGuide_mTalker_4Mobile.pdf` с.16.

Во время звонка, вы можете использовать следующие функции управления звонком:

| Функция | Пояснение |
| --- | --- |
| Выключить<br>звук | Выключить микрофон, звуковой сигнал с вашего<br>микрофона больше не будет передаваться в текущий сеанс<br>связи и ваши собеседники вас не услышат. |
| Звук | Переключение между режимами ”громкий динами” и<br>“разговорный динамик” |
| Запись | Включение/выключение записи разговора. Данная<br>функция может быть не доступна, в зависимости от<br>настроек вашей ВАТС. |
| Перевести | Перевод вызова на того или иного абонента, записанного в<br>телефонной книге. |
| Переключить | Перевод вызова на другое ваше устройство. Например,<br>если вы разговариваете через мобильное приложение<br>MTalker и у вас на рабочем ПК установлено “десктопное”<br>приложение MTalker, то с помощью данной кнопки, вы<br>можете перевести звонок с вашего мобильного на ваш<br>рабочий ПК и продолжить разговор, через рабочий ПК. |
| Сообщение | Создать чат “Один-на-один”. Данная функция доступна<br>только, если абонент записан в телефонную книгу. |
| Удержание | Удержание вызова |
| Завершение<br>вызова | Положить трубку, завершив свое участие в данном сеансе<br>связи. При этом, если вы принимали участие в групповом<br>вызове, то сеанс связи будет завершен только для вас.<br>Остальные участники продолжат сеанс связи. |
| Показать<br>экранную<br>клавиатуру | Отображение экранной клавиатуры в окне проведения<br>сеанса связи. |
