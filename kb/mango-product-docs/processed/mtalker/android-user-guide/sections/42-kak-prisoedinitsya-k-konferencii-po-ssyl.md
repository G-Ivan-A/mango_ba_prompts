# Как присоединиться к конференции по ссылке

> Трассировка: PDF §— · сквозные стр. 20 · источники: ч.1 `kb/mango-product-docs/sources/mtalker/UserGuide_mTalker_4Mobile.pdf` с.20.

Если вы получили ссылку на видеоконференцию, например, по email, вы можете присоединиться к этой видеоконференции по данной ссылке. Для этого, в основном окне MTalker следует:

![Изображение, стр. 20](../images/42-kak-prisoedinitsya-k-konferencii-po-ssyl-1.png)

1. перейдите в раздел “Конференции”, нажав на пиктограмму ;

![Изображение, стр. 20](../images/42-kak-prisoedinitsya-k-konferencii-po-ssyl-2.png)

2. нажать на ссылку “Присоединиться по ссылке” . Будет открыто окно “Войти в видеоконференцию”; 3. в поле “Ссылка на видеоконференцию” вставьте полученную вами ссылку на видеоконференцию; 4. нажмите кнопку “Войти”. Вы войдете в видеоконференцию по ссылке.
