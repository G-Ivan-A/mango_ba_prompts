# Фильтрация записей по отчетному периоду

> Трассировка: PDF §— · сквозные стр. 34 · источники: ч.1 `kb/mango-product-docs/sources/mtalker/UserGuide_mTalker_4Mobile.pdf` с.34.

Вы можете выбрать отчетный период, за который нужно отобразить в Журнале вызовов записи о звонках. Для этого, в основном окне MTalker следует:

![Изображение, стр. 34](../images/84-filtraciya-zapisey-po-otchetnomu-periodu-1.png)

1) нажмите кнопку . Будет открыт раздел “Журнал вызовов”;

![Изображение, стр. 34](../images/84-filtraciya-zapisey-po-otchetnomu-periodu-2.png)

2) нажмите на кнопку “Фильтр” . Будет открыто окно “Период”; 3) выберите нужны отчетные период (день, неделя, месяц) или введите период, нужный вам. Будет отображен список записей о звонках, совершенных в отчетный период.
