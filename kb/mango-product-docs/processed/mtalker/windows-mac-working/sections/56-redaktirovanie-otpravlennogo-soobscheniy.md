# Редактирование отправленного сообщения

> Трассировка: PDF §4.3 · сквозные стр. 28 · источники: ч.1 `kb/mango-product-docs/sources/mtalker/mTalker_User_Guide_ch1_Working.pdf` с.28.

Редактировать исходящее сообщение можно в течении 1 часа после отправки. По истечении этого времени, редактировать исходящее сообщение нельзя.

![Изображение, стр. 28](../images/56-redaktirovanie-otpravlennogo-soobscheniy-1.png)

Для того чтобы редактировать сообщение, в разделе”Чаты” следует: 1) нажать на чат, в котором будете редактировать сообщение; 2) навести курсор на сообщение и нажать левую кнопку мыши. Будет открыто контекстное меню; 3) выбрать пункт “Редактировать”. Будет показан текст выбранного вами сообщения в поле “Текст сообщения”; 4) измените текст сообщения так, как вам нужно и нажмите на кнопку “Enter”. Будет изменен текст выбранного вами сообщения, в истории переписки отредактированное сообщение будет помечено “Изменено”.
