# Переключение фокуса при входящем звонке

> Трассировка: PDF §17.6 · сквозные стр. 111 · источники: ч.1 `kb/mango-product-docs/sources/mtalker/mTalker_User_Guide_ch1_Working.pdf` с.111.

Эта настройка используется, чтобы при входящем звонке автоматически становилось активным окно MTalker “Входящий звонок”, при этом все остальные окна, открытые на вашем ПК, стали бы не активными. Чтобы принять звонок, нажмите кнопку “Enter”, а чтобы сбросить звонок – нажмите кнопку “Esc”. Кроме того, вы можете определить, как обработать входящий звонок во время активного звонка (то есть, как обработать второй входящий вызов). Вы можете выбрать: • показывать информацию о входящем звонке; • сбрасывать входящий звонок во время активного звонка; • скрывать информацию о входящем звонке. Для того чтобы включить переключение фокуса при входящем звонке, следует:

![Изображение, стр. 111](../images/280-pereklyuchenie-fokusa-pri-vhodyaschem-zv-1.png)

1) нажать на кнопку “Аватар” . Будет открыта закладка “Настройки”;

![Изображение, стр. 111](../images/280-pereklyuchenie-fokusa-pri-vhodyaschem-zv-2.png)

2) нажать на пункт “Звонки” ; 3) активировать (включить) переключатель “Автоматически переключать фокус при входящем звонке”; 4) чтобы активное окно “Входящий звонок” было зафиксировано на экране, надо активировать переключатель “Сохранять положение виджета на экране”; 5) при необходимости выберите режим обработки второго входящего звонка путем выбора значения в поле “Входящие вызовы во время активного звонка”.
