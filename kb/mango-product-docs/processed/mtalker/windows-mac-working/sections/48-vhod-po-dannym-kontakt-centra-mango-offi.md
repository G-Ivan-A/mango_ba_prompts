# 3.4. Вход по данным Контакт-Центра MANGO OFFICE

> Трассировка: PDF §3.4 · сквозные стр. 25-26 · источники: ч.1 `kb/mango-product-docs/sources/mtalker/mTalker_User_Guide_ch1_Working.pdf` с.25-26.

Кроме логина и пароля, для входа в MTalker вы можете использовать учетную запись Контакт-центра MANGO OFFICE. Данные учетной записи указываются в карточке сотрудника в Личном кабинете:

![Изображение, стр. 25](../images/48-vhod-po-dannym-kontakt-centra-mango-offi-1.png)

3.5 Как выйти из аккаунта из MTalker В MTalker можно выйти из аккаунта пользователя. После этого вы увидите окно MTalker “Добро пожаловать” и сможете снова войти в MTalker с помощью того или иного аккаунта. Порядок действий:

![Изображение, стр. 25](../images/48-vhod-po-dannym-kontakt-centra-mango-offi-2.png)

1) нажмите иконку (основное меню и профиль пользователя). Будет открыт раздел “Настройки”; 2) нажмите на строку с именем пользователя; 3) нажмите на ссылку “Сменить пользователя”. Будет выполнен выход из аккаунта пользователя и отображено окно “Войдите в ваш аккаунт”. Mango Talker для сред ОС Windows и Mac. Руководство пользователя | Версия от 23.08.2024
