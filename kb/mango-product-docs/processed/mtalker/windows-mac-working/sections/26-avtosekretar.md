# Автосекретарь

> Трассировка: PDF §1.3 · сквозные стр. 16-17 · источники: ч.1 `kb/mango-product-docs/sources/mtalker/mTalker_User_Guide_ch1_Working.pdf` с.16-17.

Раздел “Автосекретарь” предназначена для работы с одноименной услугой. Автосекретарь – это услуга MANGO OFFICE, с помощью которой вы можете самостоятельно создать индивидуальные правила распределения входящих звонков для того или иного сотрудника. Примечание. Если вы открыли этот раздел впервые, в MTalker будет показана общая информация об услуге. Нажмите кнопку “Понятно”. Mango Talker для сред ОС Windows и Mac.
