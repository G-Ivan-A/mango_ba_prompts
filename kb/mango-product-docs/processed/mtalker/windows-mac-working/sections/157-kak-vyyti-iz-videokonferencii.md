# 7.9. Как выйти из видеоконференции

> Трассировка: PDF §7.9 · сквозные стр. 67-68 · источники: ч.1 `kb/mango-product-docs/sources/mtalker/mTalker_User_Guide_ch1_Working.pdf` с.67-68.

Для того, чтобы выйти из видеоконференции, в окне проведения видеозвонка

![Изображение, стр. 67](../images/157-kak-vyyti-iz-videokonferencii-1.png)

нажмите кнопку . Будет выполнено одно из следующих действий: • если проводился групповой видеозвонок, то вы выйдете из сеанса связи, при этом остальные собеседники продолжат общение; • если выполнялся звонок абоненту, то будет завершен сеанс связи.
