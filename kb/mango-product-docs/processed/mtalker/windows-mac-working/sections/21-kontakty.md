# Контакты

> Трассировка: PDF §1.3 · сквозные стр. 14 · источники: ч.1 `kb/mango-product-docs/sources/mtalker/mTalker_User_Guide_ch1_Working.pdf` с.14.

Раздел “Контакты” предназначен для доступа к телефонному справочнику и журналу звонков. Чтобы открыть раздел “Контакты”, следует в основном окне

![Изображение, стр. 14](../images/21-kontakty-1.png)

MTalker нажать на кнопку . Будет открыт раздел “Контакты”, на котором отображаются следующие элементы интерфейса:

![Изображение, стр. 14](../images/21-kontakty-2.png)

1) кнопка отображения групп контактов из телефонного справочника;

![Изображение, стр. 14](../images/21-kontakty-3.png)

2) кнопка для добавления контакта;

![Изображение, стр. 14](../images/21-kontakty-4.png)

3) поле для поиска контакта; 4) список контактов; 5) группа полей для показа детальных данных контакта.
