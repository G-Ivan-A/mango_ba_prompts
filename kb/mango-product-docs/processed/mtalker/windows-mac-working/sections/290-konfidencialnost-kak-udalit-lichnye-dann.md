# Конфиденциальность. Как удалить личные данные

> Трассировка: PDF §17.6 · сквозные стр. 114 · источники: ч.1 `kb/mango-product-docs/sources/mtalker/mTalker_User_Guide_ch1_Working.pdf` с.114.

Вы можете удалить следующие личные данные из MTalker: • сообщения: все ваши сообщения из всех чатов и выход из всех групповых чатов; • историю вызовов: удаление всех записей из журнала вызовов; • контакты: удаление всех контактов из группы “Личные” адресной книги. Для того чтобы удалить личные данные из MTalker, следует:

![Изображение, стр. 114](../images/290-konfidencialnost-kak-udalit-lichnye-dann-1.png)

1) нажать на кнопку “Аватар” . Будет открыта закладка “Настройки”;

<!-- изображение на стр. 114: байты не извлечены (PyMuPDF недоступен) -->

2) нажать на пункт “Управление данными” . Будут отображены дополнительные поля; 3) активировать переключатель в тех типах личных данных, которые вы ходите удалить: – удалить сообщения; – удалить историю вызовов; – удалить контакты; 4) нажать на кнопку “Удалить”. Будут удалены выбранные ранее личные данные.
