# Общие сведения

> Трассировка: PDF §5.14 · сквозные стр. 48 · источники: ч.1 `kb/mango-product-docs/sources/mtalker/mTalker_User_Guide_ch1_Working.pdf` с.48.

Вы можете выйти из канала, при этом вы больше не будете получать уведомлений из этого канала, а также строка с названием канала будет удалена из раздела “Чаты” из списка ваших чатов и каналов. Если вы являетесь подписчиком, то после выхода из канала любого участника этот канал не будет удален из MTalker и в нем продолжится публикация сообщений. Если вы обладаете правами администратора, то после вашего выхода из канала будут выполнены следующие действия: • удален канал из MTalker; • подписчики канала не будут получать уведомлений из этого канала.
