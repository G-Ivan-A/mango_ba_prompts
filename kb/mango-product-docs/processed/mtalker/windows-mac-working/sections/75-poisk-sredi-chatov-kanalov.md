# Поиск среди чатов / каналов

> Трассировка: PDF §4.9 · сквозные стр. 34-35 · источники: ч.1 `kb/mango-product-docs/sources/mtalker/mTalker_User_Guide_ch1_Working.pdf` с.34-35.

Для того чтобы найти сообщение или чат/канал, в котором вы ранее участвовали, в основном окне MTalker следует:

![Изображение, стр. 34](../images/75-poisk-sredi-chatov-kanalov-1.png)

1) нажать на кнопку . Будет открыт раздел “Чаты”;

![Изображение, стр. 34](../images/75-poisk-sredi-chatov-kanalov-2.png)

2) ввести параметр поиска в поле “Поиск” . Будет выполнен поиск чата по введенному вами параметру. Результаты поиска будут показаны в разделе”Чаты” и выделены синим цветом.

![Изображение, стр. 34](../images/75-poisk-sredi-chatov-kanalov-3.png)

Примечание. Чтобы скрыть результаты поиска, нужно нажать на кнопку в поле для ввода параметра локального поиска. Mango Talker для сред ОС Windows и Mac. Руководство пользователя | Версия от 23.08.2024
