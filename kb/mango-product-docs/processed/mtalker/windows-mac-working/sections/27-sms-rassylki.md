# SMS-рассылки

> Трассировка: PDF §1.3 · сквозные стр. 17 · источники: ч.1 `kb/mango-product-docs/sources/mtalker/mTalker_User_Guide_ch1_Working.pdf` с.17.

Раздел “SMS-рассылки” предназначен для работы с одноименной услугой. SMS-рассылки – это услуга MANGO OFFICE, с помощью которой вы можете создать и управлять рассылками sms.

![Изображение, стр. 17](../images/27-sms-rassylki-1.png)

Чтобы открыть раздел “SMS-рассылки”, нажмите на кнопку . Если вы открыли этот раздел впервые, в MTalker будет показана общая информацию об услуге. Нажмите кнопку “Создать рассылку”. Нажав кнопку “Создать рассылку” вы переходите в режим создания новой рассылки. В разделе “SMS-рассылки” отображаются элементы управления данной услугой:

![Изображение, стр. 17](../images/27-sms-rassylki-2.png)

1) кнопка для добавления новой рассылки; 2) список ранее настроенных SMS-рассылок; 3) поле для показа и редактирования детальных параметров рассылки.
