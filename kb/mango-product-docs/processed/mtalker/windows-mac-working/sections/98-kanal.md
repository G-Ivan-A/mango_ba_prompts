# Канал

> Трассировка: PDF §5.2 · сквозные стр. 43 · источники: ч.1 `kb/mango-product-docs/sources/mtalker/mTalker_User_Guide_ch1_Working.pdf` с.43.

Для того чтобы создать канал, следует:

![Изображение, стр. 43](../images/98-kanal-1.png)

1) нажать на кнопку . Будет открыт раздел “Чаты”;

![Изображение, стр. 43](../images/98-kanal-2.png)

2) нажать на кнопку . Будет открыто дополнительное меню; 3) выбрать пункт “Создать канал”. Будет открыто окно “Новый канал”; 4) ввести название канала, при необходимости ввести описание канала; 5) выберите тип канала: открытый канал, закрытый канал; 6) нажмите кнопку “Далее”; 7) в строке поиска введите имя собеседника, которого нужно добавить в канал или найдите имя собеседника в общем списке; 8) активировать переключатель в строке с именем каждого собеседника, который хотите добавить в канал; 9) нажать на кнопку “Создать”.
