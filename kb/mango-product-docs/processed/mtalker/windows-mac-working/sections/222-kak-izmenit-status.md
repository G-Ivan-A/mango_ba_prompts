# Как изменить статус

> Трассировка: PDF §14.1 · сквозные стр. 91-92 · источники: ч.1 `kb/mango-product-docs/sources/mtalker/mTalker_User_Guide_ch1_Working.pdf` с.91-92.

Для того чтобы изменить статус пользователя через системные уведомления, следует: 1) открыть системные уведомления;

![Изображение, стр. 91](../images/222-kak-izmenit-status-1.png)

2) навести курсор мыши на иконку MTalker и нажать левую кнопку мыши. Будет открыто контекстное меню; 3) выбрать пункт “Сетевой статус”. Будет отображен список статусов пользователя; 4) выберите нужный статус. Mango Talker для сред ОС Windows и Mac. Руководство пользователя | Версия от 23.08.2024 Для того чтобы сменить статус пользователя через основное окно MTalker, следует:

![Изображение, стр. 92](../images/222-kak-izmenit-status-2.png)

1) нажать иконку (основное меню и профиль пользователя);

![Изображение, стр. 92](../images/222-kak-izmenit-status-3.png)

2) нажмите на строку с именем пользователя ; 3) под именем пользователя отображается поле со статусом. Нажмите на него; 4) выберите статус пользователя. Будет принудительно присвоен выбранный статус.
