# 5.4. Пригласить по ссылке нового участника

> Трассировка: PDF §5.4 · сквозные стр. 43-44 · источники: ч.1 `kb/mango-product-docs/sources/mtalker/mTalker_User_Guide_ch1_Working.pdf` с.43-44.

Вы можете создать ссылку на чат и передать ее тому или иному сотруднику. Сотрудник, получив ссылку, нажмет на нее и увидит история сообщений в данном чате / канале. Для того чтобы пригласить по ссылке нового участника в общий чат, в разделе”Чаты” следует: 1. кликнуть на строку с названием целевого чата / канала. Будет открыта история сообщений в данном чате / канале; Mango Talker для сред ОС Windows и Mac. Руководство пользователя | Версия от 23.08.2024 2. нажмите на перечень участников чата под названием чата. Будет открыто окно “Информация о чате”;

![Изображение, стр. 44](../images/100-priglasit-po-ssylke-novogo-uchastnika-1.png)

3. нажмите на кнопку “Пригласить по ссылке” . Будет открыто окно “Пригласить по ссылке”; 4. нажмите кнопку “Копировать”. Будет скопирована на ваш ПК ссылка на данный чат / канал; 5. нажмите кнопку “Ок”, чтобы закрыть окно “Пригласить по ссылке”; 6. отправьте скопированную ссылку через чат MTalker сотруднику, которого хотите пригласить в чат.
