# Звонок на добавочный номер

> Трассировка: PDF §6.1 · сквозные стр. 50 · источники: ч.1 `kb/mango-product-docs/sources/mtalker/mTalker_User_Guide_ch1_Working.pdf` с.50.

Звонок на добавочный номер выполняется через “,” (запятая). Для этого, в основном окне MTalker следует:

![Изображение, стр. 50](../images/122-zvonok-na-dobavochnyy-nomer-1.png)

1) нажать на кнопку . Будет открыт раздел “Клавиши”; 2) в поле “Номер” удали все символы, если они там есть; 3) при помощи экранной клавиатуры ведите номер телефона, затем поставьте “,” (запятая) и введите добавочный номер;

![Изображение, стр. 50](../images/122-zvonok-na-dobavochnyy-nomer-2.png)

4) нажмите кнопку . Будет выполнен звонок на добавочный номер телефона.
