# Добавление нового контакта

> Трассировка: PDF §9.5 · сквозные стр. 80 · источники: ч.1 `kb/mango-product-docs/sources/mtalker/mTalker_User_Guide_ch1_Working.pdf` с.80.

Вы можете сохранить свой личный контакт во внутреннюю телефонной книгу MTalker. Для этого, в основном окне MTalker следует:

![Изображение, стр. 80](../images/186-dobavlenie-novogo-kontakta-1.png)

1) нажать на кнопку . Будет открыт раздел “Контакты”;

![Изображение, стр. 80](../images/186-dobavlenie-novogo-kontakta-2.png)

2) нажать на кнопку . Будет открыто дополнительное меню; 3) выбрать пункт “Личный контакт”: 4) заполните поля для ввода нового контакта; 5) нажмите кнопку “Сохранить”. Будет добавлен новый личный контакт.
