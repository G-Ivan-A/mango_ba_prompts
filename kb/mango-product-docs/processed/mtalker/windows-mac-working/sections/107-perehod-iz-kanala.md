# Переход из канала

> Трассировка: PDF §5.8 · сквозные стр. 45-46 · источники: ч.1 `kb/mango-product-docs/sources/mtalker/mTalker_User_Guide_ch1_Working.pdf` с.45-46.

Для того чтобы из канала перейти к карточке абонента, в разделе”Чаты” следует: 1) кликнуть на строку с названием целевого канала. Будет открыта история сообщений в данном канале; 2) нажмите на перечень участников канала под названием канала. Будет открыто окно “Информация о канале”; 3) навести курсор на имя участника, чью карточку нужно открыть. Будут показаны дополнительные кнопки управления; Mango Talker для сред ОС Windows и Mac.
