# Удаленный выход из MTalker

> Трассировка: PDF §17.12 · сквозные стр. 120-121 · источники: ч.1 `kb/mango-product-docs/sources/mtalker/mTalker_User_Guide_ch1_Working.pdf` с.120-121.

Если вы забыли выйти из MTalker на ПК, к которому у вас уже нет доступа, то сделать это можно удаленно. Чтобы удаленно выйти из MTalker, в списке устройств, на которых открыта ваша сессия пользователя, следует: 1) нажать пиктограмму “Корзина”в строке с данными того или иного устройства, на котором выполнен вход в MTalker. Будет открыто окно “Завершение сессии”; 2) нажать на кнопку “Завершить”. Будет завершена ваше сессия пользователя MTalker на выбранном вами устройстве. Mango Talker для сред ОС Windows и Mac.
