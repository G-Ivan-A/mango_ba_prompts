# 4.12. Цитирование сообщений

> Трассировка: PDF §4.12 · сквозные стр. 39 · источники: ч.1 `kb/mango-product-docs/sources/mtalker/mTalker_User_Guide_ch1_Working.pdf` с.39.

В MTalker вы можете пересылать сообщения своему собеседнику в чате. Для

![Изображение, стр. 39](../images/88-citirovanie-soobscheniy-1.png)

этого, в разделе”Чаты” следует: 1) навести курсор на сообщение, которое надо процитировать и нажмите правую кнопку мыши, чтобы вызвать контекстное меню; 2) выберите пункт “Ответить”. Будет показан текст выбранного вами сообщения в поле “Текст сообщения”; 3) введите текст исходящего сообщения и нажмите на кнопку “Enter”. Будет отправлено исходящее сообщение, содержащее выбранную вами цитату.
