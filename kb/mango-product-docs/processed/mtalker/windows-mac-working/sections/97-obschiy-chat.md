# Общий чат

> Трассировка: PDF §5.2 · сквозные стр. 42-43 · источники: ч.1 `kb/mango-product-docs/sources/mtalker/mTalker_User_Guide_ch1_Working.pdf` с.42-43.

Для того чтобы создать общий чат, в основном окне MTalker следует:

![Изображение, стр. 42](../images/97-obschiy-chat-1.png)

1) нажать на кнопку “Чаты” . Будет открыт раздел “Чаты”;

![Изображение, стр. 42](../images/97-obschiy-chat-2.png)

2) нажать на кнопку . Будет открыто дополнительное меню; 3) выбрать пункт “Создать чат”. Будет открыто окно “Выберите участников чата”; 4) в строке поиска введите имя собеседника, которого нужно добавить в чат или найдите имя собеседника в общем списке; 5) активировать переключатель в строке с именем каждого собеседника, который хотите добавить в чат; 6) нажать на кнопку “Далее”. Будет открыто окно “Создание группового чата”; 7) введите название общего чата, при необходимости добавьте описание чата, затем нажмите кнопку “Создать”. Mango Talker для сред ОС Windows и Mac.
