# 5.10. Настройка видимости истории чата для новых участников

> Трассировка: PDF §5.10 · сквозные стр. 46 · источники: ч.1 `kb/mango-product-docs/sources/mtalker/mTalker_User_Guide_ch1_Working.pdf` с.46.

Вы можете настроить видимость истории чата для новых участников. Можно скрыть всю историю чата от новых участников или разрешить им видеть последние 200 сообщений. Важно! Настройка видимости истории доступна только в общем чате. Не возможно настроить видимость истории в канале.

![Изображение, стр. 46](../images/109-nastroyka-vidimosti-istorii-chata-dlya-n-1.png)

Для того чтобы настроить видимость истории чата, в разделе”Чаты” следует: 1) кликнуть на строку с названием целевого чата / канала. Будет открыта история сообщений в данном чате / канале; 2) нажмите на перечень участников чата под названием чата. Будет открыто окно “Информация о чате”; 3) в поле “История чата” выберите видимости истории: – скрыта: новым участникам видны только новые сообщения; – видна: новым участникам будет видно 200 последних сообщений.
