# Клавиши (номеронабиратель)

> Трассировка: PDF §1.3 · сквозные стр. 16 · источники: ч.1 `kb/mango-product-docs/sources/mtalker/mTalker_User_Guide_ch1_Working.pdf` с.16.

Раздел “Клавиши” предназначен для отображения экранной цифровой клавиатуры, которая позволяет набрать любой номер телефона. Нажатие клавиш осуществляется курсором мыши, либо нажатием кнопок на клавиатуре вашего ПК. Чтобы открыть раздел “Клавиши”, следует в основном

![Изображение, стр. 16](../images/25-klavishi-nomeronabiratel-1.png)

окне MTalker нажать на кнопку . Будет открыт раздел “Клавиши”, в котором отображаются следующие элементы интерфейса: 1) поле для показа набранного номера телефона; 2) ссылка “Сохранить номер” для сохранения введённого номера в контакты; 3) экранная цифровая клавиатура;

![Изображение, стр. 16](../images/25-klavishi-nomeronabiratel-2.png)

4) кнопки для отправки смс-сообщения / факса / автоматического дозвона по номеру;

![Изображение, стр. 16](../images/25-klavishi-nomeronabiratel-3.png)

5) кнопка вызова набранного номера;

![Изображение, стр. 16](../images/25-klavishi-nomeronabiratel-4.png)

6) кнопка редактирования набранного номера; 7) поле “Ваш исходящий номер” для показа номера, с которого будет совершен вызов (данные загружаются из вашей ВАТС).
