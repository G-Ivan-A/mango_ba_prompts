# Управление данными

> Трассировка: PDF §1.3 · сквозные стр. 10 · источники: ч.1 `kb/mango-product-docs/sources/mtalker/mTalker_User_Guide_ch1_Working.pdf` с.10.

![Изображение, стр. 10](../images/11-upravlenie-dannymi-1.png)

Чтобы открыть раздел “Управление данными”, следует нажать на кнопку в основном меню MTalker. В данном разделе предоставлена возможность удалить некоторые данные о пользователе MTalker. Вы можете удалить следующие данные о своем аккаунте: • Удалить сообщения: будут удалены все сообщения из чатов, а также произойдет выход из всех групп; • Удалить историю вызовов: вы можете очистить всю историю вызовов; • Удалить контакты: вы можете удалить все свои контакты из списка контактов MTalker.
