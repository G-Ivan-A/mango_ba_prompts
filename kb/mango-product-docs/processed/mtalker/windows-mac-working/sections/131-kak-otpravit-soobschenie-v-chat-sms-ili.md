# 6.8. Как отправить сообщение в чат, смс или факс участнику звонка

> Трассировка: PDF §6.8 · сквозные стр. 53-54 · источники: ч.1 `kb/mango-product-docs/sources/mtalker/mTalker_User_Guide_ch1_Working.pdf` с.53-54.

Вы можете создать чат “Один-на-один” с вызываемым абонентом, ранее зарегистрированным в вашей ВАТС. В этом чате вы можете отправлять и принимать текстовые сообщения, фотографии и прочие файлы. Кроме того, Вы можете отправить смс / факс на мобильный номер, зарегистрированный в вашей ВАТС или на мобильный номер, с которого звонит ваш собеседник. Важно. Функция отправки смс / факс может быть не доступна, если ваш собеседник звонит через SIP-учетную запись. Для того чтобы сообщение в чат, смс или факс участнику звонка, в окне проведения сеанса связи следует:

![Изображение, стр. 53](../images/131-kak-otpravit-soobschenie-v-chat-sms-ili-1.png)

1. нажать на кнопку “Еще” . Будет открыто контекстное меню; 2. выбрать пункт “Отправить сообщение”. Будет создан чат “Один-на-один” с вызываемым абонентом и в основном окне MTalker открыт раздел “Чаты”; 3. выполните одно из следующих действий: – чтобы отправить текстовое сообщение, в поле “Текст сообщения” введите текст сообщения и на нажмите кнопку “Enter”. Будет отправлено текстовое сообщение вызываемому абоненту; Mango Talker для сред ОС Windows и Mac. Руководство пользователя | Версия от 23.08.2024 – чтобы отправить файл или изображение, в поле “Текст сообщения”

![Изображение, стр. 54](../images/131-kak-otpravit-soobschenie-v-chat-sms-ili-2.png)

нажмите кнопку . Будет открыто окно “Выберите файл для отправки”, в котором следует выбрать файл для отправки вызываемому абоненту и нажать кнопку “Открыть”. Будет отправлен файл вызываемому абоненту; – чтобы отправить голосовое сообщение, в поле “Текст сообщения”

![Изображение, стр. 54](../images/131-kak-otpravit-soobschenie-v-chat-sms-ili-3.png)

нажмите на кнопку . Начнется запись голосового сообщения и вы можете продиктовать свое сообщение. Чтобы отправить продиктованное голосовое сообщение, нажмите кнопку “Отправить”; – чтобы отправить смс, в поле “Текст сообщения” нажмите на кнопку

![Изображение, стр. 54](../images/131-kak-otpravit-soobschenie-v-chat-sms-ili-4.png)

“SMS” . Будет открыто меню для выбора номера, на который следует отправить сообщение, если у абонента несколько номеров. Затем, введите текст сообщения и нажмите кнопку “Enter”; – чтобы отправить факс, в поле “Текст сообщения” выберите пункт

![Изображение, стр. 54](../images/131-kak-otpravit-soobschenie-v-chat-sms-ili-5.png)

“Отправить факс” . Будет открыто меню для выбора номера, на который следует отправить сообщение, если у абонента несколько номеров. Затем, автоматически откроется окно “Выберите файл для отправки”, в котором следует выбрать файл для отправки вызываемому абоненту и нажать кнопку “Открыть”. Будет отправлен файл вызываемому абоненту.
