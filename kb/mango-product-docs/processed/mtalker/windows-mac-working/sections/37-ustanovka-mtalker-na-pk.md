# 2.1. Установка MTalker на ПК

> Трассировка: PDF §2.1 · сквозные стр. 21 · источники: ч.1 `kb/mango-product-docs/sources/mtalker/mTalker_User_Guide_ch1_Working.pdf` с.21.

Установка MTalker на ПК выполняется при помощи программы-инсталлятора стандартным методом установки программ на компьютеры Mac / PC. Примечание. Рекомендуется зарегистрировать в ВАТС ваш e-mail и номер мобильного телефона. Для того, чтобы установить MTalker на ПК, следует: 1) скачайте и запустите инсталлятор для вашей версии ОС по этой ссылке. Будет открыто окно “Установка”; 2) ознакомьтесь с условиями использования MTalker, нажав на ссылку “Условиями использования M.TALKER”; 3) нажмите кнопку “Принять и установить”. Будет выполнена установка MTalker на ваш ПК. После завершения процесса установки, будут выполнены следующие действия, определенные настройками MTalker: – запущена работа MTalker ; – создан ярлык MTalker на рабочем столе; – добавлен MTalker в список программ вашей ОС, запускаемых по умолчанию.
