# Как найти и открыть загруженный файл

> Трассировка: PDF §17.4 · сквозные стр. 108 · источники: ч.1 `kb/mango-product-docs/sources/mtalker/mTalker_User_Guide_ch1_Working.pdf` с.108.

Чтобы найти папку загрузки файлов, следует:

![Изображение, стр. 108](../images/270-kak-nayti-i-otkryt-zagruzhennyy-fayl-1.png)

1) нажать на кнопку “Аватар” . Будет открыта закладка “Настройки”;

![Изображение, стр. 108](../images/270-kak-nayti-i-otkryt-zagruzhennyy-fayl-2.png)

2) нажать на пункт “Чаты” ; 3) нажать на кнопку “Открыть” рядом с полем “Расположение загружаемых файлов”. Будет открыта папка загрузки файлов на вашем ПК. Примечание. Если кнопка “Открыть” не активна, то в MTalker включен запрос места сохранения файлов.
