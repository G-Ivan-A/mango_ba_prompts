# Как редактировать или удалить правило

> Трассировка: PDF §11.2 · сквозные стр. 89 · источники: ч.1 `kb/mango-product-docs/sources/mtalker/mTalker_User_Guide_ch1_Working.pdf` с.89.

Обратите внимание, что редактировать можно только включенное правило. Для этого, в основном окне MTalker, в разделе “Автосекретарь” нажмите на строку с нужным вам правилом. В правой части окна будут показаны параметры выбранного правила. Чтобы редактировать правило, следует: 1. активируйте переключатель в названии правила; 2. измените параметры выбранного правила; 3. нажмите на кнопку “Применить”. Чтобы удалить правило, нажмите на кнопку “Удалить правило” внизу основного окна MTalker.
