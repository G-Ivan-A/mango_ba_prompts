# 15.2. Включение

> Трассировка: PDF §15.2 · сквозные стр. 94 · источники: ч.1 `kb/mango-product-docs/sources/mtalker/mTalker_User_Guide_ch1_Working.pdf` с.94.

Для того чтобы включить автодозвон, в основном окне MTalker следует:

![Изображение, стр. 94](../images/228-vklyuchenie-1.png)

1) нажмите на иконку “Телефон” ; 2) наберите номер вызываемого абонента при помощи экранной клавиатуры;

![Изображение, стр. 94](../images/228-vklyuchenie-2.png)

3) нажмите на кнопку “Еще”. Будет открыто дополнительное меню; 4) выберите пункт “Автоматический дозвон”. Будет включена функция автоматического набора номера “Автодозвон”.
