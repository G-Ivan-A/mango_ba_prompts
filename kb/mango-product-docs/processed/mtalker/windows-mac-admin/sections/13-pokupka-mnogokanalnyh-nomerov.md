# Покупка многоканальных номеров

> Трассировка: PDF §— · сквозные стр. 8-9 · источники: ч.1 `kb/mango-product-docs/sources/mtalker/mTalker_User_Guide_ch3_Admin_Guide.pdf` с.8-9.

Если вам необходимо к вашей ВАТС подключить дополнительные номера MANGO OFFICE, то вы можете прямо из MTalker перейти в интернет-магазин MANGO OFFICE и оформить покупку. Для того чтобы из MTalker перейти в интернет-магазин MANGO OFFICE, в основном окне MTalker следует:

![Изображение, стр. 8](../images/13-pokupka-mnogokanalnyh-nomerov-1.png)

1) нажать на кнопку “Аватар” . Будет открыта закладка “Настройки”;

<!-- изображение на стр. 8: байты не извлечены (PyMuPDF недоступен) -->

2) нажать на кнопку . Будет открыт раздел с данными пользователя; 3) выбрать пункт “Добавить номер” в выпадающем списке “Исходящий номер”. Будет открыт сайт mango-office.ru, подраздел “Покупка многоканальных номеров”, на котором вы можете оформить покупку. Mango Talker для ОС Windows и Mac.
