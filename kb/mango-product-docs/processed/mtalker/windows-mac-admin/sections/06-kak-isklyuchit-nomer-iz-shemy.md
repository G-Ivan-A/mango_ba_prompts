# Как исключить номер из схемы

> Трассировка: PDF §— · сквозные стр. 4-5 · источники: ч.1 `kb/mango-product-docs/sources/mtalker/mTalker_User_Guide_ch3_Admin_Guide.pdf` с.4-5.

Для того чтобы исключить номер из той или иной схемы приема звонков, следует: 1) деактивировать (выключить) переключатель “Активен” в строке с номером, который нужно исключить из схемы; 2) нажать на кнопку “Сохранить”. Будет исключен из схемы приема звонков выбранные вами номер. Mango Talker для ОС Windows и Mac. Информация для администратора ВАТС Версия от 23.08.2024
