# Прокси-сервер

> Трассировка: PDF §10.1 · сквозные стр. 17 · источники: ч.1 `kb/mango-product-docs/sources/mtalker/mTalker_User_Guide_ch2_Settings.pdf` с.17.

Если ваш ПК подключен к информационной сети, в которой необходима авторизация на прокси-сервере, то вы можете в настройках программы включить соответствующую функцию и указать данные авторизации. По умолчанию, в MTalker выключена функция использования прокси-сервера. Для того чтобы настроить подключение к сети через прокси-сервер, следует:

![Изображение, стр. 17](../images/44-proksi-server-1.png)

1) нажать на кнопку “Аватар” . Будет открыта закладка “Настройки”;

![Изображение, стр. 17](../images/44-proksi-server-2.png)

2) нажать на пункт “Сетевое подключение” . Будут отображены поля для настройки сетевого подключения; 3) активировать переключатель “Использовать прокси-сервер”. Будут доступны поля для настройки сетевого подключения; 4) введите настройки сетевого подключения и авторизации (при необходимости).
