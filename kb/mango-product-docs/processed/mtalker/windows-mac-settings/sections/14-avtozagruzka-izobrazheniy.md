# 4.5. Автозагрузка изображений

> Трассировка: PDF §4.5 · сквозные стр. 7 · источники: ч.1 `kb/mango-product-docs/sources/mtalker/mTalker_User_Guide_ch2_Settings.pdf` с.7.

По умолчанию изображения во входящих сообщениях сохраняются автоматически в папку загрузки. Если вы НЕ хотите сохранять изображения на вашем ПК, то отключите скачивание изображений. Для этого:

![Изображение, стр. 7](../images/14-avtozagruzka-izobrazheniy-1.png)

1) нажать на кнопку “Аватар” . Будет открыта закладка “Настройки”;
