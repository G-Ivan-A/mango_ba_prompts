# 4.4. Как включить запрос места сохранения файлов

> Трассировка: PDF §4.4 · сквозные стр. 7 · источники: ч.1 `kb/mango-product-docs/sources/mtalker/mTalker_User_Guide_ch2_Settings.pdf` с.7.

Если вы хотите, чтобы присланные вам файлы сохранялись только по вашей команде, то можете включить запрос места сохранения файлов. Для этого:

![Изображение, стр. 7](../images/13-kak-vklyuchit-zapros-mesta-sohraneniya-f-1.png)

1) нажать на кнопку “Аватар” . Будет открыта закладка “Настройки”;

![Изображение, стр. 7](../images/13-kak-vklyuchit-zapros-mesta-sohraneniya-f-2.png)

2) нажать на пункт “Чаты” ; 3) активировать переключатель “Запрашивать место для сохранения каждого файла перед загрузкой”.
