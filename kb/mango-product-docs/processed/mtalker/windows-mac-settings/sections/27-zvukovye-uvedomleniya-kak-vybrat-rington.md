# Звуковые уведомления. Как выбрать рингтон

> Трассировка: PDF §6.5 · сквозные стр. 11-12 · источники: ч.1 `kb/mango-product-docs/sources/mtalker/mTalker_User_Guide_ch2_Settings.pdf` с.11-12.

При входящем звонке и сообщении MTalker выдает звуковой сигнал (рингтон), оповещающий пользователя. Вы можете указать, какой рингтон будет воспроизведен при входящем звонке и отключить звуковой сигнал при входящем сообщении. Чтобы выбрать рингтон входящего звонка, следует:

1) нажать на кнопку “Аватар” . Будет открыта закладка “Настройки”;

<!-- изображение на стр. 11: байты не извлечены (PyMuPDF недоступен) -->

2) нажать на пункт “Уведомления” ; 3) выбрать рингтон в списке “Рингтон”; 4) чтобы при входящем сообщении проигрывался рингтон, нужно включить переключатель “Звуковое уведомление при входящем сообщении”. Mango Talker для сред ОС Windows и Mac. Установка настроек | Версия от 23.08.2024
