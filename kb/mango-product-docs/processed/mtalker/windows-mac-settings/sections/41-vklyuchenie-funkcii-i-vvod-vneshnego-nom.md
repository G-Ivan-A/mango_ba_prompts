# 9.2. Включение функции и ввод внешнего номера

> Трассировка: PDF §9.2 · сквозные стр. 16-17 · источники: ч.1 `kb/mango-product-docs/sources/mtalker/mTalker_User_Guide_ch2_Settings.pdf` с.16-17.

Для того чтобы включить функцию и указать внешний номер, следует:

![Изображение, стр. 16](../images/41-vklyuchenie-funkcii-i-vvod-vneshnego-nom-1.png)

1) нажать на кнопку “Аватар” . Будет открыта закладка “Настройки”;

![Изображение, стр. 16](../images/41-vklyuchenie-funkcii-i-vvod-vneshnego-nom-2.png)

2) нажать на пункт “Звонки” ; 3) активировать (включить) переключатель “Использовать внешний телефон”; 4) ввести внешний номер или SIP учетную запись, на которую будут переадресованы исходящие вызовы. Mango Talker для сред ОС Windows и Mac. Установка настроек | Версия от 23.08.2024
