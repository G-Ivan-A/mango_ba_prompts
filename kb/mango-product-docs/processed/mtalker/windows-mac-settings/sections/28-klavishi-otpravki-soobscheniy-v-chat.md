# 6.6. Клавиши отправки сообщений в чат

> Трассировка: PDF §6.6 · сквозные стр. 12 · источники: ч.1 `kb/mango-product-docs/sources/mtalker/mTalker_User_Guide_ch2_Settings.pdf` с.12.

Вы можете выбрать кнопку отправки сообщений: • кнопка “Enter”; • комбинация кнопок “Ctrl+Enter”. Примечание - В комбинации “Ctrl+Enter” на Mac вместо Ctrl используется ⌘. Для того чтобы выбрать кнопку отправки сообщений, следует:

![Изображение, стр. 12](../images/28-klavishi-otpravki-soobscheniy-v-chat-1.png)

1) нажать на кнопку “Аватар” . Будет открыта закладка “Настройки”;

![Изображение, стр. 12](../images/28-klavishi-otpravki-soobscheniy-v-chat-2.png)

2) нажать на пункт “Чаты” ; 3) в поле “Отправка сообщений” выбрать из выпадающего списка способ отправки сообщений.
