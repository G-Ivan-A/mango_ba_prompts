# Включение/выключение функций CNG, VAD, анти-эхо

> Трассировка: PDF §10.1 · сквозные стр. 17-18 · источники: ч.1 `kb/mango-product-docs/sources/mtalker/mTalker_User_Guide_ch2_Settings.pdf` с.17-18.

В MTalker реализованы следующий функции обработки звукового сигнала: • анти-эхо; • генератор комфортного шума CNG, для создания фонового шума с целью заполнить молчание в передаче. Комфортный шум также сигнализирует о том, что сеанс связи не окончен; • Voice Active Detect, VAD это обнаружение голосовой активности для отделения активной речи от фонового шума или тишины. При минимальном значении пересылка трафика приостанавливается с целью экономии. Mango Talker для сред ОС Windows и Mac. Установка настроек | Версия от 23.08.2024 Вы можете включить или выключить данные функции. Для того чтобы включить функции обработки звукового сигнала, следует:

![Изображение, стр. 18](../images/46-vklyuchenie-vyklyuchenie-funkciy-cng-vad-1.png)

1) нажать на кнопку “Аватар” . Будет открыта закладка “Настройки”; 2) нажать на пункт “Звук” ; 3) чтобы включить функцию анти-эхо, активируйте переключатель “Анти- эхо”; 4) чтобы включить функцию генерации комфортного шума, активируйте переключатель “CNG”; 5) чтобы включить функцию VAD, активируйте одноименный переключатель “VAD”.
