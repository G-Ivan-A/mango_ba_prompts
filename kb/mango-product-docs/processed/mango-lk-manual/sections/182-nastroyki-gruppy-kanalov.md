# 4.5.11.2.1. Настройки группы каналов

> Трассировка: PDF §4.5.11.2.1 · сквозные стр. 282 · источники: ч.3 `kb/mango-product-docs/sources/mango-lk-manual/LK_manual_v-121часть-3.pdf` с.80.

Главное окно группы каналов содержит следующие каналы коммуникации с клиентами: • Виджеты для сайта • Соцсети и мессенджеры • Другие каналы

![Изображение, стр. 282](../images/182-nastroyki-gruppy-kanalov-2.png)

Кликните по кнопке Настройка в правом верхнем углу окна и перейдите к настройкам группы каналов. Эти настройки буду действовать для всех подключенных каналов. После внесения необходимых изменений в настройки, сохраните их кнопкой Сохранить.
