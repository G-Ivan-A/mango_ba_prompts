# Добавление номеров

> Трассировка: PDF §4.5.19.3 · сквозные стр. 424-425 · источники: ч.5 `kb/mango-product-docs/sources/mango-lk-manual/LK_manual_v-121часть-5.pdf` с.20-21.

Номера используются при исходящих звонках. Чтобы их добавить: 1. Откройте карусель на редактирование. 2. Перейдите на вкладку Номера. 3. Нажмите кнопку Добавить. 4. Выберите нужные (возможна фильтрация и массовый выбор). 5. Подтвердите выбор кнопкой Сохранить. При редактировании карусели можно использовать до 2000 номеров, при этом рекомендуется оставить не менее двух активных номеров типов DID, DEF или МангоМобайл.

![Изображение, стр. 425](../images/256-dobavlenie-nomerov-1.jpeg)

Если из карусели удаляется последний номер, карусель будет деактивирована.
