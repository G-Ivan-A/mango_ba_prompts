# 4.5.19.4. Как работает логика маршрутизации звонков

> Трассировка: PDF §4.5.19.4 · сквозные стр. 425-429 · источники: ч.5 `kb/mango-product-docs/sources/mango-lk-manual/LK_manual_v-121часть-5.pdf` с.21-25.

Когда совершается исходящий звонок, система подбирает карусель среди активных каруселей, включающих данного сотрудника, в таком порядке: ● Сначала применяются правила по префиксу — они самые важные и всегда срабатывают первыми. ● Затем идут правила по маске или по региону. Если подходит несколько, то выбирается та карусель, у которой приоритет выше. Для правил по маске и по региону можно вручную менять приоритет. Чем выше строка карусели в списке, тем выше ее приоритет. Чтобы изменить приоритет карусели ее

строку нужно переместить выше или ниже, удерживая иконку перемещения нажатой. Система также учитывает текущую сортировку.

Когда лучше использовать правило «По префиксу» Правило «По префиксу» определяет, что все звонки, начинающиеся с определённой последовательности цифр, будут использовать нужную карусель номеров. Это правило удобно для разделения звонков по типам, направлениям, проектам или подразделениям, чтобы система автоматически выбирала нужный исходящий номер. Когда применять на практике

![Изображение, стр. 428](../images/259-kak-rabotaet-logika-marshrutizacii-zvonk-4.jpeg)

1. Для разделения служебных и клиентских звонков Если сотрудники совершают как внутренние, так и внешние звонки, префикс помогает автоматически направлять их в разные карусели. Пример: o Префикс 45 — внутренние служебные вызовы. o Все остальные номера — клиентские звонки. Таким образом, внутренние вызовы проходят по служебным линиям и не влияют на статистику продаж. 2. Для отдельных проектов или кампаний Если компания ведет несколько направлений бизнеса, префиксы позволяют разграничить звонки по проектам. Пример: o Префикс 11 — звонки по кредитным продуктам; o Префикс 22 — страховые услуги; o Префикс 33 — опросы клиентов. При наборе номера с определенным префиксом система автоматически использует соответствующую карусель номеров. 3. Для быстрого доступа к специальным линиям. Префиксы можно использовать как «ярлыки» для определенных направлений. Пример: o Префикс 99 — звонки VIP-клиентам; o Префикс 88 — линия тестовых вызовов. Сотруднику достаточно набрать короткий префикс — система сама выберет нужный номер исходящей линии. 4. Для внутренних звонков между отделами или филиалами Если в организации несколько подразделений, можно задать префиксы для каждого из них. Пример: o Префикс 71 — отдел продаж; o Префикс 72 — сервисная служба;

![Изображение, стр. 429](../images/259-kak-rabotaet-logika-marshrutizacii-zvonk-5.jpeg)

o Префикс 73 — бухгалтерия. Это позволяет четко разделить направления вызовов и сохранить порядок в отчетности. Почему это удобно ● Автоматизация без ошибок: сотрудники не тратят время на выбор нужного номера — система делает всё сама. ● Структурированная маршрутизация: легко настроить логику дозвона под конкретные процессы бизнеса. ● Приоритетность: префикс имеет самый высокий приоритет — если номер совпадает, он срабатывает всегда, независимо от других правил. ● Прозрачность аналитики: каждая группа звонков автоматически попадает в свою статистику (например, по проекту, отделу или типу вызова). ● Гибкость: вы можете задать короткие и понятные префиксы для разных целей — сотрудники быстро привыкают к их использованию. Советы по настройке ● Используйте краткие, но уникальные префиксы (1–4 цифры), чтобы их легко запомнили сотрудники. ● Не создавайте несколько каруселей с одинаковым префиксом — система не позволит дублировать значения. ● Префиксы лучше выбирать по логике работы компании: например, 1x — проект А, 2x — проект B. ● Для удобства операторов можно оформить внутренние инструкции — какой префикс соответствует какому направлению.
