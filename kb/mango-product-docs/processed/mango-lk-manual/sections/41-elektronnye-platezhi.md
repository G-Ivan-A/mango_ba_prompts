# 2.5.3. Электронные платежи

> Трассировка: PDF §2.5.3 · сквозные стр. 37-38 · источники: ч.1 `kb/mango-product-docs/sources/mango-lk-manual/LK_manual_v-121часть-1.pdf` с.37-38.

Пополнение счета с помощью электронных платежей возможно благодаря сервисам ЮMoney, QIWI, а также при помощи SMS-сообщений.

![Изображение, стр. 38](../images/41-elektronnye-platezhi-1.jpeg)

![Изображение, стр. 38](../images/41-elektronnye-platezhi-2.png)

Введите цифрами сумму платежа в одноименное поле. Выберите сервис, при помощи которого будет произведена оплата. Нажмите кнопку «Оплатить». В результате будет открыта новая вкладка браузера на странице выбранного При оплате через SMS-сообщение в поле «Кому» введите короткий номер 3116. В поле, предназначенное для ввода текста, введите сообщение в формате [сервис] [номер счета] [сумма], например, mt 77770000 500.
