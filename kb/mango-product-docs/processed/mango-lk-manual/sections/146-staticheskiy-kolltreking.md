# 4.5.8. Статический коллтрекинг

> Трассировка: PDF §4.5.8 · сквозные стр. 224 · источники: ч.3 `kb/mango-product-docs/sources/mango-lk-manual/LK_manual_v-121часть-3.pdf` с.22.

В настоящее время инструмент недоступен для подключения. Подключенный ранее инструмент работает в соответствии с заявленным функционалом. Данный инструмент предназначен для создания, настройки и отображения виджета «Статический коллтрекинг» на сайте. Виджет показывает посетителям сайта определенный телефонный номер в зависимости от ссылки, с которой посетитель перешел на сайт. Также инструмент позволяет сформировать статистический отчет по соответствующим показам.
