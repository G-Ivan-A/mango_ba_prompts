# 4.6.5.5. Автоподстановка номера

> Трассировка: PDF §4.6.5.5 · сквозные стр. 487-489 · источники: ч.5 `kb/mango-product-docs/sources/mango-lk-manual/LK_manual_v-121часть-5.pdf` с.83-85.

Данная вкладка позволяет настроить правила подстановки номеров и совершать исходящие звонки с номера того региона, куда совершается звонок, независимо от месторасположения оператора.

![Изображение, стр. 488](../images/300-avtopodstanovka-nomera-1.jpeg)

После ознакомления с условиями подключения услуги, нажмите кнопку Подключить. На вкладке размещается список существующих правил автоподстановки. Добавьте новое правило автоподстановки номера, кликнув по кнопке добавить правило. В открывшемся окне выберите: • Исходящий номер - выбирается из списка доступных сотруднику номеров, подключенных к ВАТС; • Тип – способ подставновки: по префиксу, по маске, по региону.

![Изображение, стр. 488](../images/300-avtopodstanovka-nomera-2.png)

• Префикс, маска, регион - Нажав на пиктограмму ознакомьтесь с пояснениями к каждому из вариантов, и введите необходимые данные. • Комментарий – добавьте комментарий для данного правила. Окно не является обязательным для заполнения.

![Изображение, стр. 488](../images/300-avtopodstanovka-nomera-3.jpeg)

Настройки правил с типом «маска». 7495\d* - правилу удовлетворяют все номера, начинающиеся с 7495; 5\d{7} - правилу удовлетворяет любой 11- значный номер, начинающийся с 7495; 7495\d*|7499\d* - правилу удовлетворяют все номера, начинающиеся с 7495 или 7499; 7495[5-6][5-6][5-6][5-6][5-6][5-6] - правилу удовлетворяют все номера, в диапазоне от 7495-55-55-55 до 7495-66-66-66.
