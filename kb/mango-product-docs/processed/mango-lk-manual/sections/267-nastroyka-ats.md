# 4.6. Настройка АТС

Сценарий 3. У вас уже есть формы на сайте – подключаете автодозвон без виджетов 1. На сайте уже размещены формы обратной связи (ФОС). 2. Вы подключаете «Автодозвон из форм» и размещаете код подключения на сайте. 3. Внешний вид сайта не меняется, при этом заявки из форм начинают обрабатываться через мгновенный перезвон. Результат: подключаете обратный звонок быстро и без изменений UI/дизайна. Сценарий 4. Оператор не тратит время на ручной перезвон 1. Раньше оператор вручную просматривал заявки и перезванивал по каждой. 2. После подключения «Автодозвона из форм» система инициирует звонки автоматически. Результат: меньше ручных действий, ниже риск ошибок (например, «забыли перезвонить»). Сценарий 5. Повышаете дозвон и конверсию 1. Посетитель только что запросил звонок через форму. 2. Система звонит сразу (в рабочее время), и клиент с большей вероятностью отвечает. 3. По результатам проверки на сайте MANGO OFFICE конверсия лидов из ФОС в покупку выросла на 42%. Результат: чаще дозваниваетесь и быстрее доводите заявки до продажи. 4.6 НАСТРОЙКА АТС Блок «Настройки» отображается только у администратора Лицевого счета и пользователей с правом доступа «Администратор».
