# Добавление сотрудников

> Трассировка: PDF §4.5.19.3 · сквозные стр. 425 · источники: ч.5 `kb/mango-product-docs/sources/mango-lk-manual/LK_manual_v-121часть-5.pdf` с.21.

Чтобы добавить определить, кто будет использовать карусель: 1. Откройте карусель на редактирование. 2. Перейдите во вкладку Сотрудники. 3. Нажмите кнопку Добавить. 4. Отметьте нужных сотрудников (доступны фильтрация и массовый выбор). 5. Нажмите кнопку Сохранить. Карусель может включать не более 500 сотрудников. Если из карусели удаляется последний сотрудник, карусель будет деактивирована. Уведомление о том, что сотрудник добавлен в карусель номеров, отображается в карточке сотрудника на вкладке Телефония. Там же размещена ссылка Настроить, по которой открывается вкладка «Карусель номеров» с уже установленным фильтром поиска по данному сотруднику.
