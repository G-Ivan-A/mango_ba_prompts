# 7.1.1. Избранные

> Трассировка: PDF §7.1.1 · сквозные стр. 64 · источники: ч.1 `kb/mango-product-docs/sources/speech-analytics/RECHEVAYA-ANALITIKA_VATS-_-Skoring-1.26.18.pdf` с.64.

Вкладка “Избранное” содержит список офлайновых записей разговоров, отмеченных метками. Все помеченные записи приводятся в порядке, который соответствует времени добавления метки к определенной записи. Таким образом, последняя запись, к которой была добавлена метка, отображается в верхней части списка, а запись, метка к которой была добавлена раньше всех, отображается последней.

![Изображение, стр. 64](../images/41-izbrannye-1.jpeg)

Предусмотрена фильтрация записей по меткам. Для этого следует щелкнуть по соответствующей кнопке в области фильтров. Действия по прослушиванию записей аналогичны описанным действиям в предыдущем подразделе.
