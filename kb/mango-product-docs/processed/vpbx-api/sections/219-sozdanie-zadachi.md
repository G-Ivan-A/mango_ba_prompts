# 4.9.1.1. Создание задачи

> Трассировка: PDF §4.9.1.1 · сквозные стр. 301-302 · источники: ч.1 `kb/mango-product-docs/sources/vpbx-api/MangoOffice_VPBX_API_v1.9.pdf` с.301-302.

POST /cc/task/add Позволяет создавать новую задачу. Рекомендуемая последовательность: 1) Получаем ID контакта, источника контакта и тип источника. Для этого используйте API Виртуальной АТС, Адресная книга; 2) Получаем ID сделок при помощи метода "Получение списка сделок". Ограничения: - по продукту : 'сс/task/add' => 5/1 - всего : 'сс/task/add' => 20/1 Параметры метода:

| № | Параметр | Тип | Обязате<br>льный | Описание |
| --- | --- | --- | --- | --- |
| 1 | event_type | Число | Да | Тип задачи. Доступные значения: 1 – Позвонить; 2 – Написать;<br>3 – Встретиться; 4 - Сделать |
| 2 | start_time | Временная<br>метка | Да | Дата/время начала события. |
| 3 | duration | Число | Да | Длительность события. В минутах, не более 1439 (сутки) |
| 4 | priority | Число | Нет | Важность задачи. Доступные значения: null - не важная; 1 –<br>обычная; 2 - важная |
| 5 | contact_id | Строка | Нет | ID контакта адресной книги |
| 6 | source_id | Число | Нет | Источника контакта |
| 7 | source_type | Строка | Нет | Тип источника контакта. Если не указан, то контакт из<br>внутренней адресной книги |
| 8 | from_user_id | Число | Нет | ID сотрудника, от чьего имени поставлена задача |
| 9 | to_user_id | Число | Да | ID сотрудника, которому назначена задача |
| 10 | description | Строка | Нет | Описание задачи. Ограничение - до 1024 символов |
| 11 | is_auto_call | Булево | Нет | Если true, то при создании задачи также создается задача на<br>автоматический звонок.<br>Если false, то при создании задачи не создается задача на<br>автоматический звонок. Значение по умолчанию, если не<br>указан параметр. |

| № | Параметр | Тип | Обязате<br>льный | Описание |
| --- | --- | --- | --- | --- |
|  |  |  |  | Нельзя создавать задачи с данным параметром, если время<br>начала события указано менее 5 минут |
| 12 | phone | Строка | Нет | Номер телефона. Внешняя система контролирует<br>самостоятельно корректность указания номера и контакта |
| 13 | theme | Строка | Нет | Тема задачи. Ограничение - до 50 символов<br>Если такой темы еще нет, и число тем менее 50, то создается<br>новая тема.<br>Если число тем более или равно 50, тема и задача не создается.<br>Выдается ошибка.<br>Если такая тема есть, то она указывается к создаваемой задаче. |
| 14 | deal_id | Число | Нет | ID сделок Контакт-центра. Проверяется наличие сделки в КЦ,<br>если указан |

Пример запроса: POST https://app.mango-office.ru/cc/task/add vpbx_api_key = 1234567890qwerty, sign = 1234567890qwerty, json = { "product_id":300023344, "status":1, "event_type":1, "start_time":"2021-09-31 07:30:00", "duration":1400, "contact_id":19451232, "source_id":0, "source_type":"vpbx", "from_user_id":10068242, "to_user_id":10068242, "description":"Описание задачи", "phone":"79219407346", "deal_id":233226, "priority":1, "is_auto_call":true, "theme":"Название задачи" } В результате обработки запроса, формируются и передаются JSON-данные, содержащие следующие параметры:

| № | Параметр | Тип | Обязате<br>льный | Описание |
| --- | --- | --- | --- | --- |
| 1 | result | Число | Да | Код результата |
| 2 | task_id | Число | Да | ID созданной задачи, если задача создана |
| 3 | auto_call_task_id | Число | Да | ID созданной задачи на автоперезвон, если такая задача<br>создана. Этот параметр идентичен параметру task_id из<br>звонкового события по данной задаче автоперезвона |
