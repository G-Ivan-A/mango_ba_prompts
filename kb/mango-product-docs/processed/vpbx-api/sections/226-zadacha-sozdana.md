# 4.9.2.1. Задача создана

> Трассировка: PDF §4.9.2.1 · сквозные стр. 310 · источники: ч.1 `kb/mango-product-docs/sources/vpbx-api/MangoOffice_VPBX_API_v1.9.pdf` с.310.

Событие, вызываемое при создании задачи. В событии отправляются все поля, включая поля в которых нет данных (null).

| № | Параметр | Тип | Обязате-<br>льный | Описание |
| --- | --- | --- | --- | --- |
| 1 | task_id | Число | Да | ID задачи |
| 2 | status | Число | Да | Текущий статус задачи. Доступные значения:<br>0 - Открыта (создана); 1 - Выполнена (завершена);<br>2 - Отменена; 3 - Подтверждена |
| 3 | event_type | Число | Да | Текущий тип задачи. Доступные значения:<br>1 – Позвонить; 2 – Написать; 3 – Встретиться; 4 - Сделать |
| 4 | start_time | Временная<br>метка | Да | Дата/время начала события в созданной задаче. |
| 5 | duration | Число | Да | Длительность события в созданной задаче. В минутах |
| 6 | priority | Число | Да | Важность в созданной задаче: null - не важная;<br>1 – обычная; 2 - важная |
| 7 | contact_id | Число | Да | ID контакта адресной книги |
| 8 | source_id | Число | Да | Источник контакта, в случае если контакт был указан |
| 9 | source_type | Строка | Да | Тип источника контакта, в случае если контакт был указан |
| 10 | from_user_id | Число | Да | ID сотрудника, от чьего имени создана задача |
| 11 | to_user_id | Число | Да | ID сотрудника, которому назначена созданная задача |
| 12 | description | Строка | Да | Описание задачи |
| 13 | is_auto_call | Булево | Да | Одно из двух состояний в созданной задаче: true или false |
| 14 | phone | Строка | Да | Номер телефона. Внешняя система контролирует<br>самостоятельно корректность указания номера и контакта |
| 15 | theme | Строка | Да | Тема задачи |
| 16 | deal_id | Число | Да | ID сделки Контакт-центра |
