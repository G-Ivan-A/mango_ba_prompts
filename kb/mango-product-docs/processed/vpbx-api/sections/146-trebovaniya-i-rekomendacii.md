# 3.10.1.2. Требования и рекомендации

> Трассировка: PDF §3.10.1.2 · сквозные стр. 199 · источники: ч.1 `kb/mango-product-docs/sources/vpbx-api/MangoOffice_VPBX_API_v1.9.pdf` с.199.

Чтобы использовать данный метод, необходимо в вашей ВАТС подключить услуги: - Речевая аналитика; - Распознавание разговоров; - Офлайн-скоринг. Для подробной информации об услугах и порядке их подключения, обратитесь к менеджеру MANGO OFFICE. Кроме того, рекомендуется подкключить услугу "Облачное хранилище ВАТС", тогда вы сможете не только сохранять звуковые файлы ВАТС, но и прослушивать их с помощью встроенного плеера, импортировать (скачивать) звуковые файлы на свой компьютер.
