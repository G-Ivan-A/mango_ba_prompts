# 3.10.2.1. Обзор

> Трассировка: PDF §3.10.2.1 · сквозные стр. 201-202 · источники: ч.1 `kb/mango-product-docs/sources/vpbx-api/MangoOffice_VPBX_API_v1.9.pdf` с.201-202.

Метод обеспечивает загрузку в ВАТС и распознавание речи в звуковом файле, при этом звуковой файл не будет сохранен в хранилище ВАТС и не будет привязан к сотруднику. Метод позволяет распознавать речь в звуковом файле, который должен соответствовать требованиям: - формат: WAV (несжатый аудиопоток); - максимальный размер: 100 МБ; - максимальная длина имени файла: 64 символа латиницей. Чтобы использовать данный метод, необходимо к вашей ВАТС подключить услуги: - Речевая аналитика; - Распознавание разговоров; - Офлайн-скоринг. Примечание. Для подробной информации об услугах и порядке их подключения, обратитесь к менелдеру MANGO OFFICE. В результате обработки запроса, будет автоматически сформировано и передано в сервис "Речевая аналитика" задание на распознавание речи в данном звуковом файле. Примечания: 1) после того, как распознвание речи будет выполнено, в API ВАТС будет сформировано соответсвующее событие; 2) чтобы получить результаты распознавания речи, используйте этот запрос.
