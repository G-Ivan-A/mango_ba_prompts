# 3.3.3. Изменение правила переадресации

> Трассировка: PDF §3.3.3 · сквозные стр. 64-65 · источники: ч.1 `kb/mango-product-docs/sources/vpbx-api/MangoOffice_VPBX_API_v1.9.pdf` с.64-65.

POST /vpbx/forwarding/number/change Метод позволяет изменить действующее правило безусловной переадресации на внутренний или внешний номер при звонке клиента. В запросе передаётся forward_id (обязательный параметр) и указываются значения иных параметров, которые необходимо изменить. Входные параметры:

| --- | --- | --- | --- | --- | --- |
|  | 1 | 2 |  |  |  |
| 1 | forward_id |  | integer | Да | ID правила переадресации. |
| 2 | forward_type |  | string | Нет | Тип переадресации (group - группа, user - сотрудник,<br>ext_forward - внешний номер). Если установлены<br>параметры forward_to_group, forward_to_user,<br>forward_to_ext, тогда параметр forward_type<br>обязательный. |
| 3 | forward_to_group |  |  | Нет | Массив данных при переадресации на группу.<br>Устанавливается, если у параметра<br>forward_type указано значение group. |
