# 3.7.4. Редактировать группу

> Трассировка: PDF §3.7.4 · сквозные стр. 114-116 · источники: ч.1 `kb/mango-product-docs/sources/vpbx-api/MangoOffice_VPBX_API_v1.9.pdf` с.114-116.

POST /vpbx/group/update Метод позволяет редактировать группу сотрудников в Виртуальной АТС. Изменяются только переданные данные. Параметры запроса:

| № | Параметры с уровнем<br>вложенности |  | Тип | Обяза-<br>тель-<br>ный | Описание |
| --- | --- | --- | --- | --- | --- |
|  | 1 | 2 |  |  |  |
| 1 | group_id |  |  |  | Id группы для редактирования. Описание полей в group (в<br>запросе указать только редактируемые поля, см. Пример) |
| 2 | group |  |  |  | Информация о группе |
| 2.1 |  | name |  |  | Имя группы |
| 2.2 |  | description |  |  | Примечание к группе |
| 2.3 |  | extension |  |  | Короткий номер группы |
| 2.4 |  | dial_alg_group |  |  | Алгоритм распределения звонков в группе, также см.<br>Работа с услугами виртуальной АТС: |
|  |  |  |  |  | ■ 0 : alg_serial_prior - последовательный обзвон;<br>■ 1 : alg_parallel_prior - параллельный по приоритету<br>(по квалификации);<br>■ 2 : alg_parallel - одновременно всем свободным;<br>■ 3 : alg_random - судя из названия, в случайном порядке;<br>■ 5 : alg_most_idle - равномерный (наиболее свободному) |
| 2.5 |  | dial_alg_users |  |  | Алгоритм дозвона до сотрудников в группе, также см.<br>Работа с услугами виртуальной АТС: |
|  |  |  |  |  | ■ 1 : alg_m_all - на все контакты сотрудника одновременно;<br>■ 2 : alg_m_main - на основные номера сотрудников;<br>■ 3 : alg_m_sip - только на sip-учетные записи сотрудника;<br>■ 4 : alg_m_line - на все контакты сотрудника по-очереди;<br>■ 5 : alg_m_card - как настроено в карточке сотрудника. |
| 2.6 |  | auto_redirect |  |  | Статус опции "Переадресовывать звонки на<br>"знакомого" сотрудника", также см. Работа с услугами<br>Виртуальной АТС. Значения: 0 – Нет; 1 – Да |
| 2.7 |  | auto_dial |  |  | Статус опции "Автоматически перезванивать по<br>пропущенным звонкам", также см. Работа с услугами |

| № | Параметры с уровнем<br>вложенности |  | Тип | Обяза-<br>тель- | Описание |
| --- | --- | --- | --- | --- | --- |
|  |  |  |  |  | Виртуальной АТС:<br>■ id кампании ИО, это же значение приходит в<br>events/call в поле campaign_id |
| 2.8 |  | line_id |  |  | Id исходящей линии для автоперезвона, можно<br>получить запросом Получение списка номеров ВАТС |
| 2.9 |  | use_dynamic_ivr |  |  | Статус опции "До ответа оператора осталось ...<br>Минут", также см. Работа с услугами Виртуальной<br>АТС. Значения: 0 – Нет; 1 – Да; |
| 2.10 |  | use_dynamic_seq_<br>um |  |  | Статус опции "Ваш номер в очереди ...", также см.<br>Работа с услугами Виртуальной АТС.<br>Значения: 0 – Нет; 1 – Да |
| 2.11 |  | melody_id |  |  | Идентификатор выбранной мелодии во время ожидания<br>ответа. Можно получить запросом получение списка<br>мелодий и звуковых сообщений. Если указано null - будет<br>использована мелодия по умолчанию, которую можно<br>настроить для всех групп в лк в разделе обработка звонков -><br>настройки ожидания ответа -> мелодия при удержании<br>вызова в очереди |
| 2.12 |  | operators |  |  | Массив сотрудников в группе:<br>■ id - id сотрудника, получить значение operator_id<br>можно запросом Запрос списка сотрудников, в ответе<br>на который возвращается параметр general.user_id;<br>■ priority - приоритет в алгоритмах распределения<br>звонков в группе использующих приоритет |

Важно! Параметр order - порядок в алгоритмах распределения звонков в группе использующих порядок. Присваивается автоматически, зависит от очерёдности добавляемых в группу сотрудников. В результате обработки запроса, формируются и передаются JSON-данные, содержащие следующие параметры:

| № | Параметры с уровнем<br>вложенности |  | Тип | Обяза-<br>тель-<br>ный | Описание |
| --- | --- | --- | --- | --- | --- |
|  | 1 | 2 |  |  |  |
| 1 | groups |  |  |  |  |
| 2 |  | Result |  | Да | Код результата:<br>■ 1000 – действие выполнено успешно;<br>■ 3100 - переданы неверные параметры команды;<br>■ 3300 - объект не существует;<br>■ 5XXX – ошибка сервера; |
| 3 |  | group_id |  |  | id группы |

Примеры. Пример 1. Как поменять название, примечание и короткий номер группы. Запрос: POST https://app.mango-office.ru/vpbx/group/update

| {<br>Data: {<br>vpbx_api_key: "1234567890qwerty", |
| --- |
| sign: "1234567890qwerty ",<br>json: "{ |
| "group":{<br>"name":"Group Name Updated", |
| "description":"Group Description Updated",<br>"extension":"12344"<br>}, |
| "group_id":"10049774"<br>}" |
