# 2.4.5. Как узнать свой уникальный код ВАТС и ключ создания подписи?

> Трассировка: PDF §2.4.5 · сквозные стр. 15 · источники: ч.1 `kb/mango-product-docs/sources/vpbx-api/MangoOffice_VPBX_API_v1.9.pdf` с.15.
