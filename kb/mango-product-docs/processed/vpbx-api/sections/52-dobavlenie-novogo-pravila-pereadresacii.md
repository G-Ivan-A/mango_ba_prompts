# 3.3.2. Добавление нового правила переадресации

> Трассировка: PDF §3.3.2 · сквозные стр. 62-63 · источники: ч.1 `kb/mango-product-docs/sources/vpbx-api/MangoOffice_VPBX_API_v1.9.pdf` с.62-63.

POST /vpbx/forwarding/number/add Метод позволяет добавить новое правило безусловной переадресации на внутренний или внешний номер при звонке клиента. При добавлении новой переадресации для имеющегося в списке номера клиента - возвращается ошибка, новое правило не добавляется. Опционально может содержать ID номера ВАТС (если переадресация осуществляется на него) и комментарий. Входные параметры:

| № | Параметры с уровнями<br>вложенности |  | Тип | Обяза-<br>тель-<br>ный | Описание |
| --- | --- | --- | --- | --- | --- |
|  | 1 | 2 |  |  |  |
| 1 | client_phone<br>_number |  | string | Да | Номер, с которого поступает входящий звонок;<br>указанный номер должен соответствовать типу номера,<br>указанного в client_phone_type (если client_phone_type =<br>0, тогда client_phone_number - DID-номер; если<br>client_phone_type = 1, тогда client_phone_number - SIP-<br>номер), иначе метод возвращает ошибку. |
| 2 | client_phone<br>_type |  | bool | Да | Тип номера, с которого поступает входящий<br>звонок (0 - телефон, 1 - SIP-Номер). |
| 3 | status |  | bool | Да | Статус активности правила переадресации (0 -<br>правило неактивно, 1 - правило активно). |
| 4 | forward_type |  | string | Да | Тип переадресации (group - группа, user -<br>сотрудник, ext_forward - внешний номер). |
| 5 | forward_to_<br>group |  | object |  | Обязательный, если в параметре "forward_type"<br>указано значение "group" (иначе опциональный),<br>данные при переадресации на группу. |

| 7 | forward_to_<br>ext |  | object |  | Обязательный, если в параметре "forward_type"<br>указано значение "ext_forward" (иначе<br>опциональный), массив данных при<br>переадресации на внешний номер. |

| 7.2 |  | forward_number | string |  | Обязательный, если указан параметр<br>"forward_to_ext" (иначе опциональный), внешний<br>номер, на который осуществляется<br>переадресация вызова. |
