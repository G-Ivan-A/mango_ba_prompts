# 4.3.2. Изменение задачи на автоперезвон

> Трассировка: PDF §4.3.2 · сквозные стр. 211-213 · источники: ч.1 `kb/mango-product-docs/sources/vpbx-api/MangoOffice_VPBX_API_v1.9.pdf` с.211-213.

POST /cc/task/update Метод позволяет изменить данные задачи, ранее поставленной по этому запросу. Чтобы начать работу с запросом на изменение данных задачи автоперезвон, выполните следующие действия: 1) получите id контакта, источника контакта и тип источника, при помощи запроса "API для работы с адресной книгой. Контакты"; 2) получите id сделок, при помощи запроса Получение списка сделок. Важно! Существуют следующие ограничения по количеству запросов в секунду. Не гарантируется обработка запросов сверх обозначенных лимитов.

| Запрос | Максимальное число запросов / в секунду |
| --- | --- |
| По продукту | 5/1 |
| Всего | 20/1 |

Параметры запроса:

| № | Параметр | Тип | Обяза-<br>тель-<br>ный | Описание |
| --- | --- | --- | --- | --- |
| 1 | task_id | Число | Да | ID задачи |
| 2 | status | Число | Да | Статус задачи. Доступные значения:<br>0 - Открыта (создана);<br>1 - Выполнена (завершена);<br>2 - Отменена;<br>3 - Подтверждена |
| 3 | event_type | Число | Да | Тип задачи. Доступные значения:<br>1 – Позвонить,<br>2 – Написать,<br>3 – Встретиться,<br>4 - Сделать |
| 4 | start_time | timestamp | Да | Дата/время начала события. |
| 5 | duration | Число | Да | Длительность события. В минутах, не более 1439 (сутки) |
| 6 | priority | Число | Нет | Важность задачи. Доступные значения:<br>null - не важная,<br>1 - обычная,<br>2 - важная |
| 7 | contact_id | Число | Нет | ID контакта адресной книги |
| 8 | source_id | Число | Нет | Источника контакта. Если не указан, то контакт из<br>внутренней адресной книги |
| 9 | source_type | string | Нет | Тип источника контакта. Если не указан, то контакт из<br>внутренней адресной книги |
| 10 | from_user_id | Число | Нет | ID сотрудника, от чьего имени поставлена задача |
| 11 | to_user_id | Число | Да | ID сотрудника, которому назначена задача |
| 12 | description | string | Нет | Описание задачи. Ограничение - до 1024 символов |
| 13 | is_auto_call | bool | Нет | Если изменено на true, то при изменении задачи, создается<br>задача на автоматический звонок.<br>Если изменено на false, то при изменении задачи отменяется<br>задача на автоматический звонок.<br>Не доступно изменять данный параметр, если до начала<br>события осталось менее 5 минут |
| 14 | phone | string | Нет | Номер телефона. Внешняя система контролирует<br>самостоятельно корректность указания номера и контакта |
| 15 | theme | string | Нет | Тема задачи. Ограничение - до 50 символов<br>Если такой темы еще нет, и число тем менее 50, то создается<br>новая тема.<br>Если число тем более или равно 50, тема и задача не<br>изменяется. Выдается ошибка.<br>Если такая тема есть, то она указывается к изменяемой<br>задаче. |
| 16 | deal_id | Число | Нет | ID сделок. Проверяется наличие сделки в КЦ, если указан |

Пример запроса: POST https://app.mango-office.ru/cc/task/update vpbx_api_key = 1234567890qwerty, sign = 1234567890qwerty, json = { "product_id":300023344, "task_id":45594, "status":1, "event_type":1, "start_time":"2021-09-31 07:30:00", "duration":1400, "contact_id":19451232, "source_id":0, "source_type":"vpbx", "from_user_id":10068242, "to_user_id":10068242, "description":"Описание задачи", "phone":"79219407346", "deal_id":233226, "priority":1, "is_auto_call":true, "theme":"Название задачи" } В ответе содержатся следующие данные:

| № | Параметр | Тип | Обязательный | Описание |
| --- | --- | --- | --- | --- |
| 1 | result | Число | Да | Код результата (см. Список кодов результата) |
| 2 | task_id | Число | Да | Уникальный номер задачи |
| 3 | auto_call_task_id | Число | Да | ID созданной задачи на автоперезвон, если такая<br>задача создана<br>Этот параметр идентичен параметру task_id из<br>звонкового события по данной задаче<br>автоперезвона |

Пример ответа: { "result": 1000, "task_id": 45594, "auto_call_task_id": 11024548 }
