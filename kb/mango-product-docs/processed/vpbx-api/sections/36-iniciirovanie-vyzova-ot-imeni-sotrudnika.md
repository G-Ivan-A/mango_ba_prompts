# 3.2.1. Инициирование вызова от имени сотрудника

> Трассировка: PDF §3.2.1 · сквозные стр. 33-36 · источники: ч.1 `kb/mango-product-docs/sources/vpbx-api/MangoOffice_VPBX_API_v1.9.pdf` с.33-36.

POST /vpbx/commands/callback С помощью этого запроса внешняя система инициирует исходящий вызов. Входные параметры:

| № | Параметры с<br>уровнями<br>вложенности |  | Тип | Обяза-<br>тель-<br>ный | Описание |
| --- | --- | --- | --- | --- | --- |
|  | 1 | 2 |  |  |  |
| 1 | command_id |  | string |  | Идентификатор команды (строка не более 128 байт).<br>Формируется внешней системой. ВАТС никак не<br>обрабатывает этот идентификатор, не анализирует и не<br>полагается на уникальность его значения.<br>Идентификатор можно использовать для связи команды<br>с результатом ее выполнения и возможными<br>последующими событиями, которые появляются в<br>результате выполнения команды. |
| 2 | from |  |  | Да | Данные, относящиеся к вызывающему абоненту. |
| 2.1 |  | extension |  | Да | Идентификатор сотрудника. Если у сотрудника ВАТС<br>нет идентификатора (внутреннего номера), выполнение<br>команды от его имени невозможно. |
| 2.2 |  | number | string | Нет | Номер вызывающего абонента (строка не более 128<br>байт). Поле следует использовать в случае, если вызов<br>должен быть инициирован с номера, отличного от<br>номера по умолчанию сотрудника ВАТС. В качестве<br>значения можно указывать: SIP, FMC и PSTN номера, но<br>нельзя указывать внутренние номера и номера групп<br>ВАТС.<br>К номеру будут применены правила преобразования<br>номеров ВАТС. Если будет указан номер, отличный от<br>номеров сотрудника ВАТС, которому соответствует<br>поле "extension", на время вызова этот номер будет<br>считаться номером сотрудника. |
| 3 | to_number |  | string |  | Номер вызываемого абонента (строка не более 128<br>байт). Может быть идентификатором сотрудника ВАТС,<br>внутренним номером группы операторов ВАТС или<br>любым другим номером. К номеру будут применены<br>правила преобразования номеров ВАТС. |
| 4 | line_number |  |  | Нет | Линия, которая была использована для размещения<br>вызова. Если в этом поле указано значение, то ВАТС |

| № | Параметры с<br>уровнями<br>вложенности |  | Тип | Обяза-<br>тель-<br>ный | Описание |
| --- | --- | --- | --- | --- | --- |
|  |  |  |  |  | будет использовать указанную в этом параметре линию.<br>Разрешается использовать только линии продукта, за<br>счет которого будет происходить вызов. На данный<br>момент поддерживаются следующие типы линий - SIP<br>UAC, номера 7-800, DID-номера MANGO OFFICE.<br>Важно! Чтобы вызов прошел через SIP-линию, Вам<br>нужно указать имя этой линии (а не SIP URI) в<br>параметре line_number. Имя SIP-линии задается в<br>Личном кабинете MANGO OFFICE. |
| 5 | sip_headers |  |  | Нет | Список заголовков SIP, которые могут быть переданы<br>внешней системой в ВАТС<br>Примечание. Описание поля sip_headers приведено в<br>Приложении 1. Допустимые заголовки для данного<br>метода. |
| 5.1 |  | Call-<br>Info/answer<br>-after | string | Нет | Строка не более 64 байт. |

После получения вызываемого абонента, ВАТС попытается сопоставить его сотрудниками ВАТС, если это возможно, и присвоит им идентификатор абонента ВАТС. В ответ на команду высылается уведомление о результате обработки команды. Процесс инициирования вызова представлен следующей диаграммой:

![Изображение, стр. 35](../images/36-iniciirovanie-vyzova-ot-imeni-sotrudnika-1.jpeg)

Пример запроса: POST https://app.mango-office.ru/vpbx/commands/callback vpbx_api_key = 1234567890qwerty, sign = 1234567890qwerty, json = { "command_id":"cbk1", "from": { "extension":"1234", "number":"12345678" }, "to_number":"74955404444", "line_number":"74951234567", "sip_headers": { "Call-Info/answer-after":"0" }, } Результат: POST /vpbx/result/callback В результате обработки запроса, формируются и передаются JSON-данные, содержащие следующие параметры:

| № | Параметры | Тип | Обяза-<br>тель-<br>ный | Описание |
| --- | --- | --- | --- | --- |
| 1 | command_id | string | Нет | Идентификатор команды (строка не более 128 байт). |
| 2 | result |  | Да | Результат выполнения команды инициирования вызова от<br>внешней системы. Ниже приведены возможные значения<br>результата (см. "Список кодов результатов"):<br>● 1000 - команда выполнена успешно;<br>● 2xxx - команда запрещена биллинговой системой ВАТС;<br>● 3100 - переданы неверные параметры либо команда не<br>может быть выполнена с этими параметрами;<br>● 4001 - команда не поддерживается;<br>● 5ххх - ошибка сервера. |
