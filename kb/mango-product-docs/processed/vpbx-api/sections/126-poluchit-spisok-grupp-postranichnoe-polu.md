# 3.9.2.3. Получить список групп, постраничное получение

> Трассировка: PDF §3.9.2.3 · сквозные стр. 162-164 · источники: ч.1 `kb/mango-product-docs/sources/vpbx-api/MangoOffice_VPBX_API_v1.9.pdf` с.162-164.

POST /vpbx/ab/groups/cursor Метод позволяет получить очередную страницу данных по группам. Параметры:

| № | Параметры | Тип | Обяза-<br>тель-<br>ный | Описание |
| --- | --- | --- | --- | --- |
| 1 | mode | string | Да | Режим работы поискового курсора. Для навигации по результатам<br>поиска используются один из следующих режимов:<br>● first-page - отобразить первую страницу результатов поиска;<br>● last-page - отобразить последнюю страницу результатов поиска;<br>● current-page - позволяет обновить текущую страницу результатов<br>поиска;<br>● next-page-{n} - отобразить следующую {n}-ую страницу,<br>относительно текущей страницы результатов поиска, переменная {n}<br>принимает значения в диапазоне от 1 до 9;<br>● prev-page-{n} - отобразить предыдущую {n}-ую страницу,<br>относительно текущей страницы результатов поиска, переменная {n}<br>принимает значения в диапазоне от 1 до 9 |
| 2 | cursor | string | Да | Зашифрованный объект поискового курсора |

Пример запроса: POST https://app.mango-office.ru/vpbx/ab/groups/cursor vpbx_api_key = 1234567890qwerty, sign = 1234567890qwerty, json = { "cursor":"Jtbyd2FyZCIsInNvdXJ", "mode":"next-page-1" } В результате обработки запроса, формируются и передаются JSON-данные, содержащие следующие параметры:

|  | 1 | 2 | 3 |  |  |  |
