# 3.2.2. Инициирование вызова от имени группы

> Трассировка: PDF §3.2.2 · сквозные стр. 36-38 · источники: ч.1 `kb/mango-product-docs/sources/vpbx-api/MangoOffice_VPBX_API_v1.9.pdf` с.36-38.

POST /vpbx/commands/callback_group Внешняя система инициирует исходящий вызов от имени группы. Входные параметры:

| № | Параметры | Тип | Обяза-<br>тель-<br>ный | Описание |
| --- | --- | --- | --- | --- |
| 1 | command_id | string |  | Идентификатор команды (строка не более 128 байт). Формируется<br>внешней системой. ВАТС никак не обрабатывает этот<br>идентификатор, не анализирует и не полагается на уникальность его<br>значения. Идентификатор можно использовать для связи команды с<br>результатом ее выполнения и возможными последующими<br>событиями, которые появляются в результате выполнения команды. |

| № | Параметры | Тип | Обяза-<br>тель-<br>ный | Описание |
| --- | --- | --- | --- | --- |
| 2 | from |  | Да | Данные, относящиеся к вызывающей стороне. Может быть<br>внешним номером, либо коротким номером группы. |
| 3 | to |  | Да | Данные, относящиеся к вызываемой стороне. Может быть<br>внешним номером, либо коротким номером группы. Короткий<br>номер группы обязателен для заполнения, либо в поле from,<br>либо в поле to. |
| 4 | line_number |  | Да | Линия ВАТС, которая должна быть использована для<br>размещения вызова. Линия должна принадлежать тому же<br>ВАТС, что и группа. Поддерживаются следующие типы<br>линий: SIP UAC, номера 7-800, DID-номера.<br>Важно! Чтобы вызов прошел через SIP-линию, Вам нужно<br>указать имя этой линии (а не SIP URI) в параметре line_number.<br>Имя SIP-линии задается в Личном кабинете MANGO OFFICE. |

Важно! Если в поле from указан внешний номер, а в поле to указан номер группы, то ВАТС сначала совершает дозвон на внешний номер, а после ответа клиента – начинает дозвон на группу (по заданному в группе алгоритму). Если в поле from указан номер группы, а в поле to указан внешний номер, то ВАТС сначала совершает дозвон на группу (по заданному в группе алгоритму), а после ответа оператора – начинает дозвон на внешний номер. Примеры. Пример для случая группа-абонент: POST https://app.mango-office.ru/vpbx/commands/callback_group vpbx_api_key = 1234567890qwerty, sign = 1234567890qwerty, json = { "command_id":"cbk1", "from":"1234", "to":"74955404444", "line_number":"74951234567" } Пример для случая абонент-группа: POST https://app.mango-office.ru/vpbx/commands/callback_group vpbx_api_key = 1234567890qwerty, sign = 1234567890qwerty, json = { "command_id":"cbk2", "from":"74955404444", "to":"1234", "line_number":"74951234567" } POST /vpbx/result/callback_group В результате обработки запроса, формируются и передаются JSON-данные, содержащие следующие параметры:

| № | Параметры | Тип | Обяза-<br>тель-<br>ный | Описание |
| --- | --- | --- | --- | --- |
| 1 | command_id | string | Нет | Идентификатор команды (строка не более 128 байт). |
| 2 | result |  | Да | Результат выполнения команды инициирования вызова от<br>внешней системы. Ниже приведены возможные значения<br>результата (см. "Список кодов результатов"):<br>● 1000 - команда выполнена успешно;<br>● 2xxx - команда запрещена биллинговой системой ВАТС;<br>● 3100 - переданы неверные параметры либо команда не<br>может быть выполнена с этими параметрами;<br>● 4001 - команда не поддерживается;<br>● 5ххх - ошибка сервера. |
