# 3.1.4. Уведомление о записи разговора

> Трассировка: PDF §3.1.4 · сквозные стр. 22-26 · источники: ч.1 `kb/mango-product-docs/sources/vpbx-api/MangoOffice_VPBX_API_v1.9.pdf` с.22-26.

POST https://external-system.com/events/recording Уведомление содержит информацию о процессе записи разговора. Запись разговора может стартовать по следующим сценариям: - по команде, отправленной внешней системой; - автоматически, в соответствие с настройками Виртуальной АТС; - по DTMF-команде, отправленной с телефонного аппарата в тоновом режиме; - по команде, отправленной другой внешней системой по отношению к обсуждаемой, либо интегрированными сервисами MANGO OFFICE (Контакт-центр, CRM). Параметры уведомления:

| № | Параметры | Тип | Обяза-<br>тель-<br>ный | Описание |
| --- | --- | --- | --- | --- |
| 1 | recording_id | string |  | Идентификатор записи разговора, строка не более 128 байт.<br>Уникальность идентификатора гарантируется ВАТС на<br>протяжении всего периода оказания услуг по данному API.<br>Внутренний формат идентификатора не должен как-либо<br>использоваться внешней системой. ВАТС оставляет за собой<br>возможность изменять "содержимое" идентификатора, не<br>нарушая при этом соглашение об уникальности. |
| 2 | recording_state |  |  | Состояние процесса записи разговора. |
| 3 | seq |  |  | Счетчик последовательности уведомлений по записи<br>разговора. |
| 4 | entry_id |  |  | Внутренний идентификатор группы вызовов. Не имеет<br>отношения к CALL-ID из SIP-протокола. |
| 5 | call_id |  |  | Внутренний идентификатор вызова, в котором происходит<br>запись, строка. Не имеет отношения к CALL-ID из SIP-<br>протокола. Если записываемый абонент переходит в другой<br>вызов в результате перевода, значение идентификатора<br>вызова будет обновлено. |
| 6 | extension |  | Нет | Идентификатор сотрудника ВАТС для записываемого абонента.<br>Не передается в случае, если ВАТС не удалось<br>идентифицировать вызывающего абонента как сотрудника<br>ВАТС. Если у сотрудника ВАТС нет идентификатора<br>(внутреннего номера) передается пустое значение. |
| 7 | timestamp |  |  | Время события UTC+3. |
| 8 | completion_code |  | Нет | Код завершения. Передается в состоянии Completed. |
| 9 | recipient |  | Нет | Получатель записи. Передается в состоянии Completed в<br>случае, если запись успешно выполнена. |
| 10 | command_id | string | Нет | Идентификатор команды старта записи разговора внешней<br>системой (строка не более 128 байт). Заполняется в случае, если<br>запись началась по команде API. Уникальность строки для<br>внешней системы гарантируется внешней системой (см.<br>Включение записи вызова). |

Состояние процесса записи разговора recording_state Поле recording_state может иметь следующие значения:

| Состояние | Описание |
| --- | --- |
| Started | Запись начата. |
| Continued | Запись продолжена в другом вызове, идентификатор которого указан в call_id. |
| Completed | Запись завершена. |

Ниже показана диаграмма переходов для состояния процесса записи разговора. Начальным состоянием обычно является Started, конечным состоянием - Completed.

Результаты записи разговора Код результата записи указан в поле completion_code, см. "Список кодов результатов". Все коды результатов сгруппированы в классы, перечень классов см. в таблице:

| Группа кодов | Пояснение |
| --- | --- |
| 1000 | Действие успешно выполнено. |
| 22хх | Доступ к счету ограничен. |
| 4002 | Продолжительность записи меньше минимально возможной в ВАТС, запись не<br>будет сохранена. |

Получатель записи recipient В поле recipient указан получатель записи разговора и может иметь следующее значение:

| Значение | Пояснение |
| --- | --- |
| Cloud | Запись вызова будет сохранена в Облачном хранилище и доступна из Личного<br>кабинета MANGO OFFICE. |
| Mail | Запись вызова отправлена на e-mail пользователя. |
| CloudAndMail | Запись вызова будет сохранена в Облачном хранилище и дополнительно<br>отправлена на e-mail пользователя. |

На рисунке ниже показан пример приема входящего вызова сотрудником ВАТС с последующим переводом на другого сотрудника ВАТС с предварительной консультацией. Оба сотрудника ВАТС записываются автоматически.
