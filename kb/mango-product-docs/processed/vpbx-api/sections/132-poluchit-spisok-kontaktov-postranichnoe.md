# 3.9.3.2. Получить список контактов, постраничное получение

| 1 | mode |  | string | Да | Режим работы поискового курсора. Для навигации по<br>результатам поиска используются один из следующих<br>режимов |
| 1.1 |  | first-page |  |  | Отобразить первую страницу результатов поиска |
| 1.2 |  | last-page |  |  | Отобразить последнюю страницу результатов поиска |
| 1.3 |  | current-page |  |  | Позволяет обновить текущую страницу результатов<br>поиска |
| 1.4 |  | next-page-{N} |  |  | Отобразить следующую {N}-ую страницу, относительно<br>текущей страницы результатов поиска, переменная {N}<br>принимает значения в диапазоне от 1 до 9 |

| 2 | cursor |  | string | Да | Зашифрованный объект поискового курсора |
| 3 | contact_e<br>xt_fields |  |  |  | Признак необходимости возвращать значения<br>пользовательских полей (custom_values) и поля<br>идентификатор персонального сотрудника (user_id). |
