# 3.9.2.2. Получить список групп, инициация отчета

> Трассировка: PDF §3.9.2.2 · сквозные стр. 161-162 · источники: ч.1 `kb/mango-product-docs/sources/vpbx-api/MangoOffice_VPBX_API_v1.9.pdf` с.161-162.

POST /vpbx/ab/groups/init Для получения списка всех групп нужно выполнить последовательность действий: шаг 1 - инициировать получение данных; шаг 2 - постранично получить данные. Параметры:

| № | Параметры | Тип | Обяза-<br>тель-<br>ный | Описание |
| --- | --- | --- | --- | --- |
| 1 | limit_rows |  | Нет | Кол-во выбираемых строк (по умолчанию 10, ограничение 500) |
| 2 | query | string | Да | Строка поиска, допустима передача пустой строки для возврата<br>списка всех групп |
| 3 | order |  | Нет | Массив объектов вида [ { "field": "asc \| desc" }, ... ], - правило<br>сортировки; порядок следования объектов в массиве определяет<br>порядок сортировки |

Пример запроса: POST https://app.mango-office.ru/vpbx/ab/groups/init vpbx_api_key = 1234567890qwerty, sign = 1234567890qwerty, json = { "query":"", "limit_rows":"2" } В результате обработки запроса, формируются и передаются JSON-данные, содержащие следующие параметры:

| --- | --- | --- | --- | --- | --- | --- |
|  | 1 | 2 | 3 |  |  |  |
| 1 | result |  |  |  | Да | Код результата |
| 2 | data |  |  |  |  | Массив объектов типа Группа |
| 2.1 |  | group_id |  |  |  | id группы |
| 2.2 |  | group_name |  | string |  | Название группы |
| 3 | state |  |  |  |  | Состояние выдачи данных по запросу |
| 3.1 |  | info |  |  |  | Массив, информация из курсора, продублированная в<br>незашифрованном виде, которая может быть необходима<br>программе построения пользовательского интерфейса |

| № | Параметры с уровнями<br>вложенности |  |  | Тип | Обяза-<br>тель-<br>ный | Описание |
