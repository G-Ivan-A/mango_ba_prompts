Запрос расширенной статистики – это новый вид запроса, обработка которого оптимизирована за счет улучшения используемых технологий. Преимуществом данного запроса является то, что его можно использовать для получения расширенной статистики. Сравните сами: - пример базовой статистики; - пример расширенной статистики. Получение расширенной статистики состоит из следующих этапов: 1) Запуск формирования статистики; 2) Получение статистики.
