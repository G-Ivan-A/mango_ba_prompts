# 3.9.1.3. Получить список организаций, постраничное получение

> Трассировка: PDF §3.9.1.3 · сквозные стр. 155-157 · источники: ч.1 `kb/mango-product-docs/sources/vpbx-api/MangoOffice_VPBX_API_v1.9.pdf` с.155-157.

POST /vpbx/ab/organizations/cursor Метод позволяет получить очередную страницу данных по организациям. Параметры:

| № | Параметры | Тип | Обяза-<br>тель-<br>ный | Описание |
| --- | --- | --- | --- | --- |
| 1 | mode | string | Да | Режим работы поискового курсора. Для навигации по результатам<br>поиска используются один из следующих режимов:<br>● first-page - отобразить первую страницу результатов поиска;<br>● last-page - отобразить последнюю страницу результатов поиска;<br>● current-page - позволяет обновить текущую страницу результатов<br>поиска;<br>● next-page-{N} - отобразить следующую {N}-ую страницу,<br>относительно текущей страницы результатов поиска, переменная<br>{N} принимает значения в диапазоне от 1 до 9;<br>● prev-page-{N} - отобразить предыдущую {N}-ую страницу,<br>относительно текущей страницы результатов поиска, переменная<br>{N} принимает значения в диапазоне от 1 до 9; |
| 2 | cursor | string | Да | Зашифрованный объект поискового курсора |

Пример запроса: POST https://app.mango-office.ru/vpbx/ab/organizations/cursor vpbx_api_key = 1234567890qwerty, sign = 1234567890qwerty, json = { "cursor":" eyJtb2RlIjoic2NTIsInF=", "mode":"next-page-2" } В результате обработки запроса, формируются и передаются JSON-данные, содержащие следующие параметры:
