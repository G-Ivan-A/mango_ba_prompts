# 4.8.3.1. Общение закрыто

> Трассировка: PDF §4.8.3.1 · сквозные стр. 298-301 · источники: ч.1 `kb/mango-product-docs/sources/vpbx-api/MangoOffice_VPBX_API_v1.9.pdf` с.298-301.

/events/md/onAppealClose Событие "Обращение закрыто" предается во внешнюю систему в результате перевода в КЦ обращения в статус "Закрыто". В этом событии API КЦ передает не только статус обращения, но и другие опциональные параметры обращения: - ID номер "родительского" обращения; - канал обращения; - ID сотрудников, обраотавших обращение; - данные клиента, связанного с обращением; - историю переписки с клиентом; - и т.д. Дополнительную информацию о параметрах обращения, которые передаются в данном событиии можно найти далее в этом параграфе. Важно! Установлено следующеее ограничение на передачу истории переписки с клиентов в событие "Обращение закрыто" - передается не более 50 первых сообщений из переписки. Важно! Если есть созданный контакт, то передается параметр contact. Если контакта нет, передается параметр client_info. Параметры события:
