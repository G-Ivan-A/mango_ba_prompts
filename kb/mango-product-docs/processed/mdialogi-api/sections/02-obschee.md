Система "Манго Диалоги" (далее по тексту - МД) предоставляет сервис коммуникации с Клиентами и партнерами в различных текстовых каналах как из Контакт-центра MANGO OFFICE, так из любой вашей внешней системы CRM/HRM/СDP, при интеграции ее через API. С помощью МД вы можете организовать обмен текстовыми сообщениями между Клиентами и вашими операторами через различные каналы текстовых коммуникаций. Примечание.
