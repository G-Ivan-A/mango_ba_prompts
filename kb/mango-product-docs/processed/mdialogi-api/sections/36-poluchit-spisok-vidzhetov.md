# 3.3.1. Получить список виджетов

> Трассировка: PDF §3.3.1 · сквозные стр. 29-33 · источники: ч.1 `kb/mango-product-docs/sources/mdialogi-api/Manual_API_Mango_Dialogi.pdf` с.29-33.

Метод возвращает список виджетов МД, с подробной информацией о каждом виджете. Если вы хотите посмотреть данные только по одному определенному виджету, укажите его идентификатор во входных параметрах этого запроса. HTTP-запрос: POST https://app.mango-office.ru/cc/md/widgets Параметры запроса:

| Параметр | Тип | Обяза-<br>тель-<br>ное | Описание |
| --- | --- | --- | --- |
| id | String | Да | Уникальный идентификатор вызова (например, UUID).<br>Формируется внешней системой. Манго Диалоги и ВАТС<br>никак не обрабатывают этот идентификатор, не<br>анализируют и не полагаются на его уникальность. |
| widget_id | Integer | Нет | Идентификатор виджета следует указать в запросе, если вы<br>хотите получить информацию только по определенному<br>виджету.<br>Если идентификатор НЕ указан в запросе, то метод вернет<br>список всех виджетов МД, включая их идентификаторы. |

Примеры запроса. 1) Пример запроса списка всех виджетов.

| POST https://app.mango-office.ru/cc/md/widgets |
| --- |
| vpbx_api_key = 123qwerty, |
| sign = 456qwerty, |
| json = { "id": "fc30" |
| } |
