Метод возвращает массив сообщений, которыми обменивались Клиент и оператор, в рамках определенной сессии. HTTP-запрос: POST https://app.mango-office.ru/cc/md/session/chat/history Манго Диалоги. Справочник по API | Версия от 27.02.2026 Параметры запроса:

| Параметр | Тип | Обяза-<br>тель-<br>ное | Описание |
| --- | --- | --- | --- |
| id | String | Да | Уникальный идентификатор вызова (например, UUID).<br>Формируется внешней системой. Манго Диалоги и ВАТС<br>никак не обрабатывают этот идентификатор, не<br>анализируют и не полагаются на его уникальность. |
| chat_id | String | Да | Идентификатор чата.<br>Узнать идентификатор чата вы можете при помощи<br>запроса "Получить список виджетов" и\или API<br>Realtime |
| since_message<br>_id | String | Нет | Выборка сообщений ранее, чем указанное в этом<br>параметре сообщение |
| to_message_id | String | Нет | Выборка сообщений позднее, чем, указанное в этом<br>параметре сообщение |
| since_time | Integer | Нет | Сообщений начиная с указанного времени<br>(не включительно), мс |
| to_time | Integer | Нет | Выборка до указанного момента времени<br>(не включительно), мс |
| latest | Integer | Нет | Выдавать N самых последних сообщений |
