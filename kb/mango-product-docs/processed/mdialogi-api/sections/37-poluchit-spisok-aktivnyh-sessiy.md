# 3.3.2. Получить список активных сессий

> Трассировка: PDF §3.3.2 · сквозные стр. 33-38 · источники: ч.1 `kb/mango-product-docs/sources/mdialogi-api/Manual_API_Mango_Dialogi.pdf` с.33-38.

Метод возвращает список сессий, находящихся в статуе "pending" (ожидает распределения на оператора или группу) и в статусе "dialog" (передана в работу оператору или группе) и детальную информацию о каждой сессии, в том числе: идентификатор сессии, идентификатор виджета, уникальный идентификатор пользователя в соц.сети (social_user_id) и прочее. HTTP-запрос: POST https://app.mango-office.ru/cc/md/sessions Параметры запроса:

| Параметр | Тип | Обяза-<br>тель-<br>ное | Описание |
| --- | --- | --- | --- |
| id | String | Да | Уникальный идентификатор вызова (например, UUID). Формируется<br>внешней системой. Манго Диалоги и ВАТС никак не обрабатывают<br>этот идентификатор, не анализируют и не полагаются на его<br>уникальность |

Пример запроса:

| { |
| --- |
| "id": "fc30" |
| } |
