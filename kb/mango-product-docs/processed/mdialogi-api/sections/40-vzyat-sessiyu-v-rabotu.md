# 3.4.2. Взять сессию в работу

> Трассировка: PDF §3.4.2 · сквозные стр. 40-42 · источники: ч.1 `kb/mango-product-docs/sources/mdialogi-api/Manual_API_Mango_Dialogi.pdf` с.40-42.

Метод позволяет перевести сессию из статуса "pending" в статус "dialog", то есть назначить оператора, который примет сессию в работу. Если же сессия уже передана в работу тому или иному оператору, будет возвращена ошибка. HTTP-запрос: POST https://app.mango-office.ru/cc/md/session/take Параметры запроса:

| Параметр | Тип | Обяза-<br>тель-<br>ное | Описание |
| --- | --- | --- | --- |
| id | String | Да | Уникальный идентификатор вызова (например, UUID).<br>Формируется внешней системой. Манго Диалоги и ВАТС<br>никак не обрабатывают этот идентификатор, не анализируют<br>и не полагаются на его уникальность |
| session_id | String | Да | Идентификатор активной сессии (этот идентификатор<br>можно получить при помощи запроса "Получить список<br>активных сессий") |

| Параметр | Тип | Обяза- | Описание |
| --- | --- | --- | --- |
| abonent_id | Integer | тель-<br>Да<br>ное | Идентификатор сотрудника ВАТС, который примет сессию в<br>работу.<br>Узнать список сотрудников ВАТС и их идентификаторы вы<br>можете при помощи API MANGO OFFICE или API Realtime |
| messages | Масси<br>строк | Нет | Массив идентификаторов сообщений чата,<br>ассоциированного с сессией, которые будут перемещены в<br>новый чат, созданный переводом. Если не передавать будут<br>перенесены все сообщения исходной сессии. |

| --- |

| name | String | Да | Наименование статуса HTTP |
| status | Integer | Да | Код ответа HTTP |
| code | Integer | Да | Код результата (список) |
| error | String | Нет | Текст ошибки, если она произошла |
