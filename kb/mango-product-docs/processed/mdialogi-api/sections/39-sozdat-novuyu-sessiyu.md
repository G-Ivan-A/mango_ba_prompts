# 3.4.1. Создать новую сессию

> Трассировка: PDF §3.4.1 · сквозные стр. 38-40 · источники: ч.1 `kb/mango-product-docs/sources/mdialogi-api/Manual_API_Mango_Dialogi.pdf` с.38-40.

Если Клиент ранее уже обращался в вашу компанию и у вас есть уникальный идентификатор пользователя в соц. сети (social_user_id) этого Клиента, то вы можете, от имени оператора, инициировать диалог с этим Клиентом. Данный метод позволяет: - в МД создать новую сессию, которой сразу будет присвоен статус "dialog", то есть сессия будет создана и передана в работу оператору, указанному в запросе; - отравить первое сообщение Клиенту от оператора, указанного в запросе. Метод обрабатывается асинхронно, то есть в результате обработки запроса будет сформирован и передан во внешнюю систему код ошибки, а информация о созданной сессии будет передана во внешнюю систему при помощи вебхука "Сессия взята в работу". Примечание. Подробнее о процессе инициирования диалога с Клиентом со стороны оператора вы можете узнать из Примера использования API. Манго Диалоги. Справочник по API | Версия от 27.02.2026 HTTP-запрос: POST https://app.mango-office.ru/cc/md/session/create Параметры запроса:

| Параметр | Тип | Обяза-<br>тель-<br>ное | Описание |
| --- | --- | --- | --- |
| id | String | Да | Уникальный идентификатор вызова (например, UUID).<br>Формируется внешней системой. Манго Диалоги и ВАТС<br>никак не обрабатывают этот идентификатор, не<br>анализируют и не полагаются на его уникальность |
| channel_id | Integer | Да | Уникальный идентификатор канала, через который должен<br>начаться диалог между Клиентом и оператором.<br>Узнать идентификатор канала вы можете при помощи<br>запроса "Получить список виджетов" или API Realtime |
| social_user_i<br>d | String | Да | Уникальный идентификатор пользователя (Клиента) в соц.<br>сети.<br>Узнать идентификатор пользователя вы можете из<br>вебхуков, которые передавались ранее от API к внешней<br>системе, в момент предыдущего диалога Клиента и<br>оператора |
| message | String | Да | Текст сообщения оператора Клиенту |
| abonent_id | Integer | Да | Идентификатор сотрудника ВАТС, который примет сессию в<br>работу.<br>Узнать список сотрудников ВАТС и их идентификаторы вы<br>можете при помощи API MANGO OFFICE или API Realtime |
