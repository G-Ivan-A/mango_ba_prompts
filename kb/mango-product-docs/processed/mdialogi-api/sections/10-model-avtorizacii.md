# 2.3.1. Модель авторизации

> Трассировка: PDF §2.3.1 · сквозные стр. 10-11 · источники: ч.1 `kb/mango-product-docs/sources/mdialogi-api/Manual_API_Mango_Dialogi.pdf` с.10-11.

API предоставляет внешней системе доступ к своим функциям без ограничений. Если внешней системе требуется разграничение доступа на уровне пользователей внешней системы, то это разграничение обеспечивает сама внешняя система. Манго Диалоги. Справочник по API | Версия от 27.02.2026 Внешняя система действует от имени сотрудника ВАТС в следующих случаях: создание новой сессии, взятие сессии в работу, перевод сессии на другого сотрудника, закрытие сессии, отправка сообщения оператора клиенту, редактирование сообщения оператора, сообщение клиента доставлено оператору, оператор прочитал сообщение клиента, оператор удаляет сообщение, оператор набирает текст, загрузка истории чата, сообщение оператора доставлено клиенту, сообщение оператора прочитано клиентом, новое сообщение в чате. Для этого внешняя система указывает идентификатор сотрудника ВАТС или один из его номеров в качестве номера вызывающего абонента. Действие будет выполняться в соответствии с логикой и возможными ограничениями для сотрудника ВАТС.
