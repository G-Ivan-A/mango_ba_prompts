Справочник по API | Версия от 27.02.2026 Определения и сокращения API Манго Диалоги (API) – программный интерфейс системы "Манго Диалоги", созданный в архитектурном стиле REST. При помощи него, вы можете в вашей бизнес-системе организовать обмен текстовыми сообщениями с Клиентом через Манго Диалоги по разным текстовым каналам: Telegram, WhatsApp, Email, Авито, Авито Работа, Max, Виджет «Чат на сайте», ВКонтакте. API коннектор ВАТС – универсальный инструмент для интеграции возможностей ВАТС с внешними системами. Адресная книга (АК) — адресная книга MANGO OFFICE, используется в Контакт-центре MANGO OFFICE, M.TALKER. ВАТС (Виртуальная АТС) - программно-аппаратный комплекс MANGO OFFICE для обслуживания Клиентов, предоставляющий возможности телефонии и управления ими. Внешняя бизнес-система (внешняя система) - любое приложение, CRM-система, облачный сервис и пр., имеющий публичный web-интерфейс, и реализующий протокол взаимодействия с Манго Диалоги, описанный ниже, в полном объеме либо некоторую, достаточную для ее нужд, часть. Виджет Манго Диалогов - это компонент МД, объединяющий в себе настройки текстовых каналов коммуникаций. Он предоставляется в виде кода JS, который вы можете установить на свой сайт. В результате на вашем сайте появится кнопка диалога с оператором. Идентификатор сотрудника ВАТС — соответствует внутреннему (короткому) номеру сотрудника ВАТС, который устанавливается в Личном кабинете. Также служит для идентификации сотрудника внешней системой. Коммуникатор MANGO Talker (M.TALKER) - это кроссплатформенный продукт, позволяющий реализовать все основные коммуникации внутри компании. Личный кабинет — web-интерфейс управления ВАТС и настройки параметров API с помощью браузера. Доступен клиентам MANGO OFFICE в интернете по адресу: https://lk.mango-office.ru Номер абонента — цифровой номер ТфОП, SIP-ID, внутренний номер сотрудника ВАТС. Система "Манго Диалоги" (Манго Диалоги) - это программный комплекс MANGO OFFICE, предоставляющий платформу для коммуникации через различные текстовые каналы связи, при подключении его к ВАТС и к сайту Клиента. Сотрудник ВАТС — абонент, имеющий учетную запись в ВАТС, которая, в частности, содержит список контактных номеров, а также внутренний номер. Манго Диалоги. Справочник по API | Версия от 27.02.2026
