# Ключ создания подписи (vpbx_api_salt)

> Трассировка: PDF §2.3.7 · сквозные стр. 15-16 · источники: ч.1 `kb/mango-product-docs/sources/mdialogi-api/Manual_API_Mango_Dialogi.pdf` с.15-16.

Для подписания запроса к API используется ключ создания подписи или vpbx_api_salt. Он представляет собой строку вида: 0987654321asdfgh Ключ создания подписи (vpbx_api_salt) используется обеими сторонами для подписания сообщений. Примечание. Ключ создания подписи в запросах не передается, а используется только для создания электронной подписи sign. Манго Диалоги. Справочник по API | Версия от 27.02.2026
