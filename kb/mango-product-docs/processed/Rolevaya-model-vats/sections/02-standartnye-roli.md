# 2. Стандартные роли

> Трассировка: PDF §2 · сквозные стр. 5-7 · источники: ч.1 `kb/mango-product-docs/sources/Rolevaya-model-vats/Rolevaya-model-VATS_1_26_08.pdf` с.5-7.

В Виртуальной АТС MANGO OFFICE предусмотрены стандартные системные роли. Каждая роль предназначена для определённой категории пользователей и содержит набор прав доступа. Сотрудник Базовая роль для большинства пользователей системы. Пользователь с этой ролью может выполнять повседневные операции, связанные с работой в системе, например: • работать с группами • использовать инструменты системы • просматривать информацию Административные функции и системные настройки пользователю с этой ролью недоступны. Администратор Администратор обладает расширенными правами доступа. Пользователь с этой ролью может: • управлять пользователями • настраивать систему • управлять ролями • изменять параметры телефонии • управлять интеграциями • работать с настройками безопасности Эта роль предназначена для сотрудников, отвечающих за администрирование системы. Бухгалтер Роль предназначена для сотрудников финансового отдела. Пользователь с этой ролью имеет доступ к финансовой информации, например: • просмотр баланса • просмотр счетов • работа с финансовыми документами При этом доступ к большинству административных настроек системы отсутствует. Старший сотрудник Роль предназначена для сотрудников с расширенными полномочиями. Пользователь может: • управлять частью функций системы • контролировать работу сотрудников • работать с расширенными инструментами. Роли и права доступа | v. 1.26.08 5

Руководитель группы Роль используется для управления группами сотрудников. Пользователь может: • контролировать работу сотрудников своей группы • управлять доступом сотрудников • просматривать статистику работы группы. Маркетолог Роль предназначена для сотрудников маркетингового отдела. Пользователь может: • работать с аналитикой • использовать инструменты маркетинга • просматривать статистические данные. Руководитель кампании Роль используется для управления кампаниями контакт-центра. Пользователь может: • управлять кампаниями • работать с аналитикой • использовать функции контакт-центра.
