# 3. Управление ролями

> Трассировка: PDF §3 · сквозные стр. 7 · источники: ч.1 `kb/mango-product-docs/sources/Rolevaya-model-vats/Rolevaya-model-VATS_1_26_08.pdf` с.7.

Управление ролями выполняется в разделе: Настройки АТС → Безопасность и ограничения → Настройка доступа

![Изображение, стр. 7](../images/03-upravlenie-rolyami-1.png)

Рисунок 1. Выпадающий список раздела «Общие настройки» В этом разделе можно просматривать роли, создавать новые роли, изменять права доступа ролей и удалять пользовательские роли. Роль представляет собой набор прав доступа. Назначение роли пользователю определяет, какие функции системы будут ему доступны. В этом разделе администратор может: • просматривать список ролей • создавать новые роли • копировать существующие роли • редактировать существующие роли • удалять пользовательские роли При создании или редактировании роли определяется набор прав доступа, которые будут доступны пользователям с этой ролью. внимание Настройки роли позволяют: • определять перечень ролей с доступом на изменение; • определять перечень ролей, на которые производится смена доступа; • определять перечень ролей для внесения изменений в их настройки.
