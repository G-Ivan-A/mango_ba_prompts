# 5. Матрица ролей и прав доступа

> Трассировка: PDF §5 · сквозные стр. 19 · источники: ч.1 `kb/mango-product-docs/sources/Rolevaya-model-vats/Rolevaya-model-VATS_1_26_08.pdf` с.19.

В разделе описаны возможности подключения/отключения прав доступа, установленные по умолчанию для системных ролей. Статус Доступно означает, что для роли включено (или может быть включено) данное право доступа. При этом дополнительно могут быть выбраны ограничения доступа из установленных в интерфейсе ЛК ВАТС. Статус Недоступно означает, что данное право доступа для роли включенным быть не может.
