## Решаемая проблема

Черновики промптов шагов (PR #439) собраны на срезе runtime `2db0ef51`.
В этом срезе нет golden set по классам и глоссариев РТ-4, поэтому
действуют заглушки З-3 (Ш-В) и З-4 (Ш-1). В промпте Ш-2 стоит только
ссылка на каталог, а инструкции чтения М-4 (RFC-RT-001, раздел 4) нет.
Правка типа гейта для 14 опубликованных промптов лежит заготовкой и в
`prompts/` не применена. В опубликованных промптах осталось три ссылки
на runtime по `blob/main`: это долг раздела 7 реестра, отложенный до
BL-156. Runtime PR #21 снял причину заглушек, но спица об этом не знает.
