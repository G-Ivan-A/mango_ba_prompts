# Батч D_skillaz: Интеграция с рекрутинговой системой Skillaz и внутренним контуром заказчика, SSO oauth 2.0, методы API для передачи статистики

### Требования к системе!6
№: 5

Реализована интеграция с рекрутинговой системой Skillaz/Исполнитель подтверждает готовность реализовать интеграцию за свой счет в срок до 2 месяцев с даты заключения договора, при этом у Исполнителя есть подтвержденный опыт аналогичной интеграции с другой CRM-системой (демонстрируется на встрече на примере других клиентов): <br>- интеграция позволяет работать операторам ВымпелКом в одном окне Skillaz, без перехода в программы телефонии<br>- получение и прием звонков через интерфейс Skillaz, ручные звонки по клику на номер телефона кандидата в Skillaz<br>- автооткрытие при дозвоне карточки кандидата в Skillaz оператору, который обрабатывает звонок<br>- система Исполнителя по интеграции автоматически меняет статусы воронки Skillaz по настроенным сценариям для различных результатов обзвона, например: недозвон/дозвон до кандидата<br>- получение по интеграции от Skillaz списков контактов на обзвон в заданные кампании<br>- постановка статусов работы операторов на линии в Skillaz и их синхронизация с системой Исполнителя

### Требования к системе!8
№: 7

На этапе внедрения реализация интеграции с системемой Skillaz и внутренним контуром билайна:<br> - распределение звонков на основании списка процессных ролей в карточке кандидата Skillaz (например, в последовательности Ответственный за кандидата (основной обработчик)-Рекрутеры-Другие операторы)<br> - функционал отложенного звонка кандидату - в карточке кандидата Skillaz устанавливается определенный статус с указанием даты и времени, при наступление указанной даты и времени контакт уходит в автообзвон автоматически. Звонок распределяется  в последовательности - оператор, установивший статус - Ответственный за кандидата (основной обработчик) - Рекрутеры - Другие операторы.<br> - остановка по интеграции кампаний обзвона из Skillaz<br> - передача по интеграции записей звонков в Skillaz<br> - передача по интеграции статистической информации по работе входящей и исходящей линии, работе операторов, работе иных модулей системы<br> - Авторизация из корпоративного пространства ВымпелКом пользователей SSO по протоколу oauth 2.0<br> - Наличие методов API для передачи в пространство Вымпелком полной статистики телефонии <br>
