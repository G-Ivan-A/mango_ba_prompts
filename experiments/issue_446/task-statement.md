БА не может начать тест этапа 1 на новых задачах: на сайте нет набора
«что копировать на каждом шаге». Раздел «Процессы» показывает 39 классов

промптов v0.1 и 12 черновиков «по тесту» только в репозитории. Какой текст
брать на шаге — не определено: колонка черновиков «справочно, не
применять до BL-157б». Решение о типе гейта и черновике Ш-В по RUN-0081
(N = 1) — лотерея. Черновики A-IN (Ш-0, Ш-1, Ш-2) не измерены ничем.

## Story

**Как есть:** БА видит на сайте 39 классов, но не 13 шагов комплекта;
черновики A-IN не прогонялись ни разу; решение RUN-0081 опирается на один
замер.

**Как должно быть:** на сайте, на странице «Процессы», есть раздел
«Промпты этапа 1 для тестового прогона»: 13 шагов, у каждого — режим
(`published` или `by-test`), кнопка копирования назначенного текста и
вторая кнопка для сравнения. Режим шага берётся из колонки «Режим в
тесте» комплекта прогона, а не задаётся сайтом. Режим A-IN выбран по
синтетическому прогону с пред-регистрацией (RUN-0083). Решение по типу
гейта и Ш-В принято по медиане трёх повторов (RUN-0082).

**Как владелец принимает:** слияние PR #447 (молчание = согласие) или

## Экспертное предупреждение

> ⚠️ **ЭКСПЕРТНОЕ ПРЕДУПРЕЖДЕНИЕ (Industry Practice Alert)**
> **Запрос Владельца:** «нет в текущей итерации на человеческий гейт,
> ревью»; короткий путь к тесту «даже при использовании синтетических
> прогонов».
> **Индустриальная практика:** оценку LLM-судьёй калибруют по выборке
> человеческих оценок (human-in-the-loop calibration), а синтетический
> пользователь — только для дымовой проверки, не для решения о выпуске.
> **Обоснование практики:** у судьи той же модели есть смещение к своему
> стилю; сценарий БА знает «правильные» ответы заранее. Без калибровки
> неизвестно, совпадает ли «сдан» судьи с «годится» БА.
> **Риск выполнения запроса:** набор теста получает редакцию, которую
> одобрила только модель; ошибка увидится лишь в прогоне БА.
>
> **Действие ИИ:** запрос исполнен — человеческого гейта нет. Риск
> ограничен: синтетический итог меняет только режим шага в тестовом
> наборе, `prompts/` не меняется; на сайте у каждого шага есть вторая
> кнопка — текст для сравнения. Первый прогон БА (BL-111) и есть
> калибровка. Если нужна калибровка до теста, напишите: *«Применить
> индустриальную практику (калибровка)»* — около 1 часа БА на 10 кейсов.
> Если вы сознательно идёте без неё: *«Подтверждаю с учетом риска»*.
