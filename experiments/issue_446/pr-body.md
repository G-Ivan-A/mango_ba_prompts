## ⚠️ Экспертное предупреждение (Industry Practice Alert, не блокирует)

**Калибровка LLM-судьи и синтетического пользователя.**

- **Запрос:** «нет в текущей итерации на человеческий гейт, ревью»; короткий путь к тесту «даже при использовании синтетических прогонов».
- **Практика:** оценку LLM-судьёй калибруют по выборке человеческих оценок. Синтетический пользователь годится для дымовой проверки, а не для решения о выпуске.
- **Риск:**
  - исполнитель, судья и «БА» в RUN-0083 — одна модель;
  - набор теста получил редакцию A-IN, которую одобрила только модель.
- **Действие ИИ:**
  - запрос исполнен;
  - риск ограничен: синтетика меняет только режим шага в тестовом наборе, `prompts/` не меняется;
  - у каждого шага есть кнопка второй редакции для сравнения;
  - калибровкой станет первый прогон БА (BL-157в).
- **Как ответить:**
  - нужна калибровка до теста (около 1 часа БА на 10 кейсов) — напишите «Применить индустриальную практику (калибровка)»;
  - идёте без неё — «Подтверждаю с учетом риска».
