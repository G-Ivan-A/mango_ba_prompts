# RUN-0082 — пред-регистрация замера с повторами (BL-156б, Р-03)

RUN-0081 (N = 1) дал A с типом гейта 56/62, но ядро 9/11 против 10/11

## Процедура

- N = 3 независимых повтора r1, r2, r3.
- В каждом повторе:
  - свежие изолированные исполнители `claude-opus-5-5`: A1 × 2 пакета, D × 2 пакета;
  - свежие изолированные слепые судьи: 2 пакета, X/Y-маскировка с собственным seed (8082, 8083, 8084).
- Инструкции исполнителя и судьи те же, что в RUN-0081. Кейсы те же: 62 кейса RUN-0079, seed раскладки 79.

## Правило решения

1. По каждой версии считается медиана трёх повторов отдельно по сданным
   кейсам, ядру и ложным дефектам.
2. DEC-427-11 применяется к медианам: «не хуже» RUN-0079 = медиана сданных
   ≥ 49, медиана ядра ≥ 10, медиана ложных дефектов ≤ 0.
3. Тип гейта публикуется в `prompts/`, только если A1 «не хуже» по п. 2.
4. Черновик Ш-В публикуется (П-Ш-В), только если D «не хуже» RUN-0079 по
   п. 2 **и** не хуже медианы A1 по тем же трём показателям.
5. RUN-0081 — справочный четвёртый замер, в решение не входит.
6. Кейс ядра, проваленный не во всех повторах, — признак разброса, а не
   дефекта текста. Частота провала по кейсам публикуется в отчёте и служит
   автоматическим вторым чтением GS-BCREQ-01 и GS-BCREQ-12 (пункт 3
   issue #446).
