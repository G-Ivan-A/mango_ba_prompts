issues нет (проверены API `sub_issues` #478 и исходной #5).

**Story:** автор продуктового исследования цифрового направления Академии ПСБ
получает проверяемые ФИО профессиональных руководителей и их упоминания,
чтобы адресовать предложение по функции и подтверждённым полномочиям.
Публичная активность сама по себе не доказывает право принять решение.

**SSOT:** постановка #478; исходный принятый протокол и пакет
[aether-orbis-gra PR #6](https://github.com/G-Ivan-A/aether-orbis-gra/pull/6);
для фактов — первичные страницы организации, документы и организаторы событий;
для Mango — текущие исходники и реально опубликованный сайт. Срез 09.11.2026 UTC.
PR #6 уже merged, хотя его описание/acceptance говорят о неопубликованном пакете:
проверяется содержимое закреплённого коммита, не старое сообщение о сдаче.

Текущее задание явно разрешает публикацию гипотез без юридической проверки.
Это исключение из прежнего ограничения A2, не юридическое заключение.
Новые публичные профессиональные ФИО разрешены #478; личные контакты,
семья, закрытые сведения и психологические профили в результат не включаются.
Работа прикладная, в `docs/analysis/`, без нового `research/` и без изменения GRA.
