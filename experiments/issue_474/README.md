## Воспроизведение и проверка

До изменения Ш-1 предлагал сформировать раздел 2 до отдельного пакета
вопросов/допуска. На старой странице A-IN были 24 карточки предложения без
полных копируемых промптов: [до](../../site/screenshots/issue-474/before-processes.png).
Для детерминированного контрпримера взять допустимое состояние
`Execution.valid()` из `scripts/validate_issue_474_execution.py`, удалить
`gate21`: прежний oracle #468 возвращает пустой список нарушений, новый
возвращает `explicit_ba_gate_missing` и `gate_version_mismatch`. Это проверка
спецификации, не запуск старой/новой модели.

Команды проверки:

```bash
python3 scripts/build_bcreq_a_in.py --check
python3 scripts/validate_issue_474_execution.py
make validate-full
```

Focused validator содержит 7 tests, включая старые 16 gate cases, привязку
допуска к пяти полям версии, отдельный вызов 22, отказ подписи модели,
неоднозначного yes, pending/rework и паузу. Проверяет также раздельные оси
evidence/исполнимости, безопасные примеры переноса и полные 24 текста.
`make validate-full` автоматически обнаруживает новый validator; полный
локальный прогон: 103 валидатора, 0 ошибок. Логи в игнорируемом `logs/`.

Для UI: запустить `python3 -m http.server 8768 --directory site`, исполнить
[browser-smoke.js](browser-smoke.js) через Playwright MCP run-code. Результат:
`copies:24, byteEqual:true, previewEqual:true, mobileOverflow:false,
errorRetry:true, pageErrors:[]`. Проверены clipboard каждого контракта,
preview AIN-21, 390×844 и 1280×960, отказ fetch и успешный повтор. Снимки
[desktop](../../site/screenshots/issue-474/after-desktop.png) и
[mobile](../../site/screenshots/issue-474/after-mobile.png) сохранены в репозитории.
Прежний внешний виджет может давать сетевые console errors; pageerror отсутствует.
