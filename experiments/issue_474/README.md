# #474 — постановка, план и доказательства

Контекст: [issue #474](https://github.com/G-Ivan-A/mango_ba_prompts/issues/474),
[PR #475](https://github.com/G-Ivan-A/mango_ba_prompts/pull/475), принятый
[RFC-AIN-001](../../docs/rfc/2026-11-a-in-decomposition.md), аудит #471,
решения #472 / ADR-018 (PR #473 уже в main). Required sub-issues отсутствуют;
комментарии issue и все три вида отзывов PR #475 при старте пусты.

Проблема: старый Ш-1 объединяет независимые операции и пишет раздел 2 до
вопросов; one-shot и переход new → ФТ позволяют обойти новый допуск.
Story как есть: БА вручную останавливает генерацию. Как должно быть: копирует
один полный контракт AIN, принимает версию результата; до отдельного AIN-21
раздел 2 недоступен, Заказчик получает список бизнес-вопросов через БА.

Operating Mode: Creative. SSOT списка шагов — route JSON; текста поведения —
принятый RFC и исполняемые draft промпты. Сайт — производное представление.
Адаптация существующих входов и генераторов нужна для устранения обходов;
история измерений сохраняется и не переносится на новые тексты.
