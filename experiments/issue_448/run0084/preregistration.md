## Процедура

- N = 3 независимых повтора: r1, r2, r3.
- Исполнители: в каждом повторе свежие изолированные подагенты `claude-opus-5-5`,
  3 плеча × 2 пакета = 6. Инструкция исполнителя — та же, что в RUN-0082.
- Судьи: в каждом повторе свежие изолированные слепые подагенты, по одному
  на пакет, 2 пакета. Судья видит три выхода на кейс под метками X/Y/Z.
  Порядок меток случайный, seed 8484, 8485 и 8486. Ключ судье не передаётся.
  Инструкция судьи — RUN-0082, расширенная на три выхода. Рубрика и правила
  реестра для K5 не меняются.
- Кейсы: 62 кейса RUN-0079, та же раскладка T-NN (seed 79, 2 пакета).
- Порядок запуска: исполнители повтора идут параллельно. Судьи повтора
  стартуют, только когда записаны все шесть выходов исполнителей повтора.

## Правило решения

1. Для каждого плеча считается медиана трёх повторов отдельно по трём
   показателям: сданные кейсы, ядро, ложные дефекты.
2. Р-03: плечо «не хуже контроля», если его медиана сданных ≥ медианы A0,
   медиана ядра ≥ медианы A0 и медиана ложных дефектов ≤ медианы A0.
3. Публикация в `prompts/` (одна, по лестнице):
   - если A2 не хуже A0 — публикуется A2: тип гейта и правило, версия 0.2;
   - иначе, если A1 не хуже A0 — публикуется A1: только тип гейта;
   - иначе в `prompts/` ничего не меняется.
4. Сравнение A2 с A1 и частота провала GS-BCREQ-12 по плечам — вторичные
   показатели. Они объясняют результат и в решение п. 3 не входят.
5. Медианы RUN-0079, RUN-0081 и RUN-0082 — справочные, в решение не входят.

## Ограничения, известные до прогона

1. Исполнитель и судья — одна модель (`claude-opus-5-5`), хотя и в изолированных
   подагентах. Калибровки судьи по человеку нет: владелец принял этот риск
   (issue #448, ответ 1).
2. Входы синтетические. Прогон меряет удержание правила на фрагменте, а не на
   полном документе BCREQ.
3. N = 3 — минимум для медианы. Доверительные интервалы не оцениваются.
