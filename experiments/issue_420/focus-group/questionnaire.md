# Анкета фокус-группы (issue #420)

Ответьте **только по тексту страницы**. Если ответа на странице нет или он
неоднозначен, так и отметьте — не достраивайте из общих знаний.

Для каждого вопроса укажите:

- `answer` — ответ своими словами (до 40 слов);
- `certainty` — `однозначно` (ответ прямо есть на странице, сомнений нет),
  `с сомнением` (ответ угадывается, но формулировки допускают другое чтение) или
  `не нашёл`;
- `where` — где на странице нашли (заголовок/блок).

| ID | Вопрос |
| --- | --- |
| Q1 | Из скольких разделов состоит документ BCREQ? Перечислите их номера и названия. |
| Q2 | Из каких подразделов (с номерами) состоит раздел 2? |
| Q3 | Какие разделы документа Заказчик согласует на «Согласовании 1» (гейт Г-С1)? |
| Q4 | Кто принимает решение на последнем гейте перед релизом (Г-W)? |
| Q5 | На каких основаниях (справочниках) строится глоссарий и какое основание приоритетное после слов Заказчика? |
| Q6 | Что означает правило «5±2» и к чему именно оно применяется? |
| Q7 | Чем в критериях приёмки «необходимо» отличается от «достаточно»? |
| Q8 | Какой раздел является внутренним и Заказчику не отправляется? |
| Q9 | Зачем в документе раздел 6? Ответьте одной фразой. |
| Q10 | Что делают, если термин Заказчика расходится с отраслевым словарём? |

Затем оцените страницу в целом:

- `satisfaction` — от 1 до 5: «Страница даёт мне, в моей роли, понятное и
  достаточное представление о документе; я готов(а) опираться на неё»
  (1 — нет, 3 — частично, 5 — полностью);
- `exec_ready` — `да` / `только стилистика` / `нет`: готова ли страница для
  показа руководителям;
- `top_issues` — до трёх главных претензий (каждая до 25 слов), самая важная
  первой;
- `keep` — что обязательно сохранить (до 25 слов).

Формат ответа — JSON:

```json
{
  "persona": "P1",
  "stimulus": "X",
  "answers": {"Q1": {"answer": "…", "certainty": "однозначно", "where": "…"}, "…": {}},
  "satisfaction": 4,
  "exec_ready": "только стилистика",
  "top_issues": ["…"],
  "keep": "…"
}
```
