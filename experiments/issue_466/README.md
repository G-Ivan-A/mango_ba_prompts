## Проверка

Соответствие Т-01…Т-10 и SSOT — в [RFC-TTZ-001](../../docs/rfc/2026-11-ttz-feasibility-flow.md).
PDF не используются в тестах и не оценивались заново. После изучения формы и
явных комментариев БА удалены все скачанные PDF, извлечения и рендеры из
временного каталога, также удалено временное окружение PyMuPDF. В git остался
только [manifest](pdf-manifest.json): имя задачи, SHA-256, число страниц и
отсутствие встроенных аннотаций; комментарии БА находятся в печатных таблицах.

### Воспроизведение

```bash
node scripts/generate-pages-data.mjs
python3 experiments/issue_423/port_site_v2.py --check
python3 scripts/validate_issue_466_ttz.py
make validate-full
```

Для UI запустить `python3 -m http.server 8766 --directory site`; через
Playwright MCP выполнить `browser_run_code_unsafe` с абсолютным путём к
[browser_check.js](browser_check.js), из корня репозитория. Затем закрыть
браузер и остановить сервер. Npm, полная сборка и продуктовые документы не нужны.
